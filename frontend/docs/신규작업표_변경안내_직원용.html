새 작업표, 이렇게 바뀝니다

새로 만드는 작업은 필요한 칸을 스스로 갖추고, 리뷰 상태와 리뷰 방식이 서로 섞이지 않게 표시됩니다. 아래 그림만 보면 직원이 어디를 보고 무엇을 입력하면 되는지 알 수 있습니다.

● 신규 작업에만 적용기존 작업표는 그대로직원이 열을 직접 만들 필요 없음

02 · 필요한 칸만 자동 표시

04 · 가장 중요한 변화

05 · 직원이 할 일

직원은 지금처럼 작업을 만들고, 표에서 확인하면 됩니다

새 칸을 수동으로 만들거나 리뷰 상태를 억지로 맞출 필요가 없습니다.

직원이 하는 일

  • 작업 만들 때 상품·옵션·리뷰 방식·배송 방식을 정확히 선택
  • 작업보드에서 리뷰와 입금일 칸을 확인
  • 특이사항은 비고에 기록

직원이 하지 않아도 되는 일

  • 옵션이 두 개인 작업에 칸을 따로 추가
  • 택배대행이 아닌 작업에 송장번호 칸 추가
  • 리뷰옵션의 “포토”를 보고 완료 처리
  • 리뷰 제출 전 입금완료로 처리
📌

새 작업은 더 단순하게, 상태는 더 정확하게

표에 보이는 칸의 이름대로만 확인하면 됩니다. 기존 작업표는 건드리지 않습니다.

직원 안내용 화면 그림입니다. 실제 적용 전·후의 작업명·참여자 정보는 예시이며, 개인정보를 포함하지 않습니다.
