브랜드 추가 — 브라우저 팝업 → 인라인 입력 전환 시안

현재 + 브랜드 추가를 누르면 브라우저 기본 팝업(prompt)이 뜹니다. 이 팝업은 주소(review-web-system.pages.dev)가 그대로 노출되고 디자인을 입힐 수 없어 시스템 화면과 이질적입니다. 화면 안에서 바로 입력하도록 바꾸는 두 가지 시안입니다.

지금 문제 (스크린샷 상황)
  • 브라우저 팝업이라 색상 선택·중복 검사·안내 문구를 넣을 수 없습니다 — 이름만 받고 끝.
  • 팝업이 뜨는 동안 뒤 화면이 잠겨 기존 브랜드 목록을 보면서 이름을 정할 수 없습니다.
  • 브라우저·기기마다 생김새가 달라 안내 문구가 잘리거나 "차단" 되기도 합니다.
두 시안의 공통 규칙
  • Enter = 추가, ESC = 취소. 이름이 비면 추가 버튼이 눌리지 않습니다.
  • 추가 직후 입력칸이 다시 비워져 연속으로 여러 브랜드를 만들 수 있습니다.
  • 이름 중복·서버 오류는 입력칸 바로 아래에 빨간 줄로 표시(팝업 경고창 없음).
  • 색상은 브랜드를 목록·작업 배정 화면에서 구분하는 점 색입니다. 안 고르면 기본 파랑.

A안상단 인라인 바 — 버튼 자리에서 펼쳐지는 한 줄 입력 권장

+ 브랜드 추가를 누르면 목록 맨 위에 입력 한 줄이 펼쳐집니다. 이름·색상·추가 버튼이 한 줄에 있어 시선 이동이 짧고, 기존 브랜드 목록이 아래에 그대로 보여 이름이 겹치는지 보면서 지을 수 있습니다.

① 버튼 클릭
"+ 브랜드 추가" → 목록 맨 위에 입력 줄이 펼쳐지고 커서가 자동으로 들어감
② 이름 입력
색상은 원하면 클릭(기본 파랑). Enter 또는 [추가] 클릭
③ 즉시 목록에 추가
새 카드가 목록 맨 위에 생기고 입력칸은 비워져 다음 브랜드를 바로 입력
A안 1단계 — 클릭 전(현재 상태: 브랜드 없음) 브랜드 관리

B안카드형 인라인 — 목록 끝의 "＋ 새 브랜드" 카드가 그 자리에서 펼쳐짐

목록 마지막에 항상 점선 카드 "＋ 새 브랜드"가 있고, 클릭하면 그 카드가 입력 폼으로 변신합니다. 이름·색상을 세로로 배치하고 브랜드사 화면에 어떻게 보일지 미리보기를 함께 보여줍니다.

① 카드 클릭
목록 맨 아래 점선 카드 "＋ 새 브랜드" 클릭
② 폼으로 변신
같은 자리에서 이름·색상 입력 + 결과 미리보기 표시
③ 만들기
[브랜드 만들기] → 카드로 확정되고, 아래에 다시 빈 "＋ 새 브랜드" 카드가 생김
