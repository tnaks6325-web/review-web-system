3. 지금 카드와 무엇이 다른가

항목지금시안
조치 버튼모든 카드 동일 5~6개(상세·정상·불량·이동 2종) — 중복 카드에도 이동 버튼유형이 주 버튼을 정한다(주 1 + 보조 2 + ⋯) — 클릭 오류·시선 낭비 감소
유형 표시근거 문장 속에 섞임카드 최상단 색 띠(필터 칩과 같은 6색) — 훑어보기로 분류 가능
상세 진입[상세] 버튼 + 썸네일카드 본문 전체 클릭(버튼 제거)
시각 규율버튼별 임의 인라인 색차용 원칙 적용 — 틴트 잉크·hairline·액센트 1색·유형색은 의미만
확인 필요 결정 — ① [🗑 중복파일 제거] 실행 규칙은 #562 시안 기본값(나중 제출본 제거·휴지통 30일·불량 종결) 그대로 진행 ② "리뷰화면 아님(불명)" 주 조치 = ✕ 불량(반려 전송) ③ [⋯] 메뉴 도입(vs 모든 버튼 상시 노출). 이대로 진행해도 되면 "진행해줘" — 카드 렌더러 교체 + dedup-manual 구현까지 한 PR로 갑니다.
