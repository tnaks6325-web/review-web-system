업체뷰어 — 구매캡쳐·리뷰캡쳐 폴더 바로가기 배치 시안 (3안)

각 작업(탭)마다 드라이브의 [구매캡처] 폴더(tab_configs.capture_folder_url)와 [리뷰] 폴더(tab_configs.folder_url) 바로가기를 업체뷰어에 노출하는 3가지 배치안입니다. 공통 전제(모든 안 동일):

  • 전체 작업 목록 표에 폴더 바로가기 전용 헤더(컬럼)를 신설한다 — 대시보드 "최근 작업" 표는 같은 렌더러를 쓰므로 자동 반영.
  • 진행중 상세(작업 열람 화면) 안에도 같은 바로가기가 있어야 한다.
  • 폴더 URL 미연결 탭은 회색 비활성 표시(— 미연결)로 자리를 유지해 컬럼 정렬이 흔들리지 않게 한다.
  • 클릭 시 새 탭으로 드라이브 폴더 열기. 행 클릭(열람)과 이벤트 분리(stopPropagation).
  • 분홍 테두리 + NEW 표시가 이번에 추가되는 요소입니다.
