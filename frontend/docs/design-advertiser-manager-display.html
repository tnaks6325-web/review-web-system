담당자 표기 시안 — 업체용 뷰어 · 내부 관리 뷰어

작업오더 담당자 칸(manager_name · work_manager · created_by)을 어디까지 정리할지 정하는 시안입니다. 아래 위젯으로 안을 바꿔 보세요.

A — 페이로드만 정리 B — A + 라벨 정정 C — B + 칸 정합 D — 담당 2인 표기(업체+내부) 전체 보기

지금 상태 — 업체용 뷰어 화면에는 담당자가 한 글자도 안 나옵니다. 다만 서버 응답(res.detail)이 역할 구분 없이 나가서, 개발자도구를 열면 박세희·박은비 실명과 리뷰 가이드·특이사항·유입가이드 원문이 그대로 보입니다. 리뷰어 화면에서는 같은 이름을 닉네임(만두·망고)으로 가리는 규율이 있는데 업체 쪽만 어긋나 있습니다.

A안 — 페이로드만 정리

업체 화면 변화 없음

서버 응답에 광고주 렌즈(화이트리스트)를 씌워 담당자 실명·가이드 원문을 내려보내지 않습니다. 화면은 지금과 한 픽셀도 다르지 않습니다.

업체 화면

변화 없음 — 담당자는 원래 안 보였습니다.

서버 응답

실명·가이드 원문 제거

내부 화면

변화 없음 (라벨 오류는 그대로)

// 업체용 응답 res.detail
- managerName: "박세희"        // 리뷰웹 관리자 실명
- workManager: "박세희"
- reviewGuide: "리뷰 작성 시 …"  // 가이드 전문
- specialNotes: "…"
- inflowGuide: "<p>검색어 …"
+ (담당자·가이드 필드 없음 — 화이트리스트 통과분만)

B안 — A + 라벨 정정

업체 화면 변화 없음

A에 더해, 내부 화면에서 manager_name 을 "담당AE" → "작업담당" 으로 고쳐 부릅니다. 표시 문자열만 바꾸는 것이라 데이터는 무접촉입니다. 업체 화면에는 그 칸이 애초에 안 나오므로 변화가 없습니다.

업체 화면

변화 없음

서버 응답

A와 동일 (실명·가이드 제거)

내부 화면

작업오더 상세·수정 모달 라벨 정정

// 내부 화면 — 작업오더 상세 / 관리자 수정 모달
- 담당AE : 박세희

C안 — B + 칸 정합

업체 화면 변화 없음

B에 더해 manager_name ↔ work_manager 중복을 정리합니다. 지금 53건은 work_manager 만 비어 있어 탭 담당자 닉네임(만두·망고) 매핑이 그 건들에서 안 채워졌을 수 있습니다. 접수·닉네임 매핑에 영향이 가는 범위입니다.

업체 화면

변화 없음

서버 응답

A와 동일

내부 화면

라벨 정정 + 탭 담당자(만두·망고) 표기 복구

주의 — 이 안만 데이터를 건드립니다(빈 work_manager 53건 백필). 접수 업서트·닉네임 매핑을 함께 조사한 뒤 진행하는 것이 맞습니다.

D안 — 담당 2인 표기 (업체 + 내부 양쪽)

두 화면 모두 달라진다

작업 조건 카드에 담당 행을 넣고 두 담당자를 함께 적습니다 — 담당   AE팀 황운하 / 관리자 만두. 앞은 그 업체를 맡은 AE(created_by), 뒤는 이 작업의 모집·공고를 맡은 리뷰웹 관리자(manager_name)입니다. 업체용 뷰어와 내부 관리 뷰어에 같은 행이 들어갑니다.

업체용 뷰어

내부 관리 뷰어 (같은 자리 · 같은 문장 — 내부는 나머지 4행과 발주 줄이 더 있다)

업체 화면

작업 조건에 「담당」 행 1줄 추가

내부 화면

같은 「담당」 행 + 라벨 정정(B 포함)

서버 응답

렌즈에 담당 2인만 허용 — 가이드 원문·나머지 실명은 계속 폐기

관리자는 닉네임으로 적습니다 — 박세희 → 만두, 박은비 → 망고(admin_nicknames). 이 매핑은 리뷰어 1:1문의에서 이미 쓰는 단일 출처라, 여기에 붙이면 업체 화면에 실명이 나가지 않으면서 내부에서는 누구인지 그대로 통합니다. 닉네임이 없는 계정은 관리자 한 단어로만 적습니다(fail-closed).
정할 것 두 가지 — ① AE 이름을 그대로 보일지(황운하) 부서만 보일지(AE팀). 시안은 부서 + 이름으로 그렸습니다. ② 값이 없을 때. AE 는 created_by 라 거의 항상 있지만, 관리자는 빈값이 30건입니다 — 그때는 담당   AE팀 황운하 한쪽만 적습니다(「—」로 꾸미지 않음).
