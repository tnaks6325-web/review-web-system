M4 시안 — 리뷰어 화면: 내가 고른 옵션으로 상품 페이지 열기

옵션이 여러 개인 링크유입 작업에서 리뷰어가 고른 옵션의 상품 주소로 보내는 단계입니다. 서버는 이미 고른 옵션 URL → (없으면) 공고 랜딩 URL 순으로 주소를 정해서 내려주고 있고(M2 완료), 이번에 정하는 것은 그 사실을 리뷰어에게 어떻게 보여줄지입니다. 확정사항 D6 = “버튼 위에 옵션명 한 줄”.

아래 목업은 실제 리뷰어 화면(참여 후 작업내용 카드)을 그대로 재현한 것입니다 — 같은 카드 모양·같은 버튼을 씁니다. 버튼을 눌러 보면 어느 주소로 가는지 알려줍니다(실제 이동은 안 함).
주소창에 ?v=A / ?v=B / ?v=C 를 붙이면 그 안만 볼 수 있어요.

A안 — 버튼 위에 파란 한 줄 추천

버튼 바로 위에 “내가 고른 옵션: 화이트 — 이 옵션의 상품 페이지로 갑니다” 한 줄을 둡니다. 버튼 글자는 지금과 똑같이 두어, 이미 익숙한 버튼 모양이 바뀌지 않습니다.

B안 — 버튼 글자에 옵션명 넣기 대안

줄을 늘리지 않고 버튼 자체를 “🔗 화이트 상품 페이지 열기” 로 바꿉니다. 화면이 가장 짧아지지만, 옵션명이 길면 버튼 글자가 줄바꿈되거나 잘립니다.

C안 — 옵션 칩 + 주소 출처 배지 대안

옵션명을 칩으로 보이고, 옆에 “옵션 전용 주소” / “공통 주소” 배지를 붙여 지금 열리는 주소가 옵션 전용인지까지 말해 줍니다. 정보가 가장 많지만 그만큼 시끄럽습니다.

결정해 주실 것

항목을 클릭해 고르면 아래에 요약이 만들어집니다. 그대로 복사해서 답장해 주세요.

① 어떤 안으로 할까요?

세 안 모두 여는 주소는 똑같습니다 — 다른 것은 “어느 옵션으로 가는지”를 보여주는 방식뿐입니다.

② 그 옵션에 주소가 안 적혀 있으면?

관리자가 옵션 링크를 비워 두면 공고 상품 URL(공통 주소) 로 갑니다. 이때도 옵션명 한 줄을 보여줄지 정합니다.
※ 기존 공고는 전부 여기에 해당합니다(옵션 링크를 백필하지 않기로 확정).

③ 옵션이 아예 없는 작업은?

단일 상품 공고입니다. 지금은 버튼만 있고 아무 설명이 없습니다.

④ 관리자 미리보기에도 똑같이?

관리자 [👁 리뷰어 화면]은 실제 화면과 같은 코드로 그려집니다(그래서 “미리보기 ≠ 실제”가 구조적으로 불가능). 미리보기에서는 대표 옵션 하나를 예시로 씁니다.

선택 요약

아직 고른 항목이 없습니다.
    이번 단계에서 바뀌지 않는 것
    · 여는 주소를 정하는 규칙은 이미 만들어져 있고 바뀌지 않습니다(고른 옵션 주소 → 없으면 공고 주소). 이번에는 보여주는 방식만 정합니다.
    · 유입가이드 작업에는 버튼이 없습니다 — 리뷰어가 상품 페이지로 바로 들어가면 검색어·경유 경로 안내가 무의미해지기 때문입니다(기존 규칙 유지).
    · 옵션을 바꾸면 화면이 다시 불러와져 버튼 주소도 함께 바뀝니다(기존 동작).
    · 기존 공고는 옵션 링크가 비어 있어 지금과 똑같이 공고 상품 주소로 갑니다.
