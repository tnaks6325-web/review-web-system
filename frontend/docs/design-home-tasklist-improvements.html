B 헤더행 고정 + 목록 높이 640px — CSS 수정만

  • table.wbl-t{overflow:visible} — 전역 table{overflow:hidden} 상쇄(시트그리드 관용구 그대로. 전역 규칙 자체는 다른 화면이 의존하므로 무수정).
  • border-collapse:separate + border-spacing:0 + th box-shadow:0 1px 0 var(--line) — collapse 모드에서 헤더 경계선이 본문과 함께 밀리는 특성 회피.
  • th z-index를 행 버튼보다 위로(스크롤 시 버튼이 헤더를 뚫고 그려지는 것 방지).
  • .wbl-tw{max-height:420px → 640px}(사용자 확정 Q3).

C 필터 = 사각형 3분할 토글 스위치 (왼쪽/중앙/오른쪽)

위치필터판정(진행 중 목록 대상)표시
왼쪽📅 금일 진행오늘 완료(☑) 미체크 ∧ 연결 공고가 "모집중" 상태(서버 공고 주석 state==='open' — 카드·리뷰어 목록과 같은 상태엔진 값 그대로, 화면 재계산 금지) Q1 확정서버 순서 유지
중앙💰 입금 체크제출(submitted) > 입금(paid) — 제출됐는데 입금 안 된 건이 있는 작업미입금 건수 큰 순 정렬 + 입금 칸에 (미입금 N) 빨간 병기
오른쪽🏁 마감 체크isFinishCandidate(인원 충족+전건 제출+전건 입금) — 기존 함수 그대로(사본 금지). 기존 "✓ 마감 후보 N건" 표시 배지는 이 스위치가 흡수(제거)서버 순서 유지
  • 썸(파란 채움)이 왼쪽/중앙/오른쪽으로 슬라이드하는 한 덩어리 사각 스위치. 각 칸에 라벨+건수. 같은 칸 재클릭 = 해제(전체 보기) — 해제 상태는 썸 없음.
  • 담당자 칩·검색과 AND 결합. 진행 중 탭에서만 노출(마감 보관함에서는 숨김). 상태는 STATE.finFilter 하나, 거르는 곳은 _finVisible() 한 곳(목록·건수가 같은 판정 공유 — 갈라짐 구조적 차단).
  • 조회 실패 시 무신호 금지: statsUnavailable이면 입금·마감 칸 비활성, campsUnavailable이면 금일 진행 칸 비활성 — 각각 사유 툴팁(빈 결과를 "해당 없음"으로 위장하지 않는다).
  • ⚠ Q1 확정의 귀결(화면에 안내): 공고를 발행하지 않은 작업은 "금일 진행"에 잡히지 않는다 — 필터 활성 중 목록 하단에 "공고 없는 작업 N건은 이 필터에 표시되지 않습니다" 한 줄 고지(조용한 누락 금지).

4. 건드리지 않는 것 (무접촉 보장)

  • 시트 쓰기 0 · 주문원장/큐/행배정 무접촉 · Track A 무접촉 — 전부 읽기(폴더 URL·통계·공고 상태)와 화면 표시뿐.
  • 전역 table{} 규칙 무수정(.wbl-t에서만 상쇄) · 마감/오늘 완료/공고 버튼의 기존 동작·판정·API 무변경 — 바뀌는 것은 버튼이 놓이는 칸뿐.
  • 신규 마이그레이션 0 · 신규 저장소 0(현영 폴더 URL은 저장하지 않고 캐시만 — 저장하면 리네임·재생성 시 stale 포인터가 남는다).
  • 공고 "모집중" 판정은 서버 상태엔진 값(computeCampaignState)을 그대로 소비 — 화면 재계산 사본 금지.
