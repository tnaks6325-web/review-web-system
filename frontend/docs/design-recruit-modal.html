시안 A

카드 스택 — 모든 묶음이 같은 카드, 참여형은 “카드 헤더의 스위치”

색 박스를 전부 없애고 동일한 흰 카드 + 회색 헤더바 하나로 통일합니다. 참여형·기간별 리뷰비처럼 켜고 끄는 묶음은 카드 헤더 우측 스위치로 표현하고, 색은 카드 왼쪽 3px 액센트 선으로만 남깁니다 — 켜져 있으면 본문이 펼쳐지고 꺼져 있으면 헤더만 남아 접힙니다. 타계정·현금영수증은 자기 색 박스를 버리고 같은 카드 안의 평범한 필드행이 됩니다.

세 시안 공통 — 무엇을 통일했나(이것이 “일관성”의 실체)
  • 라벨 한 종 — 우측정렬 82px 고정 1열. 지금의 64/76/세로 3종 혼재를 없앤다(1100px 이하에서만 위로 접힘).
  • 컨테이너 한 종 — 흰 카드 + 회색 헤더바. 색 박스(녹·보라·주황) 전부 폐기, 색은 좌측 3px 액센트와 글자색으로만.
  • 보조 문구 두 단 — 라벨 아래 .sub(.65rem) / 필드 아래 .hintline(.65rem). 6단 → 1크기 2위치.
  • 켜고 끄는 것은 스위치 한 종 — 참여형·기간별 리뷰비·타계정이 같은 토글 모양을 쓴다(지금은 체크박스 3종 + accent-color 3색).
  • 자동 산출 값은 숨기지 않고 회색 읽기전용 — 총모집·일건수(현재 hidden)를 드러내 “저장값과 다르게 뜬다”는 오해를 없앤다.
