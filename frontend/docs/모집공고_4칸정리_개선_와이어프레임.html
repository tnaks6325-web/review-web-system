개선 ①

유의사항 자동 채움 중단 — 공개 칸에는 아무것도 자동으로 넣지 않는다

이미 발행된 공고 소급 — 공고를 여는 순간 같은 정리가 뜬다

이미 발행된 공고의 본문은 발행 시점에 박제된 값이라 코드를 고쳐도 저절로 바뀌지 않습니다(장수돌침대 건). 자동으로 고쳐 쓰지도 않습니다 — 대신 두 군데서 사람에게 보입니다.

카드를 눌러 수정 모달이 열리면 같은 감지가 저장된 본문에 돌아 섞인 칸에 ⚠ + [🧹]가 뜸.
정리 → 미리보기 확인 → [적용] → 저장하면 그 공고의 리뷰어 화면이 즉시 깨끗해짐.
감지·정리 로직은 ③과 한 벌(사본 없음) — 발행·수정이 같은 규칙.
운영 공고가 많아 하나씩 열기 번거로우면 → (선택 후속) 공고 목록 상단 "🧹 정리 대상 N건" 필터. 이번 범위엔 카드 배지 + 수정 모달까지.
공통 안전 규칙 — 이 4가지가 지켜지는 조건에서만 구현합니다
  • 자동 삭제·자동 이동 없음 — ①·②는 "새로 채워 넣는 값"을 처음부터 깨끗하게 만드는 것(있던 것을 지우지 않음), ③·④의 정리는 항상 미리보기 → 사람 [적용]을 거친다.
  • 게시를 막지 않음 — 모든 감지는 경고 전용(오탐이 정상 발행을 막으면 그게 더 큰 사고).
  • 서버 변경 0 — 전부 발행 폼(프론트) 텍스트 처리. 저장 방식·API·DB 무변경.
  • 리뷰어 화면 렌더러 무접촉 — 화면에서 가리는 게 아니라 저장되는 값 자체를 깨끗하게(화면만 가리면 데이터는 계속 오염).
1차 — 개선 ① + ②

프리필 수정(코드 소규모) + 실측 원문 픽스처 회귀가드.
새 공고부터 즉시 효과. 문서 가드(자동반영 와이어프레임·woCampaignMapDoc)의 유의사항 항목 동반 갱신.

2차 — 개선 ③

발행 모달 자동 점검에 감지 4종 + 칸별 ⚠/[🧹] + 전/후 미리보기. 레일 목차 ⚠ 연동.

3차 — 개선 ④

수정 프리필 뒤 같은 감지 재사용(사본 금지) + 관리자 카드 🧹 배지(admin 분기).

이 와이어프레임대로 진행해도 되면 승인해 주세요 — 1차(①+②)부터 순서대로 구현합니다.
