내부 테스트 안내

대량구매(타계정 여러 건 한 번에) 테스트 공고 만들기

리뷰어에게는 보이지 않으면서, 참여·구매양식 제출까지 실제로 동작하는 공고를 만드는 방법입니다.

1만드는 방법 — 3단계

관리자 대시보드 모집공고 탭(또는 통합 작업대 모집공고 탭)에서 진행합니다.

  1. 헤더의 🧪 테스트 공고 버튼을 누릅니다

    공고 발행 창이 열리면서 테스트에 필요한 값이 미리 채워집니다(모집중 상태 · 리뷰어 숨김 · 타계정 허용 · 자율주문 · 자리 유효시간 30분).

  2. 연결할 시트 탭만 고릅니다

    구매양식이 기록될 작업 탭입니다. 실제 진행 중인 탭은 피하고 테스트용으로 써도 되는 탭을 고르세요. 제출하면 그 탭에 실제로 행이 기록됩니다.

  3. 저장을 누릅니다

    공고 카드에 🧪 리뷰어 숨김 배지가 붙으면 완료입니다. 리뷰어 앱 공고 목록에는 뜨지 않습니다.

💡 값은 언제든 바꿔도 됩니다. 미리 채워진 것은 테스트가 막히지 않는 값일 뿐입니다.

2테스트하는 방법

일괄 제출은 한 사람이 여러 명의로 동시에 참여 중일 때만 켜집니다.

  1. 공고 카드의 👁 리뷰어 화면이 아니라 실제 링크로 들어갑니다

    미리보기 화면은 제출이 막혀 있어 대량구매 테스트가 되지 않습니다. 공고 주소(campaign.html?id=…)를 그대로 열어주세요.

  2. 타계정을 2개 이상 등록한 계정으로 로그인합니다

    리뷰어 홈 → 내정보에서 타계정을 등록할 수 있습니다. 등록된 명의가 2개 이상이어야 명의 선택 화면이 나옵니다.

  3. 명의를 바꿔가며 2건 이상 참여합니다

    참여 후 화면의 ＋ 타계정으로 추가참여하기로 다른 명의를 더 잡습니다.

  4. 구매양식이 명의별 카드로 펼쳐지는지 확인합니다

    카드 위에 “구매 캡처를 한 번에 올리세요” 상자가 보이면 일괄 제출 모드입니다. 캡처를 여러 장 한꺼번에 올려 보세요.

  5. 확인 포인트

    ① 사진이 고른 순서대로 위 카드부터 들어가는지 ② 사진 속 이름이 그 카드 명의와 다를 때 경고가 뜨는지 ③ 새로고침해도 입력값·사진이 되살아나는지 ④ 제출 후 명의별 결과가 한 줄씩 나오는지.

⏱ 자리 유효시간 — 테스트 공고는 30분으로 넉넉히 잡혀 있지만, 그 안에 구매·제출을 마쳐야 합니다. 시간이 지난 카드는 ⛔ 시간 만료로 잠기고 제출에서 빠집니다.

3“리뷰어에게 숨김”이 정확히 무엇을 하나요

항목숨김 켰을 때
리뷰어 앱 공고 목록안 보입니다 (홈 미리보기 · 공고 목록 · 인기상품 안내 모달 모두)
관리자 공고 목록그대로 보입니다 + 🧪 리뷰어 숨김 배지
참여 · 구매양식 제출정상 동작합니다 (그래서 테스트가 됩니다)
공고 링크로 직접 접속들어와집니다 — 아래 주의 참고
⚠️ 목록에서만 숨깁니다. 공고 주소를 아는 사람은 들어올 수 있습니다(로그인 잠금이 아닙니다). 테스트 링크를 리뷰어에게 공유하지 마세요. 테스트가 끝나면 공고 상태를 마감으로 바꾸거나 삭제해 주세요.

4테스트가 끝난 뒤

테스트 공고는 정리하는 것까지가 한 세트입니다.

할 일이유
공고를 마감으로 바꾸거나 삭제링크를 아는 사람이 계속 참여할 수 있습니다.
연결한 탭의 테스트 행 정리제출한 건은 실제 주문으로 기록됩니다(시트·주문 원장).
남은 참여(자리) 정리참여만 하고 제출하지 않은 자리는 시간이 지나면 자동으로 풀립니다.
