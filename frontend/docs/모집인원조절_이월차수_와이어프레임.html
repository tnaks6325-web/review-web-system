📅 모집인원 조절 · 이월 · 차수 — 구현계획 와이어프레임

2026-08-07 · 리뷰웹시스템 모집공고 — 일반인용 유저플로우 시안 (아래 목업은 가짜 데이터로 실제로 움직입니다)
확정 ① 축소 시 "종료일 연장 / 남은 날 분산" 선택지 제공 확정 ② 차수 구분 표시 + 차수별 집계 확정 ③ 1단계는 일건수 캠페인만 (시트 일정 캠페인은 읽기 전용)

1왜 필요한가 — 지금 생기는 문제 2가지

지금 시스템은 "매일 같은 인원(일건수)을 모집한다"는 계획이 바꿀 수 없게 고정되어 있습니다. 실제로 모인 인원이 그 계획보다 적으면, 부족분을 다음날 자동으로 얹습니다(이월). 자연스럽게 미달된 경우엔 이게 맞는 동작이지만, 업체 요청으로 일부러 줄인 날까지 "미달"로 오해하는 게 문제입니다.

사례 1 — 업체: "오늘은 20명만 모집해주세요"

❌ 지금 — 시스템이 "20명 부족"으로 오해
오늘20명 모집
다음날60명!

일부러 줄인 20명분이 자동 이월되어 다음날 40+20=60명이 열림 → 업체 의도와 어긋남

✅ 개선 — "계획을 20명으로 바꾼 것"으로 인식
오늘20명 모집
다음날40명 그대로

빠진 20명은 관리자가 고른 방식(종료일 연장 / 남은 날 분산)으로 처리 — 총량 200은 그대로

사례 2 — 업체: "오늘은 10명 더 모집해주세요"

❌ 지금 — "오늘만 50명"을 알릴 방법이 없음

일건수를 40→50으로 고치면 매일 50명이 되어버림. 오늘 하루만 늘릴 수단이 없음.

✅ 개선 — 오늘만 50명, 내일은 40명 그대로
오늘50명
다음날40명 그대로 (30으로 줄이지 않음)

먼저 채운 만큼 마지막 날 인원이 자연히 줄어 총량 200에서 정확히 멈춤

사례 3 — 같은 캠페인에 물량 추가 (차수)

8/1 시작 200건 캠페인에 8/7 100건이 추가되면, 총량은 300이 되지만 "1차 200건 / 2차 100건"이 구분되어 각각 얼마나 진행됐는지 관리자 화면에서 보여야 합니다. 지금은 총모집 숫자 하나뿐이라 추가분이 섞여버립니다.

2절대 바뀌지 않는 원칙 (완화 금지)

① 총량은 무슨 일이 있어도 지켜진다.
하루 인원을 어떻게 조절해도 캠페인 전체 모집 수는 정해진 총량(차수 합계)을 넘을 수 없고, 총량에 도달할 때까지 모집이 계속됩니다. 총량을 늘리는 유일한 방법은 차수 추가뿐입니다.
  • ② 조절 = 계획 변경. 관리자가 어떤 날의 인원을 바꾸면 그날의 "계획 자체"가 바뀐 것입니다. 계획대로 채워졌다면 부족분이 없으므로 자동 이월도 없습니다.
  • ③ 자연 미달만 자동 이월. 조절하지 않았는데 실제 참여가 계획에 못 미친 경우에만, 지금처럼 부족분이 다음 진행일에 자동으로 얹힙니다. (버스트 상한도 지금 그대로)
  • ④ 늘린 날이 다음날을 줄이지 않는다. 오늘 +10명을 모집해도 내일은 기본 인원 그대로입니다. 대신 총량에 먼저 도달해 마지막 날이 자연히 줄어듭니다.
  • ⑤ 이미 확정된 인원 아래로는 못 줄인다. 오늘 25명이 이미 확정됐다면 오늘 인원을 25 미만으로 내릴 수 없습니다(참여 취소는 조절 기능의 일이 아님).
  • ⑥ 시트 일정 캠페인은 1단계 제외. 시트의 구매일자 컬럼으로 날짜별 정원이 자동 파생되는 캠페인은 시트가 진실원본이므로, 이 화면에서는 읽기 전용으로 보여주고 "조절은 시트에서(그날 행 수 변경)" 안내만 합니다.
  • ⑦ 조절 이력은 전부 남는다. 누가 언제 어느 날을 몇 명으로 바꿨고 빠진 인원을 어떻게 처리했는지 기록되어, "왜 오늘 20명이지?"에 화면이 답할 수 있습니다.

4유저플로우 — 시나리오별 단계

시나리오 A. 업체 요청으로 오늘 인원 축소 (40 → 20)

1
업체 연락"오늘은 20명만 모집해주세요"
2
공고 카드 → [📅 인원조절]오늘 줄의 게이지를 20까지 내림 (이미 확정 12명 아래로는 안 내려감)
3
선택 팝업: "빠진 20명을 어떻게 할까요?"㉮ 종료일 연장 — 이후 날들은 40명 그대로, 마지막에 하루가 늘어남 / ㉯ 남은 날 분산 — 종료일 유지, 남은 진행일에 고르게 +10씩
4
[확정 저장]카드에 "오늘 12/20명 (조절됨·기본 40)" 표시 · 리뷰어 화면은 오늘 정원 20으로 동작 · 이력 기록
5
다음날자동 이월 없음 — 계획대로 40명(분산 선택 시 50명)만 열림. 총량 200은 그대로.

시나리오 B. 업체 요청으로 오늘 인원 증가 (40 → 50)

1
업체 연락"오늘 10명 더 부탁드려요"
2
[📅 인원조절] → 오늘 게이지를 50으로 올림안내: "내일 이후는 그대로 40명입니다. 총량 200은 변하지 않아요." — 선택 팝업 없음(늘림은 고를 게 없음)
3
[확정 저장]먼저 채운 10명만큼 마지막 날 인원이 자연히 줄어 총량에서 정확히 멈춤 (예상 종료일이 당겨질 수 있음을 미리보기로 표시)

시나리오 C. 미래 날짜 미리 조절 (예: 다음주 월요일은 업체 휴무)

1
[📅 인원조절] → 미래 날짜 줄에서 조절오늘과 똑같은 게이지 조작 — 예: 8/11을 0명으로 (그날은 아예 열지 않음)
2
빠진 인원 처리 선택 → [확정 저장]그날이 되면 조절된 계획대로 동작 — 당일 아침에 손댈 필요 없음
3
언제든 다시 변경 가능그날이 오기 전까지는 몇 번이든 다시 조절할 수 있고, 이력이 전부 남습니다

시나리오 D. 물량 추가 = 차수 추가 (8/7에 +100건)

1
업체 연락"반응이 좋아서 100건 추가할게요"
2
[📅 인원조절] → [＋ 차수 추가]추가 건수(100)와 시작일(8/7) 입력 → 총량 200 → 300. 총모집 칸을 직접 고치는 게 아니라 차수로 추가해야 구분이 남습니다.
3
이후 화면카드·관제에 "1차 200/200 완료 · 2차 12/100" 구분 표시. 집계는 확정 순서대로 1차부터 차오름. 리뷰어 화면은 지금처럼 합산(212/300)만 보임.

6구현 계획 (단계별)

M1 — 기반: 날짜별 계획표 + 차수 원장 (백엔드)

  • 저장소 2개 신설: 날짜별 계획(캠페인 × 날짜 → 그날 인원, 값 없는 날 = 기본 일건수) · 차수 원장(차수 번호·건수·시작일·등록자, 초도분은 1차로 자동 기록). 조절·차수 변경은 전부 이력으로 남김.
  • 정원 계산 변경: "기본 일건수 × 경과일수" 대신 "날짜별 계획의 누적 합 − 누적 확정"으로 이월을 계산 → 원칙 ②③④가 구조적으로 성립(조절한 날은 계획 자체가 바뀌므로 미달이 아니게 됨).
  • 총량 = 차수 합계. 기존 총모집 값은 1차로 흡수 — 계획·차수를 하나도 안 만진 캠페인은 지금과 100% 동일하게 동작(옵트인).
  • 목록·상세·참여 게이트가 전부 같은 계획을 보도록 기존 집계 경로에 실어 보냄(화면마다 다른 정원을 보면 "카드는 열렸는데 참여는 거부"가 됨).

M2 — 조절 팝업 UI

  • 공고 카드 [📅 인원조절] → 위 3-2 팝업: 게이지 드래그 + −/＋ 버튼, 축소 시 연장/분산 선택, 예상 종료일 미리보기, [확정 저장]에서만 반영.
  • 카드에 "조절됨" 배지·차수 게이지, 관제 패널에 날짜별 계획 대비 실적 표시.

M3 — 차수 관리 UI

  • [＋ 차수 추가] 폼(건수·시작일·메모), 카드·관제 차수별 집계(1차 200/200 · 2차 12/100), 차수 이력 표시.

7한계 · 주의 (같이 알아둘 것)

  • 이미 참여한 인원은 건드리지 않습니다. 축소는 "앞으로 열 자리"만 줄입니다. 확정 취소가 필요하면 기존 주문취소 경로를 사용합니다.
  • 분산 선택 시 하루 인원이 늘어난 날은 시트 기입·검수 인력이 그만큼 필요합니다 — 미리보기에서 날짜별 인원을 보여주고 확정하게 하는 이유입니다.
  • 진행 중인 홀드(자리 잡은 리뷰어)는 축소로 밀려나지 않습니다. 축소 하한은 "확정 + 유효 홀드" 기준으로 잡습니다.
  • 시트 일정 캠페인(확정 ③)은 이번 단계에서 화면 조절이 불가하며, 후속 단계에서 "화면 조절이 시트보다 우선" 옵션을 별도 검토합니다.
  • 차수 추가는 총량을 늘리는 정식 창구가 되므로, 공고 수정 모달의 총모집 칸은 차수가 있는 캠페인에서 읽기 전용(차수 합계 표시)으로 바뀝니다 — 두 창구가 남으면 값이 어긋납니다.
