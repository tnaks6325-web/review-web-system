중복파일 제거같은 파일(duplicate fail) 유형 카드·상세에 [🗑 중복파일 제거] — 지금 제출본(나중 파일)을 휴지통으로 보내고 이전 제출본은 보존. 팝업에서 두 장을 나란히 보여 무엇이 지워지고 무엇이 남는지 명시. 실행부는 자동분류 중복 처리(sweep dup)와 같은 경로 재사용 — 휴지통(30일 복구창)·원장 slot_key='trashed'. 검수 건은 [불량 맞음(중복)]으로 종결(resolution 'bad' — 중복 제출은 오탐이 아니다).

2. 전용 팝업 — 실물 (버튼으로 열어보세요)

시스템 confirm()(브라우저 좌상단·주소 노출·줄바꿈 빈약)을 아래 전용 팝업으로 교체합니다. 두 변형 모두 실물로 떠 있습니다:

  • 대상 줄이 항상 맨 위 — 리뷰어 이름·행·탭이 굵게. 잘못 누른 카드를 여기서 알아챈다(복귀 confirm 에 작업 이름을 넣는 기존 규율과 같은 이유).
  • "무슨 일이 일어나는지"를 목록으로 — 한 문단 줄글 대신 동작 1줄씩(이동·종결·학습).
  • 되돌리기 안내를 색 박스로 분리 — 초록(되돌릴 수 있음) / 노랑(복구 조건 있음).
  • Esc·바깥 클릭 = 취소. 실행 버튼은 오른쪽 끝(파랑/빨강), 위험 동작은 아이콘·헤더까지 빨강.
