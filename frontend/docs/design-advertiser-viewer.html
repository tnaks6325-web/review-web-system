시안 — 업체용(광고주) 뷰어 화면 정돈

리뷰웹시스템[3버전]의 업체(광고주) 전용 열람 화면을 정돈하는 시안입니다. 넓은 모니터(QHD·울트라와이드)에서 상단 버튼·작업 탭·요약 카드가 화면 끝까지 무한히 벌어지던 것을 폭 상한으로 고정하고, 작업 선택 방식은 업체관리 화면 구성(왼쪽 목록 → 오른쪽 상세)을 그대로 차용합니다. 업체가 자신의 진행 업무(시작일·작업명·견적서·세금계산서·총비용·입금액·입금일·남은 입금액·진행상황)를 한눈에 확인할 수 있게 합니다.

0무엇이 문제였고, 어떻게 바꾸나

Before — 현재 화면

① 최상단 행의 FHD/QHD·사이드바 표시·전체화면·접속정보·로그아웃이 화면 오른쪽 끝까지 밀려나 본문과 동떨어져 보임.

② 작업 선택이 가로 탭 줄이라 화면 폭만큼 무한히 벌어지고, 작업이 많으면 좌우 스크롤로 찾아야 함.

③ 상품/모집/구매시간/배송/참여자/제출완료/입금완료/정산 요약 카드가 제한 없이 늘어나 카드 사이 여백만 벌어짐.

④ 정산 칸이 "미연결 · 계약 연결 필요"처럼 내부 용어로 노출되고, 업체가 궁금한 견적서·계산서·입금액·남은 금액이 없음.

After — 이 시안

① 업체용 화면은 앱 전체 폭 상한 1680px 고정(FHD/QHD 토글은 업체에게 불필요 → 미노출). 상단 버튼은 상한 안쪽 오른쪽 끝에 붙음.

② 가로 탭 줄 제거 → 왼쪽 세로 작업 목록(업체관리 사이드바 차용). 세로 목록이라 화면 폭과 무관.

③ 헤더·요약 카드·정산 카드는 본문 데이터 폭과 같은 값(920~1380px)으로 캡 — 남는 폭은 오른쪽 여백.

④ 접속 직후 기본 화면 = 내 작업 목록 표(업체관리 연결탭 표 차용) — 시작일·작업명·진행상황·정산 컬럼을 한 줄에.

1화면 A — 접속 직후 · 내 작업 목록 (업체관리 표 차용)

업체가 전용 링크/계정으로 접속하면 진행 중인 모든 작업이 표로 먼저 보입니다. 업체관리의 "연결된 탭" 표와 같은 구성이며, 업체 렌즈에서는 정산 컬럼(견적서·계산서·총비용·입금액·입금일·남은 입금액)이 핵심입니다. 행을 클릭하면 화면 B(작업 상세)로 들어갑니다.
