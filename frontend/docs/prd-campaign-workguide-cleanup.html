01 · PROBLEM

무엇이 잘못 보이고 있나 (5건 + v1.1 추가 1건)

전부 표시 계층의 문제다. 주문 접수·홀드·시트 기록 등 데이터 동작은 정상.

1
상품 · 옵션 · 결제금액 — 결제금액 2회 표기 + 줄바꿈 없음 현재: "…워셔블 전기매트 결제금액 78,000원 · 결제금액 78,000원" (한 줄에 이어짐)
목표: 상품명 ↵ 결제금액 78,000원 (금액은 1회만)
2
유입가이드 — 첨부 이미지가 리뷰가이드 블록에 "링크 문자열"로 노출 현재: [유입가이드 첨부 이미지] 파일명 + URL 텍스트가 리뷰 가이드 카드에 표시
목표: 유입가이드 블록 안에서 실제 이미지로 바로 표시
3
상품 페이지 열기(새 탭) 버튼 — 유입방식과 무관하게 항상 노출 현재: 유입가이드(guide)형 캠페인에도 버튼 노출 → 직링크 진입으로 유입방식 위반 유도
목표: 링크유입(link)일 때만 노출
4
리뷰 가이드 — 유입 관련 섹션까지 통째로 노출 현재: [유입방식]·[유입가이드]·[유입가이드 첨부 이미지]·[리뷰등록 가이드]가 전부 표시
목표: [리뷰등록 가이드] 내용만 — "전체 별점 5건 / 배송이 빠르다 / 겨울맞이 미리 준비했다 등 / 1~2줄 자연스러운 리뷰 작성 희망"
5
카톡 팀채팅방 — 제출 전부터 입장 버튼 제공 현재: 참여 직후(제출 전) 화면에 회색 "카톡 팀채팅방 입장" 카드 상시 노출
목표: 구매양식 제출 완료 후에만 제공 + 카카오 옐로(#FEE500) 버튼 + 라벨 "이 캠페인의 카톡 팀채팅방 입장"
6
[v1.1 추가] 리뷰 내역 카드 — 클릭이 리뷰제출로 직행해 상품정보·카톡 재입장 경로가 없음 현재: 내정보/현황 "리뷰 내역" 제출대기 카드 클릭 → 즉시 /search 이동 + 리뷰제출 모달 자동 오픈
목표: 클릭 → 참여상품 정보 시트(상품 URL 포함) → [이 캠페인의 카톡 팀채팅방 입장](카카오 옐로) + [리뷰제출하기] 2버튼 제공
02 · ROOT CAUSE

원인 — 작업오더 원문이 "정제 없이" 스냅샷·화면까지 흘러온다

인트라넷 작업오더의 review_guide는 실데이터상 [유입방식]·[유입가이드]·[유입가이드 첨부 이미지]·[리뷰등록 가이드]가 합쳐진 통짜 텍스트다. 관리자 화면은 이미 섹션 추출로 정제해 보여주는데(_woDetailHtml → _woPickSections), 발행 프리필과 리뷰어 화면 렌더에는 그 정제가 빠져 있다.

인트라넷 작업오더
review_guide = 섹션 합본 원문→ 발행 프리필
wd_review = 원문 그대로 (index-app.js:2200)→ 공고 work_detail 스냅샷 저장→ campaign.html 렌더
textContent 그대로 (campaign.html:321)

06 · EDGE CASES & RISK

엣지케이스 · 안전장치

✓
깨끗한 원문은 무변화 — 섹션 라벨이 없는 평문 리뷰가이드는 전문 그대로, 금액 중복 없는 상품줄도 그대로. 정규화는 "문제 패턴이 확실할 때만" 개입한다.
✓
상이 금액 다옵션 라인 보호 — 한 줄에 서로 다른 결제금액이 2개면(옵션별 병기) 병합하지 않고 원문 유지. 잘못 합쳐 정보를 잃는 것보다 낫다(fail-safe).
✓
이미지 인젝션 차단 — 리뷰가이드 텍스트에서 추출한 URL은 guide-image 프록시·Google Drive 패턴만 <img>화하고 src는 escape. 그 외 URL은 이미지로 만들지 않는다(서버 sanitize 화이트리스트와 동일 사상).
✓
리뷰등록 섹션이 아예 없는 오더 — 리뷰 가이드 카드 자체를 숨김(현재도 reviewGuide 공란이면 숨기는 동작과 동일 계열).
✓
inflowType 조회 실패(fail-soft) — work-detail의 오더 역조회가 실패해도 응답은 정상, 버튼은 기존 동작(landingUrl 유무)으로 폴백. 홀드 검증·제출 경로엔 영향 0.
✓
수동 공고(작업오더 미연결) 하위호환 — inflowType 정보가 없으므로 랜딩 버튼은 기존처럼 표시. 관리자가 의도적으로 넣은 랜딩 URL이 갑자기 사라지는 회귀 없음.
✓
제출 직후 채팅 버튼 공백 방지 — C-2(제출 전 chatUrl 미반환) 때문에 완료 전환 시 1회 재조회로 URL 수급. 실패해도 10초 폴링·재방문에서 자가 복구.
✓
[v1.1] 공고 미연결 탭(시트 단독 작업)·브리프 조회 실패 — 카톡 버튼 미노출("연결된 팀 채팅방이 없어요"), [리뷰제출하기]는 항상 동작. 리뷰제출 핫패스는 어떤 실패에도 막히지 않는다(fail-soft).
✓
[v1.1] 카톡 URL 노출 게이트 = 행 소유권 — /api/search 약한 매칭(이름 단독)으로 카드 목록이 떠도, 브리프는 _verifyRowOwnership(phone8 정확 일치·stale 링크 fail-closed) 미통과 시 403. 이름만 아는 제3자의 채팅방 URL 수집 차단 — 참여형 chat_url 게이트(§04-C)와 동일 사상.
✓
