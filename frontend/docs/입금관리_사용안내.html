입금관리 사용 안내
입금대상 뽑아 은행에 올리기

통합 작업대 → [입금관리] 탭에서 오늘 입금할 리뷰어를 자동으로 뽑아 케이뱅크·하나은행 다건이체 서식으로 내려받습니다. 구글시트를 뒤져 계좌를 손으로 옮겨 적던 일이 사라집니다.

master · admin 전용 1단계(M1) — 대상 추출 · 다운로드 2026-08-04
01

하루 흐름 — 이렇게 씁니다

1
통합 작업대 → [입금관리] 열기
오늘 입금해야 할 건이 이미 뽑혀 있습니다. 위쪽에 대상 건수·합계 금액·은행별 건수가 보입니다.
2
표를 훑어보고 뺄 건은 체크 해제
이번에 보내지 않을 건은 왼쪽 체크를 풀면 됩니다. 체크를 풀면 위 버튼의 건수·금액이 바로 줄어듭니다.
3
⬇ 케이뱅크 서식 다운로드 또는 ⬇ 하나은행 서식 다운로드
확인창이 뜨고, [확인]을 누르면 엑셀 파일이 내려받아집니다. 이 순간 그 건들은 잠깁니다(다음 목록에 다시 안 나옵니다).
4
받은 파일을 은행 사이트에 그대로 올리기
지금 하시던 것과 똑같습니다. 파일을 열어 고칠 필요 없습니다.
5
이체 후 — 아래 [이체 회차] 표에서 기록 확인
누가·언제·몇 건을 받았는지 남습니다. (은행 결과 파일을 올려 입금일을 자동 기록하는 기능은 다음 단계(2단계)입니다. 지금은 시트 입금칸을 종전대로 적어주세요.)
대상은 어떻게 뽑히나요? ① 리뷰를 제출했고 ② 아직 입금 안 됐고 ③ 한 번도 다운로드에 담긴 적 없는 건만 나옵니다. 어제 놓친 건도 자동으로 계속 남아 있으니 따로 챙기지 않아도 됩니다.
02

은행은 자동으로 갈립니다

어느 은행으로 보낼지는 작업오더의 "물건비" 항목에서 자동으로 정해집니다. 직원이 건별로 고를 필요가 없습니다.

작업오더 물건비이체 은행
현금 (현금이체로 받는 작업)하나은행 다건이체
계산서 (수수료·세금계산서로 받는 작업)케이뱅크 다건이체

바꾸고 싶을 때 — 모집공고 수정

  • 모집공고 수정 창 [이체은행] 에서 🔄 자동 🟩 하나은행 🟦 케이뱅크 중에 고릅니다.
  • [자동]이 기본값입니다 — 작업오더를 계속 따라갑니다. 그 아래에 "작업오더 물건비 '계산서' → 케이뱅크로 자동 분류돼요"처럼 판정 결과가 표시됩니다.
  • 은행을 직접 고르면 그 값이 항상 우선합니다(작업오더가 나중에 바뀌어도 안 따라갑니다). 다시 [자동]을 누르면 원래대로 돌아갑니다.
03

통장표시 — 리뷰어 통장에 찍히는 이름

  • 모집공고 수정 창 [통장표시]에 적습니다. 예) 파우더망고, 쉐이크만두 — 지금 쓰시던 방식 그대로(작업 축약명 + 담당자 닉네임).
  • 한글 8자까지만 들어갑니다(은행 서식 제한). 넘으면 잘립니다.
  • 비워두면 입금관리 화면에 "⚠ 통장표시 없음 N건" 경고가 뜹니다. 이체는 되지만 리뷰어가 무슨 돈인지 몰라 문의가 옵니다 — 되도록 채워주세요.
04

"보류"로 표시된 건은 왜 빠졌나요?

파일에서 빠진 건은 조용히 사라지지 않고 표에 회색으로 남아 사유가 적힙니다. 사유를 해결하면 다음에 자동으로 다시 잡힙니다.

표시되는 사유무슨 뜻인가어떻게 해결하나
이체은행 미지정연결된 작업오더에 물건비가 없거나, 작업오더 없이 만든 공고모집공고 수정 → [이체은행]에서 직접 선택
계좌 미등록리뷰어가 내정보에 계좌를 안 넣었다리뷰어에게 계좌 등록 안내
은행명 인식불가리뷰어가 적은 은행 이름을 시스템이 못 알아본다(오타 등)리뷰어에게 은행명 정정 안내 (틀린 은행으로 보내는 것보다 안전하게 일부러 막습니다)
예금주 미등록예금주 이름이 비어 있다리뷰어에게 예금주 등록 안내
결제금액 조회안됨그 행에 연결된 구매양식(주문) 기록이 없어 상품비를 모른다주문 기록 확인 — 외부모집 수기 건이면 구매양식 수동제출로 등록
05

잘못 뽑았을 때 — [회차 취소]

  • 아래 [이체 회차] 표에서 그 회차의 회차 취소 를 누르면 잠금이 풀려 건들이 다시 입금대상 목록으로 돌아옵니다.
  • ⬇ 다시 받기 는 같은 회차의 파일을 한 번 더 내려받습니다. 다시 받은 것도 기록에 남습니다(몇 회 받았는지 표에 표시).
이미 은행에 올린 회차는 절대 취소하지 마세요. 취소하면 그 건들이 다시 입금대상으로 나와 두 번 입금될 수 있습니다. 취소는 "은행에 올리기 전에 잘못 뽑았을 때"만 씁니다.
06

알아두실 것

  • 같은 사람이 여러 작업에 참여했으면 작업별로 따로 이체됩니다(합치지 않습니다). 통장에도 여러 줄로 들어가고, 작업별 통장표시가 그대로 보입니다.
  • 이체금액 = 상품비(결제금액) + 리뷰비입니다. 표에서 오른쪽에 25,000+1,900 처럼 내역이 함께 보입니다.
  • 이 화면은 계좌번호가 전부 보입니다 — 화면 공유·스크린샷에 주의하세요. AE·광고주 계정에는 메뉴 자체가 보이지 않습니다.
  • 다운로드 파일은 은행 공식 양식 그대로입니다. 열어서 고치지 마세요 — 계좌번호 앞의 0이 사라지는 등 엑셀이 값을 바꿀 수 있습니다.
