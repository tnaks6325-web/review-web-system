0. 구현계획 — 마감 공고도 리뷰어 화면을 보는 방법

문제

오늘 모집이 끝났거나(투입완료) 완전히 마감된 공고는 리뷰어 링크로 들어가면 잠금 화면만 보인다. 그래서 담당자가 "이 공고에 구매가이드가 제대로 들어갔나, 현영 건인데 현금영수증 발행방법 안내가 나가고 있나"를 확인하려면 방법이 없었다(참여를 실제로 해 볼 수도 없음).

해결 — 이미 있는 "관리자 미리보기"를 카드에서 바로 연다 (서버 변경 0)

수정 모달 안에만 있던 [👁 리뷰어 화면](미리보기 모드)을 모집공고 카드 액션 줄에 버튼으로 추가한다. 미리보기는 기존 campaign.html?preview=1#tok= + GET /admin/:id/preview 합성 응답을 그대로 재사용 — 마감·오픈전 공고도 [모집중 가정] 토글(기본 ON)로 참여 전 → 작업가이드(현금영수증 안내 포함) → 제출 완료 전 과정을 볼 수 있고, DB에 아무것도 쓰지 않아 홀드·정원 카운터를 오염시키지 않는다.
