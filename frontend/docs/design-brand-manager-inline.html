브랜드별 담당자 — 업체(대행사)가 셀프로 입력

대행사가 브랜드마다 자기 쪽 담당자를 최대 2명 자유입력하면, 그 브랜드사가 보는 작업 조건 카드의 「담당」 행에 그대로 표시됩니다. 아래는 확정이 필요한 갈래 A/B/C 와 입력 화면 시안입니다. 가짜 데이터로 실제 동작합니다 — 왼쪽에 입력하면 오른쪽 미리보기가 즉시 바뀝니다.

① 입력 — 업체용 뷰어 › 브랜드 관리대행사만 보는 화면

행마다 인라인. [담당자] 를 누르면 그 행 자리에서 입력칸 2개가 펼쳐집니다(팝업 없음). 최대 2명.

② 결과 — 브랜드사가 보는 작업 조건 카드브랜드 링크로 들어온 화면

지금은 이 자리에 내부 담당(AE팀 김수만 / 관리자 망고) 이 그대로 나갑니다. 세 갈래 중 무엇으로 할지 정해주세요.

확인이 필요한 것

Q1. 내부 담당(AE팀 김수만 / 관리자 망고)을 어떻게 할까요? A 대체(브랜드사에게는 업체가 정한 담당만) · B 병기(내부 담당 아래 한 줄 더) — 예시 문장으로는 A 로 읽었습니다.
Q2. 담당자를 입력하지 않은 브랜드의 브랜드사 화면은? C-1 지금처럼 내부 담당 노출 · C-2 「담당」 행을 숨김 · C-3 「—」 — 시안은 C-1(기존 동작 유지)로 그렸습니다.
Q3. 역할 라벨을 붙일까요? 지금은 AE팀·관리자 라벨이 이름 앞에 붙습니다. 자유입력 2칸은 라벨 없이 박가람 차장 / 개똥이밥먹어 로만 적으면 되는지, 아니면 라벨 칸도 따로 받을지.
Q4. 대행사 자기 화면(작업 조건 카드)에도 이 담당이 보여야 하나요? D안처럼 내부 담당 + 업체 담당을 함께 보여주면 "브랜드사에게 무엇이 나가는지" 를 대행사가 확인할 수 있습니다.
Q5. 저장 단위는 브랜드 1벌이 맞나요? (그 브랜드에 귀속된 모든 작업에 같은 담당이 표시됩니다. 작업마다 다르게 두는 게 아니라면 이 쪽이 맞습니다.)
