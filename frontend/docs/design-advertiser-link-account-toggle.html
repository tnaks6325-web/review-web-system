현재

업체에 활성 계정이 하나라도 생기면 접속 링크가 자동으로 "로그인 필요"로 바뀝니다(계정 존재 = 게이트).

계정을 만들어 두고 링크는 그냥 열리게 두는 선택지가 없습니다. 끄려면 계정을 비활성/삭제해야 합니다.

변경안

링크는 기본이 공개. 계정이 있든 없든 링크만 열면 그 업체 뷰로 들어갑니다.

로그인을 요구할지는 "광고주 계정" 카드의 토글 하나로 결정합니다. 계정 발급 = 보안 적용이 아니라, 토글 ON = 보안 적용.

4구현 범위(참고)

서버 — 게이트 판정을 "계정 존재"에서 "명시 플래그"로 옮깁니다. advertisers.account_login_required(기본 FALSE) 1컬럼 추가 → loginByLinkToken이 계정 존재 여부 대신 이 플래그를 보고 requiresLogin을 반환. 토글 저장은 기존 POST /api/trackb/advertiser-link에 액션 하나 추가(신규 엔드포인트 0), adminOrMaster 권한 그대로.

안전장치 — 켤 때 활성 계정 0개면 서버가 거부(프론트 안내 + 서버 재검증). 끌 때는 계정을 건드리지 않음(비활성/삭제 아님).

기존 업체 이관 — 지금 계정이 있어서 "로그인 필요"로 동작하던 업체는 마이그레이션에서 account_login_required=TRUE로 1회 백필합니다. 배포 순간 동작이 바뀌지 않습니다(계정 있던 곳은 계속 로그인 요구, 없던 곳은 계속 공개). 새로 만드는 업체만 기본 공개.
