상품옵션 기능 — 무엇이 바뀌었나

상품이 하나가 아니라 여러 옵션(예: 힙스 골라담기 / 콰이어트 / 어나더)으로 진행되는 캠페인에서, 관리자·리뷰어 화면이 어떻게 달라졌는지 바뀌기 전 → 바뀐 후를 화면 그림으로 비교합니다. 개발 용어 없이, 실제 화면 순서대로 봅니다.

SUMMARY

한눈에 — 바뀐 곳 7군데

옵션이 정의(관리자) → 노출(리뷰어) → 선택 → 구매·제출 → 관제까지 끊김 없이 이어지도록 7개 화면이 바뀌었습니다. 옵션이 없는 캠페인은 예전과 100% 똑같이 동작합니다.

안 바뀐 것 — 안심 포인트

이번 변경은 옵션을 등록한 참여형 캠페인에서만 켜지는 추가 기능입니다. 그 외에는 예전과 완전히 동일합니다.

  • 옵션 없는 단일상품 공고 — 옵션 선택창·카드칩이 아예 안 뜨고 예전과 똑같이 참여·제출됩니다.
  • 기존 카톡 신청형 공고 — 전혀 영향 없음(참여형이 아니라 옵션 기능 대상 밖).
  • 구매양식 시트·행 배정 방식 — 그대로. 옵션은 기존 "옵션" 열에 자동 기입됩니다.
  • 자리 계산·마감·15분 홀드 — 검증된 기존 방식을 옵션 단위로 한 겹 더 적용했을 뿐, 새 방식을 만들지 않았습니다.
  • 참여자가 있는 옵션 — 관리자가 목록에서 빼도 삭제되지 않고 "마감"으로만 처리되어 기록이 보존됩니다.
현장 팁. 옵션 캠페인을 만들 땐 모집 시작 전에 옵션표를 먼저 채워두세요. 옵션명은 시트의 "옵션" 열 값과 똑같이 적어야 시트에 정확히 기입됩니다(띄어쓰기까지 동일). 옵션별 금액이 다르면 옵션표에 각각 입력하면 리뷰어에게 참여 후 그 금액이 보입니다.
🧩옵션 요약칩·잔여 게이지 — 초록(여유)·주황(임박)·회색(마감)으로 상태를 색으로 구분합니다.
🔒금액은 참여 후 공개 — 공고·선택창에는 옵션명과 남은 자리만, 결제금액은 참여 후 화면에서 보입니다.
🔁옵션 변경 — 구매(제출) 전까지만. 변경하면 구매양식이 자동 새로고침되어 항상 최신 옵션으로 제출됩니다.
