카드 스택 추천지금 순서 유지

회색 배경 위에 흰 카드를 얹는다. 묶음 하나 = 카드 하나이고, 카드 안의 하위 블록(현영 이미지·판별 예시)은 한 단계 어두운 인셋 박스에 담아 "카드 안의 묶음"임을 색으로 보여준다. 스크롤 순서·항목 위치는 지금 그대로라 쓰던 사람이 다시 찾을 필요가 없다. 이미지 칸은 썸네일 + 등록 상태칩 + [바꾸기]/[제거]로 통일하고, 날것의 파일 선택 입력은 감춘다. 리뷰 판별 예시 9칸은 기본 접힘(요약 한 줄) — 평소 건드리지 않는 설정이 화면 절반을 먹지 않게.

추천 — 시안 A

불편의 원인은 "항목이 많다"가 아니라 "면이 나뉘지 않았다"이고, A가 그 원인만 정확히 고친다. 목차(B)는 관리자 대시보드에 이미 있는 설정 탭 구조와 겹쳐 탐색 계층이 두 겹이 되기 쉽다. A로 정돈한 뒤에도 여전히 길다고 느껴지면, 그때 카드 헤더만 남기고 카드 접기를 얹는 것이 B보다 싸다.

적용할 때 지킬 것 (둘 중 무엇을 고르든)
  • 필드 ID·onclick 이름은 한 글자도 바꾸지 않는다 — myNicknameInput·crGuideImg<Cap>·saveMyNickname() 등은 회귀가드(tests/workdeskSettingsTab.test.js)와 로더가 이름으로 묶여 있다.
