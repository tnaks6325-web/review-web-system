M2에서 새로 반영할 변경 2가지

M1을 만든 뒤 시스템에 다른 업데이트가 들어오면서, 리뷰어 참여 화면(M2)을 만들기 전에 맞춰야 할 것이 두 가지 생겼습니다. 그림으로 설명합니다.

기준 문서 참여형 캠페인 PRD v1.2 이 문서 M2 반영사항 부록
01 · 한눈에 보기

무엇이, 왜 바뀌나

1

"내 정보 확인"을 참여 전으로 당깁니다

그 사이 구매양식에 내 정보(이름·전화·주소·계좌) 검사가 새로 생겼습니다. 검사를 지금 위치(제출 순간)에 두면, 리뷰어가 돈을 다 쓰고 나서야 막히는 사고가 납니다.

검사 시점: 제출할 때 ❌ → 참여할 때 ✅
2

참여형 공고를 "만드는 화면"을 넣습니다

참여형 캠페인의 뼈대(M1)는 완성됐지만, 관리자가 참여형 공고를 만들고 게시할 화면이 아직 없습니다. 공고 등록 화면에 참여형 스위치와 설정을 추가합니다.

04 · 정리

바뀌기 전 / 후

바뀌기 전바뀐 후 (M2)
① 내 정보 확인 구매를 마치고 제출하는 순간 막힘 → 15분 낭비 + 돈 쓴 뒤 좌절 참여 버튼 누를 때 미리 확인 → 자리 잡기 전 안내, 손해 0
② 참여형 공고 만들기 만들 화면이 없음 (엔진만 존재) 공고 화면의 [참여형] 스위치 + 자동 점검 후 게시
이 2가지를 포함해 M2 범위는: 리뷰어 카드(오픈예정 타이머·실시간 카운트) → 캠페인 상세 페이지 → 화면 안 구매양식 제출 → 참여형 공고 만들기 화면 순으로 진행됩니다.
