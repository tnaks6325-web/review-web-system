# PRD — 인기상품 선행참여 우선순위

## 목적

인기상품 참여 전에 리뷰어가 진행해야 할 비인기 모집공고를 인기상품별 우선순위로 관리한다. 현재 우선순위 공고가 모집완료되면 시스템이 다음 순위 공고를 자동으로 선행참여 대상으로 전환한다.

## 대상

- 관리자: 인기상품 ON 설정과 비인기 공고 우선순위 관리
- 리뷰어: 인기상품 참여 전 현재 선행참여 공고 확인 및 구매양식 제출

## 정책

1. 인기상품마다 `비인기·참여형·모집중` 공고를 0개 이상 순서대로 설정할 수 있다.
2. 우선순위는 드래그로 변경하며, 저장된 순서가 서버의 기준이다.
3. 현재 대상은 우선순위 중 첫 번째 모집 가능 공고다.
4. 현재 대상이 마감되거나 총 모집인원이 충족되면 다음 모집 가능 공고로 자동 전환한다.
5. 리뷰어는 현재 대상 공고의 구매양식을 `제출완료`한 뒤 해당 인기상품에 참여할 수 있다.
6. 우선순위가 비어 있는 과거 인기상품은 기존 일반공고 1건 : 인기상품 1건 정책을 유지한다.
7. 우선순위 공고가 모두 완료되면 해당 인기상품의 선행참여 제한은 적용하지 않는다.

## 성공 기준

- OFF → ON에서 우선순위 선택 모달이 열린다.
- 선택 순서가 서버에 저장되고 새로고침 후에도 유지된다.
- 1순위 공고 완료 후 관리자 조작 없이 2순위가 적용된다.
- 현재 대상 미제출 리뷰어는 인기상품 참여가 차단되고, 대상 공고명과 안내를 받는다.
- 대상 공고 제출완료 리뷰어는 인기상품 참여가 가능하다.

## 비범위

- 모집완료의 수동 전환 버튼
- 기존 제출·참여 이력의 변경 또는 삭제
- 비인기 공고 외 공고를 선행참여 대상으로 설정
