작업오더에서 넘어오는 값과, 사람이 채워야 하는 값

작업오더 인박스에서 [모집공고 생성]을 누르면 공고 등록 폼이 열리면서 작업오더 값이 미리 채워집니다. 아래는 어느 칸이 자동으로 채워지고, 어느 칸이 비어 있는지를 실제 폼 배치 그대로 표시한 것입니다.

자동 — 작업오더 값이 그대로 들어옴 확인 필요 — 들어오지만 검토·보완이 필요 직접 입력 — 비어 있음 다른 경로로 반영 — 공고 폼이 아님
자동 18 확인 4 직접 6
28개 항목 중 18개가 손대지 않아도 채워집니다 (약 64%) 직접 입력이 필요한 6개는 아래 ⑤ 체크리스트로 모아 뒀습니다

1전체 흐름

작업오더 하나가 두 갈래로 반영됩니다 — 접수하면 탭 설정에, 공고 생성하면 공고 폼에. 저장하면 서로 연결되고, 이후에는 시트 일정이 우선합니다.

STEP 1
📥 작업오더 접수
AE가 올린 오더를 관리자가 접수. 이때 탭이 등록되고 담당자(작업담당→만두/망고)·구매시간대· 리뷰유형·배송유형이 탭 설정에 자동 기입됩니다(비어 있을 때만). 이 접수가 있어야 공고의 연결 탭도 자동으로 잡힙니다.
STEP 2
📣 모집공고 생성
인박스의 [모집공고 생성] → 공고 폼이 작업오더 값으로 미리 채워진 채 열립니다. 참여형 스위치는 켜진 상태.
STEP 3
💾 저장 · 역연결
저장하면 작업오더에 공고 ID가, 공고에 오더 ID가 서로 기록됩니다 (유입방식 판정·이력 추적에 사용).
STEP 4
📅 운영 중 자동 갱신
연결한 탭의 날짜 컬럼에서 시작일·마감일·그날 정원을 읽어 폼에 넣은 값보다 우선 적용됩니다(5분 주기).

2모집공고 등록 폼 — 칸별 반영 상태

실제 모달 배치(왼쪽 기본정보 / 오른쪽 모집정보)와 같은 순서입니다. 초록 칸은 열자마자 채워져 있고, 회색 칸은 비어 있습니다.

3공고 폼이 아니라 탭 설정으로 가는 값

작업오더를 접수할 때 그 탭이 등록되면서 함께 기입됩니다. 이미 값이 있으면 덮어쓰지 않습니다(2차 접수가 1차 설정을 밀어내지 않도록).

4운영 중에는 시트가 우선

📅 시작일 · 마감일 · 그날 정원 · 총 건수
연결한 탭의 날짜 컬럼(구매일자·시작일·주문일 등)에서 5분마다 다시 계산해 폼에 넣은 값보다 우선 적용합니다. 시트에 날짜를 추가하면 마감된 공고도 자동으로 다시 열립니다.
🛒 상품명 · 결제금액
폼을 열 때 상품 URL로 자동수집을 1회 시도해 성공한 항목만 덮어씁니다. 실패해도(쿠팡 봇 차단 등) 작업오더 값이 그대로 남습니다.
🔗 옵션명은 시트 옵션열과 정확히 같아야 합니다
공고 옵션명과 시트의 옵션 칸 값이 다르면 주문은 접수되지만 옵션 표시가 사라집니다. 모집 시작 후 옵션명 변경은 피해주세요.
📌 접수 전 탭은 검색·제출이 안 됩니다
탭이 작업오더 접수로 등록되어야 리뷰어가 찾을 수 있습니다 — 모집 시작 전에 접수를 먼저 해주세요.

5공고 생성 후 채워야 하는 것

📋 직접 입력 체크리스트 (6개)

  • 리뷰비 입력 (상품 결제금액과 다릅니다)
  • 안내배지 선택
  • 옵션별 총인원 · 일건수 입력
  • 종료일 입력 (선택 — 시트 날짜가 있으면 그쪽이 우선)
  • 타계정 참여 허용 여부 (기본 불가)
  • 썸네일 확인 — 자동수집 실패 시 이미지 주소 붙여넣기 또는 업로드

자동으로 채워지는 칸이라도 비어 있으면 직접 넣어주세요 — 연결 탭(접수 전 생성) · 담당자(작업담당이 랜덤) · 구매채널(모르는 쇼핑몰)은 일부러 비워 둔 것입니다.

전부 채운 뒤 상태를 게시로 바꾸면 자동점검(연결 탭·하루한도·시간창)을 거쳐 리뷰어에게 노출됩니다.
