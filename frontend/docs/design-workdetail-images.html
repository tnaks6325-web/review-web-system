4 값은 어디에 담기나 가장 중요한 부분

세 칸의 성질이 서로 다르다. 유입가이드는 지금도 HTML이고, 리뷰가이드·특이사항은 평문이다. 이 차이를 무시하고 셋 다 HTML로 바꾸면 기존 저장분이 깨진다.

칸지금 저장 형태사진을 어디에 담나
유입가이드work_detail.inflowGuideHtml

— 평문(화면에서 escape)		 새 배열 reviewGuideImages: []
특이사항work_detail.specialNotes
— 평문(화면에서 escape)		 새 배열 specialNotesImages: []
🚫 하지 않는 것 — 평문 칸을 HTML로 승격
리뷰가이드·특이사항을 HTML 필드로 바꾸면, 기존 저장분에 들어 있는 <옵션> 같은 꺾쇠 글자가 태그로 오인되어 통째로 삭제된다. 이 레포가 이미 겪어서 “평문은 escape 후 개행만 <br>”로 굳혀 둔 자리다. 그래서 텍스트 칸은 건드리지 않고 사진만 배열로 옆에 둔다.
유입가이드 — 저장할 때 최소 개입
  • 글을 안 고쳤으면 원본 HTML 그대로(단락·링크·사진 위치 보존 = 지금 동작).
  • 사진을 뺐으면 그 파일ID의 <img> 하나만 제거 · 더했으면 끝에 붙임 · 순서를 바꿨으면 <img>들만 그 순서로 다시 씀.
  • 글을 고쳤으면 고친 평문 + 사진을 다시 붙임 → 지금처럼 사진이 사라지지 않는다.
확인창 문구도 사실에 맞게 바꾼다 → “유입가이드 글을 고치셨어요 — 사진 2장은 그대로 유지되고 글자만 다시 게시됩니다. 원본에 있던 줄 서식·링크는 사라지고 사진은 글 아래로 모입니다. 계속할까요?”
(지금 문구 = “원본에 있던 이미지가 빠진 평문으로 게시됩니다” — 실제로 사진이 사라졌다.)

5 4장 상한 — 이미 더 들어와 있는 공고는 어떻게 하나

작업오더에서 넘어오는 첨부는 지금 최대 8장이다. 상한을 4장으로 두면 5장 이상 온 공고가 생긴다.

상황동작왜
관리자가 새로 넣을 때4장에서 [＋] 사라짐 + “최대 4장”확정된 상한
이미 6장이 들어와 있는 공고6장 전부 보여준다 · [＋]만 숨김 · “4장을 넘겼어요 — 2장을 빼주세요” 안내 조용히 자르면 관리자가 모르는 사이 사진이 사라진다. 무엇을 뺄지는 사람이 고른다
그 상태로 저장막지 않는다(경고만)다른 칸만 고치러 들어온 사람의 저장을 막으면, 상관없는 작업이 멈춘다(자동점검이 하드블록을 안 쓰는 것과 같은 판단)
작업오더 → 발행 프리필넘어온 그대로 담고 위와 같이 안내인트라넷 쪽 8장 상한은 이번에 건드리지 않는다

  • 서버가 남의 주소를 버린다 — 우리 프록시 형식이 아닌 주소·5장째를 넣어 실제로 저장 핸들러를 호출해 확인.
  • 리뷰어 화면에 같은 사진이 두 번 나오지 않는다(리뷰가이드 배열 ↔ 유입가이드 카드 추출 중복).
  • 업로드 3경로가 같은 함수를 지난다(사본이 생기면 실패) · onclick에 주소 문자열이 없다 · 팝업은 body 직속 · 키 리스너 1회 · 인플라이트 중 저장 차단.
  • 평문 칸이 HTML로 승격되지 않았다 — reviewGuide·specialNotes가 여전히 escape 경로임을 고정(가장 위험한 회귀).
  • 기존 가드 동반 갱신 — recruitModalLayout(칸 구조·CSS 토큰 균형) · campWorkDetailShared(카드 렌더) · campaignM3Guards·woCampaignMapDoc(rawHtml 배선 형태) · campaignFieldCleanupUI(정리 도우미 보호).
되돌리기
네 파일을 되돌리면 끝난다(DB 무접촉). 이미 저장된 사진은 남는다 — 유입가이드는 지금과 같은 형태이고, 리뷰·특이 배열은 옛 화면이 무시할 뿐 지우지 않는다.

7 남는 한계 (문서화)

한계내용
유입가이드 글을 고치면 서식은 잃는다 사진은 유지되지만 본문 중간에 있던 사진은 글 아래로 모이고 링크·굵기는 평문이 된다. 그래서 확인창을 남긴다(§4).
순서 바꾸기는 마우스 전용 키보드만으로는 순서를 못 바꾼다(4장이라 실무 영향은 작다). 필요하면 ✕ 후 다시 넣기로 우회.
리뷰어 화면 확대 없음 리뷰어는 사진을 눌러 크게 볼 수 없다(지금과 같음). 필요하면 다음 건.
작업오더 쪽 8장은 그대로 인트라넷에서 5장 이상 오면 관리자가 화면에서 빼야 한다(자동으로 자르지 않는다).
리뷰가이드 섹션 규칙은 유지 리뷰가이드 글은 지금처럼 [리뷰등록 가이드] 섹션만 리뷰어에게 나간다. 사진은 섹션과 무관하게 그 카드에 나온다.
