📝 작업오더 관리자 수정 — 와이어프레임 시안

리뷰웹시스템에서 관리자가 작업오더의 내용을 직접 수정하고, 그 수정이 인트라넷 "보낸 오더" 카드에도 그대로 반영(동기화)되는 기능의 화면 설계안입니다.
v1.0 · 2026-08-05 · 시안 단계(개발 착수 전 확인용)

0. 한눈에 보기

이 기능이 하는 일과, 동기화가 자동으로 되는 이유.
동기화는 새로 만들 것이 거의 없습니다. 인트라넷의 "보낸 오더" 목록은 지금도 화면을 열 때마다 리뷰웹의 작업오더 원장(work_orders)을 실시간으로 조회해서 그립니다(인트라넷 로컬 캐시와 병합할 때도 리뷰웹 값이 우선). 즉 리뷰웹 원장 한 곳만 고치면 인트라넷 카드는 다음 조회 때 자동으로 새 값을 보여줍니다. 추가로 필요한 것은 "리뷰웹에서 수정됐다"는 사실을 카드에 표시해 주는 안내 장치뿐입니다.
① 리뷰웹 관리자 수정작업오더 상세의 [✏ 관리자 수정] → 수정 모달에서 저장
→
② 원장 갱신 (단일 진실)리뷰웹 work_orders 원장이 갱신 + 수정 이력 기록(누가·언제·무엇을)
→
③ 인트라넷 자동 반영보낸오더 목록이 리뷰웹 원장을 실시간 조회 → 카드에 새 값 + "리뷰웹에서 수정됨" 안내

1. 어디서 수정하나 진입점 2곳 · 같은 모달 한 벌

관리자 대시보드(작업오더 인박스)와 리뷰웹시스템[3버전](작업오더 탭) 모두, 오더 행을 펼쳤을 때의 처리 열에 [✏ 관리자 수정] 버튼을 추가합니다. 두 화면은 이미 같은 공유 렌더러(work-order-detail.js)를 쓰므로 수정 모달도 한 벌로 공유합니다(사본 금지).

3. 인트라넷 동기화 — 어떻게 반영되나 자동 + 알림

보낸오더 목록은 리뷰웹 원장을 실시간 조회하므로 값 자체는 자동 반영됩니다. 다만 AE가 "내가 보낸 오더가 바뀌었다"는 사실을 모르면 안 되므로, 저장 시 기존 처리메모 채널(webhook)로 수정 알림을 함께 보냅니다.
단계동작만들 것 / 이미 있는 것
값 반영보낸오더 목록이 열릴 때마다 리뷰웹 work_orders를 조회해 그림 (캐시 병합 시에도 리뷰웹 값 우선)이미 있음 — 추가 개발 0
수정 알림저장 시 리뷰웹 → 인트라넷 webhook으로 "관리자 ○○이 △△ 항목을 수정" 메모 push → 카드의 주황 처리메모 블록에 표시기존 처리메모 채널 재사용 (INTRANET_MEMO_WEBHOOK_URL)
