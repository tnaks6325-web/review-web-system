모집공고 편집창 첨부 이미지 — 2장부터 안 보이는 문제

유입 가이드·리뷰 가이드·특이사항의 첨부 이미지 칸이 128px 고정폭 + 잘림(overflow:hidden)인데 썸네일은 한 장 74px 고정이라, 2장째는 ✕(빼기) 버튼이 잘려나가고 3장째부터는 첨부됐다는 사실 자체가 안 보입니다. 장수 표시도 가로 스크롤도 없어 "안 보임 = 없음"으로 읽히는 것이 핵심 문제입니다.

0지금 화면 — 문제 그대로 재현 현재

유입 가이드에 사진이 4장 첨부돼 있지만 화면에는 1.5장만 보입니다. 2장째의 ✕는 잘린 영역에 있어 뺄 방법이 없고, 3·4장째와 [＋추가]는 통째로 화면 밖입니다.

칸 안쪽 가용폭 118px − 1장 74px − 간격 5px = 39px만 남아 2장째가 반쯤 걸칩니다. ✕ 버튼은 썸네일(74px)의 오른쪽 위에 붙으므로 항상 잘리는 영역에 놓입니다.

AA안 — 첨부가 생기면 스트립이 입력창 아래 전폭 줄로 추천

첨부 0장일 때는 지금처럼 오른쪽 128px [＋ 사진 넣기] 칸 그대로(평소 화면 불변). 1장이라도 첨부되면 스트립이 입력창 아래 전폭 줄로 내려와 4장 + [＋추가]가 전부 보이고, ✕도 모든 장에서 보입니다. 라벨 옆에 사진 N장 표기가 붙어 접힌 상태에서도 장수를 알 수 있습니다.

동작(업로드·순서 바꾸기·확대 팝업·4장 상한)은 기존 _ig* 함수 그대로 — 바뀌는 것은 CSS와 스트립의 위치뿐이라 위험이 가장 작습니다. 세 줄이 각각 최대 72px 정도 높아지지만 편집부는 원래 세로 스크롤 영역이라 문제 없습니다.

BB안 — 128px 칸 안에서 2×2 그리드로 전부 표시

칸 크기(128×58)는 그대로 두고, 장수에 따라 1장=전폭 / 2장=좌우 / 3~4장=2×2로 나눠 담습니다. 전부 보이고 ✕도 각 장에 있지만, 4장이면 한 장이 약 55×23px로 작아져 "무슨 사진인지"는 클릭(확대)해야 알 수 있습니다.

레이아웃 변화가 없다는 장점이 있지만, ✕가 13px로 작아져 누르기 어렵고 4장일 때는 [＋추가] 자리가 없어 4장을 채우기 전에만 추가 칸이 보입니다(3장 + 추가칸 = 2×2).

CC안 — 첨부한 만큼만 사진 칸이 옆으로 늘고, 입력창이 그만큼 줄어든다 v3 · 사용자 요청 반영

고정 그리드 없이 첨부 수만큼만 칸을 만듭니다 — 미첨부 = [＋추가] 한 칸 · 1장 = [첨부1][＋추가] 두 칸 · … · 4장(최대) = 네 칸(추가칸 사라짐). 사진이 한 장 늘 때마다 왼쪽 텍스트 편집창 너비가 그만큼 줄어들고, 빼면 다시 넓어집니다. 첨부가 없는 줄은 입력창이 거의 전폭이라 평소 화면 손해가 없습니다. 아래 목업이 실제로 그렇게 동작합니다(＋로 넣고 ✕로 빼면서 입력창 폭 변화를 확인해 보세요).

칸은 장당 66px 고정이라 4장을 다 채워도 사진 영역은 약 290px — 입력창은 최소 190px을 보장합니다. 줄 높이는 지금과 같아 화면 세로 변화가 없습니다. 줄마다 첨부 수가 다르면 입력창 폭도 줄마다 달라진다는 점만 유의(위 목업의 유입 4장 / 리뷰 2장 / 특이사항 0장 비교).
