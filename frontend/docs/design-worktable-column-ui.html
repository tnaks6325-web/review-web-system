열 구성 화면 정리
디자인 시안 A · B

지금 화면은 채널이 알약과 행 두 곳에 겹쳐 나오고, 열을 담는 칸이 행마다 따로 있으며, 작업유형을 만들 때 브라우저 기본 입력창(prompt)이 뜹니다. 요청 4건을 반영한 두 가지 화면을 그렸습니다. ①②③은 두 시안이 같고, 다른 것은 ④ 만드는 방식(그 자리에서 / 작은 창)입니다.

0 반영할 요청 4건

①채널 행 제거

알약에 쿠팡·네이버·올리브영·카카오메이커스가 이미 가로로 나오므로, 아래 채널 행 4개는 없앱니다.

②열 추가는 미리보기 오른쪽 끝에서

지금 보고 있는 구성(공통/채널/유형)에 바로 열을 담습니다.

③[＋ 작업채널 추가]는 알약 줄 오른쪽

채널을 다루는 일이 한 줄에서 끝납니다.

④작업유형 추가 화면 만들기

브라우저 기본 입력창(prompt) 대신 이름·설명·위치·열을 함께 정하는 화면. 여기가 A·B의 차이입니다.

①을 하면 생기는 숙제 하나 — 지금은 직접 추가한 채널(지마켓)의 [채널 삭제]가 그 행에 있습니다. 행이 사라지면 삭제할 자리가 없어지므로, 두 시안이 각각 다른 자리를 제안합니다(A = 알약의 ✕ / B = 알약 줄의 ⚙ 관리).

A 시안 A — 제자리에서 인라인

새 창을 띄우지 않고 누른 자리에서 바로 늘어나는 방식입니다. 미리보기 오른쪽 끝 칸을 누르면 그 칸이 입력창이 되고, 작업유형 추가는 유형 목록 아래에 카드 폼이 펼쳐집니다. 화면 이동이 없어 지금 보고 있는 구성에서 눈을 떼지 않습니다.

시안 A 규칙

  • 새 창이 뜨지 않습니다 — 누른 자리에서 칸이 늘어나거나 카드가 펼쳐집니다.
  • 기본 4채널 알약에는 ✕가 없습니다(현금영수증 안내 등 다른 기능과 짝이라 지울 수 없음). 직접 추가한 채널만 ✕.
  • ✕는 누르면 "지마켓 채널과 그 열 1개를 삭제할까요? 이미 만들어진 시트에는 영향이 없습니다"를 한 번 묻습니다.
  • 카드 폼이 열려 있는 동안 아래 목록이 밀립니다(가장 큰 단점).

B 시안 B — 작은 창 팝오버 · 모달

열 추가는 미리보기 아래 작은 팝오버 한 창에서(입력과 "지금 쓰는 열" 목록이 처음부터 함께 보임), 작업유형 추가는 화면 가운데 모달에서 합니다. 목록이 밀리지 않고, 만들 때 설명을 넉넉히 둘 수 있습니다.

시안 B 규칙

  • 평소 화면에는 삭제 버튼이 없습니다 — [⚙ 관리]를 열어야 나옵니다(오클릭 방지).
  • 열 추가 팝오버는 입력 + 후보 목록이 한 창. 담으면 목록의 그 칩이 ✓로 바뀌고 창은 열린 채라 연속으로 여러 개를 담기 좋습니다.
  • 모달이 뜨는 동안 뒤 화면은 잠깁니다(만들기에 집중). 대신 지금 구성을 곁눈질할 수 없습니다.

2 무엇이 다른가

시안 A — 제자리에서시안 B — 작은 창
열 담기 미리보기 끝 칸이 입력창으로 늘어남. ▼를 눌러야 후보 목록이 나옴 미리보기 아래 팝오버. 입력창과 후보 목록이 처음부터 함께
연속으로 여러 개 담을 때마다 칸이 닫혔다 열림(1개씩이 편함) 창이 열린 채로 계속 담기 좋음
작업유형 만들기 목록 아래 카드 폼 — 지금 구성을 보면서 만듦 가운데 모달 — 설명·열 여러 개를 넉넉히
채널 삭제 알약의 ✕(커스텀만) — 빠르지만 오클릭 여지 [⚙ 관리] 안 — 안전하고 이름 변경까지
화면 흔들림 폼이 열리면 아래가 밀림 밀리지 않음(위에 뜸)
처음 쓰는 사람 설명 둘 자리가 좁음 "작업유형이 무엇인지"부터 안내 가능
만드는 품 작음(기존 요소 확장) 보통(팝오버·모달 새로 만듦)

👉 추천 — 시안 B

이 화면은 자주 쓰는 화면이 아니라 가끔 들어와 정하는 화면입니다. 그래서 "클릭 한 번 줄이기"보다 처음 열었을 때 무엇을 하는 곳인지 알 수 있는 쪽이 낫습니다. 특히 ④ 작업유형은 개념 자체가 새로워 설명할 자리가 있는 모달이 유리하고, 채널 삭제는 되돌리기 어려운 동작이라 [⚙ 관리] 안에 두는 편이 안전합니다.

다만 ①②③은 두 시안이 같으므로, "B로 가되 열 담기만 A식(칸이 늘어나는 방식)" 같은 조합도 가능합니다 — 원하시는 조합을 말씀해 주세요.

3 고르시면 그대로 만듭니다

  • 시안 A / B / 조합 중 하나를 골라 주세요(조합이면 "④는 B, ②는 A"처럼 말씀해 주시면 됩니다).
  • 채널 이름 변경이 실제로 필요할까요? B를 고르면 자연스럽게 들어가고, A를 고르면 "지우고 다시 추가"로 남습니다.
  • 공통 행(🌐)은 남깁니다 — 지금 몇 열인지 알려 주는 자리라 없애면 개수가 어디에도 안 보입니다. 필요 없으면 함께 없앨 수 있습니다.
