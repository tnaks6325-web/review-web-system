이번에 바뀌는 것 6가지
  1. 상품명 — 앞의 [상품/옵션/금액] 라벨 제거(상품명만).
  2. 결제금액 — 옵션 없으면 상품결제금액 22,000원 / 총 17,600,000원 한 줄, 옵션 있으면 블랙 22,000원(500건), 그린 24,000원(300건) 평문 + 아랫줄 총결제금액. 총결제금액은 자동계산(= 결제금액 × 건수 합산)이라 편집 대상이 아님.
  3. 유입방식 — 링크유입 / 가이드유입 둘 중 하나로만 표기(guide · 유입가이드 같은 원문 병기 제거).
  4. 일건수 — 모집인원조절로 언제든 바뀌므로 모집공고의 오늘 일건수 기준으로 표기(공고 기준 배지).
  5. 박스 접기/펼치기 — 어느 박스의 머리줄을 눌러도 세 박스가 함께 접히고 펼쳐짐. 세 박스의 하단선(높이)은 항상 일치.
  6. 머리줄에 ∨ 표시 + 호버 시 배경색 + "접기/펼치기" 안내로 클릭 가능함을 시각적으로 보여줌(접히면 ∨ 가 ▸ 로 회전).
