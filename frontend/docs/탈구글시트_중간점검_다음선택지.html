1질문에 대한 답

"남은 구현을 하면서 계속 오류나 허점을 발견해야 하는 건가요?"

답

네. 다만 그건 공사가 잘못돼서가 아니라, 이런 종류의 공사가 원래 그렇습니다. 운영 중인 시스템의 밑바닥을 갈아 끼우는 일이라 새 길이 기존 시스템과 만나는 자리마다 "여긴 시트가 있다고 가정하고 짜여 있네"가 나옵니다.

중요한 건 언제 나오느냐입니다. 켜기 전에 나오면 코드 몇 줄이고, 켠 뒤에 나오면 데이터 사고입니다. 지금은 전부 꺼져 있어서 여태 발견한 것들의 실제 피해가 0이었습니다.

같은 결함, 발견 시점만 다를 때
지금 발견 (켜기 전)
예: 3주차에 찾은 기록 증발
코드 3곳 수정 · 점검 61항목 추가
영향받은 사용자 0명
켠 뒤 발견
같은 결함이 운영 중에
입금 기록·리뷰 캡처가 사라진 뒤 발견
→ 어디까지 사라졌는지 조사 + 수기 복구
한 가지 더 — 점검 자체도 틀렸습니다

매 단계 끝에 코드를 일부러 망가뜨려 점검이 잡는지 시험했는데(총 46종), 그중 9번은 점검이 못 잡았습니다. 전부 "점검이 코드를 그대로 따라가는" 형태였습니다 (예: 상한을 400 → 999999로 바꿨더니 기대값도 같이 바뀌어 통과). "점검을 통과했다"가 곧 안전이 아니라는 뜻이고, 그래서 이 시험을 매번 돌립니다.

2지금까지 무엇이 나왔나

3주 동안 찾아서 막은 것들입니다. 전부 켜기 전이라 실제 피해는 없었습니다.

단계발견한 것그대로 뒀다면실제 피해
W1 구글시트를 읽어 오는 자동작업 4곳 중 1곳을 안 막음 시스템에서 고친 내용을 5분마다 옛 시트 값이 덮어씀 → 기능 자체가 무의미 없음
W2 구매양식이 시트로 새는 경로가 여러 갈래(이관 전에 이미 줄 서 있던 건 포함) 이관한 작업의 주문이 엉뚱하게 옛 시트에 기록 없음
W2 중간에 실패했는데 "완료"로 찍히는 순서 잘못된 연결이 남아 남의 참여 내역이 열림 없음
W2 정원 기준을 옮기는 두 조각이 짝으로 나가야 함 인원 조절 화면이 영영 잠김(조절할 시트도 없는데 창구도 막힘) 없음
W3 기록 재생성이 시스템이 쓴 값을 지움
(입금 완료 · 리뷰 제출 · 리뷰 캡처 대표 이미지)		 주문 한 건만 더 들어와도 입금·제출 표시와 캡처가 전부 증발 없음
W3 편집 반영이 영원히 수렴하지 않는 경로 화면엔 "반영 대기"로만 계속 보임(오류도 안 뜸) 없음

※ 공통점이 보이실 겁니다 — 전부 "조용히 잘못되는" 종류입니다. 화면에 오류가 뜨지 않고, 나중에 "왜 입금 표시가 없지?"로 발견되는 것들이라 미리 찾지 않으면 찾을 방법이 없습니다.

3왜 나오나 — 접점 지도

무작위로 나오는 게 아니라, 나오는 자리가 정해져 있습니다.

결함이 나오는 자리 = 새 길과 기존 시스템이 만나는 지점
① 자동으로 도는 것
5분·10분마다 스스로 구글시트를 읽으러 가는 작업들
② 시트에 쓰는 것
주문·입금·상태 표시를 시트 칸에 적던 경로들
③ 시트에서 파생되던 값
정원·폴더 이름·통계처럼 시트를 재료로 만들던 값들

이 세 종류는 셀 수 있습니다. 그래서 "언제까지 계속 나오나"에 답할 수 있습니다.

4얼마나 남았나 (실측)

코드를 직접 훑어 세었습니다.

① 자동으로 도는 경로 사실상 마무리

  • 시트 읽기 자동작업 4종 (W1)
  • 주문 기록 경로 4중 차단 (W2)
  • 사후검증 · 반영 스케줄러 (W2)
  • 정원 파생 (W2)
  • 편집 반영 스윕 (W3)
  • 폴더 자동 생성 — 시스템 DB 값을 먼저 보게 되어 있어 구글 호출까지 가지 않음. 단, 명시적 차단은 아님

② 사람이 눌러야 도달하는 도구 7곳 남음

  • 작업 아카이브 · 복구
  • 중복 정리
  • 폴더 현황 점검
  • 탭 설정
  • 인덱스 스캔 · 시트 공지문
  • 레거시 공고의 참여자 줄 추가 — 이건 이관(5주차)에 반드시 필요
✓ 남은 7곳의 성격

실패해도 "안 됩니다" 메시지가 뜨는 관리자 도구입니다 — 조용히 데이터가 사라지는 종류가 아닙니다(그 종류는 자동 경로에 있었고, 그건 다 지나왔습니다). 예외는 마지막 한 줄(레거시 공고 줄 추가)이고, 그건 5주차 이관의 필수 항목으로 이미 잡혀 있습니다.

5앞으로 위험이 어떻게 바뀌나

남은 단계는 지금까지와 성격이 다릅니다.

W1~W3은 새 길을 뚫는 일이라 결함이 많이 나왔지만 전부 꺼져 있어 피해가 0이었습니다. W4는 화면이라 위험이 낮고, W5는 진짜로 돌아가는 작업을 옮기는 일이라 여기서 나오는 오류는 처음으로 실제 사용자에게 닿습니다.

그래서 W5 전에 W4가 필요합니다

W4(전환 관리 화면)의 핵심은 스위치가 아니라 켜기 전 자동 점검표입니다 — 인원 수가 맞는지, 반영 대기가 0인지, 대조가 통과했는지를 시스템이 확인하고 조건 미달이면 아예 못 켜게 막습니다. 사람의 판단만으로 켜면 W5의 위험이 그대로 실현됩니다.

6다음 선택지 3가지

하나 골라 주시면 그대로 진행합니다.

추천 · 먼저
선택지 A

무시트 표시 · 업체 링크 정리

화면이 "이 작업은 시트를 안 쓴다"고 말하게 합니다. 지금은 담당자가 어느 작업이 이관됐는지 화면만 봐서는 알 수 없습니다. 업체에 나가는 링크도 시트 공유 없이 전용 링크 하나로 정리합니다.

규모 작음 · 위험 낮음
W5 때 "내가 뭘 옮겼는지"를 보려면 필요
선택지 B

입금 자동화 M2

이체결과 파일을 올리면 성공한 건만 자동으로 입금 처리되고, 실패 건은 리뷰어에게 "계좌를 확인해 주세요"가 나갑니다. 지금은 이체 후 입금 완료를 사람이 눌러야 합니다.

규모 큼 · 탈시트와는 별개 기능
업무 시간을 가장 많이 줄이는 항목
선택지 C

전환 관리 화면 (W4)

작업 하나를 실제로 무시트로 켜는 화면과, 켜기 전 조건을 시스템이 확인해 미달이면 못 켜게 막는 점검표를 만듭니다. 여기까지 오면 테스트 작업 1건으로 실제 검증이 가능합니다.

규모 중간 · 위험 낮음
W5(이관)의 전제 조건
따로 지시가 없으면 이렇게 하겠습니다

A → C → (실제 작업 1건으로 검증) → B 순서입니다. A는 작고 C의 재료가 되며, C까지 마치면 "켤 수 있는 상태"가 되어 실물 1건으로 확인한 뒤 이관으로 넘어갈 수 있습니다. B(입금 자동화)는 탈시트와 독립이라 언제 끼워 넣어도 되고, 업무 시간 절감이 급하시면 지금 B를 먼저 해도 됩니다.

7지금 상태 한 장 요약

항목현재
작업 한 바퀴(접수→검색→제출→캡처→정원)구글 호출 0회로 완결 가능 완료
지금 켜져 있는 작업0건 — 사용자 체감 변화 없음
자동으로 도는 경로사실상 마무리(폴더 생성만 명시 차단이 아닌 순서 의존)
사람이 누르는 도구7곳 미대응 — 실패해도 메시지, 데이터 유실 아님
누적 자동 점검262항목 · 전체 스위트 163파일 0실패
일부러 고장 내 보기46종 전부 검출(그 과정에서 점검 자체의 허점 9건 교정)
되돌리기전부 추가라 새 표시·기능을 끄면 즉시 종전 상태
결정 필요다음 선택지 A / B / C
✓ 한 문장으로

오류는 계속 나올 것이고, 그건 이 방식이 작동하고 있다는 신호입니다. 조용히 잘못되는 것들이 몰려 있던 자동 경로는 지나왔고, 남은 위험은 마지막 이관 단계에 몰려 있습니다 — 그래서 그 전에 점검표를 만듭니다.
