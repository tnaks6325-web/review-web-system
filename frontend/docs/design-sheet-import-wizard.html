시트에서 가져오기

업체관리 › 구글시트 주소로 과거 작업 가져오기 — 아래 화면의 파란 버튼을 눌러 보세요.

이 문서는 가짜 데이터로 실제 동작하는 목업입니다. 버튼·입력·체크·단계 이동이 전부 동작합니다. 서버에 연결되지 않으므로 무엇도 저장되지 않습니다. 실제 예시로 「0720수진코리아 맛있는 고양이캔 4종」 시트를 재현했습니다(개인정보는 가명으로 대체).

3. 잠기는 경우 가져오면 안 되는 시트는 이렇게 막습니다

① 연락처 칸을 못 찾은 경우

가져올 수 없습니다 — 연락처 칸이 없습니다 이 표에는 리뷰어 연락처로 보이는 칸이 없습니다. 연락처가 없으면 리뷰어가 자기 참여 내역을 영영 찾을 수 없는 명단이 됩니다. 시트에서 연락처 열의 이름을 연락처로 맞춘 뒤 다시 시도해 주세요.
