타계정 여러 건 참여, 5번 반복 대신 한 번에

여러 명의(타계정)로 참여하는 리뷰어가 구매양식을 1건씩 5번 작성하느라 30분 가까이 걸리고, 새로고침하면 작성하던 화면에서 튕겨 나가는 문제를 확인했습니다. 이 문서는 현재 방식의 문제, 개선 내용, 실제 화면 목업을 담고 있습니다.
지금은 적용이 끝난 상태이며, 아래 8번 항목에 무엇을 적용했고 무엇을 일부러 만들지 않았는지 정리했습니다.

문제 ① — 같은 작업을 5번 반복

명의 1개당 참여 → 구매 → 캡처 1장 첨부 → 양식 입력 → 제출을 처음부터 끝까지 반복해야 합니다. 5건이면 같은 화면을 5바퀴 도는 셈이라 약 30분이 걸리고, 결국 참여 자체를 포기하는 사례가 나왔습니다. 모집 정원이 비는 것은 회사 손해로 이어집니다.

문제 ② — 새로고침하면 작성 화면 이탈

작성 도중 새로고침되면(실수, 앱 전환, 브라우저 새로 열림 등) 화면이 처음 단계로 돌아가 양식까지 다시 들어가야 합니다. 입력한 글자는 일부 되살아나지만 첨부해 둔 구매 캡처는 사라지고, "이어서 작성 중"이라는 안내도 없어 리뷰어는 처음부터 다시 쓰는 것으로 느낍니다.

5점검 결과 — 캡처로 자동 인식되는 것 vs 직접 입력할 것

현재 시스템의 캡처 자동 인식(AI)과 구매양식 필수 항목을 전부 대조한 결과입니다. 결론: 캡처 5장을 올리면 대부분 자동으로 채워지고, 리뷰어가 항상 직접 입력해야 하는 항목은 사실상 "쇼핑몰 아이디" 하나입니다.

양식 항목채워지는 방법설명
수취인캡처에서 자동캡처 속 받는분 이름을 AI가 읽어 자동 입력. 이 이름으로 어느 명의의 주문인지도 자동 배정합니다.
연락처캡처에서 자동캡처 속 전화번호 자동 입력. 이름이 가려진 캡처는 연락처로 명의를 배정합니다.
배송주소캡처에서 자동캡처 속 배송지 전체 주소 자동 입력.
결제금액캡처에서 자동캡처 속 결제금액 자동 입력. 참여 옵션의 금액과 다르면 확인 표시만 띄웁니다.
주문번호캡처에서 자동캡처에 보이면 자동 입력. 원래 필수 항목이 아니라 캡처에 없어도 제출에 지장 없습니다.
주문자캡처에서 자동캡처 속 주문자 이름 자동 입력. 캡처에 없으면 배정된 명의 이름으로 채우고 확인만 받습니다.
은행 / 계좌번호 / 예금주내 정보에서 자동구매 캡처에는 계좌 정보가 없습니다. 대신 내 정보(본계정 공통계좌) 또는 타계정별 전용계좌에서 자동으로 채웁니다. 타계정에 계좌를 등록해 두지 않았다면 그 건만 직접 입력.
옵션참여 정보에서 자동참여할 때 고른 옵션이 자동으로 고정됩니다(현재도 동일). 입력 불필요.
쇼핑몰 아이디직접 입력구매 캡처 화면에는 로그인 아이디가 나오지 않아 자동 인식이 불가능합니다. 유일하게 항상 직접 입력이 필요한 항목. 다만 같은 명의로 이전에 제출한 아이디를 기억해 두었다가 미리 채워주면 재참여부터는 확인만 하면 됩니다.
비고직접 입력 (선택)필수 아님. 필요할 때만 적습니다.

추가로 "확인"이 필요해지는 경우 (입력이 아니라 확인)

경우동작
캡처가 잘리거나 흐린 경우AI가 못 읽은 칸만 노란색으로 표시하고 그 칸만 직접 입력받습니다. 나머지 자동 입력분은 그대로 유지.
명의 자동 배정 실패캡처 속 이름·연락처가 등록된 명의와 하나도 안 맞으면, 그 캡처만 "어느 명의의 주문인가요?" 선택을 받습니다. (잘못 배정하는 것보다 물어보는 것이 안전)
내 정보와 다른 배송지·계좌현재와 동일하게 확인창을 띄우고, 새 정보면 타계정으로 등록을 제안합니다(기존 동작 유지).
💡 정리하면 — 5건 일괄 첨부 시 리뷰어가 하는 일은 ① 캡처 5장 올리기 ② 건별로 쇼핑몰 아이디 입력(또는 확인) ③ 노랗게 표시된 못 읽은 칸 보완 ④ 제출 버튼 1번. 지금처럼 5건 × 9개 항목을 손으로 쓰는 일이 없어집니다.

6새로고침 문제 — 지금 상태와 해결안

"새로고침하면 나가기 되고"의 원인을 확인했습니다.

항목지금개선 후
입력하던 글자일부 되살아남 (안내 없음)전부 되살리고 "작성하던 내용을 되살렸어요" 안내 배너 표시
첨부해 둔 구매 캡처사라짐 — 다시 첨부해야 함올린 즉시 서버에 임시 보관 → 새로고침해도 그대로 복원
보고 있던 화면(단계)처음 화면으로 돌아감작성하던 화면으로 바로 복귀
참여 자격(자리)유지됨 (문제 없음)동일 — 유지
⚠️ 캡처가 사라지는 것이 "처음부터 다시"라고 느끼게 하는 가장 큰 원인입니다. 캡처 임시 보관만 먼저 적용해도 체감이 크게 나아집니다.

8적용 결과

효과 대비 안전한 순서로 나눠 적용했습니다. 아래 1·2번은 적용 완료, 3번은 일부러 만들지 않았습니다(사유 포함).

1
새로고침 복원 보강 — 적용 완료

작성 내용과 첨부한 사진을 자동 보관하고, 되살렸을 때 "작성하던 내용을 되살렸어요" 배너로 알립니다. 사진은 용량 때문에 일부를 못 살릴 수 있는데, 그 경우 "사진 N장은 복원하지 못했어요"라고 정확히 알려줍니다(되살린 척하지 않습니다).

✅ 완료
2
캡처 일괄 첨부 + 한 번에 제출 — 적용 완료

참여 중인 명의가 2명 이상이면 구매양식이 명의별 카드로 한 화면에 펼쳐지고, 사진을 여러 장 한꺼번에 올릴 수 있습니다. 사진은 고른 순서대로 위 카드부터 들어가고, AI가 읽은 수취인이 그 카드의 명의와 다르면 카드가 알려줍니다.
★ 이름으로 자동 배정하지는 않습니다 — 자동으로 옮기다 틀리면 다른 분 이름으로 주문이 접수되고, 이건 되돌리기 매우 어렵습니다. 그래서 다를 때는 [○○ 카드로 옮기기] 또는 [제가 확인했어요]를 사람이 고르게 했고, 고르기 전에는 그 카드가 제출되지 않습니다.
참여 명의가 1명이면 기존 화면 그대로입니다.

✅ 완료
3
참여도 한 번에 — 일부러 만들지 않았습니다

명의 여러 개를 한 번에 참여시키는 버튼은 만들지 않는 편이 안전하다고 판단했습니다. 자리(참여)는 본계정 15분 · 타계정 10분이면 사라지는데, 한 번에 5자리를 잡아두고 5건을 사러 가면 돌아왔을 때 뒤쪽 자리가 이미 만료되어 있습니다. 그러면 결제는 했는데 접수가 안 돼 담당자가 하나씩 손으로 처리해야 합니다.
그래서 이번 개선은 "이미 잡아둔 자리들의 제출을 묶는 것"까지만 합니다. 만료된 자리는 카드에 ⛔ 시간 만료로 표시되고 제출에서 빠집니다.

미적용
🔒 바뀌지 않는 것 — 명의당 1건 규칙, 하루 참여 한도, 본인 확인(수취인·연락처 대조), 옵션별 정원 관리는 지금과 동일하게 유지됩니다. 화면 편의만 개선하고 참여 질서는 그대로입니다.

여러 명의로 참여할 때는 구매를 먼저 다 끝낸 뒤 마지막에 한 번에 제출하도록 안내해 주세요. 참여를 2건 이상 잡는 순간 화면에도 같은 안내가 뜹니다.
그래도 5건 결제에 10~15분은 빠듯합니다 — 다건 참여가 많은 공고는 공고 설정에서 자리 유효시간을 늘리는 것을 검토해 주세요(이 값은 시스템이 임의로 바꾸지 않았습니다).
