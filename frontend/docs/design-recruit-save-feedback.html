01 — 진단

“아무 반응 없음”의 정체 — 안내가 모달 뒤에 깔린다

저장 로직은 안내를 보내고 있습니다. 다만 리뷰웹시스템[3버전]의 토스트(.wdtoast)는 z-index:60인데 공고 모달은 z-index:5000 + backdrop-filter:blur라, 모달이 열려 있는 동안 토스트는 덮개 아래에 그려지고 블러까지 먹어 보이지 않습니다. 게다가 게시 전 자동 점검에 걸리면 저장은 전송 전에 중단되므로 모달도 닫히지 않습니다 → 사용자 눈에는 정확히 “아무 일도 안 일어남”.

스크린샷의 상태가 바로 그 경우입니다. 상태 모집중 + 참여형인데 자동 점검이 ✕ 시트 탭 연결됨 (gid) 로 빨간 상태 → 저장이 차단되고, 차단 사유는 보이지 않는 토스트로만 나갑니다. (index-recruit.js 저장 함수: 점검 실패 시 토스트 후 return)
그래서 이 시안은 두 가지를 같이 고칩니다. ① 성공 — 모달을 닫고 화면 가운데에서 알린다(요청 사항). ② 차단·실패 — 토스트에 기대지 않고 모달 안쪽에 사유를 붙인다. 덮개 위/아래 문제가 구조적으로 사라진다.

지금 동작 재현 — [저장]을 눌러보세요

가운데 카드 (기본)
