같은 사진을 두 번 내는 문제 — 왜 생기고, 어떻게 막을까

리뷰검수에 쌓인 ‘같은 파일’ 28건을 살펴본 결과와, 고르실 수 있는 해결 방법입니다. 아래에서 선택하시면 맨 아래에 정리됩니다.

한 줄로 말하면 — 리뷰어가 자기가 앞서 무엇을 냈는지 볼 수 없고, 시스템도 사진을 고르는 순간에는 같은 사진인지 확인하지 않기 때문입니다. 그래서 잘못 낸 것을 되돌릴 수 있는 시점에는 아무도 눈치채지 못하고, 제출이 다 끝난 뒤에야 관리자 검수에서 발견됩니다.

1. 실제로 어떤 일이 벌어졌나

같은 사람이 다른 작업에 백은미 — 두바이 쫀득쿠키 건에 우유크림폭탄떡 사진 지난 작업 사진을 다시 올렸습니다. 갤러리에서 비슷한 최근 사진을 잘못 고르는 경우입니다.
참고 — 이 중에는 단순 실수(어느 건에 무엇을 냈는지 몰라 같은 사진을 다시 고름)와 일부러 같은 리뷰를 재사용한 경우가 섞여 있습니다. 아래 개선을 하면 실수는 거의 사라지고, 그래도 남는 건이 곧 진짜 문제 건이라 판단이 훨씬 쉬워집니다.

2. 지금은 왜 못 막나 — 리뷰어가 겪는 순서

1단계
사진 고르기
휴대폰 갤러리에서 캡처를 고릅니다. 최근 사진들이 서로 비슷하게 생겼습니다.
화면 어디에도 “내가 이 작업에 이미 낸 사진”이 보이지 않습니다.
2단계
사진을 붙이는 순간
시스템이 “리뷰 화면이 맞는지, 어느 쇼핑몰인지”만 자동으로 확인합니다.
이때 같은 사진인지는 전혀 보지 않습니다. 그래서 그대로 통과합니다.
3단계
제출
사진이 저장되고 시트에도 반영됩니다.
이때 확인하는 중복은 “같은 줄에 같은 칸”뿐입니다 — 다른 줄·다른 작업은 그냥 통과합니다.
4단계
완료 화면
“제출됐습니다.”
리뷰어는 잘못 냈다는 걸 모른 채 끝냅니다.
5단계
며칠 뒤 관리자 검수
그제서야 같은 사진이라는 게 발견됩니다.
이미 저장·반영된 뒤라 관리자가 지우고 다시 받아야 합니다(지금 보고 계신 28건).

어느 시점에 무엇을 보고 있나

확인하는 시점같은 줄에 다시 올림같은 작업 다른 줄다른 작업
① 사진을 붙이는 순간안 봄안 봄안 봄
② 제출해서 저장될 때봄(교체로 처리)안 봄안 봄
③ 제출이 끝난 뒤 검수대상 아님(정상 재제출)봄 → 사후봄 → 사후

→ 리뷰어가 스스로 고칠 수 있는 시점(사진 붙이기 전)에는 아무도 중복을 보지 않습니다.

3. 이렇게 바꾸면 됩니다

1단계
제출 화면에 들어가면
그 작업에서 내가 이미 낸 사진과 건별 제출 현황을 먼저 보여줍니다.
‘무엇을 냈는지 모르는 상태’ 자체가 없어집니다. (방법 B)
2단계
사진을 붙이는 순간
같은 사진이면 그 자리에서 “이미 ○○에 낸 사진이에요”라고 알려줍니다.
아직 저장 전이라 사진만 바꾸면 끝입니다. (방법 A · 핵심)

4. 골라주세요

아래 세 가지만 정해주시면 그대로 만들겠습니다. 고르면 맨 아래에 정리됩니다. 그냥 두시면 추천으로 진행합니다.

① 같은 사진을 붙였을 때, 어떻게 할까요?
사진을 고르는 순간 같은 사진이라는 걸 알려주는 것까지는 공통입니다. 그 다음이 다릅니다.
② 어디까지 비교해서 “같은 사진”이라고 할까요?
비교 대상은 그 리뷰어 본인이 과거에 낸 사진입니다(남의 사진과 비교하는 게 아닙니다).
③ 제출 화면 위에 “내 제출 현황”을 보여줄까요?
한 사람이 같은 작업에 여러 건 참여할 때, 어느 건에 무엇을 냈는지 보여주는 목록입니다.
고르신 내용
① 같은 사진일 때 — 알려주고 리뷰어가 선택(추천)
② 비교 범위 — 본인이 낸 모든 작업의 사진(추천)
③ 내 제출 현황 표시 — 보여준다(추천)

5. 참고 — 만들 때 지킬 것

  • 같은 건에 다시 올리는 것은 막지 않습니다. 사진을 잘못 올려 다시 올리는 것은 정상적인 재제출이라, 이것까지 막으면 멀쩡한 리뷰어가 갇힙니다.
  • 화면 개선으로 없앨 수 있는 것은 ‘실수’까지입니다. 일부러 같은 리뷰를 재사용하는 경우는 다른 사진으로 우회하므로, 관리자 알림과 ‘리뷰 글 겹침’ 검사는 계속 남깁니다.
  • 추가 비용은 거의 없습니다. 사진마다 구분 표식을 이미 저장해 두고 있어서, 붙이는 순간 확인하는 데 드는 시간은 눈에 띄지 않습니다.
  • 업체 전달물은 그대로입니다. 이 변경은 리뷰어 화면과 관리자 알림에서만 일어납니다.
