1한 줄 요약

두 주 동안 한 일을 한 문장으로.

요약

1주차에는 시스템 작업표만으로 기존 기록을 똑같이 만들어내는 장치를 만들었고, 2주차에는 그 장치 위에서 작업 한 건이 접수 → 리뷰어 검색 → 구매양식 제출 → 리뷰 캡처 저장까지 구글에 한 번도 묻지 않고 완결되게 했습니다. 아직 어떤 작업에도 켜지 않았습니다 — 켜는 화면과, 이미 진행 중인 작업을 옮기는 공사가 남아 있습니다.

2지금 화면에서 달라진 것

직원·리뷰어·업체가 오늘 느낄 변화를 그대로 적었습니다.

✓ 여전히 아무것도 달라지지 않았습니다 (의도한 결과입니다)

두 주 내내 스위치는 전부 꺼진 상태로 배포됐습니다. 새로 만든 길은 "무시트"로 표시된 작업에서만 열리는데, 지금 그렇게 표시된 작업이 한 건도 없습니다.

보는 사람오늘 달라지는 것상태
리뷰어없음 — 검색·참여·리뷰 제출 모두 종전 그대로변화 없음
직원(작업보드)없음 — 작업 목록·표·마감 모두 종전 그대로변화 없음
업체(광고주)없음 — 접속 링크·표·정산 모두 종전 그대로변화 없음
구글시트없음 — 읽기·쓰기 모두 종전 그대로변화 없음
인트라넷 리뷰오더칸 2개가 늘었습니다 — [주말 제외](기본 켬) · [휴무일]칸 추가
⚠ 유일하게 눈에 보이는 변화 — 인트라넷 리뷰오더 폼

오더를 낼 때 주말을 빼고 진행할지와 쉬는 날을 적는 칸이 생겼습니다. 비워 두어도 종전과 똑같이 동작합니다(주말은 기본으로 빠집니다). 적어 두면 리뷰웹에서 작업표를 만들 때 그 규칙이 미리 채워져 담당자가 매번 다시 지정하지 않아도 됩니다.

6직원이 손으로 하던 일이 어떻게 바뀌나

전환이 끝났을 때 실제 업무가 어떻게 달라지는지입니다.

지금 하는 일전환 후준비

업체에 구글시트를 공유 업체 전용 접속 링크만 사용(이미 있는 기능) — 시트 공유 자체가 없어짐 전환 시
진행 중인 작업을 시트에서 계속 관리 기존 작업도 전부 시스템으로 이관 남은 공사

7공사 중에 잡은 위험

만들면서 실제로 발견해 막은 것들입니다. 전부 "조용히 잘못되는" 종류입니다.

  • 자동작업이 편집을 되돌리는 문제 — 5분마다 도는 자동작업 한 곳을 빠뜨려, 시스템에서 고친 내용이 옛 시트 값으로 덮이던 경로(1주차, 테스트가 검출).
  • 구매양식이 시트로 새는 경로 — 이관 전에 이미 대기줄에 쌓여 있던 건들이 나중에 시트에 써지지 않도록, 마지막 관문에서 한 번 더 막았습니다.
  • 중간에 실패했는데 "완료"로 찍히는 경로 — 기록 생성이 실패하면 완료로 표시하지 않고, 리뷰어↔줄 연결도 남기지 않습니다(잘못 남으면 남의 참여 내역이 열립니다).
  • 주문이 몰릴 때 검색 명단이 잠깐 비는 창 — 기록을 다시 만드는 동안 겹치면 명단이 순간 비어 리뷰어에게 "내 참여가 사라진" 것처럼 보입니다. 작업 단위로 순서를 잡아 겹치지 않게 했습니다.
  • 폴더가 두 곳으로 갈라지는 경로 — 폴더 이름을 정하는 곳이 세 군데인데, 하나라도 다르면 같은 작업의 캡처가 두 폴더에 생깁니다. 한 곳에서만 정하게 묶었습니다.
  • 조절 창구가 잠기는 경로 — §5④의 빨간 상자. 두 조각을 함께 내보내 막았습니다.
  • 배포 시차에 주말 제외가 꺼지는 경로 — §5⑤의 노란 상자.

8검증 결과

"됐다"고 말하기 전에 무엇으로 확인했는지입니다.

일부러 고장 내 보기에서 드러난 것 — 점검 자체가 약했던 4건

"코드를 망가뜨렸는데 점검이 통과"한 경우가 4건 있었습니다. 전부 점검이 구현을 그대로 따라가는 형태였습니다 (예: 상한을 400에서 999999로 바꿨더니 기대값도 함께 999999가 되어 통과). 기대값을 점검 쪽에 못 박아 네 건 모두 잡히도록 고쳤습니다. 점검이 통과했다고 안전한 게 아니라, 점검을 깨뜨려 봐야 알 수 있습니다.

9아직 못 하는 것

지금 상태의 한계를 그대로 적었습니다.

  • 스위치를 켜는 화면이 없습니다 — 무시트 표시는 아직 사람이 화면에서 켤 수 없습니다(전환 관리 화면이 남은 공사).
  • 지금 켜면 안 됩니다 — 입금 처리·마감자료 같은 뒤쪽 단계가 아직 시트를 전제로 동작합니다.
  • 진행 중인 작업은 아직 옮길 수 없습니다 — 기존 작업 이관(점검 → 줄 맞추기 → 대조 → 연결 끊기)이 남아 있습니다.
  • 업체에 나가는 시트 공유는 전환과 함께 자연히 없어집니다(전용 접속 링크로 대체 — 이미 있는 기능).
되돌리기

두 주 동안의 변경은 전부 추가이고 기존 동작을 고친 곳이 없습니다. 문제가 생기면 새로 생긴 표시·기능을 끄는 것만으로 즉시 종전 상태가 됩니다.

10전체 일정에서 지금 위치

완전 전환까지 남은 단계입니다.

  1. 1주차 — 기록을 만들어내는 장치 완료
    무시트 표시 · 작업표 → 기록 3권 생성기 · 자동작업 4곳 단속
  2. 2주차 — 작업 한 바퀴 완료
    시트 없는 접수 · 주문 즉시 완결 · 폴더 업체명 · 그날 정원 달력 · 인트라넷 일정 신호
  3. 3주차 — 뒤쪽 단계 잇기 다음
    입금 처리·마감자료가 무시트 작업에서도 돌게 하고, 화면을 하나로 정리
  4. 4주차 — 전환 관리 화면
    사람이 스위치를 켜는 화면 + 켜기 전 자동 점검표(조건 미달이면 못 켜게)
  5. 5주차 — 기존 작업 전량 이관
    진행 중인 작업을 하나씩 점검 → 줄 맞추기 → 대조 → 연결 끊기(되돌릴 비상구 유지)
  6. 완료 — 시트를 읽는 작업 0건
    구글시트 공유·수기 입력이 업무에서 사라짐
✓ 지금 상태를 한 문장으로

새 길은 끝에서 끝까지 뚫렸고, 아직 차를 올리지 않았습니다. 올릴 준비(3~4주차)와, 지금 달리는 차를 옮기는 일(5주차)이 남았습니다.
