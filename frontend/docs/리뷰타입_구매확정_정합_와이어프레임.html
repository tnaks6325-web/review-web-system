맞춰야 하는 항목

인트라넷에서 리뷰타입 = 구매확정으로 오더를 넣으면, 그 값이 작업오더 → 모집공고 → 리뷰어 제출 → AI 검수까지 끊기지 않고 이어져야 합니다. 지금은 작업오더까지만 도착하고 그 뒤가 비어 있습니다. 아래는 그 사이를 잇기 위해 손대야 하는 항목 전부입니다.

⚠ 지금 이대로 구매확정 오더를 받으면 — 리뷰어가 캡처를 못 붙입니다

구매확정 완료 화면은 AI가 kind='other'(리뷰도 영수증도 아님)로 판정합니다. 첨부 즉시 도는 1차 필터가 확신 0.9 이상이면 첨부를 잠급니다 — reviewInspect.service.js 의 precheckPolicy.

2번 잠기면 “제가 올린 게 맞습니다” 우회 체크가 열리긴 하지만, 정상 제출이 매번 경고를 맞는 상태입니다.

🚑 급할 때 즉시 회피 — Railway 환경변수 REVIEW_PRECHECK_BLOCK=0 (판정은 하되 잠그지 않는 관측 모드). 배포 없이 지금 바로 적용 가능합니다.

5손대는 순서

0역방향 안전핀 (E1) — 지금 리뷰어가 잠기는 경로부터 막습니다. 이것만 먼저 나가도 사고는 멈춥니다.
1용어·값 통일 (A1~A5) — 라벨과 선택지. 위험 낮고 화면만 바뀝니다.
2판정 단일 출처 + 스키마 (D2 · B5 · A3 데이터 이관) — utils/reviewType.js 와 migration 087. 기존 행을 건드리는 유일한 단계라 미리보기 건수를 먼저 확인하고 진행합니다.
3입력 경로 (B4 · C1~C4) — 작업오더 프리필과 공고 모달 선택지.
4제출 슬롯 (D1 · D3~D6) — 소비처 4곳을 한 커밋에서 함께.
5AI 판별 나머지 (E2~E6) — 예시이미지 등록 후 경고 → 잠금 전환 검토.
6회귀가드 — 인트라넷 실측 문자열 파싱 · 소비처 4곳 배선 · 역방향 비차단 · 캐시 지문 분리.

1차 PR = 0~2단계(안전핀 + 용어 통일 + 스키마) · 2차 PR = 3~6단계를 권합니다.
