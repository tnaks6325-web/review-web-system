📋 새 기능 안내 — 캠페인탭 참여자 명단을 시스템에서 직접 관리

지금까지 구글시트로만 하던 캠페인 참여자 관리를, 시스템 안에서 확인·편집할 수 있게 준비했습니다. (현재 안전 테스트 단계)

한 줄 요약 — 캠페인탭의 참여자 명단(리뷰어 목록 + 리뷰제출·입금 표시 + 차수·상품)을 구글시트를 열지 않고도 시스템 화면에서 보고·고칠 수 있게 만드는 중입니다. 지금은 테스트 저장공간에서만 동작하며, 실제 서비스(리뷰어·구글시트)에는 아무 영향이 없습니다.

1. 왜 만들었나요?

  • 시트는 탭마다 제각각 — 헤더 위치·이름이 달라(예: 리뷰제출 vs 리뷰) 시스템이 잘못 읽는 경우가 있었습니다.
  • 이중 관리 — 입금·상태가 시트와 시스템에 따로 있어 안 맞을 수 있었습니다.
  • → 참여자 명단의 "진짜 원본"을 시스템(DB)으로 옮기면, 이런 혼선이 사라지고 관리가 한 곳에서 됩니다.

2. 전체 그림 (아주 쉽게)

구글시트지금까지의 원본
→
시스템으로 가져오기명단을 복사
→
시스템에서 관리보기·추가·수정·삭제
→
(선택) 시트로 되보내기원하면 시트도 최신

지금은 가운데 두 칸(가져오기·시스템에서 관리)까지 테스트할 수 있습니다. 맨 오른쪽(시트로 되보내기)은 준비만 해두고 꺼져 있습니다.

4. 사용 흐름 (단계별)

1
탭 선택 — 위 셀렉터에서 관리할 캠페인 탭을 고릅니다.
2
미리보기 — 그 탭 시트에서 몇 명이 들어올지 먼저 확인합니다. (저장 안 함)
3
명단 가져오기 — 시트의 참여자 명단을 시스템으로 복사합니다.
4
명단 보기 / 관리 — 리뷰제출·입금 체크, 참여자 추가·수정·삭제를 시스템에서 바로 합니다.
5
원본과 비교 — 시스템 명단이 시트와 같은지 한 번에 확인합니다.

5. 꼭 알아둘 점 (안전)

✅ 지금은 전부 "테스트 저장공간"에만 반영됩니다. 여기서 무엇을 하든 리뷰어 화면·검색·구글시트·주문은 전혀 바뀌지 않습니다. 마음껏 눌러보셔도 실제 업무에 영향이 없습니다.
🔑 지금은 최고관리자(master) 전용입니다. 일반 관리자·AE담당자 화면에는 아직 나타나지 않습니다. 충분히 검증한 뒤 단계적으로 넓힐 예정입니다.

6. 앞으로 (단계 로드맵)

단계내용상태
1시트 명단을 시스템으로 가져오기 · 보기 · 비교사용 가능

기반시스템 명단을 자동으로 최신 유지준비됨·꺼짐

각 단계는 오류 검증(적대적 검토)을 거쳐, 문제가 생기면 즉시 되돌릴 수 있게 켜고 끄는 스위치로 도입합니다.
