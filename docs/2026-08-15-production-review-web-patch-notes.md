# 2026-08-15 리뷰웹시스템 운영 반영 노트

## 적용 범위

- 작업오더의 구매채널·담당자·모집인원·일건수·구매시간대를 모집공고 프리필에 반영합니다.
- 유입가이드·리뷰가이드·특이사항의 이미지를 각 구역 미리보기로 표시합니다.
- 이미지 HTML이나 첨부 메타 문구가 가이드 텍스트 입력칸에 섞이지 않게 합니다.
- 시트 탭이 없는 작업오더도 모집공고를 저장할 수 있게 합니다.
- 모집공고 저장 버튼의 실패 사유와 성공 안내를 명확히 표시합니다.
- 링크유입의 선택 옵션 URL을 모집공고·리뷰어 흐름에 반영합니다.
- 관리자용 리뷰어 화면 미리보기를 제공합니다. 미리보기는 실제 신청·홀드·주문을 만들지 않습니다.
- 모집공고 편집 화면에서 작업오더 상품명·가격을 중복으로 표시하던 요약 영역을 제거합니다.

## 안전 조치

- 리뷰·특이사항 이미지는 텍스트 영역이 아닌 구역별 이미지 배열로 분리합니다.
- 미리보기 경로는 관리자 인증과 전용 플래그가 모두 있어야 하며 실제 참여 데이터를 만들지 않습니다.
- 시트가 없는 공고는 명시적으로 미연결 상태로 저장해 임의의 작업표 연결을 막습니다.
- 작업오더 구매채널 컬럼은 서버 기동 시 멱등 방식으로 보완합니다.

## 제외한 테섭 전용 변경

- 테스트 Railway API 주소
- 테스트 자동로그인 엔드포인트 및 `TEST_AUTO_LOGIN` 설정
- 테스트 프런트엔드 Origin CORS 허용

위 설정은 운영 인증 경계와 운영 데이터를 보호하기 위해 본섭에 반영하지 않습니다.

## 검증

- 작업오더 자동 프리필 및 구매채널 매핑
- 가이드 텍스트·구역별 이미지 분리
- 시트 없는 공고 저장
- 링크유입 옵션 URL
- 관리자 미리보기의 비쓰기 보장
- 모집공고 저장 성공·실패 피드백

## 추가 운영 반영 — 작업오더 ↔ 모집공고 연결

- 작업오더 상세에서 모집공고를 처음 저장할 때, 공고 ID를 작업오더에도 기록하는 역방향 연결을 보완했습니다.
- 리뷰웹 SSO 작업화면은 일반 관리자 주문 API 대신 Track B 전용 갱신 경로를 사용합니다. 따라서 SSO 권한 경계는 유지하면서 연결만 갱신합니다.
- 저장 후 `공고는 등록됐으나 작업오더 연결에 실패했습니다`라는 잘못된 경고가 발생하지 않도록 수정했습니다.

### 검증 결과

- 테섭에서 작업오더 `TEST-E2E-이미지·구매채널-20260815`로 공고를 저장했습니다.
- 저장 성공 후 작업오더의 버튼이 `📢 모집공고`에서 `👁 모집공고`로 변경되어 연결값 저장을 확인했습니다.
- 구매채널, 담당자, 구매시간대, 모집인원·일건수, 가이드 텍스트와 리뷰·특이사항 이미지는 저장 과정에서 유지됐습니다.

### 배포 정보

- 운영 커밋: `dcc15fa` (`fix: link workdesk campaigns through trackb`)
- 운영 API(Railway) 재기동 및 운영 웹 화면의 최신 코드 제공을 확인했습니다.

## 추가 운영 반영 — 모집인원 조절과 작업표 동기화

### 변경 내용

- 모집인원 조절을 저장하면 해당 날짜의 무시트 작업표 빈 준비 행도 같은 인원으로 즉시 재배치합니다.
- 기존 작업표에 없던 날짜를 0명에서 늘리면 필요한 빈 행을 생성해 그 날짜로 배정합니다.
- 조절 후에는 작업표 원장(`campaign_participants`)을 기준으로 작업보드의 검색·목록 투영을 즉시 재생성합니다.
- `기본으로`를 저장하면 조절 계획만 삭제하지 않고, 최초 조절 전 보관한 날짜별 작업표 인원으로 함께 복귀시킵니다.
- 작업보드 투영 재생성에 실패하면 저장 성공으로 표시하지 않고 오류를 알려주며, 같은 저장 동작으로 재시도할 수 있습니다.

### 안전 장치

- 이미 참여자·수취인·주문이 있는 행은 이동하거나 삭제하지 않습니다.
- 최초 기준값이 기록되기 전의 과거 조절 건은 추측으로 복구하지 않습니다. 이 경우 기준 확인 안내를 표시해 작업표 훼손을 막습니다.
- 시트 기반 작업표에는 이 역동기화를 적용하지 않습니다.

### 검증 결과

- 테섭에서 0명 날짜를 5명으로 조절해 작업표 5행 생성 및 작업보드 투영 재생성을 확인했습니다.
- 같은 날짜를 `기본으로` 복귀해 조절 계획 삭제와 작업표 5행 제거를 확인했습니다.
- 회귀 테스트: 모집계획 279개, 무시트 작업표 58개, 장부 53개 통과했습니다. 실제 PostgreSQL 통합 테스트 2개는 별도 `PGTEST_URL` 미설정으로 제외했습니다.

### 배포 정보

- 운영 커밋: `6cfe487` (`fix: restore worktable defaults on plan reset`)
- 포함 커밋: 작업표 행 동기화, 주말 0명 표시, 대량 작업표 투영 배치화, 저장 후 작업보드 재생성.
