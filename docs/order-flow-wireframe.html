📦 구매양식 제출 흐름

리뷰어가 구매양식을 제출하면 → 먼저 서버 DB에 저장 → 몇 초 뒤 구글시트에 자동 기록됩니다.

🟦 리뷰어 화면 ⬜ 서버(자동) ⬛ 구글시트 · 점선 박스 = 서버 DB(원장)

🔑 직원이 꼭 알아야 할 3가지

  • ① DB가 먼저, 시트는 나중. 제출하면 서버 DB에 즉시 저장돼 절대 사라지지 않습니다. 구글시트 칸은 보통 2~5초 뒤 자동으로 채워집니다(잠깐 비어 보여도 정상).
  • ② 시트가 비어 보이면 "상태"를 보세요. 관리자 대시보드의 "구매주문 시트반영 현황" 위젯에서 대기/완료/문제를 한눈에 봅니다.
  • ③ 노란 배경 행은 자동복구분. 시스템이 뒤늦게 채운 줄입니다. 직원이 손으로 넣은 줄·정상 줄과 구분하려고 색을 입힙니다.
