# 2026-08-18 오늘 미제출 제한 해제 개선

## 변경 내용

- 작업보드의 **오늘 미제출 제한 해제** 기능이 특정 공고 두 건에 고정되지 않습니다.
- 실행 시 현재 활성 모집공고를 불러오고, 공고명 또는 채널로 검색한 뒤 한 건을 선택할 수 있습니다.
- 선택한 공고명을 다시 확인한 후에만 제한 해제를 실행합니다.

## 안전 장치

- 관리자 또는 마스터 권한에서만 실행할 수 있습니다.
- 서버는 받은 공고 ID가 현재 `active` 상태인지 다시 확인합니다.
- 선택 공고의 당일(KST) `applied` 상태 홀드만 해제합니다.
- 구매양식 제출 완료 건과 작업보드 기록은 변경하지 않습니다.
- 실행자, 공고 ID·명칭, 해제 건수는 운영 로그에 기록합니다.

## 검증

- 활성 공고 목록 조회와 선택 공고 ID 전달을 확인했습니다.
- 비활성·빈 공고 선택은 서버에서 차단합니다.
- 제출 완료 상태는 해제 대상에서 제외되는 회귀 테스트를 통과했습니다.
- 테섭 `TEST_REVIEW` 배포에서 선택 팝업 코드 반영을 확인했습니다.
