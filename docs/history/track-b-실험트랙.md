- **부품3 parity**(`parityReport`/`classifyParity` 순수함수, master): **phone8 짝짓기**(행번호 금지) → 일치 / 의도된차이(BD-3 dedup·BD-6 manual·BD-8 편집) / **진짜 불일치**. 게이트 = real 0. 준비도 `_readinessFor`(d4 작업발주 정형필드 충실도·d5 업체 소유 지정·d6 공용 주문원장 귀속)는 **data-parity(d1~d3) pass와 분리한 별도 신호**. 회귀가드 `tests/trackB.test.js`.
- **부품3b 관측 대시보드 = cutover 결정 허브(fail-closed)**: `overview()`가 신호를 **`cutoverCandidate`(경량 triage=시트원본·카운트일치·소유·발주·비유령)** 와 **`cutoverReady`(=candidate+신선한 정밀 스냅샷 real=0, `TRACK_B_PARITY_FRESH_HOURS` 기본 24h)** 로 분리 노출(★약한 신호에 강한 이름 금지 — `cutoverReady`를 real 게이트 없이 재정의하지 말 것) + `ghost`(A·B 활성 0행 아카이브/리네임 잔재 — 0==0 준비 오판 차단) + `lastParity{real,takenAt,fresh}` + **write-back 건강 = 토글 스코프 `writeback{engineOn,pending,held,blocked}`**(pending=미시도 NULL — gate_off/스윕양보가 '정상'으로 못 샘) + `editCount`/`editToggle` 분리. **플립 게이트 fail-closed**: parity 계산 실패=`parity_check_failed` 거부(구 `.catch(()=>null)` fail-open 봉합), A·B 0행=`empty_tab` 거부, force만 우회(UNVERIFIED 로그) — UI force는 **탭명 타이핑** 마찰. raw_sheet_tabs 조인은 **LATERAL 최신 1행**(동명탭 곱증식 차단). `/parity`는 adminOrMaster(관측 뷰 [정밀] dead-end 해소, 샘플 phone8 `_mask`). 관측 뷰: 세션 [정밀] 30분 TTL·스냅샷 신선도('정밀 만료' 강등)·유령 배지·구백엔드 응답 `?`(배포 스큐 허위 정상 차단). 읽기전용. 회귀가드 `tests/trackBOverviewCutover.test.js`·`tests/trackBSourceOfTruth.test.js`.
- **부품3c 투영 커버리지(투영완료/총작업 · 미투영 N)** — 관측 화면 상단 요약, 읽기 전용. ★★ **왜 필요한가**: `overview()`는 `campaign_participants`에서 시작하므로 **한 번도 투영되지 않은 탭은 목록에 아예 안 뜬다** → 화면만 보면 목록이 짧은 게 "작업이 적어서"인지 "투영이 안 돼서"인지 구분되지 않는다. `projectionCoverage()`가 **분모(현재 투영 대상 활성 탭)** 를 따로 세어 그 눈속임을 없앤다.
  - ★★ **투영 대상 정의는 `participants.listActiveTabs()` 하나만**(SQL 사본 금지) — `projectActive`(크론)가 대상으로 삼는 목록과 같아야 "미투영 = 크론이 아직 안 만든 것"이 성립한다. ★★ **투영완료 판정은 `overview()`가 돌려준 items 를 그대로 재료로** 쓴다(라우트가 `projectedTabs`로 주입) — 같은 집합을 두 번 정의하면 갈라지고, 덤으로 같은 테이블 재스캔도 없앤다(단독 호출만 직접 조회 폴백). 활성 0행(유령)은 **투영은 된 것**이라 미투영이 아니다(그건 `ghost` 담당).
  - ★ **미투영 사유를 화면이 설명한다**(숫자만 두면 원인을 못 찾는다): `projectionOn`(=`TRACK_B_PROJECTION`, OFF면 크론이 **등록조차 안 됨**) · `cronBatchLimit`(=`projectActive` 기본 limit **100** — 활성 탭이 이보다 많으면 정렬 뒤쪽은 그 사이클 대상이 안 된다. 회귀가드가 **실행으로 대조**해 하드코딩 드리프트 차단) · `truncated`(분모 자체가 잘림). 미투영 칩 클릭 = 읽기 전용 목록 모달(서버 sample 상한까지, 잘리면 고지).
  - ★ **기존 `투영 N탭` 칩과 합치지 않는다** — 그건 *목록 행 수*(지금은 비활성/아카이브된 탭 잔재 포함)이고 새 분모는 *현재 활성 탭*이라 의미가 다르다. ★ 라우트는 **fail-soft**(커버리지가 죽어도 관측 목록은 뜬다) + 프론트는 **필드 부재(구버전 백엔드)=칩 미표시 / null(조회 실패)=`미투영 ?`** 로 구분(배포 스큐 허위 정상 차단).
  - ⚠ **소스에 리터럴 NUL 을 넣지 말 것**(이 작업에서 실제로 밟음): 복합키 구분자를 문자 그대로 적었더니 git 이 파일을 **바이너리로 취급**해 grep 이 죽었다 — `'\u0000'` **이스케이프 표기**를 쓴다(회귀가드가 고정).
