# InAd 리뷰어 — 시안 C 디자인 언어 (미니멀 토스풍 모바일 앱)

> 이 문서는 "시안 C"를 모든 페이지에 일관되게 적용하기 위한 디자인 스펙이자, LLM/디자이너에게 바로 넣을 수 있는 프롬프트입니다.
> 기준 파일: `frontend/mockups/sian-c.html`

---

## 0. 한 줄 요약
**토스(Toss)처럼 깔끔한 모바일 앱.** 흰 배경 · 얇은 회색 구분선 · 플랫 카드 · 중성 톤 · 작고 또렷한 타이포 · **하단 탭바 네비게이션** · 폰 프레임(좌우 여백). 보라색(`#5046E4`)은 포인트로만 절제해서 사용.

## 1. 레이아웃 원칙 (가장 중요 — 이게 빠지면 "시안 C 아님")
- **폰 프레임**: 콘텐츠 전체를 `max-width: 440px`로 가운데 정렬. 데스크톱에선 양옆 회색 여백(`#EDEEF2`)에 흰 앱이 떠 있는 형태. 모바일에선 꽉 참.
- **하단 고정 탭바(Bottom Tab Bar)**: 화면 하단에 4개 탭 — `모집공고 / 내 참여현황 / 내정보 / 가이드`. 상단 탭(세그먼트) 쓰지 않음. 본문 하단 패딩 `~80px`로 탭바와 안 겹치게.
- **상단 앱바**: 화면마다 큰 굵은 타이틀(좌측 정렬, 1.5rem/800) + 부제(작은 회색). 보라 그라데이션 헤더 금지(흰색 미니멀).
- **스크롤 단위는 한 화면**: 탭 전환 = 화면 전환(콘텐츠 교체), 페이지 새로 안 뜸.

## 2. 컬러 토큰
```
--p:  #5046E4   /* 포인트(보라) — 버튼/활성/강조에만 */
--p-d:#3730A3   --p-l:#F2F1FE
--ok: #1FB471   --ok-l:#E7F8F0     /* 모집중/완료 */
--warn:#F59E0B  --warn-l:#FEF6E6
--err:#EF4444
--bg: #FBFBFD   /* 앱 배경(거의 흰색) */   바깥여백:#EDEEF2
--card:#fff
--bd: #EFEFF3   /* 얇은 구분선/보더 */     --bd2:#E6E6EC
--t1:#191F28  --t2:#6B7280  --t3:#ADB3BE   /* 텍스트 3단계 */
--radius:16px
```
채널 색: 네이버 `#03C75A` · 쿠팡 `#E5392B` · G마켓 `#1BA641` · 스마트스토어 `#03C75A` · 11번가 `#FF0038`.

## 3. 타이포그래피
- 폰트 `Noto Sans KR`, `letter-spacing:-.01em`(타이틀 -.02~-.03em).
- 화면 타이틀 1.5rem/800 · 섹션 타이틀 1.0rem/800 · 본문 .88~.92rem/600 · 보조 .7~.78rem/500 (`--t3`).
- 가격/리뷰비/숫자 강조는 800 + 포인트 컬러.

## 4. 컴포넌트
- **카드**: `background:#fff; border:1px solid #EFEFF3; border-radius:16px; box-shadow:0 1px 6px rgba(17,24,40,.03)`. 그림자 거의 없음(플랫).
- **하단 탭**: 흰 배경 + `backdrop-filter:blur` + 상단 얇은 보더. 아이콘(1.1rem)+라벨(.65rem). 비활성 `--t3`, 활성 `--t1`(또는 포인트).
- **칩/필터**: 흰 배경 + `1px #E6E6EC` 보더 + radius 10. 활성 = 어두운 `#191F28` 배경 흰 글자.
- **버튼(주요)**: 배경 `#5046E4`, 흰 글자, radius 13~14, weight 700, padding 15~16. press 시 `#3730A3`.
- **입력**: 배경 `#F1F2F6`, 보더 없음, radius 13. 포커스 시 흰 배경 + 안쪽 포인트 링(`inset 0 0 0 1.5px #5046E4`). 라벨은 위에 작게(.78rem/600 `--t2`).
- **리스트 행(li)**: 좌측 회색 아이콘 박스(36px, radius 11) + 라벨 + 우측 값. 항목 사이 `1px #EFEFF3` 구분선. 탭 가능 행은 우측 `›`.
- **상태칩**: 모집중=`--ok-l/#0E7A4B`, 마감/비활성=`#F1F2F6/#A8AEBA`, 대기=`--warn-l`.
- **세그먼트 토글**(카드/행 전환): 배경 `#ECEDF2` 인셋, 활성 버튼 = 흰 알약 + 포인트 아이콘 + 옅은 그림자.

## 5. 모집공고 카드 — 카드/행 전환 (필수 기능)
모집공고 섹션 우상단에 **행(☰)/카드(▥) 전환 아이콘**. 선택값 `localStorage('inad_recruit_view')` 저장.
- **행(row) 뷰**: `[썸네일 56px] [채널칩+상태칩+담당 / 제목 / 리뷰비·배송·시간·모집현황] [우측 모집 N/M]` — 1열 리스트.
- **카드(card) 뷰**: 2열 그리드. 상단 썸네일(배너), 아래 제목(2줄 클램프) · 리뷰비 · 모집현황. 긴 안내문/뱃지는 숨김.
- 썸네일: 채널 이모지(네이버 📗 쿠팡 📦 G마켓 🛒 스토어 🟢) + 좌상단 채널칩(채널 색).

## 6. 화면별 구성
- **로그인(히어로)**: 상단 헤더 없이, 좌측 정렬 큰 타이틀 2줄("리뷰하고 페이백 받는 / **InAd 리뷰어**", 2번째 줄 포인트색) → 라벨형 입력(이름 / 전화 뒤8자리, `010` prefix) → 풀폭 로그인 버튼 → "처음이신가요? 인애드 등록하기 →" → 하단에 모집공고 1건 알림 카드.
- **모집공고**: 앱바(모집공고 + "총 N개") → 검색바(회색 pill) → 채널 칩 필터 → "모집중 N" + 카드/행 토글 → 목록.
- **내 참여현황**: 앱바 → 검색 → 상태 세그먼트(진행중/완료 큰 숫자 + 수정필요/리뷰대기/페이백/한달리뷰/취소·반려/참여가능 미니) → 서브탭 → 리스트(없으면 빈 상태 + "캠페인 둘러보기").
- **내정보**: 프로필 카드(아바타+이름+가입정보) → 내 등록정보(사용자명/전화/소득명의/주민번호, 미등록은 빨강 + 추가+) → 타계정 정보(N/10, 행마다 수정/삭제, 추가) → 계좌 관리(없으면 빈 상태 + 계좌 추가) → 관리(배송지/스토어계정/로그아웃 탭 행).
- **첫 이용 온보딩**: 하단 시트(핸들 바) + 아이콘 + 3스텝(캠페인 찾기 → 신청&구매 → 페이백) + "시작하기"/"다음에". `localStorage('inad_onboarded')`로 1회만.

## 7. Do / Don't
- ✅ 흰 배경, 얇은 회색 구분선, 플랫 카드, 넉넉한 여백, 작고 또렷한 글자.
- ✅ 보라색은 버튼·활성·숫자 강조 등 "포인트"로만.
- ✅ 폰 프레임 + 하단 탭바(앱처럼).
- ❌ 보라 그라데이션 헤더, 큰 그림자, 진한 테두리.
- ❌ 상단 가로 탭(세그먼트)로 주 네비게이션 대체(시안 C는 하단 탭).
- ❌ 정보 과밀(한 카드에 모든 텍스트 다 노출) — 핵심만, 나머지는 상세/클램프.

## 8. 바로 쓰는 프롬프트 (복사용)
```
InAd 리뷰어 웹앱을 "시안 C(미니멀 토스풍 모바일 앱)" 디자인으로 만들어줘.
- 레이아웃: 콘텐츠 max-width 440px 가운데 정렬(폰 프레임), 데스크톱은 양옆 #EDEEF2 여백. 하단 고정 탭바(모집공고/내 참여현황/내정보/가이드) 네비게이션. 상단은 흰색 미니멀 앱바(큰 굵은 타이틀+회색 부제). 보라 그라데이션 헤더 금지.
- 컬러: 포인트 #5046E4(버튼/활성/숫자 강조에만), 배경 #FBFBFD, 카드 흰색+1px #EFEFF3 보더+거의 없는 그림자, 텍스트 #191F28/#6B7280/#ADB3BE, radius 16. 채널색 네이버#03C75A 쿠팡#E5392B G마켓#1BA641 스마트스토어#03C75A.
- 폰트 Noto Sans KR, letter-spacing -.01em. 타이틀 1.5rem/800, 본문 .9rem/600.
- 컴포넌트: 플랫 카드, 회색 pill 검색바, 흰 칩(활성=어두운 배경), #F1F2F6 입력(포커스 포인트 링), 좌측 아이콘박스 리스트 행, 상태칩(모집중=초록 옅음/마감=회색).
- 모집공고 목록: 우상단 행(☰)/카드(▥) 전환 토글(localStorage 저장). 행=썸네일 좌측 1열 리스트, 카드=2열 그리드(썸네일 상단). 썸네일=채널 이모지+좌상단 채널칩.
- 화면: 로그인(헤더 없는 히어로: 큰 2줄 타이틀+라벨 입력+풀폭 버튼+하단 모집 알림), 모집공고, 내 참여현황(상태 세그먼트+빈상태), 내정보(등록정보/타계정/계좌/관리), 첫 이용 온보딩 바텀시트.
- 원칙: 흰 배경·얇은 구분선·여백·작고 또렷한 글자. 보라는 포인트로만. 큰 그림자/진한 테두리/상단 가로탭/정보 과밀 금지.
```
