# ★★ 브랜드별 담당자 — 업체가 작업마다 셀프 입력 (migration 136, 사용자 확정 2026-08-24)
- **발단**: 브랜드사가 보는 작업 조건 카드의 「담당」 행에 **내부 담당 실명이 그대로** 나갔다(`AE팀 김수만 / 관리자 망고`). 대행사가 브랜드사에게 알려야 할 담당은 **자기 쪽 사람**이라, 업체가 직접 적게 한다.
- ★★ **저장 단위 = 작업(탭) 하나**(사용자 확정 Q5 — 브랜드 1벌이 아니다). 표는 `trackb_tab_brand_managers(advertiser_id, sheet_id, tab_name)` PK 하나, 값은 `managers jsonb`(**최대 2명 · 라벨 없는 자유입력 · 이름 20자**). `advertiser_id` 는 `advertisers.id` 와 **같은 TEXT**(082 의 42804 규율).
- ★★ **표시 규율 3종(완화 금지)**:
  - **브랜드사 화면 = 대체**(Q1 A안) — 서버 렌즈가 브랜드 세션에 `ae`·`adminNick`·`adminRaw` 를 **아예 안 싣는다**(화면에서만 감추는 건 보안연극). 화면은 업체가 정한 이름만 그린다.
  - **미입력이면 담당 행 자체를 그리지 않는다**(Q2 행숨김) — 「—」·[미설정] 로 두면 브랜드사에게 **고칠 수도 없는 빈칸**을 보여주는 셈이다.
  - **대행사·내부 화면 = 내부 담당 + 「브랜드사 표시」 두 줄**(Q4 D안) — 같은 행에 섞으면 누가 우리 담당인지 구분이 사라진다. 값이 길면 카드가 말줄임하므로 **title 에 값도 넣는다**.
- ★★ **세션 종류가 렌즈를 가른다** — `workdeskTab({brandId})` 는 **토큰에서만** 받고(`req.admin.brand_id`, IDOR 차단) `_condAdvertiserLens(cd, {brandSession})` 가 갈린다. 종전에는 브랜드 링크 세션도 그냥 `role='advertiser'` 라 **A안과 D안을 동시에 만족할 수 없었다**.
- ★ **입력 창구 = 브랜드 관리 › 브랜드 행 펼침 › 작업 행마다 인라인**(팝업 없음). 게이트는 브랜드 CRUD 와 같은 `_advSelf`(대행사 본세션만 — **브랜드 링크 세션은 자기 담당자를 못 고친다**) + 서비스가 `ownedTabsForAdvertiser` 로 **소유 탭을 검증**(남의 작업에 담당자를 심을 수 없다).
- ★ **빈 값은 행을 지운다** — "미입력"을 **행 없음** 하나로만 표현한다(빈 배열 행이 남으면 "값이 있는데 비어 있음"과 구분되지 않는다). ★ **타이핑은 재렌더하지 않는다**(한글 IME 조합 보호) · onclick 은 **인덱스만** · 담당자 칸·입력줄은 `stopPropagation`(행 클릭 = 작업 열기와 분리) · 저장 실패는 **입력을 지우지 않고** 사유를 말한다.
- ★ **쓰기 표면 = 그 표 하나**(작업표·주문·정산·시트 무접촉) · 조회는 **fail-soft**(신규 표라 미적용이어도 담당자만 안 보이고 화면은 뜬다 — 저장은 `not_ready` 로 마이그레이션 번호를 말한다).
- ⚠ 작업 단위라 12건짜리 브랜드는 12번 입력한다(일괄 채우기는 넣지 않았다). 시안 = `frontend/docs/design-brand-manager-inline.html`.
- 회귀가드 `tests/brandShare.test.js` §8(정규화·소유 검증·쓰기 표면·fail-soft·라우터 스택·렌즈 실행 + 화면 vm 실행) · `workboardTopC` §K(담당 행 렌더를 **vm 으로 실행**해 브랜드사/대행사 두 경우 출력 대조), **변이시험 8종 검출 확인** + 진짜 PG16(마이그레이션 idempotent·업서트·CASCADE) + 실 http 오리진 브라우저 7항목. ⚠ 가드 함정: **기준값을 조작 뒤에 찍으면 항상 참**이라 검사가 공허해진다(변이시험이 이 자리를 실제로 뚫었다).
