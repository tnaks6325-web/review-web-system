# ★ 입금관리 화면의 「회차」를 「대량이체」로 부른다 · 회차 밖 돈 = 「기록 없이 나간 돈」 (사용자 확정 2026-10-27)

## 왜
- 사용자: "이체회차 대신 명칭 변경 필요 — 인트라넷·케이뱅크 관련 명칭 찾아봐" → "대량이체로 통일".
- 조사: 케이뱅크 통장 거래 구분 = **대량이체**(한 묶음을 보내면 이렇게 찍힌다 · 팝빌 remark) · 인트라넷 리뷰 페이백 = "지급 묶음" / 회차 밖 돈 = **기록 없이 나간 돈** · 인트라넷 급여 = 다건이체 파일.

## 무엇
- **화면·사용자에게 가는 문구만** 바꾼다: 이체 회차·입금 회차·회차 → 대량이체(#번호 그대로) · 회차 취소 → 대량이체 취소 · 회차 밖으로 나간 돈 → 기록 없이 나간 돈 · 회차 밖 줄/이체 → 기록에 없는 줄/기록 없는 이체.
  - 범위: `frontend/workdesk.html` 입금관리·중복정리·줄 지우기·입금일 비우기 안내 · `frontend/docs/입금관리_사용안내.html` · 서버 오류 문구(payment·paymentResult·paymentBank·trackB.routes 내려받기·paymentResultParse·workTabDelete·sheetlessLedger).
- **바꾸지 않는 것**: 코드 이름(`payment_batches`·`batchSeq`·`_pmBatch*`)·주석·API 응답 키 · 인트라넷 기계 호출 오류(paybackLedgerFeed) · 다른 뜻의 회차(알림톡 회차·캡처 회차·차수 열 키워드).
- 회귀가드 4개의 문구 패턴을 새 말로 갱신(검사 의미 불변): worktableDuplicateGuard(_DD_PAY_LABEL·담긴 적 없음) · workdeskDepositManual(잠금 풀림 토스트) · paymentResultApply(다음 대량이체 재포함).

## 앞으로
- 입금관리에 새 문구를 쓸 때 사람에게 보이는 말은 「대량이체」 「기록 없이 나간 돈」을 쓴다(코드 이름은 그대로 batch).
