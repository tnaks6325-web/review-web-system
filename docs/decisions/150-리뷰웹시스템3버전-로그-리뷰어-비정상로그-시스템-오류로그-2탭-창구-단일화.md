# ★ 리뷰웹시스템[3버전] 「로그」 = 리뷰어 비정상로그 + 시스템 오류로그 (2탭, 창구 단일화)
- **배경(사용자 확정 2026-08)**: **리뷰웹시스템[3버전]이 메인**이고 관리자 대시보드는 폐기 대상이다. 그래서 nav 「리뷰어 로그」를 **「로그」**로 바꾸고 안에서 **리뷰어 비정상로그(기본) / 시스템 오류로그** 두 서브탭으로 나눈다. 시안 = `frontend/docs/design-log-tabs.html`.
- **데이터는 그대로** — 시스템 오류로그 = 이미 쌓이고 있는 `error_logs`(026/028)이고 수집 경로(`logAbnormal`)도 무접촉. **신규 테이블·마이그레이션 0**, 화면만 옮겼다. 서버는 `/api/trackb/error-logs*` **5경로 프록시**(`_delegate`로 기존 `admin.routes` 핸들러 위임 — SQL·로직 복제 0). Track B 경로에 두는 이유 = C/S·설정과 같다: 인트라넷 SSO 토큰(`via:'intranet'`)은 `/api/admin/*`에 **도달 자체가 불가능**.
- ★★ **표 idiom을 통일한다("모든 오류의 기준 = 리뷰웹시스템[3버전]")** — 시스템 오류도 관리자 대시보드의 *카드 목록 + 우측 패널*이 아니라 **리뷰어 로그와 같은 `.lgtable` + 행 펼침**으로 그린다. 두 탭의 열이 1:1 대응(상태 · 발생시점 · 대상 · 오류내용 · 조치안내)해 탭을 옮겨도 읽는 법이 안 바뀐다. 무거운 **AI 다중에이전트 분석만 모달**(리뷰검수 상세 팝업과 같은 방식, **body 직속** 마운트 — 뷰 스크롤 컨테이너에 넣으면 오버레이가 화면 흐름에 섞인다).
- **권한**: 리뷰어 비정상로그 = 종전대로 내부인 열람(AE는 담당 탭만) · 해결은 adminOrMaster. **시스템 오류로그 = master/admin 전용**(경로·스택·요청 컨텍스트가 실려 AE 담당 스코프로 나눌 수 없다 — 등록리뷰어DB와 같은 판단). AE에겐 **알약 자체를 안 그린다**(서버 게이트가 최종 방어).
- ★★ **관리자 대시보드에서 발생한 오류는 제외 — 단, 로그인 4경로는 예외(완화 금지)**: 판정 단일 출처 = `utils/adminUiErrorFilter.js`. `/api/admin/*`은 이미 `flow='admin'`으로 기록되고(그 표면은 대시보드만 쓴다) 그게 곧 "대시보드에서 난 오류"지만, **`/api/admin/login`·`staff-login`·`advertiser-login`·`intranet-login`은 이름만 admin이고 실제 호출자는 리뷰웹시스템[3버전]**(workdesk 로그인 폴백 4단)다 → 통째로 걸러내면 **작업보드 로그인·SSO 장애가 어느 화면에도 안 뜨는 무신호 상태**가 된다. 회귀가드가 그 4경로가 실제로 workdesk.html에 있는지까지 대조한다.
- ★ **제외는 조용히 하지 않는다** — 목록 상단에 "관리자 대시보드 경로 N건 제외"를 표기하고 `includeAdminUi=1`로 포함해 볼 수 있다. **요약(헤더 뱃지)도 같은 기준으로 센다**(표엔 없는 건이 뱃지에만 잡히면 "미해결 12인데 표는 2줄"이 된다). 원본 `admin.routes` 목록에서 제외는 **opt-in(`excludeAdminUi`)** 이라 다른 소비처 동작 불변. 시트·Drive·AI·DB·큐 등 **공용 인프라 오류는 그대로 남는다**(어느 화면에서 눌러 났든 같은 고장).
- ★ **nav 뱃지 = 두 탭 중요 건수의 합** — `_NAVLG{rv,sys}`에 각각 기억해 두고 합계만 그린다(C/S 뱃지와 같은 규율). **둘 다 미조회/실패면 뱃지를 건드리지 않는다**(숫자가 사라지면 "손볼 것 없음"으로 오독).
- ★ **로딩 자리표시자를 깐 함수는 어떤 예외에도 화면을 종결**시킨다 — `api`는 네트워크 오류에서 throw 하므로 try/catch가 없으면 "불러오는 중…"이 영원히 남는다(리뷰검수 무한로딩 실측 사고와 같은 자리). `_loadSysLogs`는 실패 시 [다시 시도] 버튼으로 끝낸다.
- **제거**: `admin.html`·`admin-siand.html`의 「오류디버깅」 탭 버튼·패널 + `index-app.js`의 그 화면 코드 605줄(탭 분기·뱃지 호출 포함). ★ HTML만 남기고 JS를 지우면 **누르면 ReferenceError로 죽는 탭**이 되므로 회귀가드가 세 화면 모두에서 흔적 0을 고정한다.
