# ★★ 작업표 옵션 칸 — 칸이 없으면 리뷰어가 고른 옵션이 조용히 사라진다 (2026-08-20 실사고, 스키마 변경 0)

- ★★ **수정 3겹**:
  - ① **복구 창구** `POST /api/trackb/worktable/option-column`(adminOrMaster · **미리보기 기본**, `confirm:true` 로 실행) + 작업보드 [⋯] → **[🧩 옵션 열]**. 칸을 만들고 **이미 들어온 주문의 선택값을 소급 기입**한다. 실행부 = `worktableOptionColumn.service.ensureOptionColumn` **한 벌**.
  - ② **재발 방지 2곳**: `worktablePlan` 이 옵션 배분이 있는데 칸이 없으면 **자동으로 덧붙인다**(리뷰옵션·택배송장번호와 같은 규율 — 종전 `no_option_column` 경고는 `option_column_added` 로 대체, **조용한 자동 추가 금지**) · **공고 저장(create/update)** 이 살아있는 옵션 2종 이상이면 연결 무시트 작업표에 칸을 보장한다(`_ensureLinkedWorktableOptionColumn` — 같은 서비스 호출, **절대 throw 없음**).
  - ③ **조용한 누락 차단**: `sheetlessOrder.buildRowPatch` 가 `optionUnmapped` 를 돌려주고, 기입할 칸이 없으면 `logAbnormal(flow:'order_mirror', step:'option_column_missing', warn)` + logger.warn. ★ **보존(blank-only)과는 다른 신호다** — 그쪽은 값이 이미 있는 정상 동작이고 이쪽은 **칸 자체가 없다**(사람이 칸을 만들어야 풀린다). `reviewer_event_logs` 는 쓰지 않는다(도배 방지).
- ★★ **완화 금지**: **무시트 탭 전용**(fail-closed — 시트 기반 탭의 열은 시트가 정한다) · **판정 사본 0**(옵션 칸 = `orderLedger.optionWriteColumns` 매퍼 파생 · 리뷰옵션 제외는 `isReviewOptionHeader` · 자리는 `classifyHeaders` 의 자동 열 뒤) · **소급 값도 매퍼가 정한다**(`mapOrderToSheetRow` 를 새 헤더로 돌려 읽는다 — `|` 다중 옵션까지 앞으로의 쓰기와 한 글자도 같다) · **기입은 blank-only**(관리자 작업지시 '텍스트'·'포토리뷰' 를 덮지 않는다).
