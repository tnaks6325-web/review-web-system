## 결정
1. 표시 규칙 단일 출처 = `server/src/utils/sequentialDisplay.js`
   - `sequentialDisplay(base, views)` — 참여 전(목록 카드·상세·머리 제목). 제목 안에서 **어느 한 선택지만 쓰는 이름**(상품명/옵션명)을
     긴 것부터 찾아 지금 모집 중 선택지의 같은 종류 이름으로 바꾼다. 못 찾으면 제목 그대로 + `nowRecruiting`("지금 모집: ○○").
     사진 = 지금 모집 선택지 사진 → 없으면 공고 사진. 전부 마감·순차 아님 = null(저장값 그대로).
   - `joinedDisplay(base, views, joined)` — 참여한 사람(참여 후 머리 제목·내 참여 내역). **내가 고른 선택지로 고정**
     (나중에 다음 상품이 열려도 바뀌지 않게).
   - 여러 선택지가 함께 쓰는 이름(같은 상품의 옵션들이 공유하는 상품명)은 단서로 쓰지 않는다 — 어느 선택지인지 모른다.
2. 저장: `campaign_options.thumbnail_url`(181, 빈 값 = 공고 사진). 입력 = 관리자 공고 설정 상품별 줄의 "🖼️ 상품 사진"
   (주소 붙여넣기 · [올리기] = 공고 썸네일과 같은 업로드 창구 `_uploadImageToProxy` → `/api/order/guide-image`).
   - 서버 정규화 `_normalizeOptionThumb`: **https 만**·공백/따옴표/꺾쇠 없음·2048자. 형식 불량 = 저장 거절(400 — 생성·수정).
   - **미전달 = 유지**(`COALESCE($14, campaign_options.thumbnail_url)`) — 구버전 화면이 저장해도 사진이 지워지지 않는다. `''` = 지움.
3. 적용 위치: 공개 목록·상세(`_applySequentialDisplay` — `view.title`/`view.thumbnail_url` 교체, 원래 값은 `baseTitle`/`baseThumbnailUrl`) ·
   work-detail `joinedDisplay`(참여 후 머리 제목) · 내 참여 내역 참여 중(`reviewer.routes._applyJoinedDisplay`) ·
   리뷰비 내역 사진(무시트 주문 — 고른 선택지 사진 우선 `COALESCE(NULLIF(co.thumbnail_url,''), rc.thumbnail_url)`).
   관리자 화면(관리자 상세·편집·카드 편집)은 저장값 그대로.

## 코드리뷰 반영 (Codex · 머지 전)
- 🟡 참여자 표시 순차 판정을 **공고 기준**(선택지 중 하나라도 sequential)으로 — 고른 선택지를 관리자가 닫으면 그 뷰엔 sequential 표시가 없다.
- 🟡 제목에 **서로 다른 선택지 이름이 둘 이상**이면(예: "빨강/파랑 에코백") 바꾸지 않고 "지금 모집" 줄로만(긴 이름이 덮은 자리 안의 짧은 이름은 세지 않음).
- 🟡 "지금 모집" 줄은 공고 상태가 open 일 때만(오픈 전·오늘 마감·종료 옆에 쓰면 참여 게이트와 모순).
- 🟡 옵션 없는 작업 모드에서는 상품 사진 줄을 숨긴다(선택지 원장을 저장하지 않아 올려도 버려진다).
- 🟡 리뷰비 내역 사진: 신청 id 가 비어 있는 옛·복구 주문도 `order_submission_id` 로 신청을 되찾는다(다른 리뷰비 조회와 같은 LATERAL 규칙).
- 🟡 배포 시차: 저장 응답 `optionThumbnails: true`(새 서버만) — 화면이 사진을 보냈는데 표시가 없으면 "상품 사진은 저장되지 않았습니다 — 다시 저장" 안내.

## 완화 금지
- ★★ 제목을 통째로 상품명으로 바꾸지 않는다 — 관리자가 붙인 표시(`빈)))` 등)가 사라져 리뷰어가 배송 방식을 잘못 안다.
- ★★ 상품 사진 저장에서 **미전달을 빈 값으로 접지 않는다**(COALESCE 유지) — 옛 화면 저장 한 번에 사진이 전부 지워진다.
- ★ 사진 주소는 https 만(리뷰어 화면 `<img src>` 로 그대로 나간다).
- ★ 참여한 사람의 표시는 지금 모집 상품이 아니라 **고른 상품** — 섞으면 은갈치를 산 사람에게 고등어가 보인다.
