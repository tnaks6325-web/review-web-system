# 업체관리 — 작업 줄 [업체 이동] · 작업 없는 업체는 목록에서 뺀다 (사용자 확정 2026-10-07)

## 발단
- 광고주를 잘못 연결한 작업을 다른 업체로 옮겨야 하는데, 직원도 운영자도 방법을 몰랐다. 기능(결정 083 이관)은 있었지만
  업체 펼침 → [소유 작업] 패널 → 작은 [이관] 버튼 안에 숨어 있었다.
- 작업을 다 옮긴 업체가 업체관리 목록에 0건으로 계속 남았다(운영 실측 43곳 중 8곳).

## 결정
- 업체를 펼쳤을 때의 **작업 줄마다 [업체 이동]**(A안) — "열기 ›" 앞 새 열. 실행부는 같은 이관 팝업·같은 서버 경로
  (`ownTransfer` · `POST /api/trackb/ownership/transfer`) = 사본 0. 소유 행 찾기 = 탭 gid 일치 → 없으면 그 시트의 옛 '전체' 소유.
  권한은 이관과 같은 내부 담당자(`_isInternalRole`, 서버 internalMiddleware). 팝업 문구는 "이관" → "이동".
- **작업이 0개인 업체는 업체관리 목록(사이드바·개요 표·업체 수)에서 뺀다 — [보기] 줄 없음**(`_ovmHasWork`, 정렬 함수 한 곳).
  - 지우지 않는다(접속 링크·계정·브랜드 그대로) — 작업이 다시 붙으면 다시 나타난다.
  - 이동 대상 검색은 전체 업체 목록(`STATE.advs`)이라 숨긴 업체로도 옮길 수 있다.
  - ★ 집계를 모르면(개요 응답 실패·미도착) 숨기지 않는다 — 실패 한 번에 업체가 통째로 사라지면 안 된다.
  - 이동으로 원래 업체가 0개가 되면 그 업체를 다시 펼치지 않고 개요로 돌아간다.

회귀가드: `vendorManagementRedesign`(13칸 · 숨김 3갈래 vm 실행) · `ownershipTransfer`(문구 이동). 실 브라우저(가짜 데이터)로 숨김·버튼·팝업 확인.
