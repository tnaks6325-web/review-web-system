- **원인**: 마감이 두 벌이다. ㉮ 작업보드 🏁 마감 = `trackb_tab_finished`(결정 087) ㉯ 옛 대시보드 ⬛ 마감 = `tab_configs.is_closed`. 087 은 "옛 대시보드는 폐기 예정 — Track A 무접촉"으로 ㉯를 건드리지 않았고, 그래서 옛 대시보드는 ㉮를 몰랐다. 작업보드 홈 목록은 정상(운영 DB 읽기전용으로 `scopedActiveTabs` + `finishedTabsMap` 실행 → `fin:true`).
- **결정(사용자 확정)**: 옛 대시보드도 🏁 마감을 마감으로 **보여준다**. 저장은 하지 않는다.
  - 서버: `/api/admin/dashboard` 각 탭에 `workFinished`(판정 = `trackB.finishedTabsMap`/`isTabFinishedIn` 단일 출처, 이름 → gid 폴백). 조회 실패 = 전부 false + 응답 `workFinishedUnavailable:true`(표시 없음으로 접힘 — 마감을 "모르면" 진행 중으로 둔다, 종전 동작).
