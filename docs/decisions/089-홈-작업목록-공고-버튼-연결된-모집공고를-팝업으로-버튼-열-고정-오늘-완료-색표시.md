# ★ 홈 작업목록 → [공고] 버튼 (연결된 모집공고를 팝업으로) · 버튼 열 고정 · 오늘 완료 색표시

> ⚠ **표기는 [166](166-홈-작업목록-모집공고-칸-다-찬-작업은-모집완료-사용자-확정-2026-09-22.md) 에서 바뀌었다** — `＋공고발행` → `공고발행`, 모집이 다 찬 작업은 `모집완료`. 아래 본문의 `＋공고발행` 표기는 그 시점 기록이다.

- **시안** `frontend/docs/design-home-campaign-popup.html`. 홈 작업 목록 줄마다 **[● 공고]** — 그 작업에 연결된 모집공고를 **그 자리에서 팝업**으로 연다(화면 이동 0). 종전엔 상단 [모집공고] 탭으로 옮겨 카드 더미에서 찾아야 했다.
- ★★ **새 화면을 만들지 않는다** — 모집공고 탭에서 쓰는 그 모달(`js/recruit-modal.js`)을 `openRecruitModal(공고id)` 로 그대로 연다. 축약 폼을 새로 만들면 필드가 빠져 **저장 시 기존 설정이 빈 값으로 덮인다**(리뷰어앱 축약 편집에서 겪은 함정). 저장·검증·미리보기는 전부 기존 기능에 위임하고 홈은 **여는 일만** 한다.
- ★★ **상태 점은 카드·리뷰어 목록과 같은 계산**(`tabCampaignsMap` 이 `computeCampaignState` + `deriveSchedules` 를 그대로 태운다) — status 컬럼으로 흉내 내면 "목록엔 모집중인데 참여는 거부"가 된다. 점 = 모집중(초록)·오픈예정/오늘마감(주황)·마감(회색).
- ★ **키는 이름 + gid 폴백**(마감 주석과 같은 규칙 — 탭 리네임으로 연결이 조용히 풀리면 담당자가 **이미 있는 공고를 또 발행**한다). **빈 gid 는 키를 만들지 않는다**(만들면 gid 없는 탭이 한 키로 뭉친다).
- ★★ **조회 실패는 "공고 없음"이 아니다** — 서버가 `campaignsUnavailable` 로 말하고, 버튼은 비활성 + 목록 상단 고지, 프론트는 그 응답으로 **기존 주석을 덮지 않는다**(088 무신호 규율). 빈 값으로 접으면 중복 발행이 난다.
- ★ **한 작업에 공고가 2개 이상**(차수 재발행)이면 **생성일과 함께 보여주고 사람이 고른다**(사용자 확정 — 최신을 말없이 열지 않는다). 버튼에 건수 표기(`공고 2`).
- ★ 미발행 = **＋공고발행**(편집 허용명단만) → 같은 모달을 발행 모드로 열고 **그 작업의 탭을 프리필**(`linked_sheet_id/name/gid`). 권한 없으면 비활성(눌러도 아무 일 없는 버튼 금지). 판정은 **홈 전용 플래그 `STATE.campEdit`** — `STATE.canEdit` 은 작업보드 그리드 편집에도 쓰여 작업 탭을 한 번 열면 덮어써진다.
- ★ 주석은 **`?stats=1` 일 때만** 조회(작업바 로드는 가볍게) + 30초 캐시, **`fresh=1`** 로 캐시 우회(공고 저장 직후 — 없으면 발행하고도 [＋공고발행]이 한동안 남아 "저장이 안 된 것"으로 보인다). 저장 후 갱신은 **`window.CAMP_ON_SAVED` 훅**(훅 미설정 = 관리자 대시보드 동작 불변). `loadRecruitList` 는 컨테이너가 없으면 조기 반환 — 없으면 홈 팝업 저장이 **성공했는데도 "저장 오류"** 로 보인다.
- ★★ **맵은 전 탭 무스코프** — 응답에 통째로 싣지 말 것(tabs 루프가 유일한 스코프). **광고주에겐 미동봉**(마감 주석과 같은 판단).
- ★★ **버튼은 줄마다 자기 열을 지킨다**: `.wbl-act` = **고정 폭 grid**(진행 중 4칸 92/46/88/64px · 보관함 3칸 · 열람전용 2칸) + 버튼 `width:100%`. flex(내용 폭)로 되돌리면 같은 버튼이 줄마다 다른 x 좌표에 온다(사용자 신고). [공고] 버튼은 **연결됨·미발행·조회실패가 전부 같은 칸** — 그래서 미발행 문구도 `＋공고발행`(띄어쓰기 없음).
- ★★ **[오늘 완료]는 글자를 바꾸지 않고 색으로 말한다**(`.wbl-b.today.on` 파란 채움) — 종전 `☑ 오늘 완료 ↔ 해제` 라벨 스왑은 ① 폭이 달라져 열이 어긋나고 ② "해제"가 무엇을 해제하는지 모호했다. **동작·API 는 그대로**(`toggleTodayDone`), 바뀐 것은 표시뿐.
- ★ onclick 에는 **인덱스만**(`openTabCampaign(i)`·`_campPick(i,ci)`) — 시트/공고에서 온 문자열을 넣으면 따옴표 하나로 탈출된다(M1 실측 XSS).
- 회귀가드 `tests/homeCampaignButton.test.js`(스텁 pool 로 서비스·라우트 **실제 실행** + 버튼 렌더러 vm 실행 + 배선, **변이시험 검출 확인**) + 실 http 오리진 브라우저로 **줄별 버튼 x 좌표가 전부 동일**함과 선택 팝업(생성일 표기)을 실측.
