# 탈 구글시트(무시트 운영) — 지금 지켜야 하는 규율
- **완료된 이관이다**(W1~W5 + 프로덕션 E2E 완주 2026-08-08). 진행 기록·사고 조사·의사결정 경위는 **`docs/history/탈구글시트-이관.md`**. 남은 358건(구매일 연도 미확정 과거 자료)은 **이관하지 않는다**(전환 화면이 건수를 고지).
- **모델 = 길 B**: 장부 3권(`raw_sheet_*` · `index_master` · `review_index`)은 그대로 두고 **채우는 손만** 시트 → 작업표(`campaign_participants`)로 바꾼다. 그래서 검색·행배정·리뷰내역·홈 통계·입금대상 등 소비처 수십 곳이 **무수정**이고 stale-pl 보안 게이트도 그대로 산다.
- ★★ **"구글에 물어야 하는가" 판정 단일 출처 = `utils/sheetlessScope.js`** — 시트 단위 제외는 **`BOOL_AND`(등록 탭이 전부 무시트일 때만)**, 탭 단위는 **이름 → gid 폴백**, **빈 gid 는 키를 만들지 않는다**, **조회 실패·컬럼 미적용은 빈 집합(fail-open)**. 게이트는 크론 **네 곳 전부**(`smartBuild`·`buildIndexSmart`·`checkDirtySheets`·`rawMirror`) — smartBuild 를 빠뜨리면 5분 크론이 **작업표로 만든 장부를 옛 시트 값으로 덮는다**.
- ★★ **장부 생성기 `sheetlessLedger.rebuildLedgers`** — 작업표를 시트 모양 2차원 배열로 재조립해 **기존 파서 `indexBuilder.parseTabRows` 를 그대로 통과**시킨다(판정 사본 0). 헤더는 **`COALESCE(detected_headers, headers)`**(`headers` 는 시트 A1 행이라 그것만 보면 전 탭이 빈 명단이 된다). **seq = 시트 실제 행 번호**, 탭 단위 `pg_advisory_xact_lock`. fail-closed 3종 = `not_sheetless`(시트 값 덮어쓰기 차단) · `tab_not_registered` · `no_headers`. **`preflight` 는 `dryRun` 과 함께일 때만** 게이트를 연다.
- ★★ **접수 = `sheetlessAccept.resolveAcceptMode` 단일 출처**(라우트·화면에 사본 0): 명시 요청 > **이미 무시트면 되돌리지 않는다** > 명시 시트 > URL 있음 > **URL 없음 = 무시트**(기본). URL 이 있는데 형식이 틀리면 **추측하지 않고 멈춘다**. 가상 시트ID `wt_`+hex20(23자)·숫자 gid, `sheet_url` 은 **빈 값**(죽은 링크 금지). 킬스위치 `SHEETLESS_ACCEPT_DEFAULT=0`. **접수 흐름에 구글시트 생성 창구를 두지 않는다**(두면 `work_sheet_url` 이 다시 붙어 시트 경로로 되돌아간다).
- ★★ **주문 즉시 완결 `sheetlessOrder`** — 큐를 안 타고 작업표 `row_json` 에 직접 기록 후 장부 재생성. **`mirror_status` 는 그대로 `'written'`**(새 상태를 만들면 소비처 여러 곳을 훑어야 하고 한 곳만 놓쳐도 조용히 미완결). **매핑 사본 0**(`mapOrderToSheetRow` · 옵션 칸은 `optionWriteColumns` · 옵션 blank-only). **시트 쓰기 차단 5중**(리뷰어 제출 · 외부모집 수동제출 · reconcile 은 큐 대신 작업표 재기록 · 큐 실행부 fail-closed 백스톱 · 리뷰제출 표시 배경작업). **완결 순서가 계약**: 작업표 기록 → **장부 재생성 성공** → `markOrderWritten` → 신원 링크(중간 실패에 링크를 남기면 교차노출).
- ★★ **상태·메모는 작업표 칸에 쓴다**(`sheetlessStatus.markStatusCell`/`markSheetlessMemo`) — 시트에도 칸이 있는 값(제출·입금)은 **보존이 아니라 기록**, 시트에 칸이 없는 값(대표 리뷰 이미지)은 **재생성 시 스냅샷 보존**. 어느 칸인지는 `review_index.submit_col/submit_col2`(파서가 감지해 둔 헤더명). **시트 기반 탭·판정 실패는 `{handled:false}`** → 호출부가 자기 기존 경로를 탄다(`true` 로 접으면 시트 탭의 기록이 조용히 사라진다).
- ⚠⚠ **2026-09-26 뒤집힘** — 날짜별 인원은 이제 규칙이 정하고 작업표가 따라간다([182](182-날짜별-인원은-규칙이-정하고-작업표가-따라간다-2026-09-26.md)). 아래 D3-a 서술은 그 이전 규율이다.
- ★★ **정원은 달력이 정한다**(D3-a): 무시트 탭은 시트 일정(063) 판정에서 제외하고 발행 시 작업표 날짜를 `campaign_daily_plans` 로 프리필(`ON CONFLICT DO NOTHING`·과거 날짜 제외·fail-soft). ★ **`parseDateColumn` 에 `fallbackAnchor` 필수** — 작업표 구매일자는 `M / D (요일)` 라 연도가 없어 앵커가 없으면 **전 행 null 로 조용히 죽는다**. 두 조각(제외·프리필)은 **반드시 함께** 나간다.
- ★★ **표시는 서버 플래그 `sheetless` 하나로**(배지·죽은 링크 제거) — **ID 모양(`wt_`)으로 추측하지 않는다**(이관된 기존 작업은 진짜 시트 ID 를 그대로 쓴다). 필드가 없으면(구버전 백엔드) 아무것도 그리지 않는다.
- ★★ **표식을 켜는 유일한 창구 = 전환 화면**(`/api/trackb/sheetless/*`, adminOrMaster). 점검표 5항목은 **fail-closed**(`unknown` 도 통과 아님)이고 **경고 전용(advisory)은 ④ 시트 사본 최신 하나뿐** — 여기에 항목을 더하면 이관이 조용히 헐거워진다. 이관 **순서가 계약**: 마지막 반영(미러→빌드→**투영**) → **표식 켜기** → 비활성 import 줄 은퇴 승격 → 장부 재생성 → 시트 안내문(best-effort). 되돌리기([재연결])는 점검표 없이 언제든.
- ★★ **미반영 주문은 시트가 아니라 작업표로 인계한다** — 실행부는 `sheetlessOrder.writeOrderToWorktable` 한 벌이고 **표식을 켠 뒤에** 부른다. 다만 **배정된 줄이 없는 주문은 계속 잠근다**(옮길 자리가 없으면 진짜로 사라진다).
- ★ **폴더 1단 = 업체명**(`folderTitle.service`, D2-a) — **시트 기반 탭에는 `null` 을 돌려줘** 기존 경로를 바이트 불변으로 유지한다(소비처 3곳 공용).
- ★ **파생 규칙 2종**(이관 대조로 드러난 것): `campaignSchedule.DATE_HEADER_KEYWORDS` 에 **`구매날짜`** 포함(단 `날짜`·`일자` 로 넓히면 `입금일자`·`리뷰날짜` 를 구매일로 오인) · parity 짝짓기는 phone8 그룹 **안에서 줄 번호로**(`_pairByRow`) — 한 번호에 여러 줄인 리뷰어에서 허위 불일치가 났다.
- ⚠ **레거시 공고(participation_mode=false)의 참여 행추가**는 주문 큐와 별개의 시트 직접 쓰기라 `sheetlessApplicant.addApplicantRow` 가 분기한다 — **무시트인데 실패하면 `throw`**(조용히 false 를 돌려주면 아무도 안 읽는 시트에 참여자가 남는다).
