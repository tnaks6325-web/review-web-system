# 리뷰어 홈 구매사진 — 홈 탭 맨 위 한 줄 알림 + 누르면 아래에서 올라오는 창(주문 한 줄씩) (사용자 확정 2026-11-13)

## 왜

- 2026-11-09 「구매사진 셀프보완」(결정 357) 이후 리뷰어 홈 맨 위에 **최근 2주 주문 전부**가 카드로 쌓였다(최대 20건, 카드마다 같은 안내 문장 반복). 홈 · 리뷰내역 · 내정보 탭에 모두 붙었다.
- 리뷰어 문의 「홈이 불편하다」가 늘었다. 가짜 데이터(주문 8건 · 사진 빠진 2건) 휴대폰(390×844) 실측:
  - 모집공고 시작: 과거(11/7) 화면 0.9장 → 현재 2.5장
  - 리뷰내역 목록 시작: 0.4장 → 2장
  - 사진을 다 낸 리뷰어도 홈 맨 위에 카드 6장(화면 1.1장)
- 전후비교·시안: `~/Documents/리뷰어홈-전후비교/비교.html` · `시안.html`(안1 접기 / 안2 한 줄 알림) → 사용자 「안2로 하되 한 줄 알림 + 창 높이 최대한 낮게」 → `시안-안2개선.html` → 「애플 디자인 적용해서 버튼과 입력란이 보이게」 → `시안-안2애플.html` → **「좋다」**.

## 확정 동작

- **홈 탭 맨 위 한 줄**(높이 40px)
  - 손볼 것이 있으면: 빨간 점 · 「구매사진 보완 필요 **N건**」 · 「확인하기」
  - 다 냈으면: 초록 점 · 「구매사진 **N건 접수**」 · 「보기」
  - 내역이 없으면 자리를 차지하지 않는다(빈 칸 숨김).
  - **조회 실패는 「없음」으로 숨기지 않는다**(결정 359): 주황 점 · 「구매사진 내역을 불러오지 못했어요」 · 「다시 조회」.
  - 리뷰내역 · 내정보 · 1:1 문의 탭에서는 보이지 않는다(첫 화면 = 홈에서는 보인다).
- **누르면 창**(휴대폰: 아래에서 올라옴 · PC: 가운데 작은 창)
  - 주문 한 줄씩(상품명 · 명의 · 상태 표시). 「보완 필요 N건」 묶음이 위, 「사진 낸 주문 N건」이 아래.
  - 동시진행(네이버·쿠팡) 주문은 갈래별로 상태를 따로 보인다.
  - 줄의 상태 표시는 승인 시안 그대로 짧게 쓴다 — 빨강 「사진 없음 · 보완 필요」 / 회색 「확인 중 · 담당자 확인 중」 / 초록 「접수됨 · 확인 완료」(`chipOf`). 긴 상태 글자(`saveLabels`·`reviewLabels`)는 종전 펼침 목록·직원 창이 그대로 쓴다.
  - 줄을 누르면 **그 줄만** 펼쳐진다(다른 줄은 접힘): 보완 사유 · 사진 미리보기 · 메모칸(회색 채움, 글자 16px — 아이폰 확대 방지, 적는 만큼 120px까지 늘어남) · 「사진 추가」(옅은 파랑) · 「이미 제출했어요 · 확인 요청」(파랑 채움). 사진 추가·확인 요청 기능·서버 호출은 종전과 같다.
  - 「사진 확인과 명의·리뷰·입금 승인은 별개예요」는 창 맨 아래 한 번만.
  - **줄 왼쪽 작은 상품 사진**(36×36, 사용자 요청 2026-11-13 「쪼끄만 상품 사각썸네일 좌측에 모두」): 모집공고 카드와 같은 공고 썸네일(`recruit_campaigns.thumbnail_url`). 참여 연결이 없는 작업 주문은 그 작업에 연결된 공고(`linked_sheet_id`/`linked_tab_name` 또는 `campaign:<id>` 작업)에서 썸네일 있는 것을 고른다. 응답 필드 `thumbnailUrl` — **https 주소만** 싣고(화면이 그대로 `<img src>` 로 쓴다) 그 밖은 `null`. 없거나 안 뜨면 회색 빈 자리(가방 그림)로 줄 모양을 맞춘다.
    - 운영 실측(읽기 전용, 최근 14일 주문 3,271건): 참여 연결로 2,706건 · 작업 연결 공고까지 3,094건(94.6%)에 썸네일이 있고 모두 https. 나머지 177건은 빈 자리.
    - 작업 연결 공고 조회는 **SAVEPOINT 로 가둔다** — 실패해도 목록·사진 처리 트랜잭션은 그대로이고 사진만 빈 자리(꾸밈이 기능을 막지 않는다).
  - 창을 닫으면 홈 한 줄의 건수를 다시 읽는다. 다시 읽는 동안 지금 줄을 지우지 않는다(깜빡임 없음 — 그동안 옛 줄을 눌러도 창은 열리지 않는다).

## 바뀌지 않는 것

- 서버: 응답에 `thumbnailUrl` 한 칸만 더한다(읽기 · 스키마 변경 없음). 권한 · 쓰기 경로 · 기존 필드 변경 없음. 구버전 화면은 새 칸을 무시하고, 새 화면 + 구버전 서버는 빈 자리로 그린다.
- 직원 창(`PurchaseCaptureStaff`, 작업보드 문의함): 그대로. 새 모양 CSS 는 `.rpc-bannerhost` · `.rpc-banner*` · `.rpc-sheet` 안에서만 적용한다(가드가 범위를 센다).
- `ReviewerPurchaseCapture.mount`(종전 펼침 목록)·`open`(주문 하나 창)의 계약: 그대로. 새 모양 창은 `open({compact:true})` 일 때만.
- 옛 서버용 보완 목록(`_mcItems`, 셀프보완이 없는 서버): 종전대로 문의함 탭에서만 숨긴다.
- 배포 스큐: 새 홈 + 캐시에 남은 옛 모듈이면 `banner` 가 없어 종전 `mount` 로 그린다. 모듈·CSS 는 `?v=20261113-home-banner` 로 함께 갱신된다.
