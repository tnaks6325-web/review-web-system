# ★★ 구매양식 구매일자가 비면 서버가 오늘을 채운다 · 관리자 화면 빈 스텁 버튼 예외 (2026-10-08 · 스키마 변경 0)

## 발단 (순차진행 E2E 테스트 중 발견 — 결정 212·214)
1. **구매일자 빈칸 덮어쓰기** — 구매양식 제출(`POST /api/submit/order`)이 `dateStr` 없이 오면, 공유 매퍼(`mapOrderToSheetRow`)가
   날짜 칸에 `''` 를 돌려주고 그 빈 값이 **작업표에 미리 적힌 구매일자를 지우는 쓰기**가 된다(결정 017 과 같은 메커니즘).
   실측: 테스트 서버에서 날짜 없이 15건을 제출하자 은갈치·옥돔 15줄의 구매일자(10/8)가 전부 빈칸. 날짜 칸은 날짜별 계획 물량 계산의 재료이기도 하다.
   - 리뷰어 화면(`search-app.js`)은 항상 오늘 `M / D (요일)` 을 보내 **지금 운영 영향은 없다** — 화면을 거치지 않은 제출·옛 화면 대비.
2. **관리자 화면 `_applyHiddenCols` 예외** — admin.html 의 `#btnColVis` 는 자식 없는 **빈 스텁**인데, 마지막 자식의 `textContent` 를 쓰다
   `Cannot set properties of undefined` 예외. 이 함수를 부른 대시보드 렌더의 **뒤 단계**(정렬 초기화·검색 초기화·너비 감지·변경 배지)가 건너뛰어졌다.
   결정 186(코드 다이어트 장부)에 "기존 결함 · 영향 미확인"으로 적혀 있던 것.

## 결정
1. 제출 입구에서 `dateStr` 가 비면 **관리자 수기 주문과 같은 함수** `manualOrder.todayKstDateStr()` 로 채운다(사본 금지).
   - ★ 공유 매퍼는 고치지 않는다(결정 017 — 주문 취소의 칸 비우기·Track B 마스크가 `''` 반환에 의존).
   - 입구 전수: 빈 날짜가 들어올 수 있는 곳은 리뷰어 제출 1곳(수기 주문은 이미 `todayKstDateStr()`).
2. `_applyHiddenCols` 는 글자 칸이 없으면 만들고, 있으면 그 글자만 바꾼다(정상 버튼 동작 불변).

## 완화 금지
- ★★ 구매양식 제출의 `dateStr` 를 빈 문자열로 그대로 넘기지 않는다 — 미리 적힌 구매일자를 지운다.
