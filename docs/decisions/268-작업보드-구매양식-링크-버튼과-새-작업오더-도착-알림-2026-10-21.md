## 결정
### 구매양식 링크
- 작업 제목 줄 [🔗 링크 복사](직원용 작업보드 주소) · [🏢 광고주링크] 옆에 **[🛒 구매양식 링크]**. 내부 역할(`_isInternalRole`)만 · 보관(마감) 작업에서는 숨김. AE 도 쓴다(옛 대시보드도 로그인한 누구나).
- 서버 `POST /api/trackb/form-link {sheetId, tabName}` — `authMiddleware + internalMiddleware + _ensureEditScope`(작업보드 본문과 같은 판정. 인트라넷 로그인 직원도 도달 — `/api/short/create` 는 인트라넷 토큰이 막힌다).
- ★ 코드 규칙 단일 출처 = `services/shortLink.service.js` `ensureShortLink`. `/api/short/create` 도 이것을 쓴다(라우트 안 INSERT 사본 0).
- ★ 재료는 **서버가 tab_configs 에서** 읽는다: s=sheet_id · g=tab_gid · t=tab_name · d=display_name · 차수 없음 = 옛 `copyShortLink` 와 같은 composite key → **옛 대시보드에서 만든 링크가 있는 작업은 같은 코드가 다시 나온다**(이미 보낸 링크와 갈리지 않는다).
- 복사 주소 = `<API>/r/<코드>`(카카오톡 미리보기 → `search.html?r=<코드>`) — 옛 것과 같다. 복사가 막히면 주소 창(`_shareLinkPopup`).
- 차수별 링크는 만들지 않는다(최근 30일 사용 0).

### 새 작업오더 도착 카드
- `sse.workOrderNewTarget`: 옛 관리자 연결(role='admin') + 작업보드 연결 중 **로그인 등급 master/admin** 만. 작업보드 SSE 연결이 `userRole: _role(req)` 를 싣는다. AE(staff)는 보내는 쪽이라 받지 않는다.
- 화면: `work_order_new` 수신 → 오른쪽 아래 카드(최신 위 · 최대 5장 · [작업오더 열기]/[닫기]) + **이미 허용된 경우에만** 데스크톱 알림(권한 창을 띄우지 않는다 — 가격·품절 알림과 같은 규칙) + 작업오더 메뉴 배지 갱신(값 단일 출처 `STATE.woCounts` → `_woSyncNavBadge`).
- 카드는 `#app` 안에 붙인다 — 로그아웃(`renderLogin` 이 `#app` 을 갈아끼움)하면 함께 사라진다.
- 덤으로 고친 것: `_loadOrders` 가 응답을 기다리는 사이 화면을 떠나거나 로그아웃하면 `#wohead` 가 없어 `TypeError` 가 났다 → 배지만 맞추고 표는 그리지 않는다.

## Codex 리뷰 반영 (P2 ×3)
- **링크 발급 원자성**: `composite_key` 에 유니크 인덱스가 없어(기존 데이터 그대로) 동시 요청 둘이 서로 다른 코드를 만들 수 있었다 → `ensureShortLink` 를 트랜잭션 + `pg_advisory_xact_lock(hashtext('short_links:'+key))` 로 "조회 → 없으면 만들기"를 한 줄로 세우고, 코드 충돌은 SAVEPOINT 로 그 INSERT 만 되돌린다. 화면 버튼도 연타 방지(`copyFormLink._busy`). 로컬 실 DB 동시 5요청 → 코드 1개·행 1개.
- **원본 수정은 새 오더가 아니다**: `work_order_new` 는 인트라넷 원본 수정(`event` = source_revision · source_partial_edit · source_contract_match)에도 온다 → `event` 가 있고 재제출이 아니면 카드 없이 목록·배지만 갱신(`_woRefreshQuiet`).
- **늦게 온 응답 무시**: 알림이 연달아 오면 `_loadOrders` 응답 순서가 뒤바뀌어 옛 목록이 새 목록을 덮을 수 있었다 → 순번(`STATE._woReqSeq`)으로 마지막 요청만 반영.
