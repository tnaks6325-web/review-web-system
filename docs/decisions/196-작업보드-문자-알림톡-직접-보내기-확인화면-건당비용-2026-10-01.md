# 196. 작업보드 문자·알림톡 직접 보내기 — 디자인된 확인 화면 · 건당 비용 표기 (사용자 확정 2026-09-30·10-01)

## 무엇
- 작업보드 우클릭 **[📨 문자·알림톡 보내기]** (시안 A · 내부 담당자 전원 · 여러 줄 한 번에). 실행부 `server/src/services/manualMessage.service.js`, 화면 `frontend/workdesk.html` `_MS*`, 기록 migration 171 `manual_message_sends`.
- **문자**: 담당자 직접 입력. 끝에 "발신 전용 · 1:1 문의로" 안내 + 리뷰웹 `#cs` 주소를 자동 첨부하고, 같은 본문을 그 리뷰어 1:1 문의방에도 남긴다(발신번호가 대표 개인 휴대폰이라 답장을 직원이 볼 수 없다 — 답을 C/S 창구로 모은다).
- **알림톡**: 자동 알림(결정 194)의 **다음 회차**를 지금 보낸다(`reviewReminder.sendManual` → `sendOne` 공유 — 원장·종결 흐름 동일, 같은 회차 중복 없음). 날짜 전(not_due)만 앞당김 허용.

## 확인 화면 (2026-10-01)
- ★★ **브라우저 시스템 확인창(`confirm()`)을 쓰지 않는다** — 팝오버 안 확인 화면([돌아가기] / [N명에게 보내기 확정])으로 받는 사람 · 방식 · **1건당 비용** · 예상 합계 · 잔액을 보여준다.
- 단가는 발송 업체 단가표(`/pricing/v1/messaging`)에서 종류별(알림톡·단문·장문) **부가세 포함/별도**로 받는다(`solapi.getAccountBilling().prices`). 2026-10-01 실측(부가세 별도): 알림톡 13원 · 단문 18원 · 장문 45원.
- ★★ **단가를 못 받으면 금액을 지어내지 않는다**("단가를 불러오지 못했습니다").
- ★ 문자 종류는 **안내 문구 포함 길이**로 정한다(90바이트 초과 = 장문). 안내 문구가 약 120바이트라 **문자는 사실상 항상 장문(45원)** 이다.
- ★ 단가 조회는 **미리보기에서만** 한다 — 실제 발송 경로(`withBilling:false`)는 단가 서버 지연에 묶이지 않는다.
