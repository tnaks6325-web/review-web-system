# ★ 작업보드 상단 3단 구성 (시안 B · 마감은 작업명 행에서)
- **시안** `frontend/docs/design-workboard-top-3section.html`(A/B 두 안, `?v=A|B` 단독 보기). **B 확정**(사용자 2026-08-06) + master 도구 [⋯] 접기 확정. 대상은 **작업 화면 상단만** — 시트 그리드(작업상세)·툴바·우측 레일 무접촉.
- **종전 = 세로로 쌓인 5블록**(제목 행 / 마감 전폭 띠 / 요약 스트립 8칸 / 정산 상세 / 발주 배너)이라 정작 일하는 표가 아래로 밀렸다. **지금 = 제목 행 + `[작업 조건 · 진행 현황 · 정산]` 3분할 카드**(`.tp3grid`, 광고주는 정산 열 없이 2열 `.n2`).
- ★★ **마감 안내 문구 + [🏁 마감]은 작업명과 같은 행**(사용자 확정): `_finBarHtml` 이 전폭 띠(`.wbl-finbar`, 폐기)가 아니라 **제목 행에 넣을 조각**(`.tp3fin`)을 돌려준다. ★ **루트 `id="finBar"` 유지 필수** — `_finRefresh` 가 `outerHTML` 로 통째 교체하는 계약이다. 상태 3종(진행중 / ✓마감 후보 / 🏁마감된 작업+복귀)은 **같은 자리**에서 표현하고 `openFinishCur`·`doReopenCur`·검수 게이트는 **무변경**.
- ★★ **제목 행은 `nowrap` 이라야 한다**(`.mh.mh-wb`): flex 는 **줄바꿈을 먼저 하고 축소는 그다음**이라(줄나눔 판정 = 축소 전 max-content) `min-width:0` 만 주면 좁은 폭에서 **[마감]이 아랫줄로 떨어진다** — 시안 검증에서 실측. `nowrap` + 제목·시트명·문구의 `min-width:0` 이 **한 벌**. 긴 문장 뒷부분은 `.opt` 로 감싸 1280px 미만에서 CSS 가 접고 `title` 툴팁으로 전문을 남긴다(지우지 않는다). ★ 스코프는 **`mh-wb` 한정** — 공유 클래스 `.mh` 를 건드리면 작업오더·모집공고 등 다른 뷰 헤더까지 nowrap 이 된다.
- ★ **master 도구 3종(Track B 전환·write-back 시뮬·그림자 투영)은 [⋯] 메뉴로**(`#mhTools`) — 주 행동인 [마감]이 오른쪽 끝을 갖는다. `sotBtn`/`projBtn` id 는 그대로(호출부가 참조). 바깥클릭·Esc 리스너는 **최상위 1회만**(`_mhToolsBound` — 열 때마다 걸면 겹쳐 쌓인다).
- ★ **발주 '미연결' 배너는 ① 작업 조건 카드 안쪽 줄**(`_woUnlinkedRow`, admin/master 만)로 흡수 — `renderWorkOrderSection` 은 `!d` 면 `''` 를 돌려준다(같은 말 두 번 금지). 연결된 경우의 작업세부 펼침(`.wodetail`)은 종전 그대로.
- ★ **정산 열은 `#setlCell` + `.setlsummary` 계약 유지**(클릭=상세 펼침·`outerHTML` 교체). 초기 상태도 **`setlSummaryHtml(null)` 한 곳**에서 만든다 — 따로 조립하면 로드 전/후 구조가 갈려 단계 막대가 flex 행에 갇힌다(실브라우저로 잡음). 4단계 표시(마감자료→견적서→계산서→입금)는 `_setlStage` 와 **같은 필드**를 읽는 표시 보조일 뿐 새 판정을 만들지 않는다.
- ★ 제목 행의 초록 배지 「참여자 N」은 뺐다 — 바로 아래 [진행 현황] 열이 같은 값을 `252/300 · 84%` 로 더 크게 보여준다(값이 사라진 게 아니라 자리를 옮긴 것).
- 회귀가드 `server/tests/workdeskWidthCap.test.js` 섹션 I~K + **실브라우저 실행검증**(역할 4종 × 폭 3종 — 같은 행 유지·열 수·상한·중복 배너 0·[⋯] 열고닫기·정산 2회 갱신). ⚠ 이 변경으로 `advertiserViewer` 의 `body.advm` 캡 규칙 패턴을 함께 갱신(`.stripA`→`.tp3grid`, 검사 의미 불변).
