# 업무가이드 메뉴 (리뷰웹시스템[3버전] — 직원용 안내서 모음)
- 리뷰웹시스템[3버전] nav **[업무가이드]** → 직원용 안내서를 분류별 카드로 모아 새 창으로 연다(`renderGuidesView`). 흩어져 있던 `frontend/docs/*.html` 안내서를 직원이 찾을 수 있게 하는 창구.
- ★ **목록 단일 출처 = `workdesk.html`의 `WORK_GUIDES` 배열** — 문서를 추가하면 여기 한 줄만 넣는다. 사본을 두면 "어떤 화면에서는 안 보이는 안내서"가 생긴다. 분류 3종(업무 절차 / 문제 해결 / 기능 이해).
- ★ **내부 설계문서(`prd-`·`design-` 접두)는 넣지 않는다** — 직원이 실제로 따라 하는 절차서·문제해결·기능이해만 담아야 목록이 쓸모를 유지한다. 예외는 `prd-userflow.html`(시스템 소개서, 관리자 화면에서도 쓰는 공식 안내서) 하나.
- ★ **광고주에게는 nav 자체가 없다**(내부 업무 문서) — 관리자·AE 두 nav 변형에만 버튼을 둔다. 한글 파일명은 `encodeURIComponent`, 링크는 `target=_blank rel=noopener`.
- ★★ **주석 안에 `*` + `/` 조합을 쓰지 말 것**(실측 사고): 설명문에 `prd-*/design-*`이라고 적었더니 그 `*/`가 **블록 주석을 조기 종료**시켜 뒤 문장이 JS로 파싱되며 `workdesk.html` 메인 스크립트 전체가 죽었다(CSS `:root` 삼킴 사고와 같은 계열 — 브라우저는 에러 없이 넘어가고 grep 가드로는 못 잡는다). 회귀가드가 **인라인 스크립트를 실제로 파싱**해 고정한다.
- 회귀가드 `tests/workGuides.test.js`(스크립트 파싱·죽은 링크·사본 금지·설계문서 배제·광고주 미노출. 변이시험으로 검출 확인).
