# ★★ 명의 카드 — 2단계 조각 1: 카드 만들기(가산 전용 · 아직 아무도 읽지 않음) (migration 166, 사용자 확정 2026-09-24)

- **배경**: 174 의 뿌리 원인이다. 타계정이 `reviewers.sub_accounts` JSON 에 **칸 순번 목록**으로 저장돼 있다. 같은 사람이 두 번 들어가거나(이름 같음·번호 다름 91명), 주소가 빈 칸(216)이 그대로 남는다. 이 목록을 고치는 곳도 8군데이고 규칙이 제각각이다.
  - 설계안 = `frontend/docs/구매양식_명의카드_2단계_설계안.html`(6조각).
  - 사용자 결정(2026-09-24):
    1. 가 — 가족이 같은 번호를 쓰는 명의 허용
    2. 가 — 다른 리뷰어끼리 겹치는 번호 69개는 담당자 판단
    3. 가 — 합치기 화면은 등록리뷰어DB 안
    4. 나 — 조각 4·5(화면)는 시안을 먼저 보여 준다
- ★★★ **142 의 `reviewer_identities` 를 채우지 않는다(되살리지 말 것)** — 운영 데이터로 시험한 결과, 그 번호표를 켜면 **타계정이 있는 리뷰어 632명 중 174명(27%)이 막힌다**. 이유는 다음과 같다.
  - `buildIdentitySeeds` 가 소유자 안 번호 중복을 거부하는데, 가족이 같은 번호를 쓰는 경우가 168명이다. 회원가입도 "같은 번호 + 다른 이름 = 타계정"으로 받아 왔다.
  - 열린 별칭 phone8 을 **전역 유일**로 강제한다.
  - 주소·계좌를 `member_no = 배열 순번 + 1` 로 찾는다.
  - 게다가 그 표를 **이미 9개 파일이 읽어서** 채우는 순간 라이브 동작이 바뀐다.
  - 그래서 새 표 `reviewer_identity_cards` 를 두고, 옛 번호표는 꺼진 채로 둔다.
- **모델**: 카드 = 명의 하나. `id`(UUID)가 곧 이름표이고 칸 순번·전화번호로 사람을 구분하지 않는다.
  - 본인 카드는 소유자당 하나(부분 유일).
  - **이름·번호가 완전히 같은 카드만** 유일 인덱스로 막는다(`owner, name_key, phone8`). 같은 번호·다른 이름(가족)은 허용한다.
  - 완전 중복 칸은 한 장으로 합치고 **빈 칸만** 채운다. 값이 서로 다르면 `exact_duplicate.conflicts` 로 보고한다.
  - **이름만 같고 번호가 다른 칸은 따로 만들고** `same_name_diff_phone` 으로 보고한다. 합치기는 담당자가 한다(조각 4).
- ★★ **이 조각의 약속(완화 금지)**:
  - ① **아무도 카드를 읽지 않는다** — `sub_accounts` 가 여전히 진실원본이다. 가드가 `src/` 전체에서 표 이름 참조가 서비스 1개뿐임을 고정한다.
  - ② **`sub_accounts` 를 한 글자도 바꾸지 않는다**.
  - ③ **주민번호를 옮기지 않는다**(민감정보 복제 확산 방지 — 조각 3 에서 다시 정한다).
  - ④ 동기화는 **빈 칸만 채우고, 카드를 지우거나 값이 있는 칸을 덮지 않는다**. ⚠ 조각 2-1(176)이 이 약속을 "목록을 그대로 따라가는 거울"로 대체했다.
  - ⑤ 적용은 `confirm:true` 필수 · 소유자 행 `FOR UPDATE` · 소유자마다 한 트랜잭션 · 여러 번 돌려도 결과 동일.
- ★ **FK 는 `ON DELETE CASCADE`**. RESTRICT 로 두면 카드를 채우는 순간 **등록리뷰어DB 의 리뷰어 삭제가 전부 막힌다**(개발 중 진짜 PG 시험이 잡았다). 조각 1 의 카드는 사본이라 잃는 것이 없다. 카드가 진실원본이 되는 조각 3 에서 다시 정한다.
  - `merged_into` 는 `SET NULL` 이다. RESTRICT 면 합친 카드끼리의 연결이 소유자 삭제를 막는다.
- **API**: `GET /api/trackb/identity-cards/preview`(쓰기 0) · `POST /api/trackb/identity-cards/apply {confirm:true, limit, afterId}`. 둘 다 adminOrMaster, 화면 없음.
