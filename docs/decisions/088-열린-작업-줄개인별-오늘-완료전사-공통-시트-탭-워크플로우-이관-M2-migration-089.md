# ★★ 열린 작업 줄(개인별) + 오늘 완료(전사 공통) — 시트 탭 워크플로우 이관 M2 (migration 089)
- **완성된 그림**: 0단 = 내가 열어둔 작업(브라우저 탭) · 1·2단 = 업체 세그먼트/그룹 탭(기존) · 마감(088) = 보드에서 제거 · 오늘 완료(089) = 뒤로+회색. 이제 **업체를 거치지 않고 0단 클릭만으로 작업을 오간다**(직원이 지적한 불편의 직접 해소).
- ★★ **"오늘 완료"와 "마감"을 절대 합치지 말 것**(사용자 확정): 오늘 완료는 **목록에서 사라지지 않는다**(뒤로 밀고 회색만 — 사라지면 오늘 몫을 끝낸 작업을 다시 못 연다), 마감은 **영구**(보드에서 제거·보관함으로). 합치면 "오늘 몫 끝낸 작업이 모두의 보드에서 사라지거나, 끝난 작업이 매일 아침 되살아난다".
- ★★ **자정 리셋 크론이 없다** — 판정 = `done_date = KST 오늘`이라 날짜가 바뀌면 어제 행이 **저절로** 빠진다. boolean 컬럼으로 바꾸는 순간 어제 체크가 영원히 남고 그걸 지울 배치가 필요해진다. **해제는 오늘 행만 DELETE**(어제 이력을 지우면 "언제 처리했나"가 사라진다). KST 파생은 `campaignState.kstTodayStr` **재사용**(사본 금지 — 날짜 규칙이 두 벌이면 갈린다).
- ★★ **열린 줄은 즐겨찾기 원장에 얹지 않는다** — 그쪽은 클라가 **Set 으로 재직렬화해 순서가 사라진다**. 여기서 순서 = 사용자가 드래그로 정한 탭 배치라 신규 테이블(계정당 1행 + JSONB 배열). 키 규약(`_favKey`)은 재사용(두 벌이면 같은 탭이 다른 키가 된다).
- ★★ **부팅 경합**(실브라우저가 잡은 실측 사고): 부팅 조회(`_wtSyncFromServer`)가 **사용자의 첫 클릭보다 늦게 도착하면 방금 연 탭을 덮어쓴다**. → 변경은 **단일 커밋 지점 `_wtCommit`** 에서만 하고 거기서 `_wtDirty` 를 세운다. dirty 면 서버 값을 버리고 **서버를 내 상태로 맞춘다**. 커밋 사본을 두면 어떤 경로는 dirty 를 안 세워 경합이 되살아난다.
- ★ **작업을 여는 모든 경로가 `selTab` 으로 수렴** → 거기서 `_wtOpen(t)` 한 번(그룹 탭·검색·홈 목록·딥링크 공통). 사본을 두면 어떤 경로로 연 작업만 줄에 안 남는다.
- ★ **마감된 작업은 열린 줄에서 자동 정리**(전사 공통이라 남이 마감해도 빠진다). ★★ 단 **목록이 아직 안 왔을 때(`STATE.tabs` 비어 있음)는 정리하지 않는다** — 안 하면 부팅 때 열린 줄이 통째로 지워진다.
- ★ **상한 12**(사용자 확정 ㉤): 서버는 **잘라 담을 뿐 요청을 튕기지 않는다**(튕기면 화면이 멈춘다), 화면은 **안내만** 하고 자동으로 닫지 않는다.
- ★ **onclick 문자열 보간 금지는 여기도 동일**(M1 실측 XSS): `wtPick(this.dataset.k)` — 그리고 **닫기(×)에도 `data-k` 를 붙인다**(부모 `.wt0` 에만 두면 `this.dataset.k` 가 undefined 라 닫기가 죽는다 — 실브라우저가 잡음).
- ★ 조회 실패는 `dailyUnavailable` 로 고지하고 **기존 체크를 덮지 않는다**(088 의 무신호 규율과 동일). 토글 실패 시 낙관적 반영을 되돌린다. 권한은 마감과 같다(master/admin 전체 · staff 담당 탭 · 광고주 차단·주석 미동봉). 단 **열린 줄은 개인 데이터라 스코프 게이트가 없다**(자기 것만 읽고 쓴다 — 즐겨찾기와 같은 계약).
- ★★ **계정 전환 시 메모리 상태를 반드시 비운다**(코드리뷰 blocker): localStorage 키가 계정별이어도 `_wtLoaded`/`_wtDirty`/`worktabs` 를 안 비우면 **키 분리가 무의미**하다 — 새 계정 캐시를 읽지 않고 이전 계정 배열을 그리고(스코프 밖 탭명 노출), dirty 가 남으면 `_wtSyncFromServer` 가 새 계정 GET 을 버리고 **이전 계정 목록을 새 계정 서버 행에 저장**한다. `logout` **과 `_dropSession`(401 재로그인)** 둘 다.
- ★★ **`getWorkdeskWorktabs` 도 `{ok, tabs}`**(코드리뷰 blocker): 조회 실패를 빈 배열로 접으면 프론트가 그것을 서버 원본으로 신뢰해 로컬을 덮고, 다음 탭 하나를 여는 순간 **서버 행이 1건짜리로 영구 대체**된다. 라우트가 `worktabsUnavailable` 을 실어 주고 프론트는 로컬 유지 + 고지. 저장의 42P01 도 `not_ready` 로(프론트 `catch` 가 삼켜 무신호가 되던 경로).
- ★★ **부팅 경합 가드는 1회 한정(`_wtBootSynced`)** — `_wtDirty` 를 영구 깃발로 쓰면 세션 중 탭을 한 번 연 뒤로 서버 값을 **영영 안 받아** 다른 창·다른 PC 의 변경이 한 방향으로만 지워진다("기기 무관 유지" 약속과 정면 충돌). push 성공 시 dirty 해제. **자동 정리(`_wtPruneFinished`)는 dirty 를 세우지 않는다**(시스템 정리를 사용자 편집으로 치면 구식 로컬이 최신 서버를 이긴다).
- ★ **정리는 데이터 도착 지점에서, 렌더는 순수하게** — 렌더 함수가 서버에 쓰면 부수효과가 렌더 타이밍에 묶여 0단이 없는 화면(홈)에선 정리가 안 도는 비대칭이 생긴다.
- ★ **상한에서 열기를 막는다** — 서버가 뒤를 자르는데 클라가 끝에 추가하면 **방금 연 탭만 저장되지 않아** 새로고침 시 이해 불가한 동작이 된다. ★ **드래그는 오른쪽=대상 뒤**(항상 앞이면 끝자리로 옮길 수가 없다).
- ★ **오늘 완료에는 gid 폴백이 없다(의도)** — `trackb_tab_daily_done` 에 `tab_gid` 가 없고 하루짜리 상태라 리네임으로 풀려도 다음날 초기화된다(마감은 영구라 폴백이 필요). 주석으로 명시 — 없으면 다음 사람이 버그로 읽는다.
- ★ **밤새 띄워 둔 화면**은 `visibilitychange` 복귀 시 날짜를 확인해 자가치유(토글 시점 자가치유만으론 조작이 없으면 어제 체크가 계속 보인다).
- CSS 는 `tb0`·`wt0` 접두 신설. 회귀가드 `server/tests/workboardWorktabs.test.js`(라우터 스택 실검사 + 스텁 pool 로 서비스·라우트 실행 + 격리 + 프론트 배선, **변이시험 검출 확인** — 그중 1종은 가드가 통과시켜 단언을 강화했다: 실패 경로가 둘(응답 실패·네트워크 예외)이면 **둘 다** 검사할 것) + **진짜 PG16**(순서 보존·상한·멱등·**어제 행이 저절로 빠지는지**·해제가 오늘 행만 지우는지) + **실브라우저 실행검증**(열기/닫기/드래그/전환·오늘 완료 뒤로 밀기·마감 시 자동 정리·부팅 경합·새로고침 유지·**계정 전환 누수**·**조회 실패 시 데이터 보존**·상한 절단·자정 자가치유). ⚠ M2 도입으로 `workboardFinish`(블록 추출 경계)·`workdeskTopbar`(selTab 새 의존) 가드를 함께 갱신했다.
