# 선택지 유입가이드 사진 자리 = 글 속 사진 주소 한 줄 (D4 「나」 · 사용자 확정 2026-10-22 · 미반영)

## 배경
양방향 공고 편집 v3 4단계(D4). 선택지별 유입가이드는 지금까지 "글 칸 + 사진은 글 아래(최대 4장)" 모양이라
사진을 글 중간에 둘 수 없었다. 시안 가(블록 문서 · 새 저장 칸)와 나(글 속 사진 주소 한 줄 · 저장 칸 그대로)를 보고
사용자가 **「나」** 를 골랐다(시안: claude.ai artifact Ru2WrKN28rTNtxMN7Z4Gy1).

## 결정
- **저장 모양(새 칸 없음)**: 작업오더 `guide: { text, images }` 의 `text` 안에 **사진 주소만 있는 한 줄 = 그 자리에 사진**.
  - **맨 끝(뒤에 글이 없는) 사진은 자리 표시를 하지 않는다** — 목록(`images`)에만. 그래서 옛 모양("글 + 사진 목록")과 같은 가이드다.
  - 공고(`campaign_options.inflow_guide_html`) 는 그 자리에 `<img>`(앞뒤 `<br>`) + 맨 끝 사진 `<img>` + `inflow_guide_images`(글 속 차례).
  - 서버 투영(`inflowGuideCompose.plainGuideToHtml`)은 원래 글 속 주소를 그 자리 `<img>` 로 바꿨으므로 손대지 않았다. 리뷰어 화면(`campaign-workdetail`)도 HTML 을 그대로 그리고 목록 사진은 겹치면 접으므로 손대지 않았다.
- **비교 규칙(`utils/guideCanon`)이 사진 자리를 본다**: `canonGuide(html, images)` → `{ text, images, view }`
  - `text` = 오더에 싣는 글(주소 줄 포함) · `view` = 비교·표시용 글(주소 대신 `⟦사진 N⟧` — 호스트가 달라도 같은 파일이면 같다)
  - `canonGuideKey` · `orderToCampaignProjection._optionShape` · `campaignSharedEdit._planGuideEdit` 의 비교는 `view` 로.
  - 운영 실측(2026-10-20): 진행 중 선택지 가이드 21개 중 사진이 글 중간에 낀 것 0 → **이 규칙으로 바뀌는 기존 비교 결과 0**(회귀가드 `bidirD4GuidePosition` ① 이 옛 모양 열쇠 불변을 고정).
- **편집 화면(리뷰웹 공고 카드 · 인트라넷 리뷰오더 둘 다)**: 글 칸 하나 안에 사진 줄이 끼어든다.
  - 넣고 싶은 자리를 누르고 「여기에 사진 넣기」 → 커서 줄에서 글이 갈라지고 사진 줄이 들어간다(붙여넣기도 커서 자리 · 「끌어다 놓기 · 클릭해 고르기」는 맨 끝).
  - 사진 줄마다 위로·아래로(옆 글 한 줄과 자리 바꿈, 바로 옆이 사진이면 둘을 바꿈)·빼기. 최대 4장이면 넣기 버튼이 꺼진다.
  - 리뷰웹: `index-recruit.js` `_ugSt/_ugDocSync/_ugDocRender/_ugDocBind/_ugMove/_ugLoad/_ugCompose`. 사진 항목은 `_igState[key]` 의 그 객체(올리기·장수·확대 보기는 위젯 한 벌 그대로). 종전 "사진 스트립 왼쪽 · 글 오른쪽"(2026-08-25 3차 통일) 규격을 대체한다.

## 지킬 것(완화 금지)
- ★★ **글 칸 타이핑 중에는 다시 그리지 않는다** — 한글 조합이 깨진다. 사진을 넣고·옮기고·뺄 때만 다시 그린다(가드 `campaignUnitGuideFront` [L·M]).
- ★★ **맨 끝 사진에 자리 표시(주소 줄)를 붙이지 않는다** — 붙이면 옛 모양 가이드의 비교 열쇠가 바뀌어 기존 연결 공고가 전부 "다름" 으로 뜨고, 옛 화면에 쓸데없는 주소 글자가 보인다.
- ★ 사진 줄의 주소는 `https` 여야 저장된다(공고 HTML 정화 `sanitizeGuideHtml` 이 https 만 남긴다 — 실제 주소는 늘 https).

## 배포 스큐(알고 감)
- 새로고침하지 않은 옛 화면에서 글을 고쳐 저장하면 사진 자리가 맨 끝으로 간다(사진은 남는다). 옛 인트라넷 화면은 주소 줄을 글자로 보여 준다.
