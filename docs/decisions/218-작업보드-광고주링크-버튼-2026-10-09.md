# 작업보드 상단 [🏢 광고주링크] — 그 작업의 광고주 접속 링크를 즉시 복사 (사용자 확정 2026-10-09 · 스키마 변경 0)

## 요청
- 작업보드 [🔗 링크 복사] 옆에 [🏢 광고주링크] 버튼 — 해당 작업의 광고주 뷰어 링크를 바로 복사.

## 충돌과 결정
- 2026-09-09(커밋 76c7dae7 "unify viewer link controls")에 **업체관리** 목록·상세에 흩어진 광고주 링크 복사 버튼을
  「광고주 접속 링크」 한 곳으로 모았고, 가드(`advertiserLinkNoLogin`·`shareLink`)가 파일 전체에서 `copyAdvertiserLink` 를 금지했다.
- 사용자 확정(선택지 1): **업체관리는 한 곳 그대로**, 작업보드 상단에만 하나 더 허용한다. 가드는 범위를 좁혔다 —
  업체관리 목록·상세 중복 경로(`_ovmCopyAdvLink`·`ovm-lkcopy`) 금지 유지 + `copyAdvertiserLink()` 호출은 작업보드 상단(`advLinkBtn`) **딱 1곳**.

## 동작 (`frontend/workdesk.html copyAdvertiserLink`)
- 링크 = 업체관리와 **같은 것**(업체당 하나 · `/api/trackb/advertiser-link` `action:'ensure'` — 없으면 만들고 기존 링크는 바꾸지 않는다. 회전은 업체관리에서만).
- 소유 업체 = 작업목록이 붙인 `advertiserId`(탭지정 > 시트전체 — 업체관리와 같은 판정).
- 업체 미지정 → 서버 호출 없이 "업체관리에서 먼저 지정" 안내 · 폐기된 링크 → 복사하지 않고 [다시 활성] 위치 안내(fail-closed) · 조회 실패 → 실패를 말한다.
- 자동 복사 성공 = 화면 중앙 알림, 막히면 주소 창(노출 범위 경고 포함 — 조용한 실패 금지).
- 내부 역할(master/admin/staff)만 — 서버 `internalMiddleware` 와 1:1. 마감 작업은 [링크 복사]와 같이 숨김.
- ⚠ 이 링크는 그 업체의 **모든 작업**(리뷰어 연락처·주소 포함)을 보여준다 — 버튼 설명·복사 안내에 "광고주에게만 전달" 명시.

## 완화 금지
- ★ 작업보드 버튼에서 링크를 회전(`generate`)하지 않는다 — 누를 때마다 광고주가 쓰던 링크가 죽는다.
- ★ 업체관리 목록·상세에 복사 버튼을 다시 늘리지 않는다(09-09 통합 유지).
