# ★★ 작업(소유) 이관 — 다른 거래처로 옮기기 (2026-08-10 위프코리아 건 · 스키마 변경 0)
- **사고**: 「위프」 작업이 `(주)위드프렌즈` 소유 시트 안에 있는데 실제 광고주는 **별개 등록된 `주식회사 위프코리아`**였다. 종전엔 옮길 창구가 없었다 — 거래처 등록 폼은 **미지정 시트만** 고를 수 있어(`_ovmAddAdvHtml` 의 `freeSheets`) **이미 소유된 시트의 일부 탭만 새 업체로 넘기는 것이 구조적으로 불가능**했고, [소유 추가]로 겹쳐 지정하면 두 업체가 같은 작업을 갖는 상태가 됐다.
- **모델 = 기존 `advertiser_campaigns` 만**(신규 테이블·마이그레이션 0). 이관 = **같은 범위의 기존 소유 소프트 해제 + 새 업체 업서트**를 `transferOwnership` 이 **한 트랜잭션**으로 한다 — 중간 실패로 "주인 없는 작업"이 남지 않는다.
- ★★ **범위(scope)가 계약**: `tabGid` 있으면 **그 탭만**, 없으면 **시트전체 행만**. 탭 이관은 시트전체 행을 **건드리지 않아** 나머지 탭이 옛 업체에 그대로 남고, 시트 이관은 **타 업체의 탭지정 세분 소유를 보존**해 `keptTabOverrides` 로 보고한다(조용한 삭제 금지 — 세분 소유는 사람이 명시한 더 강한 결정이다).
- ★★★ **판정 우선순위(탭지정 > 시트전체)를 전개 SQL 에도 반영해야 한다** — `ownedTabsForAdvertiser`·`advertiserOverview` 의 시트전체 전개에서 **타 업체가 탭지정으로 가져간 탭을 `NOT EXISTS` 로 배제**한다. 빼면 이관한 작업이 **옛 업체 표·작업 수에 그대로 남아** "이관했는데 아무것도 안 바뀐" 화면이 된다(`advertiserForTab`·`scopedActiveTabs` 가 이미 쓰는 규칙을 같은 자리에 맞춘 것 — 사본이 아니라 정합).
- ★★ **`advertiserOverview` 는 `SELECT DISTINCT` 필수 (진짜 PG16 실측으로 발견)**: 한 업체가 같은 시트의 **시트전체 + 탭지정을 동시에** 가지면 그 탭이 두 own 행에 매칭돼 **작업 수가 이중 계수**된다(탭 이관 → 시트 이관 순으로 두 번 하면 즉시 도달). 연결탭 표는 `tabs` CTE 의 `DISTINCT ON` 이 접어 주므로 여기만 두면 **개요 숫자 ≠ 연결탭 표**로 갈린다.
- **API = `POST /api/trackb/ownership/transfer`(adminOrMaster)** — 업체 간 재배치는 staff 초기매핑 게이트가 이미 "재배치는 관리자에게 요청"으로 못박은 admin 소관이다. 대상 검증은 **fail-closed**(업체 미존재 404 · **종료(ended) 거래처 거부** · 필수값 없으면 쓰기 0 + ROLLBACK).
- **화면 = 업체관리 › 소유 캠페인 줄 [이관]**(admin/master 에만 렌더 = 서버 게이트와 1:1) → 팝업에서 **범위**(시트 전체 / 특정 탭 다중선택)와 **대상 거래처**를 고른다. ★ 대상에 **[＋ 새 거래처 등록]** 경로를 둔 것이 이번 사고의 직접 해소 — 인트라넷 광고주DB **정확일치 검증**(`_trChk`, 등록 게이트 동일 · 서버 `createAdvertiserScoped` 가 최종 방어)을 통과해야 실행되고, **이미 등록된 이름이면 새로 만들지 않고 그 업체로 이관**한다(409 예방).
- ★ 팝업은 **body 직속**(드로어 스크롤 컨테이너에 두면 흐름에 섞인다) · **바깥 클릭으로 닫지 않는다**(고른 값 보호, Esc·[취소]만) · **Esc 리스너는 드로어보다 먼저 등록 + `stopImmediatePropagation`**(팝업과 드로어가 한 번에 같이 닫히지 않게) · onclick 은 **인덱스만**(탭명·업체명은 시트/외부발 문자열) · 새 거래처명 입력 중에는 **팝업을 재렌더하지 않는다**(제안 목록·검증 문구만 갱신 — IME 조합 보호).
- ★ **부분 실패를 "완료"로 꾸미지 않는다** — 탭 여러 개를 고르면 건별로 전송하므로 `일부만 이관됨 (1/2) — 사유` 로 **몇 건이 옮겨졌는지 사실대로** 말한다.
- ⚠ **이관해도 따라오지 않는 것(문서화)**: 계약·정산 링크(`trackb_settlement_links`)는 탭에 매달려 있어 **그대로 유지**된다 — 계약이 옛 업체 것이면 [계약 매칭]에서 다시 매칭해야 한다(팝업이 문장으로 고지). 브랜드 배정·광고주 접속 링크도 업체별 원장이라 별개.
