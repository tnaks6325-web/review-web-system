## 바뀐 것
- **구매양식(틀 안)**: 카드 테두리를 걷고 `<details class="of-fold">` 구획 5개(구매사진·주문 정보·받는 사람·배송지·이번 주문의 입금 계좌·비고). 이름표 96px 왼쪽, 필수 빨간 별 대신 선택 칸에 "선택". 배송주소·비고는 한 줄로 시작해 내용만큼 늘어남(`_ofAutosize`). 가림문자 칸 아래 "가려짐(*)"(`_syncMaskNotes`). 구매사진 = 세로 썸네일 + [전체 보기](사진 아래로 크게 펼침 — 틀 안이라 화면 고정 창을 쓰지 않음) + [사진 변경].
- **칸 순서**: 결제금액 → 「주문 정보」 안(아이디 다음), 아이디 저장 체크 → 「주문 정보」 맨 아래. ★ 그래서 `_EMBED_FORM_LAYOUT = 2`(결정 350의 첫 사용).
- **현재 참여 명의 두 줄**: 아이디 `${cid}_identityWho`·`${cid}_identityStatus`는 그대로 두고 받는 사람 구획 맨 아래 `#${cid}_identityBlock`로 옮김. 오른쪽 상태 = `_renderIdentityHead`(판정은 종전 `_identityIssues`·`approvalToken` 그대로) → "✓ 명의 확인됨" / "확인 필요 N개". 직접 링크에선 명의 줄을 숨긴다(종전엔 "선택한 참여 명의 / AI 확인" 자리표시자가 남아 있었다).
- **내 정보에서 선택**: 작은 글자 링크 + 화면 폭 안(양쪽 8px · 최대 340px) 두 줄 목록, 고른 값 ✓, 아래 공간이 모자라면 위로(`_ofPlaceMenu`). 틀 안에서는 틀이 내용 높이로 늘어나 있어 **부모 화면의 틀 위치·보이는 높이**로 위/아래를 정한다(`_ofVisibleBand`).
- **공고 화면(바깥)**: 흰 바탕 한 장 흐름. 남은 시간 줄 = 회색 글자 + 굵은 숫자, 3분 미만 "· 곧 마감돼요"(주황), 제출 시간이 오늘 모집 마감에 잘렸으면 "오늘 모집 마감 HH:MM까지". 작업 내용 = `CampWorkDetail.renderInto(..., {layout:'v18'})` 일 때만 상품 한 줄 + [전체 안내] + 특이사항(펼침)→유입(기본 펼침; 2026-11-10 후속 요청)→리뷰 가이드(접힘). 링크유입 카드는 접지 않음(구매 길을 숨기지 않게).
- **직접 링크**: 로그인한 리뷰어 = 얇은 한 줄(답 8), 주문 추가(최대 5) = 작은 글자 버튼(답 7), 제공정보 카드 얇게.

## ★★ 완화 금지 / 규칙
- ★★ **제한시간 0 = 바로 "제한시간이 만료되었어요" + [다시 참여하기]**(답 9). **이미 누른 제출은 끊지 않는다** — `_formSubmitting()`(틀 안 `window._submitOrderFormInProgress`)이 참이면 `releaseExpiredHold` 가 화면을 덮지 않고 2초 뒤 다시 본다. 이 확인을 빼면 제출 도중 만료 화면이 떠 리뷰어가 같은 주문을 다시 내거나 "제출 안 됨"으로 오해한다.
  - 운영 서버의 작업 조회는 유예 없이 `expires_at <= now` 면 바로 `expired` 를 준다(`campaign.routes.js` work-detail). 30초 유예(`HOLD_GRACE_SEC`)는 확정 처리 쪽 지연용이다.
- ★★ **작업 내용의 새 배치는 `layout:'v18'` 옵션일 때만** — `cardsHtml()` 출력은 그대로 두고 그린 뒤 DOM 만 바꾼다. 관리자 미리보기(모집공고 모달·공고수정)는 옵션을 넘기지 않아 종전 그대로(답 10: 미리보기 문구는 이번에 안 바꿈).
- ★★ **새 모양은 새 클래스 아래에만** — `.of-fold`·`.of-identity-block`·`.of-mask-note`·`.is-floating`·`body.embed-mode` 등. 네이버·쿠팡 동시진행 양식(`dual-channel-purchase.js`)이 `.of-field/.of-order-card` 를 같이 쓰므로 옛 클래스 규칙을 바꾸면 그 화면까지 바뀐다.
- ★ 칸을 보여주거나 스크롤할 때는 `_ofReveal(el)` 로 접힌 구획을 먼저 연다(오류 표시·명의 칸 안내·캡처 선택·옵션/상품 고르기·별표 칸·첫 오류칸 — 8곳).
