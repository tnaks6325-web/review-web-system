# ★★ 필수 배송메세지를 리뷰어 작업가이드에 보인다 — 결제 전 자리(상품 카드 · 현금영수증 안내 다음) 「🚚 필수 배송메세지」 카드 (2026-11-19 · 스키마 변경 0)

## 무슨 일이 있었나
- 담당자 요청(2026-11-19 · 「11/19(네이버)위프_탈취제_버건디 3종 15건」): 「배송메세지 진행건 가이드에 리뷰어도 필수 배송메세지가 보이게 해 달라」.
- 결정 260 의 필수 배송메세지(`recruit_campaigns.required_delivery_memo`)는 구매양식 제출 때 캡처에서 그 글자를 확인해 막는 **검사 기준**일 뿐,
  리뷰어 작업가이드 응답(`/api/campaign/:id/work-detail`)에도 화면에도 실리지 않았다. 리뷰어는 결제 전에 무엇을 적어야 하는지 볼 곳이 없었고,
  직원은 공고 제목(「… / 배송메시지 00<<<」)이나 특이사항에 문구를 따로 적어 우회했다(운영 실측: 값이 든 공고 5건 중 2건).

## 결정
- 서버: 작업가이드·관리자 미리보기 응답에 `requiredDeliveryMemo` — 구매양식 검사와 같은 정규화 함수(`requiredDeliveryMemo.service.normalizeRequired`) 결과, 없으면 ''.
  이미 그 글자로 검사하는 값이라 새로 드러나는 정보는 없다(참여 후 응답에만 · 참여 전 공개 목록에는 싣지 않는다).
- 화면(`campaign-workdetail.js` 공용 렌더러): 값이 있으면 **상품 카드 다음(현금영수증 안내가 있으면 그 다음)** 결제 전 자리 — 현영 안내의 「상품 바로 뒤」 자리(cashReceiptGuide 가드)는 그대로 「🚚 필수 배송메세지」 카드 —
  문구를 굵게 그대로 + 오른쪽 [복사] 버튼(사용자 요청 2026-11-19 — 누르면 「복사됨」 · 복사가 막힌 브라우저는 문구를 선택해 두고 「길게 눌러 복사」 · 크롬 실제 클립보드 확인) + 하단 작은 문구 한 줄 「구매캡처에 이 배송메세지가 보여야 구매양식이 제출돼요.」(사용자 확정 2026-11-19 — 다른 안내 문장 없이 이것만 · 줄바꿈 없이 한 줄, 좁은 폰은 글자 크기만 줄인다: 320·360·390 폭 크롬·WebKit 에서 잘림 0 실측)
  - 제목은 개편 배치(v18)의 접는 카드 표식(📦·🧭·📝·📌)으로 시작하지 않는다 — 접히거나 상품 카드로 오인되지 않게. v18 이 카드 테두리·여백을 지우므로 인라인으로 준다.
  - Q&A(구매 없음)에는 안 보인다. 값이 없으면 카드째 없음 = 종전 HTML 한 글자도 같다.
- 공고 창 인라인 미리보기도 입력칸 값을 넘겨 같은 카드를 보인다.
- 배포 순서 무관: 옛 화면 + 새 서버 = 칸 무시(종전) · 새 화면 + 옛 서버 = 칸 없음 → 카드 없음(종전).
