# 오늘 마감 카드 — 아래로 정렬 + 회색 썸네일 + 재오픈 카운트다운
- 리뷰어 목록에서 **오늘 마감된 공고가 진행 중인 공고 사이에 섞여 있으면** 참여 가능한 공고를 놓친다 → `campaign-cards.js` `sortByAvailability`(공용)로 등급 정렬: 0 지금 참여 가능(open) / 1 곧 열림·잔여 대기(preopen·soft_full) / 2 오늘 마감(cutoff·daily_done) / 3 완전 종료(closed). **안정 정렬**이라 같은 등급 안에서는 서버 순서(⭐ 별표 우선노출·최신순)가 그대로 유지된다. 소비처 = `index.html` 홈 미리보기 · `recruit.html` 목록 · `renderInto`/`gridHtml`. **관리자 모집공고 탭은 미적용**(별표 순서가 관리 의도라 그대로 둔다).
- **마감 카드 표시**: 썸네일 위에 `.pt-ovl.pre`(반투명 어둠 + `backdrop-filter:grayscale(1)`)를 덮고 가운데에 흰 글씨로 **다시 열릴 때까지 카운트다운**. 같은 말을 하는 `금일 모집완료` 리본은 오버레이가 뜨면 겹치지 않는다(`dailyOverlay`).
- ★★ **카운트다운 기준은 `reopensAt`이지 `opensAt`이 아니다**: `opensAt`은 **오늘의** window_start(=이미 지난 시각)이고 **자율주문은 아예 null**이라 그대로 쓰면 카운트다운이 0에 붙는다. `computeCampaignState`가 daily_done 세 분기에 `reopensAt`을 따로 실어 준다 — 다음 오픈일 판정은 `nextOpenDate`(아래 항목 — 시트 진행일 · 주말 미게시 · 0명 조절을 함께 본다). 시각은 window_start(자율주문은 KST 자정). 휴무일(rest_day)은 기존 `opensAt`과 같은 값. `opensAt` 시맨틱은 **건드리지 않았다**(카드 시간표기·오픈전 카운트다운·`_fmtHM` 소비처 무영향). 공개 뷰·관리자 목록 양쪽 응답에 실린다.
- ★★★ **"다시 오픈" 날짜는 실제로 열리는 날이어야 한다 — 주말 미게시·0명 조절을 건너뛴다 (2026-08-21 신고)**: 종전 `_reopenIso()` 는 시트 일정(063, **기본 꺼짐**)이 없으면 **무조건 내일**이라, 주말 제외 공고가 금요일에 정원을 채우면 썸네일이 `8/22(토) 다시 오픈` 이라 말하고 정작 토요일엔 apply 가 막혀 `주말 미게시 · 월요일 재개` 로 **문구가 뒤집혔다**. → `campaignState.nextOpenDate(c, from, sch, plans)` 가 후보를 훑으며 ① **주말 미게시**(104) ② **0명 조절**(095 — 0 = "그날은 안 연다", 휴무일·일정종료 판정이 이미 쓰는 뜻) 인 날을 건너뛴다.
  - ★★ **주말 판정 사본 0 = `campaignWeekend.isWeekendClosedOn`** — **apply 게이트(`weekendPublicationState`)와 같은 함수**를 본다. 사본을 두면 "카드는 토요일 오픈이라 하는데 서버는 토요일에 막는" 상태가 그대로 되살아난다. 0명 조절도 `planOverrideFor` 그대로(정원 판정과 같은 것).
  - ★★ **못 찾으면 첫 후보(=종전 동작)로 접는다** — 60일을 훑어도 열리는 날이 없으면 `null` 이 아니라 내일/다음 진행일을 돌려준다(카운트다운을 빈 값으로 두면 카드가 아무 말도 못 한다). ★ **1명 이상 조절은 건너뛰지 않는다**(사람이 정한 인원 — 완화 금지).
  - ★ **오픈 시각 파생도 한 곳**(`openMinutesFor(c)` — 자율주문 = KST 자정 / 시간창 = window_start). 금일마감·휴무일·주말 재개 셋이 같은 것을 쓴다. ★ **"무조건 내일" 헬퍼(`kstTomorrowStr`)는 제거했다** — 되살리면 신고 건이 그대로 재현된다(회귀가드가 부재를 고정).
  - ★★ **주말 미게시 카드에도 썸네일 카운트다운이 있다** — 종전엔 상태가 `weekend_unpublished` 로 덮이면서 오버레이가 통째로 사라져, 금요일에 본 "(토) 다시 오픈"이 토요일엔 **아무 표기 없이** 없어졌다. 재개 ISO 는 `resumesAt`(신규 필드), 날짜는 정책값(다음 월요일)이 아니라 `nextOpenAt`(같은 판정)이 정한다 — 월요일이 0명 조절이면 "월요일 재개"가 거짓이 되기 때문. **계산 실패는 정책값으로 접는다.** ⚠ apply 403 의 `resumesOn`·문구는 종전 정책값(월요일) 그대로다(그 경로는 counts·schedule 을 갖지 않는다).
  - ★★ **관리자 목록(`/admin/list`)에도 주말 미게시를 싣는다** — 종전엔 공개 목록에만 적용돼 **토요일 관리자 카드가 "모집중 · 오늘 모집 0/30"** 으로 보였다(리뷰어는 신청 불가인데). 카드 렌더러의 weekend 분기(`_zeroQuotaNote`·footer)는 이미 이 값을 기다리고 있었다(dead branch 였다).
  - ★ 정렬 등급에 `weekend_unpublished: 2`(= 오늘 마감) 합류 — 없으면 기본값 1(곧 열림)로 접혀 **오늘 마감 카드보다 위로** 올라온다. ★ 푸터도 '내일'을 박지 않고 `reopensAt` 을 말한다. ★ 문구 조각은 `_fmtOpenWhen`(시점만) + `_fmtOpenLabel`(= 시점 + ' 오픈') 으로 나눠 "8/24(월) **오픈 다시 오픈**" 중복을 없앴다.
  - ⚠ **정원 계산·신청 게이트는 무접촉**(표시 경로만). 주말 제외 공고의 토/일 정원은 여전히 계산되고 소진되지 않아 **자동 이월(066)로 다음 진행일에 얹힌다**(상한 2배). 그리고 **주말 토글을 바꿔도 날짜별 계획·작업표는 자동 재배치되지 않는다**(그 기능 자체가 없다 — [📅 인원]에서 사람이 조절·저장해야 반영).
