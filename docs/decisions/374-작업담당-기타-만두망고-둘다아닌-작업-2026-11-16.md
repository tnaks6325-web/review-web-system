# 작업담당 「기타」 — 만두·망고 둘 다 아닌 작업(예: 블로그) · 인트라넷과 같은 네 값 · 미지정 아님 · 입금관리는 만두·망고 칩에 섞지 않음 (사용자 확정 A·가 2026-11-16)

## 요청
- 사용자: "홈화면 확인할것에 블로그작업은 만두도 망고도 아니다(기타)선택지 필요하다".
- 확정(2026-11-16): **A** 인트라넷 리뷰오더 작업담당에도 「기타」를 넣어 두 시스템 값을 같게 유지 / **가** 입금관리 담당자 고르기에서 기타 작업은 만두·망고에 섞지 않는다(「전체」에서 보이고, 기타 작업이 있으면 「기타」 칩이 함께 생긴다).

## 결정
- 판정 단일 출처 `utils/workManager.mapWorkManager` 가 **정확히 「기타」** 를 `'기타'` 로 읽는다(`OTHER_MANAGER`). 다른 이름 속 글자는 잡지 않는다.
  → `resolveWorkManager` 결과가 '기타' → 홈 질문의 미지정 판정에 안 걸리고(다시 묻지 않음), 입금관리 `_pmManagerName` 은 '기타' 그대로라 미지정 줄(모든 칩 맨 아래)로도 안 간다.
- 공유 저장(담당자 전용) 허용 목록 `['박세희','박은비','랜덤','기타']` · 인트라넷 접수/수정 해석 `_canonicalOriginalWorkManager('기타') = '기타'` · 전송 본문은 '기타' 그대로(랜덤으로 바꾸지 않음).
- 홈 「오늘 확인할 것」 담당자 질문: [만두][망고][기타] — 답 `etc` → 오더 갈래 = 공유 저장으로 '기타'(인트라넷 전달 대기 1건), 탭 갈래(결정 323) = 빈 칸에 '기타'.
- 작업보드 담당자 빠른 배정·관리자 수정 작업담당 알약에도 [기타].
- 인트라넷(inadd-webapp): 작업담당 선택지·서버 허용 목록(`REVIEW_ORDER_WORK_MANAGER_VALUES`)·수정 기준 읽기/덮기 허용 목록에 '기타'.

## 배포 순서 (완화 금지)
- **인트라넷 먼저 → 리뷰웹 나중.** 리뷰웹이 먼저 나가면 그사이 리뷰웹에서 고른 '기타' 를 옛 인트라넷이 받지 않고 버린다(인트라넷 값은 '랜덤' 으로 남아 갈라진다).
- 옛 리뷰웹 + 새 인트라넷: 인트라넷에서 '기타' 를 골라 보내면 옛 리뷰웹은 해석하지 못해 미지정처럼 다룬다(쓰기 거부·미지정 질문 유지 — 갈라지지만 덮어쓰지 않는다). 짧은 시차라 허용.

## ★★ 완화 금지
- 「기타」를 미지정으로 되돌려 읽지 않는다(질문이 계속 되살아나고 입금관리에서 모든 칩 맨 아래에 끼어든다).
- 인트라넷·리뷰웹 허용 목록은 같은 네 값이다 — 한쪽에만 값을 더하지 않는다(받는 쪽이 조용히 버린다).
