# ★★ 리뷰 제출 사진 칸 3분할(PC) — 왼쪽 Ctrl+V · 가운데 끌어다 놓기 · 오른쪽 파일 추가 · 선택 표시 (사용자 요청 2026-10-20 · 스키마 변경 0)

## 무엇이 문제였나
- 사용자 신고: "리뷰 제출할 때도 복사 붙여넣기(Ctrl+V)나 끌어다 놓기 할 수 있어야 함 · 저장 없이 실시간 붙여넣기 가능해야 하는데 **어딜 누르고 붙여넣어야 하는지 불분명**".
- 실측(2026-10-20): `search.html` 리뷰 제출 2·3단계의 사진 칸 3종(단건 `#dropZone` · 다건 `.mr-slot-dropzone#mrDz_i` · 캡처 슬롯 `#csDz_<key>`)은
  **클릭·드래그는 이미 됐고, 붙여넣기(paste) 처리기는 어디에도 없었다**. 이 화면에서 Ctrl+V 는 아무 일도 하지 않았다.
- 같은 파일의 구매양식 일괄 캡처(`_batchMountDropzone`, 결정 046)만 `document` paste 를 받았는데, 조건이 `_BATCH` 하나뿐이라
  **그 칸이 안 보이는 화면에서도** 붙여넣기를 가로챌 수 있었다(리뷰 화면 사진이 숨은 구매 카드로 샐 수 있는 구조).

## 결정
1. **PC 에서 사진 칸을 3분할한다**(사용자 3차 확정: "해당 영역을 3분할 — 좌 Ctrl+V · 중앙 끌어다놓기 · 우 파일추가").
   단건 칸(`search.html` 정적 마크업)과 다건·슬롯 칸(`_dzSplitHtml()`)이 **같은 모양**이다(가드가 비교).
   - **왼쪽 [Ctrl+V]** = 그 칸을 선택하고 `navigator.clipboard.read()` 로 사진을 바로 넣는다(`_zonePasteFromClipboard`).
     **미지원·권한 거절·사진 없음은 각각 이유 + "키보드 Ctrl+V" 안내**(조용한 실패 금지) — 칸은 이미 선택돼 Ctrl+V 가 그리로 간다.
   - **가운데 [끌어다 놓기]** = 놓는 자리 표시(드래그 중 파랗게). 누르면 그 칸 선택만.
   - **오른쪽 [파일 추가]** = 파일 탐색기. **PC 에서 파일 탐색기를 여는 곳은 여기 하나**(2차 요청 "클릭 시 즉시 파일탐색기를 열지 말 것").
   - 칸의 다른 곳을 누르면 선택만 한다. 사진 삭제(×)는 칸 클릭으로 처리하지 않는다. 마우스를 올리는 것만으로는 선택이 바뀌지 않는다.
   - **선택 표시** = 실선 파란 테두리 + 바깥 고리 + 왼쪽 칸이 파랗게 "✓ 선택됨 · 여기로 들어가요"(2차 요청 "선택했다는 시각적 표시").
   - 사진이 들어간 뒤엔 미리보기 아래 **한 줄짜리 3분할 막대**(더 넣기). 단건 "추가" 타일은 PC 에서 숨긴다.
   - 슬롯 칸을 덮은 투명 파일 입력은 PC 에서 `pointer-events:none`(클릭을 칸이 받게 · 드래그 놓기는 칸 div 의 ondrop 이 그대로 받는다).
   - `toss-theme.css` 의 `button{border-radius:12px !important}` 를 3분할 안에서만 `0 !important` 로 끊는다(평평한 구획).
   - **휴대폰은 종전 그대로** — 3분할을 숨기고 누르면 바로 사진 고르기(Ctrl+V·끌어다 놓기가 없다).
   - 경과: 1차 = hover 로 대상 칸 표시 → 2차 = 클릭 시 [바로 붙여넣기/파일에서 고르기] 선택지 → 3차(확정) = 상시 3분할.
2. **Ctrl+V 는 화면 어디서나** → 선택된 칸(아직 안 눌렀으면 비어 있는 첫 칸 → 다 찼으면 첫 칸, `_pasteTargetZone`).
   붙여넣은 뒤 토스트 "붙여넣은 사진 N장을 「○번 상품명」 칸에 넣었어요".
3. **넣는 길은 클릭·드래그와 같은 함수**(`_pasteInto` → `addFiles` / `_mrAddFiles` / `_csAddFiles`). 형식 검사·10MB·AI 사전확인(`_preCheckFiles`) 사본 0.
   클립보드 사진은 이름이 모두 `image.png` 라 `붙여넣기_HHMMSS[_n].ext` 로만 다시 붙인다(내용 그대로).
4. **사진이 없으면 가로채지 않는다** — `preventDefault` 는 이미지 항목 확인 뒤(비고란 URL 붙여넣기 보존).
5. **보이는 단계 화면(`.step-pane.active`)의 보이는 칸에서만** 받는다. 구매양식 일괄 캡처 paste 도 그 칸이 보일 때만 받도록 같이 막았다.
6. 3분할·선택 표시는 PC(`@media (hover:hover) and (pointer:fine)` / `_isPcPointer`)에서만 — 휴대폰은 화면 불변.
   기존 문구 "클릭 또는 드래그 · JPG/PNG/WebP"는 그대로 둔다(현금영수증 안내서 가드 `cashReceiptGuideDoc`).
