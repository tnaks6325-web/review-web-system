- ★★ **보관 해제 단계 비교를 「보관 뒤 바뀐 경우만」으로 좁히지 않는다**(스냅숏 없으면 그냥 열리는 빈틈 — 옛 단계로 조용히 다시 모집 = 모두 1개 구매). 비교 못 함 = 막음.
