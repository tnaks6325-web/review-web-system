# 사고·결정 기록 INDEX

이 폴더는 이 저장소의 **사고 경위 · 설계 결정 · 완화 금지 규율**을 항목당 파일 하나로 담는다(현재 **159항목**).
원래 `CLAUDE.md` 안에 쌓여 있던 것을 그대로 옮긴 것이라 **본문은 한 글자도 바뀌지 않았다**.

## ★★★ 작업 전 검색 필수

코드를 한 줄이라도 고치기 전에 여기서 관련 항목을 찾아 **본문을 끝까지 읽고** 착수한다.
「사전 충돌 점검」의 1번 축(단일 출처·사본)이 여기서 시작된다.

```bash
grep -n  "<키워드>" docs/decisions/INDEX.md   # 제목·migration 번호로 항목 찾기
grep -rln "<키워드>" docs/decisions/          # 본문까지 뒤져 관련 항목 찾기
grep -rn "완화 금지" docs/decisions/          # 되돌리면 안 되는 규율 전수
```

★★ **못 찾았다고 "없다"로 단정하지 않는다** — 같은 주제가 여러 항목에 나뉘어 있다
(예: 옵션 칸은 `제출 시 옵션 칸 지워짐` · `옵션 칸은 두 종류다` · `작업표 옵션 칸` 셋에 흩어져 있다).
**기능 이름 · 표(테이블) 이름 · migration 번호 · 회귀가드 파일명** 네 가지로 각각 찾는다.
