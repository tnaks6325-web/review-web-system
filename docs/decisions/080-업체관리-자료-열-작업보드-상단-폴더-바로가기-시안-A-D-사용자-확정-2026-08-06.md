# ★ 업체관리 [자료] 열 + 작업보드 상단 폴더 바로가기 (시안 A + D · 사용자 확정 2026-08-06)
- **시안** `frontend/docs/design-vendor-folder-buttons.html`(배치 후보 6곳 판정표 + 3안 목업 + D 작업보드 상단, `?v=A|B|C`). 확정 4건 = ① **A안**(연결된 탭 표에 `[자료]` 열) ② 기본 **켬** ③ **3버튼**(구매·리뷰·현영) ④ **작업보드 상단도 같이**. 업체용 뷰어에는 이미 있던 폴더 바로가기가 내부 화면(업체관리)에는 없어 시트를 열어야 폴더에 닿던 것을 없앤다.
- ★★ **렌더러·열기 동작은 한 벌** — `_folBtnsInner`/`_folMat`/`_folRow`/`openTabFolder` 를 홈 작업목록·업체관리 표·작업보드 상단이 함께 쓰고, 다른 것은 **재료가 담긴 자리와 버튼 크기뿐**이라 `src('home'|'own'|'cur')` 로 그것만 가른다. 사본을 두면 한쪽만 `_folUrlOk`(Drive 호스트 검증)가 풀리거나 현영 판정이 갈라진다.
- ★★ **현영 판정 단일 규칙 = `captureSlots.hasCashReceiptSlot`**(`effectiveCaptureSlots` 파생 — 규칙 사본 0): 소비처 3곳 = `tabStatsMap`(홈 버튼) · `ownedTabsForAdvertiser`(업체관리 표) · `/tab-folders`(서버 폴더 해석). 종전에는 홈만 `income_type` 을 보고 라우트는 `capture_slots` 까지 봐서, 수동 슬롯 탭이 **"버튼은 비활성인데 서버는 허용"** 으로 갈라져 있었다. ★ 슬롯을 `[review]` 로 명시한 탭은 업로드가 현영 서브폴더를 만들지 않으므로 '대상 아님'이 사실이다(업로드 경로와 같은 판정).
- ⚠ **아직 통일되지 않은 소비처 1곳(의도)**: 리뷰어 공개 카드의 `🧾 현금영수증` 배지(`campaign.routes._cashReceiptFlags`)는 여전히 `isCashReceiptIncome`(income_type) 만 본다 — 그건 **리뷰어에게 참여 전 안내**를 켜는 다른 기능이고(현금영수증 3시점 D안), 바꾸면 리뷰어 화면 배지가 사라지는 탭이 생긴다. 폴더 바로가기 3곳만 `hasCashReceiptSlot` 으로 묶었다.
- **재료 공급**: 업체관리는 연결탭 응답에 `cashReceipt` 를 파생해 싣는다(`tab_configs` 를 **이미 조인**하고 있어 쿼리 순증 0, 판정 원재료 `capture_slots`·`income_type` 는 **응답에서 버린다** — 316행 × JSONB 전송 낭비 + 프론트 재판정 금지). 작업보드는 **`GET /api/trackb/tab-folders?kind=info` 가산 분기**(그 탭 **한 줄**만 읽음 · 신규 엔드포인트 0 · 같은 스코프 게이트 · 60초 캐시) — ★ **홈처럼 `?stats=1`(review_index 전체 GROUP BY)을 붙이지 않는다**(탭 전환마다 무거운 집계 금지), 홈을 거쳐 왔으면 `t.stats` 를 재사용해 **요청 0**.
- ★★ **"모른다"와 "없다"를 구분한다**(조용한 거짓 안내 금지): 통계 미도착·조회 실패는 비활성 + **그 사유**(폴더가 없다고 말하지 않는다), `cashReceipt` 가 **undefined**(구버전 백엔드)면 '대상 아님'으로 단정하지 않고 "알 수 없습니다". 비활성은 **숨기지 않고 옅은색**(줄마다 버튼 수가 같아야 눈이 열을 다시 찾지 않는다 — 홈과 같은 규율).
- ★ **onclick 은 인덱스만**(`openTabFolder(0,'capture','own')`) · 폴더 버튼은 `stopPropagation`(행 클릭 = 작업보드 열기로 튀지 않게) · 새 창은 **await 전에** 열어 둔다(현영은 서버에 물어본 뒤 이동 — 비동기 뒤 `window.open` 은 팝업 차단).
- ★ **자료 열 폭 136px** — `.wbl-fol` 은 `3×40px + gap 3px×2 = 126px` 고정 그리드다. 좁히면 버튼이 칸 경계를 넘어 옆 열(계약) 위에 겹쳐 그려진다(grid 트랙 이탈은 `scrollWidth` 로 안 잡혀 **실측**으로만 보인다).
- ★★ **표 폭 상한 1400 → 1560px**(`.ovm-hd`·`.ovm-tools`·`#owntabsSect` **세 곳 같은 값**) — 열이 늘어난 만큼 넓혔다(사용자 지시). 한 곳만 넓히면 버튼이 데이터 오른쪽 끝에서 어긋난다(`#wohead .mh` 규칙과 같은 이유). FHD(1920)에서 가로 스크롤·작업명 잘림 0. ⚠ 노트북(≈1440)은 **[자료] 없이도 이미** 스크롤이 나는 폭이고(필요 1222 vs 여유 1152), [자료]를 끄면 종전 폭으로 되돌아간다(열 묶음 토글이 탈출구).
- ★ **광고주에게는 작업보드 상단 버튼을 그리지 않는다** — 광고주 화면엔 이미 자기 폴더 링크가 있고 `/tab-folders` 는 `internalMiddleware` 라 누르면 403 막다른 길이 된다. **staff(AE)는 담당이 아니어도 전부 연다**(사용자 확정 2026-08-19 — `/workdesk`·`/tabs` 가 이미 `allowAllStaff` 라 폴더 버튼만 막는 것은 반쪽 규칙이었다. 좁히기로 되돌린다면 그 둘·공유 링크와 **함께** 좁혀야 한다).
- ★ 도착 후에는 **버튼 묶음(`#folBar`)만** 갈아치운다(그리드 전체 재렌더 금지 — 편집 중 셀·검색 하이라이트를 잃는다) + `STATE.cur===t` 확인(다른 작업으로 옮긴 뒤 도착한 응답 미반영).
- ★★★ **캐시는 스코프 게이트 뒤에 둔다 (코드리뷰가 잡은 블로커)**: `/tab-folders` 가 캐시 히트를 `canAccessTab` **앞에서** 반환해, 누군가 그 탭을 최근에 열어 둔 동안(info 60초 · 현영 10분) **담당 밖 AE 가 Drive 링크를 그대로 받았다** — 이 라우트가 스스로 적어 둔 불변식이 캐시 한 줄로 무력화된 상태였다. 순서 고정 = **파싱 → 스코프 → 캐시 → 작업**. ⚠ **기존 403 가드가 이 구멍을 통과시켰다** — 한 번도 캐시되지 않은 탭명을 썼기 때문. **스코프 검사는 캐시가 채워진 키로도 확인할 것**(admin 으로 데운 뒤 staff 로 호출).
- ★★ **현영 슬롯은 key 가 아니라 라벨로도 찾는다**: `capture_slots` 의 **유일한 writer**(`tabconfig.routes` 캡처 슬롯 저장)는 key 를 **위치로** 부여한다(`0번=review`, 그 외 `slot2`…) — 즉 **`receipt` 라는 key 는 영영 저장되지 않는다**. key 만 보면 관리자가 `[리뷰, 현금영수증]` 으로 설정한 현영 탭의 버튼이 "대상 아님"으로 죽는다(업로드는 그 라벨로 폴더를 실제로 만들어 둔 상태). 판정 = `cashReceiptSlotInfo`(key `receipt` **또는** 라벨에 현금영수증·현영·지출증빙). ★ **Drive 폴더 이름도 그 슬롯의 실제 `label`** — 종전 `slotLabel(...,'receipt')` 은 수동 슬롯 탭에서 문자열 `receipt` 폴더를 뒤졌다(함께 고침). ★ 현영인데 슬롯에 그 칸이 없으면 **'대상 아님'으로 뭉개지 않고** 고칠 곳을 말한다(`CR_MISCONFIG_NOTE` 단일 문구, 서버·툴팁 공용).
- ★★ **배포 스큐 표식 `kind:'info'`**: 구버전 백엔드는 `kind` 를 모르고 **현영 분기로 답한다** — 표식이 없으면 프론트가 그 `{ok:true,url}` 을 info 로 오독해 폴더가 멀쩡히 있는데도 "아직 폴더가 생성되지 않았습니다"로, `{ok:false,'대상 아님'}` 이면 **구매·리뷰 버튼까지** 그 문구로 위장한다(실측 시나리오). 표식 없는 응답은 '모른다'로 두고 사유를 말한다. ★ 표식은 **응답 3경로(신규·캐시·미등록) 전부**에 실려야 한다(한 곳만 붙이면 샌다 — 변이시험이 실제로 통과시켰다).
- ★ **실패한 `_fol` 이 나중에 도착한 `stats` 를 덮지 않는다**: `_finEnsureStats` 는 같은 탭 객체에 stats 를 **병합**하므로(identity 보존), 직행 진입 → info 일시 실패 → 홈 방문 → 재진입 이면 버튼이 **세션 내내** 죽어 있었다. `const f=(t._fol&&!t._fol.err)?t._fol:(t.stats||t._fol)`. ★ 실패는 **재진입 시 재시도**(한 번의 장애로 되살릴 방법이 없어지지 않게).
- ★★ **저장폴더 링크는 담당(inad_pm) 무관 내부인 전원**(사용자 확정 2026-08-24): 종전엔 `/ownership/tabs` 가 staff 일 때 **폴더 URL 2개와 현영 판정을 비우고 `folderScoped:false` 로 고지**했는데, **폴더를 실제로 여는 통로 `/tab-folders` 는 이미 내부인 전원에게 열려 있어**(*"staff는 작업보드 전체 운영 권한이므로 담당 여부와 무관하게 폴더를 연다"* — 2026-08-19 확정) **버튼만 흐린 반쪽 규칙**이었다. 마스킹·`folderScoped` 플래그·화면 안내를 **통째로 제거**했다(죽은 규칙을 남기면 다음 사람이 되살린다). ★ **되살리려면 `/tab-folders` 스코프와 함께** 좁힌다(한쪽만 좁히면 이 상태로 되돌아온다). ★ 광고주·리뷰어는 `internalMiddleware` 가 막는다(불변).
- ⚠ **테스트 도구 함정**: "그 호출이 코드에 없다"를 보려고 **블록 주석 정규식(`/\*…\*/`)으로 주석을 지우면** 이 레포의 정규식 리터럴을 물어 **41KB(코드 3분의 1)가 통째로 사라진다**(실측). **줄 주석만** 지운다 — 지우려는 것보다 큰 것을 지우는 도구는 쓰지 않는다.
