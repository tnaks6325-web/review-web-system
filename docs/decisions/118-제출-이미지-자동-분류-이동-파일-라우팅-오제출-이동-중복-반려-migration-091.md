# ★★ 제출 이미지 자동 분류·이동 (파일 라우팅) — 오제출 이동 + 중복 반려 (migration 091)
- **목적**: 리뷰 칸에 현금영수증 / 영수증 칸에 리뷰 / 리뷰 칸에 구매캡처가 올라오면 **올바른 폴더로 자동 이동**하고, 이동 대상 칸에 **같은 파일이 이미 있으면 휴지통 + 반려**. 와이어프레임 = `frontend/docs/리뷰제출_이미지_자동분류_와이어프레임.html`. 기존 검수(verifyCapture)의 판정값을 그대로 재사용해 **AI 콜 순증 0**.
- ★★ **전이표 단일 출처 = `utils/captureRoute.js`**(`routeDecision` 순수함수). 정의된 4조합만 이동(review→receipt/order_capture, receipt→review/order_capture — receipt 이동은 그 탭에 영수증 슬롯이 있을 때만 = "폴더가 있는 경우"), **verdict.sure(확신≥0.9)만**, 표 밖(other·purchase_confirm·애매 0.7~0.9)은 전부 현행 경고 유지. 카카오메이커스 채널 전체 제외(피드형). 실행부 = `fileRoute.service.js`, 배선 = `diag.routes` `/review-upload`.
- ★★ **반려(제출 거절)의 유일한 근거 = SHA-256 정확 일치**(`findSlotDuplicate` — 같은 행·같은 리뷰어·**대상 슬롯**에 같은 지문의 다른 파일). **AI 판정만으로는 절대 반려하지 않는다**(완화 금지 — routeDecision 의 동작은 none/route 뿐임을 회귀가드가 매트릭스 실행으로 고정). ★ 2차 검수 `findDuplicate`(다른 사람·다른 자리)와 스코프가 정반대라 **재사용 금지**(합치면 정상 재제출이 반려된다). 판정 불가·쿼리 실패 = 중복 아님(fail-open).
- ★★ **삭제는 휴지통(trashFiles)만** — 영구삭제 API 금지(30일 복구창). 반려 파일은 원장 미기록·fileId 미반환, 응답 `files[].rejected` + 전부 반려면 최상위 `error`.
- **모드** env `AUTO_FILE_ROUTE`: `off`(0) | **`dry`(기본 = 관측)** | `auto`(1). 기본이 dry 인 이유 = 사용자 확정 "관측 1회 수행 후 출시결정" — 배포 즉시 관측(계획을 `capture_route_plan` info·resolved 로 기록)만 하고 이동 0. 출시는 Railway 에서 `AUTO_FILE_ROUTE=auto`. 반려만 끄는 스위치 `AUTO_FILE_ROUTE_REJECT=0`.
- ★★ **구매캡처(order_capture) 이동은 판별 예시 2장(구매캡처+구매확정)이 모두 등록돼야 발동**(사용자 확정 — 주문내역·구매확정 화면은 생김새가 비슷한 가장 약한 고리). 슬롯 단일 출처 = `utils/routeSampleKinds.js`(`route_` key 접두 = 캐시 지문 충돌 방지), 등록 = 설정탭 aisamples 패널(서버 응답 그대로 렌더, POST `kind:'route'`).
- ★★ **kind `order_capture` 추가는 줄 추가만**(gemini classify — 기존 review/receipt 판정 기준 줄 불변) + **캐시 접두 `classify3:`→`classify4:`**(옛 캐시가 새 종류를 모른 채 히트 차단, 087 2차와 같은 규율).
- ★★ **예시 조립 단일 지점 = `reviewInspect.submissionSamples`** — 1차 필터(precheck)·업로드 검수·2차 검수·소급 스윕이 전부 이걸 쓴다. 조립처가 갈리면 sampleSig(캐시 지문)가 갈려 **같은 이미지에 AI 콜 2번**(diag.routes 에 `loadSamplesFor` 직접 호출 0을 가드가 고정).
- **정합 3종**: ① A-2 원장은 라우팅 반영 **최종 슬롯**으로 기록 + `routed_from_slot/routed_at/routed_by`(091, fail-soft UPDATE — 마이그레이션 늦게 붙어도 업로드 불사) ② 대표 이미지는 라우팅 발생 시 `recomputePrimary` 가 원장 기준 재계산(영수증이 대표로 남지 않게, 0장이면 비움) ③ **완료 판정**: 슬롯 탭은 서버 원장 기준이라 자동 정합, 단일 첨부 탭은 프론트가 "남은 파일 0 = 제출 기록 안 함"(`search-app.js` `_rtStayed` — 리뷰 캡처 0장에 완료 찍힘 방지).
