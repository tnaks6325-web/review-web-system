# ★ 작업보드 참여자 칸 = 참여횟수 배지(명의 기준) — 사용자 확정 2026-08-19
- 종전 `주문` 배지를 **참여횟수 배지**로 교체했다: `[1회]` 파랑 · `[2회]` 노랑 · `[3회]` 이상 빨강. **색은 3단계로 끝내고 숫자가 실제 횟수를 말한다**(4회·5회도 빨강 — 색을 늘리면 한눈에 읽히는 신호가 약해진다).
- ★★ **세는 단위는 리뷰어(소유자)가 아니라 계정 명의(`phone8`)** — 한 사람이 본계정으로 1회·타계정으로 1회면 **둘 다 [1회]** 이고, 같은 타계정으로 또 참여해야 [2회]. 집계 범위는 **이 작업(탭) 안**(전 작업 누적 아님 — 다른 작업 이력이 이 표에 섞이지 않는다).
- ★★ **판정은 서버 한 곳**(`trackB.workdeskTab` 의 `visitSeen`) — 화면은 `visitNo` 를 **그리기만** 한다. 프론트에서 다시 세면 표를 필터·정렬할 때 숫자가 흔들린다.
- ★★ **마스킹 전 원본 phone8 로 센다** — 광고주 렌즈의 `_mask` 를 거친 뒤 세면 전 줄이 같은 값이 되어 1,2,3… 으로 무너진다(회귀가드가 코드 순서를 고정).
- ★ **모르는 것을 1회로 꾸미지 않는다** — 명의 미상(빈 슬롯·연락처 없음)은 `visitNo` 자체를 안 싣고 화면도 배지를 안 그린다. 구버전 백엔드(필드 부재)도 같다.
- ★ **화면에서 뺀 줄(`_hidden` 오버레이)은 번호를 먹지 않는다** — 표에 없는 줄이 번호를 차지하면 뒤 줄이 밀린다(카운트는 `continue` 뒤에서 한다).
- ★★ **렌더러는 한 벌 `_visitBadge(r)`**(workdesk.html) — 시트 그리드와 기본 표가 같은 것을 쓴다(종전에는 같은 배지 문자열이 두 곳에 복사돼 있었다).
- ★ **`수동` 배지와 🔒(편집 잠금)는 유지**(사용자 확정) — 성격이 다르다. 사라진 `주문` 배지의 정보(주문 원장 연결 여부)는 **툴팁으로 남긴다**(정보 손실 0).
- ★ **복사값에서 배지를 뺀다**(`.visit` 를 `_gridCopyText` 제거 목록에 합류) — 안 그러면 표를 복사할 때 셀 값에 `2회` 가 섞인다.
