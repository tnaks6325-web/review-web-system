# 견적서 여러 장 — 큰 번호 탭 (사용자 확정 2026-10-02 · A안 변형)

## 발단
- 견적서 팝업에서 장 선택이 회색 글자 세그먼트라 버튼으로 보이지 않아, 두 번째 견적서를 못 보고 닫기 쉬웠다(업체 뷰어 신고).

## 결정
- 시안 3안 중 **A안**(번호 붙은 큰 탭) — 단 사용자 지시로 **안내 띠("견적서는 N장입니다")와 상태 배지(보는 중·확인함·미확인)는 넣지 않는다.**
- 탭 = 테두리 있는 버튼 + 번호 원 + 작업명 + 금액. 보는 장은 파란 테두리·옅은 파랑 바탕·파란 번호 원. 아래 "견적서 N장 · 합계" 한 줄은 그대로.
- 마크업 클래스 `qdtab` · `data-di` · `_qdocPick` 계약 불변(내부·업체 공용 팝업).

검증: 실 브라우저(견적서 2장 작업)로 렌더·전환·JS 오류 0 확인.
