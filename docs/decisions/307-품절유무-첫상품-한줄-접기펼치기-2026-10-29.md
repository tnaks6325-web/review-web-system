# 품절유무는 첫 상품·기존 버튼·나머지 펼치기를 한 줄로 표시한다

## 승인 범위 (2026-10-29)
- 사용자 승인 시안: 첫 상품 1개 + 기존 [열기]/[멈추기] + [외 N개 펼치기]. 펼치면 나머지만 표시하고 첫 상품을 중복하지 않는다. 다시 [접기] 가능.
- 예전 5줄 표시·상태별 합계 줄 제안은 사용하지 않는다. 긴 상품명은 기존 말줄임을 유지한다.
- 멈춤 또는 신고가 있는 상품을 먼저 표시하며 그 안에서는 원래 순서를 유지한다.

## 연결과 불변 계약
- 변경은 `frontend/workdesk.html`의 `_cndSalesRow`와 해당 스타일에 국한한다. 서버 `optionSales`를 그대로 소비하고 새 상태 판정·저장 경로를 만들지 않는다.
- 정렬은 `{o,i}` 사본에만 적용한다. 원본 배열의 첨자 `i`를 `_cndSale(i)`로 넘겨 실제 처리 대상이 시각적 순서와 혼동되지 않게 한다. 기존 확인창·요청 본문·실패 안내·갱신은 변경하지 않는다.
- 접힘 상태는 현재 시트·탭(gid 우선, 없으면 이름)·공고 키에 묶는다. 같은 작업의 실시간 재그리기에서 유지하고 다른 작업/공고는 기본 접힘이다. 이전 작업의 남은 버튼은 키가 다르면 동작하지 않는다.
- 0개는 숨김, 표시 가능한 1개는 펼치기 없음. 읽기 전용의 신고만 표시, 광고주 미노출, 이름 없는 공고 전체 줄과 `{whole:true}`는 결정 229·259 그대로다.
- DB·모집 상태·금액·인원·신고 2명 기준·알림 및 서버 변경 없음. 운영 데이터 확인용 쓰기 없음.

## 검증
- `server/tests/workdeskStockCollapse.test.js`: 실제 렌더러·기존 처리 함수를 VM에서 실행. 새 펼치기 문구가 없는 기존 코드에서 먼저 실패(RED), 적용 후 통과(GREEN).
- 0/1/24개, 우선 순서·원본 불변·중복 없음·24개 원래 첨자별 요청, 펼침/접힘/재그리기, 다른 시트/탭/공고 및 늦은 버튼, 광고주·읽기 전용, 공고 전체, 확인 취소·서버 거절을 확인한다.
- 기존 품절·가격·작업조건 가드의 의미를 바꾸거나 정규식을 느슨하게 하지 않는다.
- 실제 HTTP에서 원본 전체 HTML과 CSS·작업조건 렌더러를 실행한 가짜 데이터 브라우저 검증: 1440/390/320px, 접힘·펼침 캡처, 긴 이름 말줄임·한 줄 유지·가로 넘침 없음, 키보드 Enter/Space, 기존 버튼의 로컬 가짜 서버 왕복. 외부 네트워크는 브라우저 단계에서 차단한다.
- 전체 서버 검사는 운영 자격 없는 환경 + 로컬 연결 불가 DB + 외부 네트워크/실제 pg 차단으로 실행한다. pg 차단은 실제 pg와 같이 비동기 거절을 반환해야 한다(동기 throw는 `.catch()` 계약을 깨뜨려 기존 검사에 거짓 실패를 만든다).
