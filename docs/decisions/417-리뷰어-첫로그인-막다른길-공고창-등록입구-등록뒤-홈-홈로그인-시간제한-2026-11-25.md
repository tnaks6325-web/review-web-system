## 완화 금지
- 🚫 등록 화면의 돌아갈 공고(`returnCamp`)를 형식 검사 없이 주소로 쓰거나, 공고 id 대신 주소를 받게 바꾸지 않는다 — 남이 만든 링크로 가입한 사람을 바깥 주소로 보내는 길이 된다(결정 045 와 같은 검사 한 벌).
- 🚫 홈의 공용 세션 옮겨 적기에서 관리자 홈 탭 제외·12시간 만료·「이미 홈 기록이 있으면 덮지 않음」을 빼지 않는다 — 빼면 관리자 미리보기 탭이 실제 리뷰어 홈으로 열리거나, 다른 탭 로그인이 이 홈의 사람을 바꾼다(결정 246). 옮겨 적는 칸을 늘리지 않는다(이름·뒤 8자리·열쇠·시각뿐).
- 🚫 등록·로그인 뒤 홈으로 보내는 길을 구매양식 대기·틀 안·등록 화면이 아닌 진입까지 넓히지 않는다 — 양식 작성 중인 사람·틀 안 화면이 홈으로 튕긴다.
- 🚫 홈 [로그인]의 시간 제한(20초)·`finally` 단추 되살리기를 빼지 않는다 — 신호가 약하면 「확인 중...」에서 다시 멈춘다.
