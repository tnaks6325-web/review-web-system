# ★★ 입금관리 — 입금명(통장표시) 없는 작업은 선택할 수 없고, 누르면 작업보드의 입금명 설정 창을 바로 연다 (2026-10-08 · 사용자 확정 · 스키마 변경 0)

## 배경
- 입금관리 「입금 대상 선택」(C스타일)에서 입금명(통장표시)이 없는 작업도 **그대로 선택·서식에 포함**됐다. 화면은 `⚠ 통장표시가 없는 건 N건 — 이체는 되지만 리뷰어 통장에 이름이 안 찍힙니다` 경고만 했다.
- 서버 판정은 그대로 `warnings: ['no_memo']`(경고) — 이체 자체는 막지 않는다(`payment.service` — 공고 `transferMemo` → 탭 `deposit_name` 순서).

## 결정 (사용자 확정 2026-10-08 · 질문 4개에 대한 답)
1. **처음부터 선택에서 뺀다** — 입금명 없는 줄은 `_pmOn` 이 false. `_pmOn` 은 다운로드·합계·대상자 수·작업 목록·표 체크·"N건 대상"의 **단일 출처**라 한 곳만 바꿔 모두 함께 바뀐다(한 곳만 따로 막으면 "목록엔 없는데 파일엔 들어감"). 판정은 서버 `no_memo` 그대로(`_pmNeedsMemo` — 화면에서 `transferMemo` 를 다시 보지 않는다).
2. **창구 = 작업보드 › 작업 조건 › 입금명**(결정 111 의 "작업 단위 값 창구는 하나" 그대로). 입금관리에 입력칸을 되살리지 않는다. 대신 작업보드에 도착하면 **입금명 설정 창을 자동으로 연다** — `STATE.pendingCndFix` 예약 → `renderWorkdesk` 끝의 `_runPendingCndFix()` 가 **한 번만**, **같은 작업일 때만** `_cndFix('memo')` 호출(공고 있으면 모집공고 수정 모달 · 없으면 탭 설정 미니 모달). 다른 작업이 열렸으면 예약을 버린다(엉뚱한 작업에 저장 방지). 작업 조건을 못 받았으면 토스트로 말한다(조용히 끝내지 않음).
3. **저장 뒤 자동 선택하지 않는다** — 선택이 아직 "전체(null)"이면 입금명이 생기는 순간 저절로 끼어들므로, 그때만 `_pmHoldMemoWorks` 가 선택을 목록으로 굳혀 그 작업을 뺀다(`STATE.pmMemoSeen` — 이 세션에서 입금명 미설정으로 본 작업). 이미 목록으로 고른 상태는 손대지 않는다. ★ `_pmRender` 에서 **`_pmVisibleItems()` 보다 먼저** 부른다(순서 계약). 담당자 칩을 다시 누르면 그 담당자 작업 전체가 선택된다(사람의 명시적 선택).
4. **아래 표도 막는다** — 입금명 없는 줄은 체크박스 `disabled`(통장표시 칸의 [미설정] = 작업보드 + 설정 창 예약). 머리줄 `선택 N/M` 의 분모에서 그 줄을 뺀다.

## 화면
- 작업 선택 목록 아래 **「입금명 미설정 N개」** 구역 + `[입금명 필요 ›]` 줄(점선·주황). ★ 드래그 선택 배선·`data-work-key` 를 달지 않는다(끌어서 고르는 범위에 끼지 않게) · onclick 은 **인덱스만**(`_pmOpenMemoWork(i)` — `STATE.pmMemoWorks`, 작업명 보간 금지).
- 대상 = **고를 수 있는 줄이 하나도 없고 입금명만 정하면 대상이 되는 작업**(`_pmMemoWorkEntries`). 보류(계좌·은행)로만 빠진 작업은 제외(보완 카드가 말한다). 한 작업에 입금명 있는 줄이 섞이면 그 작업은 평소처럼 고르고, 없는 줄만 표에서 막힌다.
- 상단 경고·통계 숫자는 **담당자 범위 전체**에서 센다 — 선택에서 빠졌다고 0 으로 꾸미지 않는다.

- ★ **담당자 미지정 안내(`_pmUnassignedWorks`)는 `_pmOn` 이 아니라 "이체 대상(보류·제외 아님)" 기준** — `_pmOn` 으로 거르면 담당자·입금명이 둘 다 없는 작업이 담당자 칩을 고르는 순간 선택 목록·미지정 안내·입금명 집계 어디에도 안 보인다(Codex P2 리뷰, PR #1591).

## 완화 금지
- `_pmOn` 에서 `_pmNeedsMemo` 를 빼면 입금명 없는 건이 다시 서식에 들어가 리뷰어 통장에 이름 없이 찍힌다.
- 입금관리에 입금명 입력칸을 다시 만들지 않는다(결정 111 — 창구 둘이면 문구·권한이 갈린다).

## 사각지대
- **서버는 막지 않는다**(화면 판정만) — 바뀌기 전 화면을 새로고침 없이 열어 둔 사람은 한 번은 예전처럼 내려받을 수 있다.
