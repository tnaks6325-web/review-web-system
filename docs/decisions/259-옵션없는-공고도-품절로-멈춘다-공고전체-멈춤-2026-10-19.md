# ★★★ 옵션 없는 공고도 품절로 멈춘다 — 공고 전체 멈춤 · 신고 2명 자동 멈춤도 똑같이 (사용자 확정 2026-10-19 · migration 190)

## 발단
- 사용자: "품절로 멈추기 기능 없는 시트가 있고 있는 시트가 있는데 차이가 어떤 걸까요?" → 원인 조사.
- 결정 229 의 멈춤은 **상품(campaign_options) 단위**뿐이었다. 공고를 "옵션 없는 작업"으로 만들면 상품 줄이 없어
  작업조건 카드에 「상품 판매」 줄·[품절로 멈추기]가 없고, 품절 신고가 와도 [확인했어요] 알림만 떴다(229 "상품을 나누지 않은 공고 = 알림만").
- 운영 실측(2026-10-19 읽기 전용): 진행 중 공고 16개 중 **8개가 옵션 없는 작업**(멈출 수 없음).
- 부수 발견: 처음 문의한 시트(10/19 쿠팡 알파넥신 영양제2종)는 상품이 정상 등록돼 있었다 — 화면을 공고 저장(15:32) 전에 열어 둔 것. 새로고침으로 해결.
- 사용자 확정: ① 공고 전체 "품절 멈춤" 상태를 새로 만든다(마감 상태 재사용·상품 1개 자동 전환 대신) ② 신고 2명 자동 멈춤도 **똑같이 적용**.

## 설계
- ★★★ **상품 이름 '' = 공고 전체(WHOLE)** — 신고·알림 원장은 184 표 그대로(`opt_key = ''` 는 184 부터 "상품을 나누지 않은 공고"였다).
  멈춤 칸만 공고 행에 새로 둔다: `recruit_campaigns.soldout_paused_at`·`soldout_paused_reason`('manual'|'auto_soldout')·`soldout_paused_by`.
- ★★★ **멈춤은 status 와 따로(완화 금지)** — 229 와 같은 이유. status 를 쓰면 공고 수정 저장이 멈춤을 풀고(active/closed/draft 만 저장), 마감과 구별되지 않는다(리뷰어에게 "모집 종료"·마감 후처리).
- ★★★ **상태 엔진(computeCampaignState)에 넣지 않는다 — 참여 게이트에서만 막는다(완화 금지)**.
  상태 엔진은 18곳(apply·카드·하루 인원·앞날 예상·부족 팝업·수동 주문·작업보드…)이 읽는다. 새 state 값을 넣으면
  "모르는 값 = 열림"으로 접는 소비처가 하나만 있어도 새고, 하루 인원·예상이 멈춤을 따라 바뀐다(229 "일시 멈춤은 인원·예상·작업표를 바꾸지 않는다" 위반).
  → `campaign.routes` apply: 상태 판정(open) **바로 뒤** `camp.soldout_paused_at && ENABLED` 면 409 `campaign_paused`. 상품별 멈춤(option_paused)과 같은 자리·같은 규율.
  - 상품변경(이미 참여한 사람)은 막지 않는다(새 신청만).
  - 수동 주문·구매양식 직접 제출은 막지 않는다(229 "수동 주문은 안내만"과 같다).
- ★★ **공고 전체로 멈추려면 명시해야 한다(완화 금지)** — `POST /api/trackb/campaigns/:id/option-pause` 는 `whole: true` 일 때만 공고 전체.
  이름이 빈/빠진 요청은 종전처럼 400(상품 이름이 빠진 요청이 공고를 통째로 멈추지 않게).
- ★★ **[품절로 멈추기]는 살아 있는 상품이 없는 공고에서만** — 상품이 있으면 409 "상품별로 멈춰 주세요".
  ★★ **[다시 열기]는 언제나** — 멈춘 뒤 상품이 생겨도 풀 길이 사라지지 않게. 카드 재료(`optionSalesForCampaign`)도
  "살아 있는 상품이 없거나 **공고 전체가 멈춰 있으면**" 맨 앞에 공고 전체 줄(`{optKey:'', whole:true}`)을 싣는다(막다른 길 방지).
  - 상품이 전부 마감인 공고 = 옵션 없이 참여되는 공고(liveOptions 0) → 공고 전체로 멈춘다.
- 신고 세기: `_resolveOrderTarget` 이 상품 없는 공고를 `''` 로 돌려주던 것 그대로 → 다른 리뷰어 2명이면 `_pauseWholeRow`(auto_soldout).
  이미 멈춘 공고(손으로 포함)에 온 신고는 알림을 만들지 않는다(229 P2 와 같다).
- 알림: `listOpenAlerts` 가 `wholeCampaign`(= opt_key '' && 살아 있는 상품 없음)·공고 행 멈춤을 싣는다 → 화면은 상품 알림과 같은 버튼.
  `resolveAlert` 는 공고 전체 알림에 종류별 버튼(pause/not_soldout · reopen/keep) + **[확인했어요](ack)도 계속 받는다**(배포 순간 옛 화면).
  종류가 안 맞는 버튼은 229 와 같이 stale 409.
- 멈춤·다시 열기 = **인원 규칙 변경 시각(quota_rules_changed_at)** 을 남긴다 — 멈춰서 못 채운 어제 인원을 "어제 부족" 팝업(결정 202)이 묻지 않게(184 트리거와 같은 뜻).
  ★ `updated_at` 은 건드리지 않는다(공고 수정 충돌 판정·동기화가 그 값을 본다 — 멈춤은 설정 변경이 아니다).
- 활동 기록: `campaign_plan_events` `campaign_paused`/`campaign_resumed`(SAVEPOINT 격리 — 기록 실패가 멈춤을 되돌리지 않음).
- 끄는 스위치 = 229 와 같은 `CAMPAIGN_OPTION_PAUSE=0`(게이트·카드 표시·신고 자동 멈춤 모두 열림 · 다시 열기는 허용).
- 화면:
  - 작업조건 카드 줄 이름 = **「품절유무」**(사용자 확정 2026-10-19 — 종전 「상품 판매」). **「판매 중」 표시 없음**(멈췄을 때만 「멈춤」·「자동 멈춤」).
    공고 전체 줄은 **이름 없이** [품절로 멈추기]/[다시 열기]만 — 누르면 `{whole:true}`. 상품을 나눈 공고는 상품마다 한 줄(상품명 + 멈춤/신고 + 버튼).
    보여줄 것이 없는 줄(열려 있고 버튼도 없음 — 보관·읽기 전용)은 그리지 않는다.
  - 품절 알림 창: 공고 전체 알림도 [품절로 멈추기]/[품절 아님] · 자동 멈춤 [다시 열기]/[멈춘 채로 두기]. 상품이 생긴 공고만 종전 [확인했어요].
  - 리뷰어 공고 상세: 참여 버튼 = "품절로 잠시 멈춤"(비활성) · 거절 문구 `campaign_paused`.
  - 공고 카드(리뷰어·관리자): "품절로 잠시 멈춤" 칩 · 리뷰어 카드 버튼 끔 · 정렬은 오늘 마감과 같은 등급.
  - 공개 목록·상세: `soldoutPaused`(칸 && 스위치) — state 는 그대로.

## 코드리뷰 반영(2026-10-19)
- ★★ **옛 방식(participation_mode=false)·보관 공고는 공고 전체로 멈추지 않는다** — 그 신청 경로에는 멈춤 게이트가 없어 "멈춤"이 기록만 되고
  신청은 계속 들어온다(거짓 버튼). 카드 줄도 싣지 않고, 손 멈춤은 409, 자동 멈춤 UPDATE 도 `participation_mode = TRUE AND archived_at IS NULL` 조건(0행 = 종전처럼 알림만).
- ★ 알림 `wholeCampaign` = **멈춰 있으면 언제나** — 멈춘 뒤 상품이 생긴 공고의 알림이 [확인했어요]로 닫히면 공고는 멈춘 채 아무도 모른다.
- ★ 이름이 빈 **다시 열기** 요청은 공고 전체로 받는다(배포 순간 옛 카드) — 멈추기는 여전히 `whole:true` 명시만.
- 리뷰어 상세: 참여 거절 뒤 `finally` 가 버튼을 [참여하기]로 되살리던 것을 멈춤 표시로 유지.
- 필수 스키마에 `soldout_paused_reason` 추가.
- 남겨 둔 것: 상품이 전부 마감인 공고는 손으로는 공고 전체를 멈출 수 있지만 신고는 상품 판정 불가(unknown_option)로 자동 멈춤·알림이 없다(멈추지 않는 쪽 — 229 규율) ·
  관리자 카드 칩은 원본 칸을 보므로 끄는 스위치가 꺼져도 "멈춤"으로 보인다(표시만).

## 배포 스큐
- 옛 화면 + 새 서버: 리뷰어 카드는 [참여하기]로 보이지만 누르면 서버가 `campaign_paused` 로 거절(문구는 서버 error).
  작업조건 카드의 공고 전체 줄은 이름 없이 보인다 — [다시 열기]는 서버가 공고 전체로 받고, [품절로 멈추기]는 400(whole 없음 — 새로고침하면 맞춰진다).
  옛 알림 창은 공고 전체 알림에 [확인했어요]만 그린다(자동 멈춤 알림을 그걸로 닫으면 공고는 멈춘 채 — 카드의 「멈춤」·[다시 열기]로 보인다).
- 새 화면 + 옛 서버: 필드가 없으니 종전 화면과 같다.
