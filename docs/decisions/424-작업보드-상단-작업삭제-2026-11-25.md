# ★ 작업보드 상단 [⋯ 작업 도구] → [🗑 작업 삭제] — 홈 작업목록 [⋯] 와 같은 확인창 (사용자 확정 2026-11-25 · 스키마 변경 0)

## 요청
- 직원 신고: 인트라넷에서 프로젝트(오더)를 지웠는데 리뷰웹에 작업·모집공고가 남아 있다 → 작업보드에서 지우고 싶다.
- 남는 것은 의도다(결정 254 — 손댄 작업은 남기고 「원본 오더 삭제됨」 표시). 삭제 창구는 홈 작업목록 줄 끝 [⋯] 안에만 있어 못 찾았다.
- 사용자 선택: 작업보드 화면 위쪽에도 삭제를 둔다(선택지 3).

## 결정
- 자리 = 작업보드 제목 줄의 기존 [⋯ 작업 도구] 메뉴 맨 아래(빨간 글자). 상단 줄에 버튼을 새로 늘리지 않는다 — 결정 091 의 "주 줄 버튼은 늘리지 않는다" 규율 · 잘못 누르기 방지.
- 실행 = 홈과 **같은** `openTaskDelete`(미리보기 → 체크 → 실행 · 입금 기록 별도 확인 · 드라이브 별도 체크). 화면 쪽 사본 0 — `openTaskDeleteCurrent` 는 연 작업을 목록 인덱스로 바꿀 뿐이다.
- 게이트 = 홈과 같은 `_taskDelAllowed`(admin/master · 서버 adminOrMaster 와 1:1). AE·광고주에게는 버튼이 없다.
- 마감 작업은 [⋯] 자체가 숨는다(종전) — 마감 작업 삭제는 홈 [⋯] 로.
- 지운 뒤: 보고 있던 작업이면 홈으로 보내고, 열린 작업 줄(0단)에서도 뺀다(누를 곳 없는 탭 방지 — 홈 경로에도 함께 적용).
