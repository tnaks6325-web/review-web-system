## 증상
- 작업보드 → 모집공고 수정 창에서 **시간만** 바꿔 저장한 세라모사이드 공고(`camp_e4a143db7c60`)의 상품 안내가
  `글쓰기      세라모사이드 3가지 맛 중 택1 (피치 / 레몬 / 스트로베리) - 결제금액 12,400원` →
  `… (피치 레몬 스트로베리) - 결제금액 12,400원` 으로 바뀌었다. 시간과는 무관 — 옵션 없는 공고는 **아무 칸도 안 고치고 저장만 해도** 같다.
- 금액은 그대로(글자 안 「결제금액 N원」이 남는다) — 리뷰어 화면에서는 **표기만** 바뀐다.

## 원인 (실행 재현으로 확정 — 로컬 http + 가짜 API Playwright, 운영 호출 0)
1. 수정 창이 열리면 `renderOptRowsWithProduct(json.options, wd.productLines, c)` — 옵션 원장 0건 분기.
2. `parseProductLinesToRows` 가 금액을 걷어낸 나머지를 `rest.split(/\s*[-–/|·]\s*/)` 로 **조각낸다**(옵션 추측용).
3. 결정 042 의 「옵션 원장이 비면 조각을 옵션으로 승격하지 않고 상품명으로 **되붙인다**」가 `join(" ")` — **구분자 원형이 공백으로 바뀐다**.
4. 표를 그리면 `_syncPreviewFromOptRows` 가 상품 안내 칸(`rf_wd_product`)을 표에서 다시 만들고, 저장(`productLines: rf_wd_product.value.trim()`)이 그 글을 보낸다.
- 새 공고(작업오더 프리필) `applyProductRowsFromOrder` 도 같은 `join(" ")` 패턴.
- 운영 전수(옵션 없는 공고 74건, 읽기 전용 덤프 + 실제 함수 vm 실행): 열고 저장하면 바뀌는 공고 **6건**(살아 있는 것 1건 `1. 본품+리필1p 세트 / 23호` · 나머지 보관) · 금액이 바뀌는 공고 0건.

## 결정
- ★★ **옵션 없는 공고·오더의 상품명 = 금액만 걷어낸 그 줄 원문**(`parseProductLinesToRows` 가 돌려주는 `lineName`). 구분자·공백을 그대로 둔다.
  - `lineName` = 결제금액 표기가 있으면 `결제금액 N원` 만 걷고(상품명 속 `(2,000원 할인)` 은 지킨다), 없으면 금액으로 읽은 `N원` 을 걷은 뒤 양 끝 구분자만 다듬는다.
  - 편집(`renderOptRowsWithProduct` 원장 0 분기): `r.lineName ||` 종전 규칙. 원문이 비는 줄(금액만 있는 줄)만 종전대로 접는다.
    - 부수 효과(바람직): 둘째 줄이 첫 줄 이름으로 시작하면(`샴푸 리필`) 종전엔 접두가 잘려 `리필` 로 바뀌던 것도 사라진다.
  - 작업오더 프리필(`applyProductRowsFromOrder` 옵션 배열 없음): 같은 줄이면 `lineName`, 한 덩어리 줄이 **오더 상품명을 이어받은**(inherited) 경우만 종전대로 「오더 상품명 + 줄」(무회귀 — `작업오더 글자 옵션은 오더 상품명을 이어받는다`).
- ★★ **결정 042 그대로 유지** — 옵션 원장이 빈 공고·옵션 배열 없는 오더는 `mode:'none'` 강제 · 옵션 0건. 조각 분해는 **옵션 공고(원장 살아 있음)의 상품명 되찾기에만** 쓴다(그 갈래는 무변경).
- 걸러지는 것: 예전 오염 문장 `상품명 결제금액 N원 - 결제금액 N원`(042 ②)은 금액 표기 하나로 정리된다(종전과 같음 · 상품명 글자·주소의 `/` 는 이제 지킨다). 운영에서 이 정리가 일어나는 공고 2건(둘 다 보관 · 금액 동일).
- **범위 밖**: 화면이 `payAmount` 를 보내지 않아 연결 오더가 지워진 공고에서 그 키가 빠지는 서버 쪽(보고서 보조안) — 읽는 곳이 모두 글자 속 금액을 먼저 쓰므로 금액 영향 0, 이번에 하지 않는다.

## 완화 금지
- ★★ 옵션 없는 공고의 상품명을 다시 **조각 `join(" ")`** 으로 만들지 않는다 — 열고 저장만 해도 상품 줄이 바뀐다(이번 사고).
- ★★ 그렇다고 조각을 **옵션으로 승격**하지도 않는다(결정 042 — 우레온 잠금 사고).
