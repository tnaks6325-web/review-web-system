## 결정
1. **보충 줄은 지운 줄의 계획 칸과 배정 표식을 잇는다**(`_inheritSlotPlanInTx`).
   - 잇는 칸 = `worktablePlan.planCellHeaders`(작업표 생성 `planToSheetValues` 가 줄마다 채우는 칸: 상품·옵션·1·2차옵션·리뷰옵션·배송구분·회수·차수).
     번호·구매일자·주문 칸(수취인·연락처·결제금액·주문번호…)은 잇지 않는다. `옵션금액`·`비고(옵션확인)`은 분류상 계획 칸이 아니다(018).
   - 값 = **화면 합성과 같은 순서**: 현재 앵커 편집(채워진 줄 = 주문 앵커) → 물리행 앵커 편집(손 글씨) → 줄 값.
     채워진 줄이면 그 주문이 실제로 고른 상품이 곧 비워진 자리다(처음 채울 때 상품 칸·표식을 실제 선택으로 맞춘다 — 043 보강).
2. **줄 고르기는 손 글씨 상품도 계획으로 본다**(상품 단위 선택 · 옵션 키 없음 · `productPick` 있을 때만).
   - 계획 = 배정 표식 → 손 글씨(물리행 앵커 `col:상품` 편집) → 줄의 상품 칸. 짝짓기 후보 표기에도 들어간다.
   - 순위 보강: 고른 상품 줄 → 같은 리뷰옵션 빈 줄 → 같은 리뷰옵션 다른 상품 자리 → **계획 없는 빈 줄(3)** → 다른 상품 자리(4).
     종전엔 리뷰옵션이 다르면 계획 없는 빈 줄과 다른 상품 자리가 같은 순위(3)라 날짜가 앞선 다른 상품 자리(손 글씨 「옥돔」)를 가져갔다.
3. **처음 채운 빈 줄의 손 글씨가 실제로 산 상품과 다르면 내린다** — 지우지 않고 `reverted_by='system:order-fill'` 로 취소 표시만(편집 이력에 남는다).
   상품 2종 이상으로 짝지은 경우(`productOverwrite`)만 · 같은 상품(표기만 다름)이면 그대로.
4. **공고 총원 ↔ 상품별 남은 자리 합 어긋남 경고**(`campaignState.optionTotalBalance` → 관제 응답 `quotaBalance` → 공고 [참여 관리] 「옵션별 현황」 표 위 한 줄).
   - gap > 0: 상품별로는 자리가 남았는데 총원이 먼저 찬다(넘친 상품 표시) · gap < 0: 상품별로 받을 자리가 총원보다 모자란다.
   - 판정 재료는 단일 출처 그대로(총량 = `totalQuotaUsage`, 선택지 = `computeOptionViews` — 공고 밖 주문 포함). 화면은 숫자를 문장으로만 바꾼다.

## 완화 금지
- ★★ 보충 줄을 다시 **전부 빈 줄로** 만들지 않는다 — 순차진행·상품별 계획 작업표에서 "어느 상품 자리인지"가 사라지고, 날짜·업체 화면이 공고와 어긋난다.
- ★★ 잇는 칸을 `planCellHeaders` 밖으로 넓히지 않는다(주문 칸을 이으면 남의 수취인·결제금액이 빈 자리에 남는다). 키워드 규칙을 따로 만들지 않는다.
- ★★ 손 글씨를 **지우지 않는다**(DELETE 금지 · reverted 표시만) — 담당자 기록은 편집 이력에서 보여야 한다. 내리는 것은 처음 채운 줄 + 상품 2종 짝지은 경우만.
- ★ 손 글씨 조회·이어받기·내리기는 모두 SAVEPOINT 격리 + throw 없음(실패 = 종전 동작) — 이것 때문에 행 삭제·주문 기록이 실패하면 안 된다.
- ★ 총원 대조는 모르면 말하지 않는다(null) — 총량 사용량 모름·총원 0·정원 무제한 선택지·선택지 없음. 0 으로 꾸미지 않는다.
- 끄는 스위치(env): `WORKTABLE_SLOT_PLAN_INHERIT=0`(1번) · `WORKTABLE_SLOT_OVERLAY_PLAN=0`(2번 손 글씨 조회 — 끄면 3번도 일어나지 않는다).
