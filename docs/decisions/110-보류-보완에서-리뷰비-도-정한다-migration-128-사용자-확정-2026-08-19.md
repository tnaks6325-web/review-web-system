# ★★ 보류 보완에서 **리뷰비**도 정한다 (migration 128, 사용자 확정 2026-08-19)
- **배경**: 리뷰비는 `recruit_campaigns.review_fee`(+082 구간표) 한 곳에만 있어 **연결 공고가 없는 작업**(옛 작업·외부모집·수기 진행)은 넣을 칸이 아예 없었다 → 입금관리가 `no_review_fee` 경고로만 흘려보내고 **상품비만 이체**됐다. 보완 팝업에 통장표시와 **같은 자리**에서 리뷰비를 넣는다.
- ★★ **판정은 여전히 `utils/campaignFee.resolveReviewFee` 단일 출처** — 바뀐 것은 **폴백 순서**뿐이다: **스냅샷 → 구간표 → 공고 `review_fee` → 탭 `review_fee`(128)**. **스냅샷·구간표 우선은 완화 금지**(082) — 팝업이 `feeSource` 를 읽어 "이미 참여한 건은 안 바뀐다 / 구간이 우선한다"를 **문장으로 말한다**(저장했는데 안 바뀌는 조용한 no-op 금지).
- ★★ **탭 값은 NULL = 미설정**(0 = 무상 지정과 구분) — `|| 0` 으로 접으면 공고 폴백과 구분이 사라져 출처 표시가 거짓이 된다. 빈 값 저장 = 미설정으로 되돌림, **미전송 = 변경 없음**(리뷰비 칸 없는 화면이 저장해도 조용히 지워지지 않는다 — 이체설정과 같은 계약).
- ★ **저장처는 서버가 정한다**(공고 있으면 공고 `review_fee`, 없으면 탭) · 공고 UPDATE 는 **이체 2칸 + 리뷰비 3칸만**(축약 폼 클로버 금지 — 회귀가드가 SET 목록을 센다) · 숫자 아님·음수·과대는 **쓰기 0건으로 거부**(추측 저장 금지).
- ★ `REQUIRED_SCHEMA` 에 `tab_configs.review_fee` 등록 — `_loadTabMeta` 는 fail-soft 라 컬럼이 없으면 **이체은행·통장표시까지 함께 조용히 미설정**으로 보인다.
- 회귀가드 `tests/paymentIssueFix.test.js`(§3 폴백·스냅샷 우선·SELECT 실검사 / §4 저장 계약 / §6·§7 팝업 배선·문구 — 변이시험 검출 확인).
- ★★ **리뷰비 0원은 경고가 아니다 (사용자 확정 2026-08-19)**: 이 계정은 **상품비만 주는 작업이 다수**(실측 공고 32건 중 27건이 `review_fee=0`)라, 0 을 "미설정"으로 읽으면 입금관리가 상시 `no_review_fee` 로 뒤덮여 **진짜 신호(계좌·은행 미비)가 묻힌다**. → 경고는 **금액이 0이라서**가 아니라 **근거를 못 찾아서**(`!fee && !feeSource`) 띄운다.
- ★★ 종전 버그는 2겹이었다: 공고 로더가 `COALESCE(c.review_fee,0)` + `|| 0` 으로 **0 과 NULL 을 같은 값**으로 만들고, `campFee` 가 truthiness 로 0 을 걸러 **무상 작업 전건이 경고**를 달았다(위프 800건 24/24 · `campaignReviewFee` 가 0 인데도 null 로 나가 보완 팝업 프리필까지 비어 보였다) — 082 의 `_int()` 규율이 **거울상으로** 재발한 자리다. ★ **공고는 있는데 `review_fee` 가 NULL 이면 여전히 미설정**(0 으로 접지 않는다 — 회귀가드가 두 경우를 따로 고정). ⚠ **한계**: 발행 폼에서 리뷰비 칸을 비우면 서버가 0 으로 저장하므로 "0원으로 정함"과 "안 넣음"은 DB 에서 구분되지 않는다 — 사용자 확정으로 **0 = 무상**으로 읽는다. 회귀가드 `tests/paymentIssueFix.test.js` §3c6~3c8(변이시험 5종 검출 확인).
- ★★ **보완 창구의 바로가기는 [📋 작업보드] 하나 — 구글시트 버튼은 제거했다(사용자 확정 2026-08-19)**: 탈시트 이후 그 작업의 진실원본은 시스템 표라, 시트를 열어 두면 거기서 고친 값이 **시스템에 반영되지 않아** 사고가 난다(옛 "참고용 시트" 경고 팝업도 함께 제거). 이동은 관측 뷰·업체관리와 **같은 `pendingTab` 계약**(사본 금지)이고 **팝업을 먼저 닫는다**(오버레이가 작업보드를 가린다). 재료 `tabGid` 는 **서버가 실어 준다**(화면이 gid 를 추측하면 리네임 시 엉뚱한 탭이 열린다). 회귀가드가 `docs.google.com`·옛 함수(`_pmSheetBtn`·`_pmOpenSheet`) **부재를 고정**한다(창구가 둘이 되면 다시 시트에서 고치게 된다).
