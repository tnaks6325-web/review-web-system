# ★★ 리뷰어 앱 공고수정은 인트라넷 관리자 로그인으로 연다 — phone8 허용명단 폐지 (사용자 확정 2026-10-19 · 스키마 변경 0)

- **배경**: 옛 관리자 대시보드 폐기 준비. 리뷰어 앱(`index.html`) 공고수정은 [040](040-리뷰어-앱-공고수정-권한-마스터-허용명단-스코프-토큰.md) 의 **phone8 허용명단**(`reviewer_campaign_editors`, 3명, 마스터가 옛 대시보드 설정탭에서만 관리)으로 열렸다. 대시보드를 없애면 명단을 고칠 화면이 사라진다. 사용자 확정: "제거하고 인트라넷에서 지정된 관리자들이라면 리뷰어 공고수정 허용 가능하도록"(방식 가 = 리뷰어 앱에서 인트라넷 아이디로 한 번 더 로그인).
- **결정**:
  - 발급 `POST /api/reviewer/campaign-token-intranet`(리미터 = `intranetLoginLimiter`) → `reviewerCampaignEditor.issueCampaignTokenForIntranetAdmin`.
  - ★★ **관리자 판정 단일 출처 = `auth.service.verifyIntranetIdentity`** — 작업보드 인트라넷 로그인(`loginIntranet`)에서 떼어 낸 것이다(`INTRANET_SSO_ADMIN_USERS` / `INTRANET_SSO_ADMIN_GROUPS`). 인트라넷 자체 `role` 필드는 종전대로 **불신뢰**(자기신고). 사본을 만들면 "작업보드에선 관리자인데 리뷰어 앱에선 아님"이 생긴다.
  - 토큰 `{role:'admin', via:'reviewer_campaign', iu, ia:true}` 2h — **넓은 8h 인트라넷 토큰은 발급하지 않는다**. 스코프 격리(`authMiddleware`: 공고 PUT + 상품 미리보기만)는 무변경.
  - 저장 시점 `_scopedCampaignEdit` 은 `isIntranetAdminCampaignToken`(`via` + `ia===true` + `iu`)만 통과 — **옛 phone8 토큰은 거절**(배포 직전 받은 열쇠는 최대 2h 안에 다시 로그인).
  - 폐지: `POST /api/reviewer/campaign-token`(phone8 발급) · `GET/POST /api/admin/campaign-editors` · 옛 대시보드 설정탭 명단 UI · 리뷰어 로그인 때마다 하던 자동 발급 시도(헛요청 0, [189] 거절 기억 키 제거).
  - 화면: 리뷰어 홈 "모집공고" 제목 줄에 [✏️ 공고 수정] → 인트라넷 아이디·비밀번호 창 → 성공 시 기존 관리자 권한모드 배너·카드 [✏️ 관리자 수정]. 관리자가 아니면 "작업보드에서 수정해 주세요" 안내.
- ⚠ **재확인 강도**: 종전은 저장 때마다 명단을 다시 봐 즉시 회수됐다. 지금은 인트라넷 비밀번호 없이 관리자 여부를 다시 물을 수 없어 **열쇠 수명(2h)이 회수 지연 상한**이다(인트라넷에서 관리자 해제 → 최대 2h 뒤 차단).
