# ★★ 🏁 마감 작업은 [🛒 구매양식 링크]를 숨기고 거절한다 · [외부모집 수동제출] 버튼은 admin 도 편집 허용 명단과 맞춘다 (사용자 확정 2026-10-21 · 스키마 변경 0)

## 무엇이 있었나 (로컬 가짜 데이터 실흐름 점검 · 2026-10-21)
1. **🏁 마감 작업에도 [🛒 구매양식 링크]가 보였다** — 결정 268 의 "보관(마감) 작업에서는 숨김"은 `wd.archived`(옛 대시보드 ⬛ 마감, 결정 258 의 읽기 전용) 만 봤다. 지금 쓰는 🏁 마감(`trackb_tab_finished`, 결정 087)은 `archived` 를 세우지 않아 버튼이 그대로였고, 서버도 링크를 내줬다 → 리뷰어가 마감한 작업의 구매양식을 열 수 있었다.
2. **[외부모집 수동제출] — 명단 밖 admin 에게 막다른 길** — 화면 `canOpenExternalManualOrder` 는 `master||admin` 이면 무조건 true 였는데, 서버 `/api/trackb/manual-order/*` 는 `editorOnlyMiddleware`(`workdeskEditors.canEdit`: master 통과 · AE staff 통과 · **admin 은 명단에 있어야**)라 명단 밖 admin 이 붙여넣으면 "분해 실패: 이 화면에서는 편집 권한이 없습니다"로 막혔다. 결정 143 의 "화면 게이트 = master/admin ∪ 명단 AE" 서술이 서버와 어긋나 있었다.

## 결정 (사용자 확정 — "둘다 권장대로 고쳐")
- **①** 🏁 마감 작업에서는 **[🛒 구매양식 링크]만** 숨긴다. [🔗 링크 복사]·[🏢 광고주링크]는 지난 작업 열람용이라 그대로 둔다.
  - 화면: 버튼에 `id="formLinkBtn"` + 마감이면 `hidden`. `_finRefresh`(마감/복귀 직후)가 `hidden` 을 다시 맞춰 **새로고침 없이** 사라지고/돌아온다. `.btn{display:inline-flex}` 가 `hidden` 을 이기므로 `#formLinkBtn[hidden]{display:none}` 를 둔다.
  - 서버: `POST /api/trackb/form-link` 가 마감 작업이면 **409 "마감된 작업입니다 … [진행중으로 복귀]"** 로 거절하고 링크를 만들지 않는다. 판정은 **마감 단일 출처** `trackB.finishedTabsMap` → `isTabFinishedIn`(이름 → gid 폴백, `tab_configs.tab_gid` 를 넘긴다). `shortLink.service` 는 trackB 를 끌어오지 않고 호출부가 `isFinished(row)` 콜백으로 넘긴다(옛 경로 `/api/short/create` 는 판정 없이 그대로).
  - fail 방향: 마감 조회 실패(`ok:false`)는 **막지 않는다**(fail-open) — 화면 버튼이 이미 숨겨져 있고, 조회 장애로 진행 중 작업의 링크 발급까지 멈추게 하지 않는다.
  - 이미 보낸 링크(`/r/<code>`)는 그대로 열린다 — 링크를 무효화하지 않는다. 마감 작업의 리뷰어 본인 리뷰 제출 차단은 결정 256 이 따로 맡는다.
- **②** `canOpenExternalManualOrder` = **master 는 true · staff/admin 은 `STATE.campEdit === true`(= `/api/trackb/perm` 의 `canEdit`, 서버와 같은 판정)**. 명단 판정이 오기 전에는 그리지 않고 도착하면 `_emoSyncBtn` 이 채운다(종전 규율 그대로).
