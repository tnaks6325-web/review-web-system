# ★ 작업보드 표 검색 (실시간 · 노란 하이라이트 · 자동 이동) — 시안 C
- **시안** `frontend/docs/design-grid-search.html`(A/B/C 목업, `?v=A|B|C` 단독 보기 — **가짜 데이터로 실제 동작**). 사용자 확정 = **C안**(툴바 왼쪽 인라인 + 스크롤 위치 눈금) · **[일치하는 행만 보기] 제외** · **왼쪽 고정 3열(#·참여자·연락처) 검색 대상 포함**.
- 시트 그리드 툴바(`.gridbar`) **맨 앞** = 표 왼쪽 위에 검색창. 치는 즉시 찾아 **일치 셀 연한 노랑 + 일치한 글자 진한 노랑**, **현재 1건만 주황 테두리**. 가로로 밀려나도 남게 `#` 칸에 세로 막대, 표 오른쪽 바깥 띠(`.gsmap`)에 결과 분포 눈금.
- ★★ **매칭은 데이터(`STATE.gRows`)에서 센다 — DOM 훑기 금지**: 이 그리드는 첫 `_GRID_CHUNK`(60)행만 즉시 그리고 나머지는 rAF 로 이어 붙이므로, DOM 기준이면 **아직 안 그려진 행이 통째로 결과에서 빠진다**. 대신 **이동할 때** `_gsFlushAll` 로 남은 청크를 먼저 다 그린다. ★ 회귀가드는 "호출이 있나"가 아니라 **`_gsFlushAll` 이 첫 `_gsTr(` 조회보다 앞인지 순서를 본다** — 그룹 펼침 분기에도 같은 호출이 있어 존재 검사만으로는 첫 호출 제거를 통과시킨다(변이시험 실측).
- ★★ **하이라이트는 `!important`** — 셀 배경은 이미 세 갈래로 칠해진다: ① 담당자 지정 셀 배경색(migration 080)은 **인라인 style** 이라 클래스로는 못 이긴다 ② 편집 셀(`.gedit.edited`) 파란 배경 ③ 행 호버. 하나라도 못 이기면 "찾았다는데 노란 게 안 보이는 셀"이 생긴다. ★ 기존 앰버 `.rowhit`(리뷰어 로그 딥링크 행 강조 `#fef3c7`)와 **색을 분리**(검색 `#fff3b0`/`#ffe14d`, 현재 `#ff8a00`).
- ★★ **이동은 세로뿐 아니라 가로도** — 주소·계좌번호는 표 오른쪽 끝이라 세로만 맞추면 "찾았다는데 화면엔 안 보인다". `STATE.gFrozenW`(왼쪽 고정열 폭 합, buildGrid 가 기록)로 **고정열 뒤에 가려지지 않는 위치**까지 계산하고 sticky 헤더 높이도 뺀다. 고정열 셀(`.gfz`)은 가로 이동 안 함.
- ★★ **입력 중 그리드·툴바를 재렌더하지 말 것** — 입력칸이 든 툴바를 다시 그리면 **한글 IME 조합이 깨진다**(홈 작업목록 검색에서 실측된 `ㅁ며면면` 사고와 같은 자리). `_gsInput`/`_gsPaint`/`_gsStatus` 는 `#gbody` 셀과 카운터 `textContent` 만 건드린다(120ms 디바운스).
- ★ **`<mark>` 는 텍스트 노드만 훑어 삽입** — 셀 innerHTML 을 통째로 갈면 배지(주문/수동)·되돌리기(↩) 마크업이 깨진다. 해제 시 텍스트로 되돌리고 `normalize`.
- ★ **조용한 누락 금지**: 결과 없으면 입력칸 빨강 + "결과 없음", **필터로 숨겨진 행에 결과가 있으면 건수를 고지**, `n개 행 · m칸 일치`로 풀어서 표기. ★ 재렌더(필터·정렬·숨김) 후엔 하이라이트만 복원하고 **다시 스크롤하지 않는다**(보던 자리를 뺏지 않게). ★ **탭 전환 시 검색어 초기화**(남으면 "왜 여기만 노랗지"가 된다).
- 조작: `Enter` 다음 · `Shift+Enter` 이전 · `↑↓` · `Esc` 지우기, 마지막 다음은 처음으로 **순환**. 4자리 이상 숫자는 "숫자만" 비교도 함께 봐 `010-3498-2400` 을 `34982400` 으로 찾는다(3자리 이하는 폴백 미적용 — 짧은 숫자로 표가 통째로 노래지는 것 방지).
- 회귀가드 `tests/gridSearch.test.js`(정적 배선 + **`_gsCompute` vm 실행**, 변이시험 검출 확인) + 실브라우저 실행검증(청크 밖 행 탐색·가로/세로 이동·IME 조합 실측·필터 고지·탭 전환·광고주 화면). ⚠ 이 변경으로 `advertiserViewer` 가드의 `rerenderGrid` 패턴을 함께 갱신(검사 의미 불변).
