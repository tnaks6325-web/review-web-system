# ★ 업체관리 화면 리디자인 (시안 A · 업체 작업대) — 기능 삭제 0 · 재배치
- **시안·결정** `frontend/docs/design-vendor-management.html`(A/B 2안 + 기능 보존 대조표 18항목, `?v=A|B` 단독 보기, 가짜 데이터로 실제 동작). 사용자 확정 4건 = ① **시안 A**(지금 업체 중심 흐름 유지) ② 표 기본 열 = **정산상세 접힘 + 브라우저 기억**(`localStorage.wd_own_cols`) ③ **'처리필요' 배지 = 마감자료 검수 대기만**(계약 미매칭·미입금은 표의 필터 칩으로) ④ 개요 표 **집계 추가**.
- **바뀐 것은 배치와 조작뿐** — 기존 함수명·id·계약을 한 줄도 바꾸지 않았다(`#ownPanel`·`#owntabsSect`·`#advs`·`.advitem[data-i]`·`.ct`·`.pmn`·`#addSheet`·`#advSheet`~`#advCreateBtn`·`openOwnTab(i)`·`editTabMemo(event,i)`·`ownMatchContract(event,i)`·`_contractMatchApplied`·`refreshAdvCounts`·`saveAe`). ★ 신규 엔드포인트 0 · 마이그레이션 0.
- **기본 화면 = 전체 개요 표**(업체 미선택): 종전엔 빈 **거래처 추가 폼**이 뜨고 오른쪽 절반이 비어 있었다. 이제 업체별 작업수·계약 미매칭·마감자료 검수·접속링크·계정을 한 표로 보여 **어느 업체를 봐야 하는지**부터 말한다. 거래처 추가는 사이드바 [＋ 업체]·미지정 시트에서 열리는 **우측 패널**로 이동(`showAddAdvertiser`는 이름·검증·필드 id 그대로, 그리는 곳만 패널).
- **설정은 우측 슬라이드 패널**(접속링크·계정·소유 시트·소유 추가·거래처 등록·미지정 시트): 매일 보는 연결탭 표가 화면 위를 차지한다. ★ 패널은 **뷰 루트 직속 + `position:fixed`** — 스크롤 컨테이너 안에 두면 오버레이가 화면 흐름에 섞인다(모집공고 모달 실측 사고). ★ **ESC 리스너는 `document`에 1회** — 컨테이너에만 붙이면 포커스가 밖일 때 닫히지 않는 오버레이가 된다(시안 목업에서 실측).
- ★★ **마감자료 검수 대기 판정 = `trackB.service.finishCandidate(stats)` 단일 출처**: 인원 충족 + 전건 제출 + 전건 입금(088 마감 후보와 **같은 규칙**), 재료도 **홈과 같은 `tabStatsMap`**(index_master + review_index PAID). 업체관리가 `campaign_participants`(bTotal/bSub/bPaid)로 따로 세면 **같은 작업이 홈에서는 후보, 업체관리에서는 아님**으로 갈린다. ★ **통계 없으면 판정 안 함**(`total` 0·null 을 충족으로 접지 않는다 — 회귀가드가 실행으로 고정). ★ 서버가 행마다 `finishCand`/`finished` 불리언을 실어 주고 **프론트는 재계산하지 않는다**(배지·칩·표 숫자가 구조적으로 일치).
- ★★ **통계 주석은 opt-in(`annotate`)** — `ownedTabsForAdvertiser` 에 `tabStatsMap`(=`review_index` 전체 GROUP BY)을 무조건 붙였다가, 이 함수의 소비처 4곳 중 **광고주 경로**(`advertiserWorkSummary` → `/my-work-summary`, 무로그인 공개 링크로도 도달)·정산 요약·브랜드 배정에까지 그 비용이 매달렸다(CLAUDE.md "통계는 홈 전용, 작업바 로드엔 붙이지 않는다"와 정면 충돌). **켜는 곳은 `/ownership/tabs` 하나**. ★ 광고주 렌즈는 화이트리스트 재구성이라 `finishCand`/`finished` 가 광고주에게 나가지 않는다.
- ★ **`?overview=1` 의 접속링크 상태는 admin/master 에만 싣는다** — 링크를 다루는 다른 모든 라우트가 `adminOrMaster` 인데 목록만 staff 에게 열면 **서버가 프론트보다 넓어진다**(프론트는 이미 admin 분기). 작업수·미매칭·검수 집계는 staff 도 받는다(담당 판단에 필요).
- **개요 집계** `advertiserOverview` + `GET /api/trackb/advertisers?overview=1`(같은 라우트에 얹음 — 미지정 시 응답 불변): ★★ **로컬 DB만·인트라넷 무접촉**(17업체분 sales 프록시 금지) · **쓰기 쿼리 0**(접속링크를 여기서 생성하지 않는다). ★ 그래서 **개요에 미입금 열을 두지 않는다** — 입금액은 인트라넷 `sales.matched_bank_amount` 에만 있어 여기서 셀 수 없고, 0 으로 꾸미는 대신 "업체를 고르면 표의 미입금 필터로" 라고 화면이 말한다.
- ★★ **fail-soft 는 조용하지 않다 — 그리고 플래그를 "싣는 것"과 "소비하는 것"은 다른 일이다**(코드리뷰가 잡은 blocker): `advertiserOverview` 는 소스별 `statsUnavailable`/`finishedUnavailable`/`contractsUnavailable`/`linksUnavailable`, `ownedTabsForAdvertiser` 는 `{rows, statsUnavailable, finishedUnavailable}`(배열 반환에서 변경 — 호출부 **4곳** 갱신)로 올린다. 처음 구현은 서버가 이 4개를 정성껏 실어 보내면서 **화면이 `overview.ok` 만 봐서**, `ok:true` 인데 통계만 죽은 경우가 **"마감자료 검수 0건"으로 조용히 위장**됐다. 판정은 `_ovmCandKnown`/`_ovmMatchKnown`/`_ovmLinkKnown` **한 곳**으로 모아 배지·사이드바 칩·개요 표 3곳이 **열별로** `?`(사유 tooltip)를 띄우고, 판정 불가 칩은 **클릭도 막는다**(누르면 "조건에 맞는 업체가 없습니다"라는 확정 문장이 나와 다시 오독된다). ★ 특히 접속링크 열의 "모름"을 **"미생성 — 열면 자동 생성됩니다"** 로 적으면 폐기·로그인필요 링크를 **적극적으로 틀리게** 안내한다.
- ★★ **이 뷰는 내부 스크롤이다**(`.own-wrap{height:calc(100vh - var(--toph,57px))}`): 종전엔 `.own-panel{overflow:auto}` 가 있는데도 높이가 콘텐츠만큼 늘어나 **스크롤이 안 일어나 도구줄 sticky 가 영영 죽었다**(홈 목록 헤더행에서 겪은 것과 같은 함정 — 실측). 덤으로 사이드바·[미지정 시트] 버튼이 항상 보인다. ★ 좁은 화면(≤780px)은 1열로 접히므로 `height:auto` 로 문서 스크롤 복귀(고정 높이면 아래가 잘린다).
- ★★ **검색 중 입력칸을 재렌더하지 말 것**: 도구줄과 행을 분리해 검색은 `#ownRows` 만 갈아치우고, **정산 요약이 타이핑 중에 도착해도**(`_rerenderOwnTabs` → `#ownRows` 있으면 rows only) 입력칸 DOM 을 건드리지 않는다. 섹션을 통째로 innerHTML 교체하면 한글 IME 조합이 파괴된다(`ㅁ며면면` 실측 계열). 비고 편집 중 재렌더 연기(`.omemoin`)는 그대로.
- **열 4묶음 접기**(작업정보·진척·자료·정산상세): 열 폭·`min-width` 를 **JS(`_ovmGrid`)가 인라인으로** 정한다(CSS 고정값을 되돌리면 접어도 가로 스크롤이 남는다). 기본 13칸(자료 켬·정산상세 접힘)에서 FHD 가로 스크롤 없음, 정산상세를 펼치면 17칸(그때만 스크롤). ★ **헤더 칸 수 ≡ 행 칸 수 ≡ grid 열 수**는 회귀가드가 **16조합 전부 실행**해 대조한다(열을 끼워 넣을 때 가장 흔히 깨지는 자리).
- 브랜드 칩은 **상위 5개 + 드롭다운**(40개가 3줄로 넘쳐 필터 구실을 못 했다). 상태 필터 5종(전체·계약 미매칭·마감자료 검수·미입금·마감)의 **숫자와 목록은 `_ovmRowMatch` 한 판정**을 쓴다(따로 세면 "칩은 12인데 표는 3줄"). 마감된 작업은 표에 `🏁 마감` 배지로 구분(서브라인 **앞** — 뒤에 두면 시트명 말줄임에 잘려 사라진다, 실측).
- ⚠ **곁다리로 고친 라이브 버그**: `workdesk.html` 주석의 별표+빗금(`qd*/qv*/idc*`)이 주석을 조기 종료시켜 바로 아래 `.bb.docv{cursor:pointer;text-decoration:underline dotted}` 가 **브라우저에서 통째로 삼켜져** 있었다(견적서·계산서 [문서 보기] 배지가 클릭 가능해 보이지 않음). `workboardFinish` 의 CSS 균형 가드가 그 때문에 계속 빨간 상태였다 — **빨간 가드는 새 변경도 못 지킨다**.
