- **발단**: 한 작업에 **상품A(옵션 2개) + 상품B(옵션 없음)** 이 섞이면 리뷰어의 참여 선택지는 **3가지**(A-옵션1 / A-옵션2 / B)인데, 종전 모델은 ㉮ "옵션"만 선택 단위였고 ㉯ 유입가이드가 **공고당 한 벌**(`work_detail.inflowGuideHtml`)뿐이라 **둘 다 표현할 수 없었다**. 가이드유입 작업은 선택지마다 검색어·경유 경로가 다른데 한 가이드를 셋이 나눠 쓰면 유입이 통째로 어긋난다. 기획·시안 = `frontend/docs/prd-multiproduct-guide.html` · `frontend/docs/복합작업_선택지별_유입가이드_와이어프레임.html`.
- ★★ **모델 = 선택 단위(`campaign_options` 한 행 = 리뷰어가 고르는 한 줄)**: `unit_kind='option'`(종전 그대로) / **`unit_kind='product'`(옵션 없는 상품 자체가 선택지)** + `product_name`(리뷰어 화면의 상품 묶음 머리) + `inflow_guide_html`·`inflow_guide_images`(그 선택지 전용 가이드). 137 = **컬럼 추가만 · 백필 0 · CHECK 0 · FK 0**(원래 134로 개발됐으나 main 이 134~136 을 먼저 써서 137 로 재번호)(082 의 42804 규율) 이고 기본값이 종전 동작과 같아 **배포 즉시 동작 불변**(opt-in).
- ★★★ **`unit_kind='product'` 의 `opt_key` 는 시트 옵션 칸에 쓰지 않는다(완화 금지)**: 그 단위의 키는 **상품명**이라 그대로 쓰면 시트 옵션 칸에 상품명이 박힌다 — 8/3 우레온 사고(상품명이 옵션명으로 승격)를 **저장 경로에서 재현**하는 것이다. 소비처 2곳이 같은 규칙: 리뷰어 제출(`submit.routes` `sheetOptKey = unitKind==='product' ? '' : effectiveOptKey`) · 외부모집 수동제출(`manualOrder.service`). ★ 옵션 정원·홀드·관제 집계는 **종전대로 `opt_key` 로 센다**(선택 단위 = 옵션 행이라는 계약 불변).
- ★★ **가이드는 "그 선택지 것"이 있으면 그것, 없으면 공고 공통으로 접는다**(`campaign-workdetail.js` `usingUnitGuide`) — 폴백을 없애면 가이드를 아직 안 넣은 선택지가 **빈 카드**가 된다. ★ 두 층을 **합치지 않는다**(단위 가이드가 있으면 공통은 안 그린다 — 섞으면 리뷰어가 어느 경로를 따라야 하는지 잃는다).
- ★★ **계약(`product_options_json` v2)은 가산 키만**: 상품마다 `product_mode: 'opt'|'none'`, 단위마다 `guide: { text, images }`. **`guide` 는 가이드유입일 때만 실린다**(링크유입은 각 선택지의 URL 이 곧 유입) · **옵션 있는 상품의 상품 줄에는 싣지 않는다**(그 줄은 선택지가 아니다) · **`product_mode` 가 없는 옛 오더는 종전 추론**(옵션 2개 이상)이 그대로 돈다.
- ★★★ **`product_mode` 는 전 상품에서 읽는다** — 첫 상품만 보던 판정(`arr[0]`)은 **`상품B(옵션없음) + 상품A(옵션)` 순서로 오면 복합 구조를 통째로 버린다**. `explicitMode = arr.some(p => p.product_mode)` 로 **`none` 도 명시 신호로 인정**하고(그래야 발행 프리필이 표를 옵션 모드로 잘못 열지 않는다), 그 신호가 없을 때만 옵션 수 추론으로 떨어진다.
- ★★ **`guide` 는 객체로 읽는다** — 문자열만 보던 수신부에 객체가 오면 `String({})` 이 **`[object Object]` 로 리뷰어 가이드 카드에 그대로 나간다**(실측 위험). 문자열로 온 옛 초안도 계속 읽는다(`_woUnitGuide` 정규화 단일 출처).
- ★★ **글자만 있는 가이드를 지우지 말 것** — `_woPlainGuideToHtml` 은 **첨부가 하나도 없으면 빈 문자열을 돌려주는 이미지 승격 전용** 함수다. 그대로 쓰면 사진 없는 안내문이 통째로 사라지므로 그 갈래는 **escape 해서 보존**한다.
