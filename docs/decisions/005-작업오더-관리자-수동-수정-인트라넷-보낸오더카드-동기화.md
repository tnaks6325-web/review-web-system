# 작업오더 관리자 수동 수정 (인트라넷 보낸오더카드 동기화)
- **시안** `frontend/docs/작업오더_관리자수정_와이어프레임.html`(2026-08-05 확정). `PUT /api/order/admin/edit`(adminOrMaster) + `PUT /api/trackb/work-orders/edit`(`_delegate` 위임, internal+**editorOnly** — 접수·상태변경과 같은 2단 권한). 화이트리스트 `ADMIN_EDIT_FIELDS` 부분수정(PATCH), **빈 값 = "지움"이 아니라 "변경 없음"**(칸 비우기 사고 방지), 같은 값 = no-op(메모 도배 방지).
- ★ **편집 불가 3종(완화 금지)**: `status`(전용 [상태 변경] 흐름) · 계약건 `sales_id/contract_number/quote_id`(인트라넷 발주 확정값·정산 매칭 보호) · `work_sheet_url`(접수·작업표 생성·gid 교정 재접수가 관리). `guide_images`는 1차 제외(업로드 UI 필요).
- **동기화 = 신규 채널 0**: 인트라넷 "보낸 오더" 목록은 리뷰웹 `work_orders`를 실시간 조회(`/api/review-order/list` → intake/list 프록시, 캐시 병합 시 리뷰웹 값 우선)라 **값은 자동 반영** — 수정 diff 요약만 기존 처리메모 webhook(`_pushIntranetMemo` 공용 헬퍼, send-memo와 한 벌)으로 push해 카드 주황 메모 블록에 표시(인트라넷 수신부 무변경, fail-soft). diff는 `memo_log`에 `kind:'admin_edit'`로 누적(수정 이력, `admin_memo`는 안 덮음). 긴 텍스트 필드는 "내용 수정"으로 요약.
- **모달은 공유 한 벌**(`work-order-detail.js` `woAdminEditModal`) — 호스트가 `opts.save`로 자기 경로 주입(admin=`orderAdminEdit` / workdesk=trackb, workdesk 버튼은 `_woEditActions` 안 = 허용명단 게이트 상속). ★ 오더 값은 전부 `.value`/`textContent`로만 주입(innerHTML 보간 금지). 바뀐 필드만 전송. 회귀가드 `tests/workOrderAdminEdit.test.js`(스텁 pool 핸들러 실행 + 모달 vm 실행 XSS·diff 전송).
