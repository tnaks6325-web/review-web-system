# ★★★ 업체 지정 단위 = 작업(작업보드) 하나 — 시트 축 폐지 (사용자 확정 2026-08-23, 스키마 변경 0)
- **발단**: 업체관리의 지정 축이 **구글시트 파일(`sheet_id`)** 이었다 — [시트 전체 지정] 한 번이면 그 시트의 **모든 탭 + 앞으로 생길 탭까지** 자동으로 그 업체 소유가 됐다(`advertiser_campaigns.tab_gid IS NULL`). 사용자 지시 = "더이상 구글시트로 업체를 지정하지 않는다 · **활성 작업보드 목록 중 미지정 작업만** 업체 지정한다".
- ★★★ **무시트화(탈시트 전환)로는 이 축이 안 없어진다** — `sheetlessCutover` 는 `tab_configs.sheetless` 플래그만 켜고 **`sheet_id` 는 그대로 둔다**(이관된 작업은 진짜 시트 ID 를 계속 쓴다). 그래서 `tab_gid IS NULL` 소유 행은 무시트화 뒤에도 살아 그 시트의 모든 작업을 계속 덮는다. **축을 실제로 없애는 것은 "펼치기"** 다(아래).
- **창구 4곳에서 시트 선택지를 제거**: ① 미지정 목록 = **작업마다 [업체 지정] 하나**(시트 그룹 머리·[시트 전체 지정]·시트 단위 [거래처 등록] 폐지 — 새 업체는 지정 팝업의 [＋ 새 거래처 등록]으로) ② 소유 추가 = 미지정 작업 드롭다운 ③ 거래처 등록 = **미지정 작업 선택 + 그 작업 소유 지정**(`#advSheet`→`#advTabSel`) ④ 이관 팝업 = 범위 라디오 제거(작업만 고른다). ★ **`tabGid:null` 로 보내는 분기가 코드에 없다**(회귀가드가 부재를 고정 — 되살리면 새 작업이 자동 포함돼 작업 단위 지정이 무의미해진다).
- ★★ **판정·후보는 화면의 미지정 판정과 같은 재료 하나**(`STATE.mapTabs` 의 `advertiserId` 없음) — 소유 추가·거래처 등록·미지정 목록이 **같은 목록**을 본다(따로 세면 "여기선 23건인데 저기선 21건"). gid 판정은 `_ovmTabGid` 단일 출처, 무시트 라벨 숨김은 `_isNoSheet` 단일 출처.
- ★ **gid 없는 작업은 지정 불가**(개별 소유를 만들 수 없다) — 숨기지 않고 **비활성 + 사유**([시트 반영 점검]의 gid 채우기로 안내). 죽은 버튼을 두지 않는다.
- **기존 시트 전체 소유 정리 = `expandSheetOwnerships`**(`POST /api/trackb/ownership/expand`, internal + 담당 게이트): 시트 전체 소유 1건 → **그 시트의 활성 작업 N건 소유**로 펼치고 원 행을 소프트 해제. 창구 = 업체 패널 ▦ 줄 [작업 단위로 펼치기] + 개요 헤더 [▦ 시트 전체 소유 정리](전체 일괄).
  - ★★ **완화 금지 4종**: ① 대상 작업은 **활성 작업 목록**(`participants.listActiveTabs` — 화면 판정과 같은 재료) ② **gid 없는 작업이 하나라도 있으면 그 시트는 펼치지 않는다**(fail-closed — 펼치면 그 작업이 **주인 없이** 남는다) ③ **다른 업체가 작업 단위로 가진 건 건드리지 않는다**(탭 지정 우선 = 사람이 명시한 더 강한 결정, `transferOwnership` 의 `keptTabOverrides` 와 같은 규율) ④ **미리보기 기본**(`confirm !== true` 면 쓰기 0) · 시트 하나당 한 트랜잭션(전부 아니면 전무).
  - ★ **활성 작업 0건·전부 남의 것이면 펼치지 않는다**(모르는 채로 소유를 지우지 않는다) · **쓰기 표면 = `advertiser_campaigns` 한 곳**(시트·장부·주문·정산 무접촉) · 하드 삭제 0(소프트 해제) · 부분 실패는 **건수와 사유를 말한다**.
  - ⚠ **되돌리기는 자동이 아니다** — 펼친 뒤 그 시트에 새 작업이 생기면 **미지정으로 뜬다**(그게 목적). 시트 전체 소유로 되돌리려면 DB 를 손봐야 한다(화면 확인창이 그 사실을 말한다).
- ★ **읽기 경로는 무변경** — `tab_gid IS NULL` 을 해석하는 소비처(`advertiserForTab`·`ownedTabsForAdvertiser`·`scopedActiveTabs`·`advertiserOverview`)는 그대로다. 남아 있는 레거시 행이 계속 정상 동작하고, 펼치면 자연히 사라진다.
- **개요 KPI 도 작업 기준**(`_ovmTabCounts` — 「연결된 소유 시트」→「업체 지정 작업 N / 활성 작업 M」). ★ 재료(`mapTabs`)를 못 받으면 **숫자를 지어내지 않고 `?`**.
