# ★ 작업보드 표 — 오늘 참여현황 표기 (툴바 맨 앞 · 시안 C+B 믹스)
- **시안** `frontend/docs/design-grid-today-progress.html`(A/B/C + 상태 6종 + 결정사안, `?v=A|B|C`). 사용자 확정 = **C안 도넛 + B안 파란 날짜**. 시트 그리드 툴바 **맨 앞**(검색창 왼쪽)에 `◔ 8/10 (월) 참여현황 12/20명` — "오늘 몇 명을 채워야 하고 지금 몇 명이 들어왔나"를 표를 세지 않고 알게 한다.
- ★★ **정원 판정 사본 0 = `computeCampaignState.dailyQuota` 그대로**(`trackB.tabTodayProgress`): 여기서 "일건수 + 이월"을 다시 세우면 **066 이월 상한 · 095 날짜별 조절 · 098 이월 보류 · 총량 clamp** 를 모르는 두 번째 기준이 생겨 **툴바는 20명인데 카드·[📅 인원] 은 25명**으로 갈린다(`todayNaturalQuota` 를 서버가 실어 보내는 것과 같은 이유). 재료 3종(counts·시트 일정·now)도 `tabCampaignsMap`/`admin/list` 와 같은 것을 모은다. **프론트는 서버가 준 값을 그리기만** 한다.
- ★★ **분자 = 작업표 기준(사용자 확정 2026-08-10 B안 — 종전 "오늘 제출 확정"에서 변경)**: `tabFilled.service.todayFilledMap` 이 `review_index`(이름 있는 행만 = **채워진 줄**)에서 **구매일자가 오늘인 행 수**를 센다. 계기 = 장수돌침대 900건에서 표 27줄인데 표기는 8명(지각 참여·시트 수기 입력·외부모집분이 공고에 없어 안 세어짐, 진단 문서 `frontend/docs/design-participation-count-mismatch.html`).
  - ★★ **계산은 한 곳** — 모집공고 카드(`/campaign/admin/list` → `todayFilled`)와 작업보드 툴바(`tabTodayProgress` → `sheetFilled`)가 **같은 함수**를 소비한다. 각자 세면 "왜 카드와 표가 다르냐"가 방향만 바꿔 되돌아온다.
  - ★★ **`parseDateColumn` 에 `fallbackAnchor` 필수** — 시트 표기는 `8 / 10 (월)` 로 **연도가 없어** 안 넘기면 전부 null → "오늘 0명"으로 조용히 죽는다(W2-b F-2 와 같은 자리).
  - ★★ **중복 탭 키 제거** — 한 탭에 공고가 여럿(차수 재발행)이면 같은 키가 두 번 들어와 JOIN 이 행을 **두 번 매칭**해 숫자가 배가 된다("42/42 완료"로 위장).
  - ★★ **소비처는 셋** — 작업보드 툴바 · 관리자 모집공고 탭(`/campaign/admin/list`) · **홈 모집공고 카드(공개 목록 `/campaign/list`)**. 홈 카드가 빠지면 "작업보드는 맞는데 홈만 다르다"가 남는다(실제로 그렇게 신고됐다). 공개 목록은 **5초 캐시 안에서** 계산한다.
  - ★★ **표시는 운영자 게이트 뒤에만**(`admin || _adminTok`) — 일반 리뷰어에게는 종전(공고 기준) 그대로여야 한다. 참여 허용 판정이 공고 기준이라 리뷰어 화면까지 바꾸면 **"게이지는 찼는데 참여는 되는"** 상태가 생긴다. 재료(`todayFilled`)는 공개 응답에 실리되 **그리는 쪽이 게이트**를 건다. ★ 게이트는 **`✏️ 관리자 수정` 칩과 같은 범위**(`_adminTok` = 진짜 admin_token **또는** 공고수정 허용명단 스코프 토큰) — `_realAdminTok`(진짜 토큰만)로 좁혔더니 **스코프 토큰으로 홈을 보는 담당자에게 카드만 옛 숫자로 남았다**(실측 신고 2026-08-10: 서버는 40 을 내려주는데 화면은 13). 회귀가드가 두 게이트의 **동일성**을 고정한다.
  - ★ 표시 숫자를 바꾸면 **완료 판정·채움 폭도 같은 값**을 따라가야 한다(`pubFull`/`shownFull`) — 안 그러면 39/42 인데 카드가 "완료" 색으로 칠해진다.
  - ★ **못 세면 null → 종전 값으로 폴백하고 그 사실을 말한다**(0 위장 금지). ★ **표 ≠ 공고 확정의 차이는 툴팁으로 남긴다** — 그 차이가 곧 **지각 참여 확정 대기·수기 입력 신호**라, 표기를 바꿔도 신호를 잃지 않는다.
  - 진행 중(결제 중 홀드)은 `holds` 로 따로 — 합치면 홀드 만료 때 **숫자가 줄어든다**.
  - 회귀가드 `tests/sheetBasedParticipation.test.js`(, **변이시험 검출 확인**). ⚠ 가드 함정 2종: **스텁은 SQL 을 해석하지 않으므로 WHERE 절은 쿼리문으로 고정**할 것 · **`indexOf` 순서 단언은 `-1 < n` 이 항상 참**이라 존재 확인을 먼저 할 것(둘 다 변이시험이 실제로 뚫었다).
- ★★ **"없다"와 "모른다"를 다른 모양으로**: 정원 0(휴무·일정 종료·총원 충족·0명 조절) = 회색 `0/0명 · 오늘 모집 없음` / 공고 없음·게시 전 = 점선 `12 / ?명 · 모집 기준 없음`(**구매한 인원은 사실이라 그대로 보여주고 분모만 ?**) / 조회 실패 = 점선 `? / ?명 · 불러오지 못함`. **0/0 으로 위장하면 "오늘 할 일 없음"으로 읽힌다.** 초과는 감추지 않고 `+3`.
- ★★ **gid 는 서버가 `tab_configs` 에서 다시 구한다** — 클라이언트가 보낸 `tabGid` 를 믿으면 낡은 화면이 **같은 시트 다른 탭의 공고 정원**을 이 표에 띄운다(스코프 판정이 tabGid 를 안 믿는 것과 같은 규율). 매칭은 **이름 + gid 폴백**(리네임으로 연결이 조용히 풀리면 멀쩡한 공고를 두고 "모집 기준 없음"이 뜬다), ★ **빈 gid 는 절을 켜지 않는다**(`$3 <> ''` — 켜면 gid 없는 공고가 전부 매칭).
- ★ 살아있는 공고가 여럿(차수 재발행)이면 **합산하고 `campaignCount` 로 그 사실을 말한다**(하나만 고르면 나머지 물량이 조용히 빠진다). 참여형 + `status='active'` 만 대상(레거시는 정원 개념이 없다).
- ★★ **업체(광고주) 뷰어에도 같은 자리·같은 모양으로 표기한다**(사용자 확정 2026-08-10) — 단 **`_tpAdvertiserLens` 를 거친다**: 공고를 거친 확정 수·결제 중 홀드·합산 공고 수는 **응답에서 폐기**하고 `done` 을 표 기준과 같은 값으로 눕혀 **"차이 N명(지각 확정 대기·수기 입력)" 내부 문구가 아예 생성되지 않게** 한다. ★ **화이트리스트 재구성**(`{...tp}` 스프레드 금지 — 나중에 필드가 늘면 조용히 샌다). 화면은 무수정(`buildGrid` 가 광고주에게도 같은 툴바를 그린다). · **읽기 전용**(쓰기 쿼리 0 · 시트 무접촉 · 클릭 동작 없음) · **fail-soft**(어떤 실패도 throw 하지 않아 작업보드 로딩을 죽이지 않는다).
- ★ **칩 높이 28px = 툴바의 다른 컨트롤과 같다** → 툴바 높이 불변(실측 32px, 칩 없을 때와 동일 = 표가 아래로 안 밀린다). 도넛은 `conic-gradient` 한 겹(외부 이미지·SVG 0), 클래스는 **`tprog` 접두로 스코프**(맨몸 `.ring` 금지). 좁은 화면(≤720px)은 라벨만 접고 **숫자는 어떤 폭에서도 남긴다**. 날짜 표기는 `_fmtKDate` 단일 출처.
- 회귀가드 `tests/gridTodayProgress.test.js`(스텁 pool 로 서비스 **실제 실행**(총량 clamp 로 판정 사본 검출) + 렌더러 vm 실행 6상태 + 배선·CSS 계약, **변이시험 검출 확인**) + 실브라우저 검증상태 실측(툴바 높이 불변·칩이 검색창 왼쪽·JS 오류 0). ⚠ 이 변경으로 `gridSearch` 가드의 "검색창이 툴바 맨 앞" 패턴을 갱신했다(검사 의미 불변 — 앞에 올 수 있는 것은 **읽기 전용 표기뿐**).
- ⚠ **가드 함정 2종(변이시험이 실제로 뚫었다)**: ① 시그니처 검사를 파일 전체로 하면 **호출부 문자열**(`tabTodayProgress(db, { sheetId, tabName })`)이 대신 통과시킨다 → **선언부 destructuring 만** 볼 것. ② `title="${esc(tip)}"` 는 이 파일에 **5곳**이라 파일 전체 검사는 여기서 escape 를 빼도 통과한다 → **함수 본문으로 잘라서** 볼 것. ⚠ **변이시험은 커밋 후에** — `git checkout` 이 미커밋 변경(이번엔 인접 가드 갱신)을 통째로 되돌린다.
