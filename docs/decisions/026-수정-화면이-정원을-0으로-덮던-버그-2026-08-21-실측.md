# ★★ 수정 화면이 정원을 0으로 덮던 버그 (2026-08-21 실측)
- **증상**: DB 총인원 500 · 일건수 30 인 공고를 수정 화면에서 열면 화면이 **0/0** 이고, 그대로 저장하면 정원이 통째로 리셋됐다.
- **원인**: `work_detail.productLines`(작업내용 상품 원문)가 **빈** 공고는 `parseProductLinesToRows` 가 0행을 돌려줘 진행상품 표가 비고, `_syncPreviewFromOptRows` 의 수정 모드 분기가 `head = live[0] || rows[0] || {}` → **빈 객체**로 떨어져 총인원·일건수를 0 으로 썼다. (2026-08-19 에 고친 "상품 줄 2개 이상" 케이스와 **다른 갈래**다 — 그쪽은 첫 행 값을 쓰게 해 해결됐다.)
- ★★ **수정 = 표가 한 줄도 없으면 정원을 다시 만들지 않는다**(`|| {}` → `|| null` + `if (head)`) — 프리필로 실린 캠페인 원장 값을 그대로 지킨다. 회귀가드가 **옛 형태(`|| {}`)의 부활을 차단**한다.
