# 직원 화면 「INADD 리뷰오더 상품정보 가져오기」 확장 프로그램 필수 설치 — 차단 + 예외 (사용자 결정 2026-10-13)

## 결정
- 리뷰오더(인트라넷)·리뷰웹 **직원** 화면 접근자는 크롬 확장 프로그램 「INADD 리뷰오더 상품정보 가져오기」(웹스토어 미등록 게시, 항목 ID `hlhphdglgkacdbbknpfmaoklcbinnaoe`)를 반드시 설치한다.
- 강도 = **차단 + 예외**: PC 크롬·웨일·엣지에서 미설치면 화면을 가리고 설치 안내(웹스토어 · 사진 가이드 · 새로고침). 휴대폰·사파리·파이어폭스는 막지 않고 안내 문구만.
- 대상 = **직원만**. 리뷰어 화면과 광고주(업체) 화면은 제외 — 바깥 사람에게 회사 확장 설치를 요구하지 않는다.

## 리뷰웹 배선
- `frontend/js/product-reader-gate.js` — `window.productReaderGate({ isStaff })`.
  - 관리자 화면: `index-app.js` `enterAdminScreen()` 진입 때 `isStaff: true`.
  - 작업데스크: 토큰 역할 확인 직후 `isStaff: STATE.role !== 'advertiser'`.
- 설치 확인 = 확장 1.0.4 의 `externally_connectable` + `onMessageExternal` **PING**(버전만 답함). 확장이 없으면 페이지에 `chrome.runtime` 이 없거나 연결 오류 → 「미설치」.
- 스위치 = 파일 안 `PRODUCT_READER_REQUIRED`(기본 false).

## ★ 켜는 순서 (어기면 설치한 직원까지 막힌다)
1. 확장 **1.0.4 웹스토어 심사 통과**(2026-10-13 제출, 「검토 대기」) — 1.0.3 은 PING 에 답하지 않는다.
2. 통과 확인 후 `PRODUCT_READER_REQUIRED = true` 로 바꿔 배포. 화면이 바뀌는 변경이므로 미리보기 확인을 받는다.
3. 즉시 끄기 = 값을 false 로 되돌려 배포(프론트 자동 배포 ~20초).

## 켠 기록 (2026-10-14)
- 1.0.4 게시 확인: 웹스토어 업데이트 서버(`clients2.google.com/service/update2/crx`) 응답 `version="1.0.4"` + 상세 페이지 표기 1.0.4. (개발자 대시보드는 Google 재로그인 요구로 못 봄.)
- 실브라우저 확인: 웹스토어판을 설치한 웨일에서 `https://review-web-system.pages.dev` 에서 PING → `{"ok":true,"version":"1.0.4"}`.
- 잠금 화면에 안내 한 줄 추가 — 아직 1.0.3 인 설치자(자동 업데이트 전)가 「설치했는데 계속 뜬다」고 헤매지 않게 「브라우저를 완전히 껐다 켜기」 안내.
- 시험 주소 예외(`isTestHost`): Railway PR 미리보기(`test-review-wdb-web-review-web-system-pr-<번호>.up.railway.app`)·`localhost`·`127.0.0.1` 은 잠그지 않는다. PR 미리보기는 확장 `externally_connectable` 밖이라 설치자도 PING 이 안 닿아, 막으면 화면 변경 미리보기 확인(CLAUDE.md 2-1)이 불가능해진다. 운영·Cloudflare 미리보기·테섭 production 은 예외 아님(PR #1633 리뷰).
- 작업데스크 로드 순서: `product-reader-gate.js` 를 `<head>` 로 옮김 — 맨 아래 첫 `boot()` 보다 뒤에 있으면 재방문·SSO 입장 때 `window.productReaderGate` 가 없어 잠금이 조용히 빠진다(PR #1633 리뷰). 회귀가드가 순서를 검사한다.

## 인트라넷 쪽 (참고, 인트라넷 저장소)
- 리뷰오더 화면 잠금 + 즉시 끄는 스위치 `app_settings.product_reader_required = 'off'`, 사진 가이드 `/static/product-reader-install-guide.html`. 운영 문서 `docs/operations/product-reader-extension.md`.
