## ★★ 완화 금지
- **`zeroPricePurchaseOf` 의 조건을 느슨하게 하지 말 것**(빈칸·문자를 0 으로 읽기 · 리뷰오더 없음/금액 모름 허용 · 주문 금액 확인 빼기 · split/업체입금/Q&A 로 넓히기) — 결제금액을 실수로 비우거나 0 으로 적은 일반 작업이 제품값 없이 리뷰비만 받고 끝난다(되돌리려면 사람이 찾아 다시 보내야 한다).
- **판정을 화면·라우트마다 따로 쓰지 말 것** — 이 함수 하나 + 회차 항목 표시 하나.
- **`isFeeOnlyItem`/`feeOnlyItemSql` 의 `zero_price_purchase` 제외를 빼지 말 것** — 빼면 0원 구매 지급이 입금일·페이백 완료 없이 끝나 리뷰어 화면이 "미입금"으로 남고 다음 회차에 다시 잡힐 근거가 된다.
- **회차 항목을 읽어 판정에 넘기는 곳(결과 파일·통장 확인·입금일 다시 쓰기)에서 `is_qna`·`zero_price_purchase` 를 빼지 말 것** — 통장 확인 경로가 실제로 빠져 있었다.
- **회차 담기의 표시 값은 서버가 다시 계산한 대상값으로만** 넣는다(화면 값을 믿지 않는다).
