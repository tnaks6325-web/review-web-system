# ★★ 참여자 수동 추가([＋ 줄 추가]) — 무시트 탭은 900000 대역 금지 (2026-08-21 실측 결함 수정)
- **결함(에셀라이트 유산균 건 조사 중 발견)**: `addParticipant`(`/api/participants/add`·`/api/trackb/workdesk/add`)가 무시트 탭에서도 ① seq 를 **900000 격리 대역**에 배정하고 ② **`row_json` 을 비워** 넣었다 → 장부 생성기(`sheetlessLedger.buildValues`)가 seq 크기만큼 시트 모양 배열을 만들어 **줄 하나에 90만 칸**을 할당하고, 빈 `row_json` 줄은 파서가 이름 없는 행으로 버려 **검색 명단·입금대상에서 영영 빠졌다**.
- ★★ **무시트 탭 분기(`_addParticipantSheetless`)**: 실제 행 번호 대역에 이어붙이고(`MAX(seq) FILTER (WHERE seq < MANUAL_SEQ_BASE)`) `row_json` 을 헤더명 키로 채운 뒤(열 판정 = `utils/applicantColumns` 단일 출처) **장부 재생성**까지 한다. `source='worktable'`(manual 이면 리뷰제출·입금 표시가 영영 안 켜진다). ★ **번호 칸은 비워 둔다**(자동 재번호 스윕 담당 — 헤더가 1행이 아닌 탭에서 seq−1 은 틀린 번호다). ★ fail-closed 3종 = 이름 없음·미등록 탭·열 구성 미상이면 **쓰기 0건 거부**(조용히 900000 대역으로 낙하 금지). 판정 실패는 종전 경로(fail-open — 시트 기반이 절대 다수).
- ★★ **900000 대역 오염 방어(형제 경로 3곳 + 장부)**: `appendSlot`·`registerBlogger`·`addApplicantRow` 의 `MAX(seq)` 도 **실제 대역(< 900000)만** 센다 — 오염된 줄이 하나라도 있으면 모든 새 줄이 90만 대역으로 이어붙는다(상수는 `participants.MANUAL_SEQ_BASE` 단일 출처 export). `buildValues` 는 900000 대역 줄을 배열에 넣지 않고 `manualBandSkipped`/`manualBandWithData` 로 세어 알리며, 값이 있는 잔재 줄은 `rebuildLedgers` 가 warn 으로 드러낸다(조용한 누락 금지).
- ★ **시트 기반 탭은 종전 경로 100% 불변**(900000 대역 = "시트 행을 모를 때"용 격리 대역이라 그쪽에선 여전히 옳다 — `prepareRosterSlots` 도 무변경). 작업보드 UI 의 사람 추가 창구는 여전히 [외부모집 수동제출]·[＋ 블로거 추가]뿐(가드가 add UI 부재를 고정 — 이 수정은 API 경로의 결함 제거다).
