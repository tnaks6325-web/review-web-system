# ★★ 업체 화면 — 마감(🏁)한 작업은 덜 채웠어도 「완료」 · 업체에는 끝남 불리언 하나만 보낸다 (사용자 확정 2026-11-03 A안 · 스키마 변경 0)

## 발단 (운영 읽기 전용 전수 대조 2026-11-03)
- 업체 화면(`#adv=` 링크 · `advertiserWorkSummary`)의 진행/완료 판정 `_awStatus` 는 **제출 ≥ 총건수** 또는 비활성만 완료로 봤다.
  마감 여부를 몰라서, 덜 채우고 마감한 작업은 업체에게 **영원히 「진행중」** 으로 보였다.
- 실측: 업체 소유 마감 작업 128건 중 **51건**(그중 34건은 총건수도 없음). 예: 유일기획 「암막커튼 2차 35건」 마감 · 업체 화면 「진행중 0%」.

## 충돌과 결정
- 결정 087 「★ 광고주에겐 마감 주석·통계를 아예 안 보낸다(마감자·담당자는 내부 정보)」와 부딪힌다 → 사용자에게 물어 **A안 확정**:
  **끝남 불리언 `finished` 하나만** 싣는다. 마감자·마감일·담당자·통계는 여전히 싣지 않는다(087 의 이유는 그대로 지킨다).
- `/api/trackb/tabs` 광고주 응답에 `finished` 를 싣지 않는 087 회귀가드(`workboardFinish`)는 **그대로 유효**하다 — 이번 칸은 업체 요약(`/my-work-summary`) 렌즈에만 있다.

## 구현
- 서버 `advertiserWorkSummary`: `finishedTabsMap()`(작은 표 1회 조회) → 이름 키, 없으면 gid 키(리네임 대비 — 087 과 같은 규칙)로 `finished: true|false`.
  ★ 조회 실패면 칸을 **아예 뺀다**(undefined) → 화면이 종전 규칙으로 판정("모름"을 "안 끝남"으로 꾸미지 않는다).
  ★ `ownedTabsForAdvertiser({annotate:true})` 를 켜지 않는다 — `tabStatsMap` 비용을 공개 링크 경로에 붙이지 않는다(그 함수 주석 규율).
- 화면 `_awStatus`: `done = it.finished===true || it.active===false || 제출≥총건수`. 라벨은 종전대로 실제 달성률(「완료 77%」).
  `_awDone` 단일 출처라 사이드바 진행중/완료 그룹·대시보드 게이지·표 칩이 함께 바뀐다.

## 배포 스큐
- 새 서버 + 구 프론트: 추가 칸 무시(종전 동작). 구 서버 + 새 프론트: 칸 없음 → 종전 규칙.

## 완화 금지
- **업체 요약에 마감자·마감일(`finishedBy`·`finishedAt`)을 싣지 말 것** — 087 의 내부 정보 규율. 회귀가드 `advertiserViewer` 가 직렬화 결과에 그 값이 없음을 단언한다.
- **마감 조회 실패를 `finished:false` 로 접지 말 것** — 실패 = 칸 없음(가드 단언).

## 검증
- 회귀가드 `server/tests/advertiserViewer.test.js` — 미마감 false · 마감(gid 폴백) true + 마감자/일자 미노출 · 조회 실패 = 칸 없음 · `_awStatus` vm 실행(덜 채우고 마감 = 「완료 77%」, 칸 없음 = 「진행중 77%」). 종전 코드로 돌리면 실패.
