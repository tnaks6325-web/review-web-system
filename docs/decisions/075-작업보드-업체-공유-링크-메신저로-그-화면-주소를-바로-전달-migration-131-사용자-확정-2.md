# ★★ 작업보드·업체 공유 링크 — 메신저로 그 화면 주소를 바로 전달 (migration 131, 사용자 확정 2026-08-19)
- **발단(직원 요청)**: 택배·문의 인수인계 때 "그 업체 그 작업"을 상대가 **검색 탭에서 매번 찾아** 들어가야 했다. 작업보드에는 고유 주소라는 개념이 아예 없었다(리뷰어 로그 → 작업보드 딥링크 `#go=` 는 있었지만 **복사해 공유하는 창구가 어디에도 없었다**). 이제 작업보드 상단 **[🔗 링크 복사]** 한 번이면 `…/workdesk#w=<code>` 가 복사되고, 카톡으로 받은 사람은 열자마자 그 작업보드로 직행한다. 업체관리 업체 패널의 **[🔗 업체 링크 복사]** 는 그 업체의 작업 목록으로 직행한다.
- ★★ **링크는 권한이 아니다(완화 금지)** — `code` 는 **어디로 갈지만** 말한다: ① 여는 사람은 평소대로 **로그인해야 하고**(비로그인 진입 없음) ② 되찾기 게이트는 **작업보드 본문과 같은 단일 출처 `_ensureEditScope`**(내부 직원 허용 · **광고주는 탭 이름조차 못 받는 403**, 라우터 `internalMiddleware` 와 이중). 그래서 링크가 카톡방에 굴러다녀도 권한이 넓어지지 않는다. ★★ **여기에만 담당 스코프를 걸지 말 것**(2026-08-19 확정) — 내부 직원은 이미 모든 작업보드를 열므로(`allowAllStaff`) 링크만 좁히면 **목록엔 보이는데 링크로는 안 열리는 막다른 길**이 된다. 좁힐 때는 `/workdesk`·`/tabs` 와 **함께**. **광고주 전용 접속 링크(058)와 정반대의 물건** — 그쪽은 로그인을 대신하는 열쇠, 이쪽은 로그인한 사람에게 길만 알려 주는 이정표다.
- ★★ **공유 주소에 토큰을 싣지 않는다** — 리뷰어 로그의 `_logOpenWorkdesk` 는 **자기 새 탭용**이라 `&sso=<토큰>` 을 붙이지만, 사람에게 건네는 주소에 그러면 **세션을 통째로 넘기는 링크**가 된다(회귀가드가 `_shareLinkCopy` 본문에 토큰 문자열 부재를 고정).
- ★ **대상마다 코드 1개**(부분 유니크 `(sheet_id, tab_name) WHERE kind='tab'` · `(advertiser_id) WHERE kind='advertiser'`) — 언제 눌러도 **같은 주소**가 나온다. 이미 공유해 둔 링크가 다음에 눌렀다고 죽으면 "고유 링크"가 성립하지 않는다. 발급은 `ON CONFLICT DO NOTHING` + 재조회(경합 안전), `tab_gid` 는 **blank-only 보정**.
- ★ **쓰기 표면 = `trackb_share_links` 한 곳**(운영 테이블·시트·인트라넷 무접촉) · 업체 삭제 시 CASCADE · 되돌리기 = 라우트 제거 + DROP TABLE. **131 은 신규 테이블이라 `REQUIRED_SCHEMA`(컬럼만 검사)로는 못 막는다** → 42P01/42703 은 `not_ready` 로 마이그레이션 번호를 말한다(088 무신호 규율).
- ★★ **로그인 전에 열어도 살아남는다** — `#w=` 는 `initToken`(해시 제거)보다 **먼저** 읽어 `_SHARE` 모듈 변수에 담는다. `boot` 이 로그인 화면으로 되돌아가도 값이 남아 **로그인 직후 boot 재실행 때 소비**된다(실브라우저로 왕복 확인). 소비 시 주소창에서 해시를 지운다(새로고침 재발동 방지).
- ★ **실패는 조용히 홈으로 떨어뜨리지 않는다** — 폐기·담당 밖·업체 삭제를 각각 사유로 말한다(`_SHARE_ERR` → alert / 업체 미발견 → 토스트).
- ★★ **클릭 = 즉시 복사, 확인 팝업 없음**(사용자 확정 2026-08-19 — 주소를 눈으로 확인할 일이 없다): 성공하면 **화면 정중앙에 「링크가 복사되었습니다」가 천천히 페이드아웃**(`_shareLinkOk` — body 직속 · `pointer-events:none` 이라 화면 조작을 막지 않음 · **연타해도 겹치지 않음** · 애니메이션 이벤트가 안 와도 `setTimeout` 백스톱으로 반드시 사라짐 · 문구는 `textContent`). ★ **복사가 막힌 경우에만** 주소 팝업을 띄운다(조용한 실패 금지 — 복사된 줄 알고 빈 메시지를 보내는 것이 가장 나쁘다). 복사는 **`_copyText` 단일 출처**(Clipboard API → 비보안 오리진·구브라우저는 임시 textarea + `execCommand` 폴백). 팝업은 **body 직속** · Esc 리스너는 **최상위 1회**(`_shlKeyBound`).
- ★★ **창구 3곳 · 실행부 한 벌(`_shareLinkCopy`)**: ① 작업보드 상단 ② **홈 작업목록 줄마다 `[🔗 링크]`**(작업표 열 바로 뒤 `공유` 열 — 목록을 훑다가 보드를 열지 않고 바로 복사) ③ 업체관리 업체 패널. ★ 홈 목록 버튼은 **줄 클릭(작업 열기)과 겹치지 않게 `stopPropagation`** · **인덱스만** 넘긴다 · **마감 보관함에도 같은 칸을 둔다**(열 수가 모드마다 달라지면 눈이 열을 다시 찾는다 — v3 규율, 헤더 칸 수 ≡ 행 칸 수 11).
- ★ 업체 패널의 기존 **[🔗 접속 링크]**(광고주가 로그인 없이 여는 058 매직 링크)와 이름이 겹치므로, 새 버튼은 **[🔗 업체 링크 복사]** 로 두고 툴팁이 "광고주 접속 링크와 다르다"를 말한다.
- **API** = `POST /api/trackb/share-link`(발급·재사용) · `GET /api/trackb/share-link/:code`(되찾기), **둘 다 `authMiddleware + internalMiddleware`**(광고주·리뷰어 도달 불가 — 광고주에게는 058 링크가 따로 있다).
- 회귀가드 `tests/shareLink.test.js`(58케이스 — 스텁 pool 로 서비스·되찾기 라우트 **실제 실행**(같은 대상=같은 코드·재발급 0·blank-only·거부 시 쓰기 0) + 라우터 스택 실검사 + 화면 배선) + **진짜 PG16**(idempotent·부분 유니크·CASCADE) + **실 http 오리진 브라우저 실측**(공유 링크로 보드 직행 · 로그인 후 직행 · 담당 밖 사유 고지 · 팝업 body 직속 · 주소에 토큰 0).
