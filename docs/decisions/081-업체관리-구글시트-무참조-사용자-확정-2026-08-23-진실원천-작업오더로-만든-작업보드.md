# ★★★ 업체관리 = 구글시트 무참조 (사용자 확정 2026-08-23 · 진실원천 = 작업오더로 만든 작업보드)
- **지시**: "업체관리에서 구글시트와 관련된(찾아오거나·참조하거나·탭목록을 보여주는) 기능을 모두 제거 · **인트라넷 리뷰오더 → 리뷰웹 작업오더 → 작업보드**만이 업체별 작업의 기준(진실원천)".
- **제거한 것**: ① **시트에서 가져오기 4단계 마법사**(진입점 3곳 + `openSheetImport`/`_si*` 함수 + `si-` CSS **전부** — 진입점만 지우고 함수를 남기면 다음 사람이 되살린다) ② **시트 제목 표기 전부**(미지정 목록·소유 목록·연결 작업 표 부제·후보 optgroup·이관 팝업 라벨 — 업체관리에서 `sheetTitle()` **호출 0**) ③ 시트 전체 소유 **펼치기 UI**(운영 정리 완료) ④ `/owned-sheets` 조회·`ownedSheetIds` 상태 ⑤ 어휘(`소유 시트`→`소유 작업` · `미지정 시트`→`미지정 작업` · `캠페인 탭`→`작업` · `연결된 탭`→`연결된 작업`).
- ★★ **서버는 남긴다** — `/api/trackb/sheet-import/*`(sheetImport.service)·`/ownership/expand`(expandSheetOwnerships) 는 라우트·게이트·회귀가드 그대로다. 되살릴 일이 생기면 **화면만 다시 붙이면 된다**(가드가 "서버 창구는 살아 있다"를 고정).
- ★★ **판정 재료는 `STATE.mapTabs` 하나** — 미지정 후보·사이드바 배너·개요 KPI 가 같은 집합을 본다. `refreshAdvCounts` 가 **mapTabs 를 다시 받는다**(안 하면 [×] 해제 뒤 사이드바 숫자가 옛값으로 남는다 — 종전엔 `/owned-sheets` 재조회가 그 일을 했다).
- ★★ **마감(🏁)된 작업은 지정 후보·집계에서 뺀다**(`_ovmLiveTabs` 단일 출처) — 업체관리가 다루는 것은 진행 중인 작업이다. **분모·분자가 같은 집합**이어야 "지정 N / 진행 중 M" 산수가 맞는다. ★ `finished` 를 못 받으면(구버전 백엔드) 종전대로 포함(모르는 것을 숨기지 않는다). ★ **이미 지정된 마감 작업은 소유 목록·연결 작업 표에 그대로 남는다**(정산이 걸려 있다).
- ★ **레거시 `tab_gid IS NULL` 소유**는 `전체(레거시)` 로만 표기하고 **[×] 해제로만** 정리한다(이관 버튼도 그 줄에는 안 그린다 — 옮길 범위를 고를 수 없다).
- ★ **`_nsBadge`(무시트 배지)는 유지**(2026-08-23 오전 확정) — 시트 제목·링크·목록이 아니라 "이 작업은 시트를 안 쓴다"는 표시다. `pendingTab.spreadsheetTitle` 은 **서버가 준 값만** 넘긴다(여기서 `sheetTitle()` 로 지어내면 시트 개념이 되살아난다).
- ⚠ **운영 함의**: 접수를 거치지 않아 시스템이 모르는 시트를 **업체관리에서 가져올 수 없다**(그 경로가 진실원천을 우회하는 창구였다). 그런 과거 자료가 필요하면 서버 API 를 직접 부르거나 화면을 되살린다.
- ⚠ **잔재(운영 확인 2026-08-23)**: 시트 전체 소유 **0건**(하우스브릿지 1건 해제 — 그 시트의 7월 작업은 종료). 시트 기반 활성 작업 1건(어니스트캄 `4/27(메이커스)…98건`)은 **마감 처리**했다 — 그 탭은 `tab_configs` 등록 행이 없어(접수 게이트 이전) **무시트 전환이 불가**하다(`tab_not_found`).
