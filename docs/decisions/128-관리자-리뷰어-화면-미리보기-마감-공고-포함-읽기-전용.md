# 관리자 "리뷰어 화면 미리보기" (마감 공고 포함 · 읽기 전용)
- 관리자가 **마감·오픈전 공고를 포함한 어떤 참여형 공고든** 리뷰어가 실제 보는 진행 화면(참여 전 → 작업가이드 → 제출 완료)을 확인. 진입 = 모집공고 카드 [👁 리뷰어 화면] + 수정 모달 미리보기의 [전체 화면으로 보기](`index-recruit.js` `openReviewerPreview`) → `campaign.html?id=&preview=1#tok=<admin_token>`.
- **격리(핵심)**: 무인증 리뷰어 게이트 `GET /:id/work-detail`은 **일절 미변경**(관리자 분기 없음). 대신 관리자 전용 `GET /api/campaign/admin/:id/preview`(authMiddleware+adminOrMaster)가 같은 shape을 **합성**해 반환 — `application`은 미저장 가짜 객체(`id:'preview'`), `canChangeOption:false`, `chatUrl`은 관리자라 그대로. **DB write 0**(campaign_applications INSERT/UPDATE 없음 = 홀드·정원·일일한도 카운터 무오염). 리뷰어앱 스코프 토큰(`via:'reviewer_campaign'`)은 `PUT /api/campaign/admin/:id` 끝앵커+PUT 한정이라 이 GET 경로에 도달 불가.
- **프론트 가드**(`campaign.html`, `PREVIEW = ?preview=1`): `getHold`는 preview면 항상 null·`setHold`/`clearHold`는 no-op(같은 브라우저의 실제 리뷰어 홀드 격리) / `onJoin`·`_doApply`·`_doChangeOption`·`onCancel` 전부 `_pvBlock` 차단 / 폴링 미실행 / 카운트다운 0 도달로 티커가 `loadCampaign`을 재호출해도 보고 있던 단계를 유지(`_pvStep !== 'pre'`면 화면 전환 생략). 참여 후 화면 렌더는 리뷰어와 **공용 `_renderJoinedView(j, hold)`** — 표시 내용 동일, 다른 건 iframe 파라미터·폴링뿐.
- **구매양식(iframe)**: 실제 폼을 그대로 렌더하되 **제출만 차단**. `search-app.js`의 `preview` 플래그는 `_EMBED_CTX`(=`embed=1`) 안에서만 존재(`_PREVIEW_MODE`) → 리뷰어 진입 URL엔 실리지 않아 **제출 동작 불변**. 차단은 `confirmOrderSubmit`+`submitOrderForm` 양쪽 조기 return(재제출 등 팝업 우회 호출까지 커버) + `body.embed-preview` CSS로 버튼 비활성. 미리보기는 리뷰어 로그인 게이트를 우회해 폼을 보여주되(`authSession` 자리표시자) **입력값 저장/복원은 안 함**(`_EMBED_FORM_KEY` 공란). 연결 탭 없는 공고는 폼 대신 안내(`#pvFormNote`).
- **토큰 전달**: 새 탭은 sessionStorage 미공유라 `#tok=` 프래그먼트로 넘기고(서버 로그·Referer 미유출) 도착 즉시 `history.replaceState`로 주소창·히스토리에서 제거(저장 실패해도 `finally`로 **정리는 항상** 수행). 저장은 **전용 키 `camp_preview_tok`**(`sessionStorage.admin_token`을 덮어쓰지 않아 타 모듈 동작 불변), 미리보기 새 창은 `noopener`(토큰 복제 차단).
- **레드팀 반영(재발 방지 — 이 가드들을 풀지 말 것)**: ① **`preview=1`만으로는 절대 미리보기가 켜지지 않는다**(`PREVIEW = PREVIEW_REQ && 토큰있음`) + 주소창에서 preview 파라미터 제거 — 관리자가 미리보기 주소를 공유해도 리뷰어는 평범한 참여 화면을 본다(그렇지 않으면 그 공고의 구매 시간창 전체가 마비). ② 미리보기 구매양식은 **잔여 리뷰어 세션을 절대 쓰지 않음**(`authSession` 무조건 자리표시자 + `_prefillBankFromProfile`/`_precheckProfileGateOnEntry` 스킵) — 관리자 브라우저에 남은 세션의 계좌번호·실명이 화면공유·스크린샷에 노출되는 것 차단. ③ 마감·게시전 공고는 실제 상태가 `closed`라 참여 화면이 잠기므로 **[모집중 가정] 토글**(`_pvForceOpen`, 기본 ON)로 진행 화면을 볼 수 있게 하되 클릭은 여전히 차단. ④ 단계 전환 시 **iframe URL이 같으면 재로드 안 함**(재로드마다 실 시트 읽기 = 시트 lane 소모). ⑤ 로드 실패 시 단계 버튼 제거(데이터 없이 ③을 눌러 가짜 "참여 확정!"을 정상으로 오판하는 것 방지). ⑥ **카운트다운 0 재조회가 화면을 되돌리지 않음** — `loadCampaign`은 참여 전 화면일 때만 `renderPre` (리뷰어가 구매 진행 중 cutoff를 맞으면 작업가이드·구매양식이 사라지던 **기존 버그도 함께 수정**). ⑦ 미리보기 옵션 고정표시는 `selectable`일 때만(리뷰어가 도달 불가한 마감 옵션 오표시 방지). ⑧ 수정 모달 버튼은 참여형일 때만(레거시 공고는 `campaign.html`이 리뷰어 홈으로 리다이렉트).
- ★ **향후 리팩터 금지선**: preview 판정을 sessionStorage/전역으로 옮기면 부모↔iframe·새 탭에 전파돼 **그 탭의 실제 리뷰어 제출이 영구 차단**된다. `_adminTok` 유무로 판정하는 것도 금지(`rapp_camp_edit_token` 보유자 = 실제 리뷰어라 조용히 제출 차단됨). 제출 차단 4중(`confirmOrderSubmit`·`submitOrderForm`·CSS·홀드문맥 미전달) 중 어느 하나도 제거 금지. 회귀가드 `tests/campaignAdminPreview.test.js`.
