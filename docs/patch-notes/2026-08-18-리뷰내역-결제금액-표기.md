# 2026-08-18 패치노트 — 리뷰내역 결제금액 표기

## 적용 대상

- 본섭 리뷰웹시스템 리뷰어 화면의 **리뷰 내역 → 받을 예정 금액**

## 수정 내용

- 무시트 전환 이후 제출된 구매양식도 주문원장의 실제 결제금액을 예상 금액에 반영합니다.
- 주문원장 금액이 비어 있는 과거 건은 연결된 작업보드의 `결제금액` 값을 대체 사용합니다.
- 기존 시트 색인으로 이미 표시되는 주문은 제외하여 상품비용과 리뷰비가 두 번 합산되지 않도록 했습니다.

## 영향 범위

- 구매양식·작업보드·입금 데이터는 수정하지 않습니다.
- 리뷰어 화면의 금액 조회 및 합계 표시만 변경됩니다.

## 검증

- 무시트 주문의 결제금액 집계 및 중복 제외 회귀 테스트를 추가했습니다.
- 서버 구문 검사와 테스트섭 Railway 배포 성공을 확인했습니다.

## 롤백

- 문제가 발생하면 본 변경 커밋을 되돌리면 됩니다. 기존 주문·작업보드 데이터는 변경되지 않습니다.
