# 2026-08-18 유입가이드 모집공고 연동 패치노트

## 적용 대상

- 본섭 리뷰웹시스템의 작업오더 접수 후 모집공고 등록 화면

## 수정 내용

- 인트라넷 리뷰오더의 `inflow_type` 값을 모집공고 편집의 유입 방식 선택값으로 전달합니다.
- `guide`로 접수된 오더는 모집공고 등록·편집 화면에서 **가이드유입**으로 표시됩니다.
- `link`로 접수된 오더는 기존처럼 **링크유입**으로 표시됩니다.
- 유입 방식 값이 없던 과거 오더는 기존 기본값인 링크유입을 유지합니다.

## 원인

- 작업오더 수신값은 정상적으로 저장됐지만, 새 모집공고를 여는 프리필 객체가 유입 방식을 편집 토글에 전달하지 않았습니다.
- 그 결과 화면의 초기 기본값인 링크유입이 표시됐습니다.

## 검증

- 작업오더 `guide` 입력이 모집공고 프리필 `guide` 값으로 전달되는 자동 검증을 추가했습니다.
- 기존 링크유입 및 값 없는 과거 오더의 기본 동작도 함께 회귀 검증했습니다.

## 롤백

- 문제 발생 시 본 변경 PR의 병합 커밋을 revert하면 됩니다. 기존 작업오더·모집공고 데이터는 변경하지 않습니다.
