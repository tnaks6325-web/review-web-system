# 리뷰어 홈 구매사진 영역 좌우 여백 보완

## 적용 대상
- 리뷰어 홈의 구매사진 셀프보완 영역. 사용자가 로컬 전후 캡처를 확인한 뒤 운영 반영을 승인했다.

## 변경
- `#sectionMissingCapture.rpc`에 좌우 16px 안쪽 여백을 추가한다.
- 홈의 CSS 캐시 버전을 갱신한다. 직원·리뷰어 대화창, 서버, 저장·승인 규칙과 데이터는 변경하지 않는다.

## 검증
- 기존 화면에서 크롬/사파리 엔진 × 320/390/440/1280 폭의 글자 기준 좌우 여백 0px을 재현했다.
- 같은 브라우저 시험에서 수정 후 좌우 16px, 가로 넘침 없음, 펼침 후 사진 추가·확인요청 버튼과 입력칸 접근 가능, 대화창의 기존 여백 보존, 쓰기 요청 0건을 확인했다.
- 화면·연결 집중검사 35개 통과, 건너뜀 0. 실제 고객 자료 없이 로컬 HTTP와 가상 주문을 사용했다.
- 배포 전 전체 검사와 배포 완료 확인은 별도 실행 로그에 기록한다. 실제 사진 업로드·운영 주문 수정 시험은 이 변경의 검증 범위가 아니다.

## 롤백
- 본 변경의 머지 커밋을 되돌린다. 저장 구조·운영 데이터 변경이 없어 데이터 복구는 필요 없다.
