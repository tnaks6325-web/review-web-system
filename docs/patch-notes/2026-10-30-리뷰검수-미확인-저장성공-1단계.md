# 2026-10-30 리뷰검수 1단계 — 미확인 정상처리와 저장 성공 집계 수정

## 적용 대상

- 운영 서버의 기존 제출 후 리뷰 검수, 영수증 재검수 성공 집계, 이미지 판정 캐시.
- 화면 배치·문구·버튼, 제출 허용 조건, 영수증 지급 기준, DB 스키마 변경 없음.

## 변경

- 읽지 못한 사진·낮은 확신·대조 조회 실패를 실제 적용제외와 구분한다. 보조 검사 통과만으로 전체 정상으로 기록하지 않는다.
- 상품명만 확인한 판정이 다른 항목의 미확인을 정상 종결하지 않도록 JS와 SQL 경로를 함께 보호한다.
- 계산 결과와 실제 저장 결과를 분리한다. 저장 예외·반영 0행은 완료로 집계하지 않으며 사진 제출·교체 성공을 뒤집지도 않는다.
- 다른 사진의 같은 앞부분이 같은 캐시로 합쳐지지 않도록 전체 입력을 SHA-256으로 식별한다.

## 검증

- 최신 main(PR #1719·#1720 포함) 통합 후 전체 로컬 검사 652파일 통과·실패 0(135.7초).
- 실제 폐기용 PGlite에서 기존 migration과 운영 UPSERT SQL 실행: 미확인 종결 방지·확인 시각/주체 보존·영수증 기존 정책 확인.
- 독립 검토 보안·논리 차단 0. 비차단 추가 검사 권고 반영.
- 2026-10-29 원장 20,125행의 오프라인 재생에서 명시적 판독/조회 불가 기록이 있는 기존 정상 151건은 새 종합 함수로 모두 미확인 계산. 사진 불량 확정이나 전체 오판률은 아니며 기존 운영행은 수정하지 않았다.
- 검사는 가짜 입력·폐기용 로컬 DB와 저장된 읽기 전용 스냅샷만 사용. 실제 AI 요청·운영 쓰기 없음. 운영 배포 완료는 머지 커밋의 프론트/백엔드 두 신호로 별도 확인한다.

## 아직 하지 않은 것

- 과거 적체의 일괄 변경·새 자동 재검수 활성화.
- 상품명과 용량·수량·모델의 의미 비교 통일(2단계), 기준 지문·유한 재시도·최신 제출/사람 판정 경합 보호(3단계).
- 자동 반려·리뷰어 통지·사진 이동/삭제·영수증 지급 정책 변경.

## 되돌리기

- 코드 revert PR로 복귀한다. 마이그레이션·데이터 삭제가 없으므로 DB 복구는 필요하지 않다.
- 이미 저장된 unknown을 구버전이 무시할 수 있으므로 구버전 복귀 상태에서 새 무인 정상종결을 켜지 않는다.
