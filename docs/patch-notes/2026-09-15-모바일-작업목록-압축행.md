# 모바일 작업 목록 압축 행

## 적용 대상

- 리뷰웹시스템[3버전] 내부 직원용 홈
- 화면 너비 720px 이하

## 변경

- 작업 카드 기본 높이를 약 76px의 압축 행으로 변경
- 접힌 행에 작업명, 업체, 담당, 인원, 입금, 상태 표시
- 작업 버튼은 행 오른쪽 펼침 버튼을 누를 때만 표시
- 펼침 버튼이 카드 전체의 작업표 열기 동작과 겹치지 않도록 분리
- 펼침·접힘 상태를 보조기기에 전달

## PC 화면

- 721px 이상에서는 기존 작업 목록 표 유지

## 검증

- 390px 렌더링에서 가로 넘침 없음
- 접힌 작업 행 높이 76px
- 한 화면에서 4개 작업 행 노출 확인
- 펼침 시 기존 작업 버튼 전체 노출 확인
- 홈·작업 목록·공고·마감·스크립트 자동 점검 통과

## 롤백

- 이 변경 커밋을 되돌리면 모바일 작업 목록이 펼쳐진 카드 형태로 복귀
