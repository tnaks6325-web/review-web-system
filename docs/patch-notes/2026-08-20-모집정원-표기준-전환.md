# 2026-08-20 — 모집 누적·정원의 표(주문 원장) 기준 전환

## 적용 대상
- 본섭 `main` (PR: claude/recruitment-count-mismatch-hnrfbx)
- 서버 `campaignState.service.js` · `campaignArchive.service.js` · `campaign.routes.js`(admin/list) · 프론트 `campaign-cards.js`

## 배경(신고)
작업보드는 169/200인데 모집공고 카드는 49/200 — 외부모집 수동제출·수기 원장 기록·지각 구매가
공고 홀드(campaign_applications)를 안 거쳐 카드 누적·정원 판정에서 빠졌다. 활성 공고 21건 중 11건 동일
(관제 대조 실측: 차이의 96~100%가 주문 원장에 실존하는 `orderOnly`).

## 변경
1. **1단계(표시)**: 관리자 카드 누적 = 작업보드 표 채워진 줄(`archiveSuggest.filled`, `[표]` 배지)
   — 작업보드 게이지와 같은 판정(`rowNumbering.filledSql` 단일 출처 합류). 재료 부재 시 종전 표기 폴백+툴팁 고지.
2. **2단계(게이트, 기본 observe)**: `CAMPAIGN_TABLE_QUOTA` = `off` | `observe`(기본) | `on`.
   재료 = **주문 원장(order_submissions)** — 작업표 줄이 아니다(선기입 참여 소각·링크 오염·투영 지연 면역).
   observe = 카드에 `표 기준이면 마감` 칩만(참여 무변경 — **배포일 모집 동작 변화 0**).
   on = `max(공고확정, 주문건수)+진행중홀드 ≥ 총모집` → soft_full(비영속 — 주문 취소 시 자동 재오픈).
