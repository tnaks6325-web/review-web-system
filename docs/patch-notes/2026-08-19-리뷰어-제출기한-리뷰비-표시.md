# 2026-08-19 패치 노트 — 리뷰어 제출기한·리뷰비 표시

## 적용 대상

- 본섭 리뷰웹시스템의 리뷰어 홈 · 리뷰 내역

## 변경 내용

- 참여 중인 카드에 구매양식 반영 상태를 **구매양식반영완료**로 표시합니다.
- 구매일 기준 30일 제출기한을 `제출기한 : X일 남음`으로 표시합니다.
  - 20일 이상: 녹색
  - 10~19일: 주의색
  - 9일 이하: 빨간색
  - 5일 이하: `X일 뒤 작업종료 · 페이백 불가` 안내를 추가합니다.
- 카드에 상품비와 리뷰비를 함께 표시합니다. 리뷰비가 없으면 `리뷰비 없음`으로 표시합니다.
- 상단 받을 예정 금액은 기존대로 상품비와 리뷰비를 합산하며, 카드 표시는 같은 금액 원천을 사용합니다.

## 호환성

- 기존 시트 연동 공고와 무시트 주문원장 공고 모두 구매일을 내려주도록 보완했습니다.
- 구매양식·작업보드 데이터 자체를 변경하거나 새로 생성하지 않습니다.

## 검증

- 제출기한 경계값(28일, 14일, 8일, 4일), 리뷰비 없음, 구매양식반영완료 문구 회귀 테스트를 통과했습니다.
- 리뷰어 홈 가상 참여 건에서 상품비 13,900원 + 리뷰비 3,000원 = 받을 예정 금액 16,900원 합산을 확인했습니다.

## 알려진 별도 이슈

- 테섭의 일부 구매양식 작업보드 반영 실패는 이번 UI·금액 표시 배포의 범위 밖이며, 본 배포 차단 조건에서 제외했습니다.

## 롤백

- 문제가 발생하면 이 변경 PR의 병합 커밋을 되돌린 뒤 기존 버전을 재배포합니다. 주문·리뷰 데이터의 마이그레이션은 없습니다.
