# 2026-10-13 같은 번호 타계정 정리(결정 226 3·4단계)

## 적용 대상
- 본섭 서버(Railway) · 리뷰어 홈(`index.html`) · 담당자 등록리뷰어DB 「판단 내역」(`workdesk.html`) · migration 185(가산 전용)

## 변경
- 본계정과 번호가 같은 타계정 칸을 본계정으로 합치는 기능(미리보기 · 실행 · 되돌리기). **배포만으로는 아무것도 바뀌지 않는다** — Railway `SAME_PHONE_FOLD_MODE` 스위치로만 돈다.
  - `preview` → 목록 기록 → 사용자 확인 → `apply:<미리보기 번호>` → 끝나면 `off`.
- 본계정 로그인 때 "타계정이 본계정으로 합쳐졌어요" 팝업([확인] · [다시 보지 않기]).
- 정리 전에 열어 둔 내정보 화면이 지운 칸을 되살리지 않게 저장에서 뺀다.
- 판단 내역: 종류 "같은 번호 정리" · 목록 200건.

## 검증
- 로컬 실DB(전체 마이그레이션 2회 재실행 멱등): `identityFoldSamePhone` 22개(미리보기→실행→재실행→거울→로그인 안내→옛 화면→팝업→하나/전체 되돌리기), 명의 관련 PG 테스트 12종 개별 통과, 표준 자동 점검 전체.
- 변이시험: 주민번호 기록 · 실행 때 재판정 · 옛 화면 빼기 · 옛 이름표 당김 — 모두 검출.
- 화면: 실제 리뷰어 홈을 가짜 데이터로 띄워 팝업 표시·[다시 보지 않기] 저장 호출 확인.

## 롤백
