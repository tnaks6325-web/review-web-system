## 변경
- 참여 관리의 기존 「인기상품목적 참여건」 배지를 클릭하면 해당 비인기 구매 기록(상품·옵션·고른 수량·구매양식 제출 시각)과 실제 FIFO로 연결된 인기상품·옵션을 작은 팝업에 표시한다.
- 참여권 최근 24시간·명의별 FIFO·정원·신청 규칙 불변. 일반 신청 및 바로 구매 지원. 담당자 상품 정정/되돌림은 기존 목록과 같은 우선순위다.
- 가격 신고 팝업·작업조건 카드에서 신고자의 이름·전체 전화번호·기록 시각·발생 근거·당시 금액을 표시한다. 직접 가격 취소 신고와 구매 금액차이 검사 기록을 구분한다.
- 신고 명의와 정확히 결속된 신청/주문에서만 이름·번호를 가져온다. 근거 없는 경로·상품·수량·시각은 추측하지 않는다.
- 직원 화면만 제공. 업체/브랜드·공개 공고·리뷰어·실시간 신호·브라우저 알림/저장소에 개인정보 추가 없음.
- 스키마 변경 및 운영 데이터 수정 없음. 기존 금액 수정·신고 집계·보류 처리 불변.

- 실제 로컬 HTTP Chromium PC/390px: 배지 3개 개별 클릭·구매/연결 인기 옵션·ESC 닫기·신고자 두 명의 이름/전체번호/시각/서로 다른 이유. 브라우저 오류 0.
