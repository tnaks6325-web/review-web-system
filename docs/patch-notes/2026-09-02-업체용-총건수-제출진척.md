# 2026-09-02 패치 노트 — 업체용 총건수·제출 진척 일치

## 변경 사항

- 업체용 작업 목록의 총건수를 내부 활성 작업행 수가 아닌 작업보드와 같은 모집 정원으로 표시합니다. 공고 모집 정원을 우선하고, 없으면 발주 모집 수를 사용합니다.
- 제출 수는 기존처럼 작업표의 리뷰 제출 칸을 기준으로 표시합니다.
- 진행 중 배지는 모든 상태에서 `제출 ÷ 총건수` 퍼센트를 표시합니다.
- 진행 배지는 100% 표기 폭(80px)을 고정으로 사용하여 1%, 10%, 100% 사이에서 목록 열 폭이 변하지 않게 했습니다.

## 영향 범위

- 변경 화면: 업체용 뷰어의 사이드바, 전체 작업 목록, 브랜드 작업 목록, 대시보드 제출 진척 및 진행 게이지
- 작업보드의 참여자·제출완료·입금완료 집계와 작업행 생성·정리 정책은 변경하지 않았습니다.

## 검증

- 업체용 작업 요약 API 회귀 테스트 108건을 통과했습니다.
- 작업보드 인라인 스크립트 파싱 및 업무가이드 회귀 테스트 11건을 통과했습니다.

## 되돌리기

- 문제가 발생하면 이 변경을 되돌리는 커밋을 `main`에 적용하면 기존 업체용 활성 작업행 기준 표기로 복귀할 수 있습니다.
