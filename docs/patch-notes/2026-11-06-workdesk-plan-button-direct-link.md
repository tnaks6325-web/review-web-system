# 2026-11-06 작업보드 [📅 모집인원 조절]이 "연결된 모집공고가 없습니다"로 안 열리던 문제

## 적용 대상
- 본섭(main) — 리뷰웹 작업보드(workdesk)

## 무슨 일
- 주소 링크(`#w=…`)로 바로 연 작업에서, 작업 목록이 뒤이어 새로 도착하면 목록 항목은 새 객체가 되고 지금 열린 작업(`STATE.cur`)은 옛 객체로 남는다.
  공고 주석(`campaigns`)은 새 목록 항목에만 붙어, 버튼이 옛 객체만 보고 "이 작업보드에는 연결된 모집공고가 없습니다"로 막혔다(340)11/4(쿠팡) 쿠션 21호 200건 실사례).

- `openCurrentCampaignDailyPlan`·`CAMPAIGN_DAILY_PLAN_SAVED` 가 이 함수를 쓴다. 통계를 받은 뒤 다시 찾는다.
- 연결 공고가 정말 없을 때·공고 조회 실패 때 안내는 종전 그대로.
