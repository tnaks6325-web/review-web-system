# 리뷰어홈 마지막 화면 복원

## 적용 대상

- 리뷰어홈 하단 탭과 리뷰내역의 `참여중/제출완료` 탭

## 변경

- 새로고침하거나 브라우저를 다시 열면 마지막으로 보던 화면을 복원한다.
- 일반 리뷰어의 상태는 리뷰어별로 저장하고, 관리자 미리보기는 현재 탭에만 따로 저장한다.
- 리뷰 제출 완료와 내정보 바로가기 주소는 저장된 화면보다 먼저 적용한다.
- 로그아웃하면 현재 리뷰어의 저장된 화면 위치를 삭제한다.

## 검증

- 참여중 화면 복원, 관리자 미리보기 격리, 손상된 저장값의 홈 복귀, 로그아웃 삭제, 직접 이동 주소 우선순위를 자동 점검한다.

## 롤백

- 이 변경을 되돌리면 리뷰어홈은 종전처럼 접속할 때마다 홈 화면에서 시작한다.
