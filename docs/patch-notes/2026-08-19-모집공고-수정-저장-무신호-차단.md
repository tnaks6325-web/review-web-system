# 2026-08-19 — 모집공고 수정이 "저장되었는데 값이 그대로"였던 문제

## 증상

모집공고 수정 모달에서 값을 고치고 [저장]을 눌러도, **다시 열면 마지막으로 저장한 값이 아니었다**
(실사례: 옵션 행의 일건수 30→10, 다계정 허용/미허용).

## 원인 — 저장이 안 된 게 아니라 **저장 요청이 아예 나가지 않았다**

실브라우저(http 오리진)에 같은 데이터를 넣고 저장까지 돌려 확인한 결과 `PUT` 호출이 **0건**이었다.

### ① 옵션 URL이 비면 저장이 통째로 차단됐다

`frontend/js/index-recruit.js` — 진행상품 표의 모든 옵션 행에 `http(s)` 옵션 URL을 **필수**로 요구해,
하나라도 비면 `return` 으로 저장을 중단했다. 옵션 URL 칸은 2026-08-18 편집기 개편에서 새로 생긴
칸이라 **그 이전에 발행된 공고는 `campaign_options.option_url` 이 전부 비어 있다** → 기존 공고의
수정 저장이 사실상 전부 봉쇄됐다. 상품메인 URL은 `landing_url` 로만 복사될 뿐 옵션 URL을 채우지 않는다.

### ② 차단 사유가 화면에 안 보였다 (무신호)

`frontend/js/recruit-modal.js` 의 `recruitSaveBlock()` 이 `#recruitModal .modal-footer` **첫 번째**에
⚠ 배너를 붙였는데, 첫 번째는 편집기 안쪽 인라인 푸터이고 이건 `.rf-compact-main .footer{display:none}`
로 **숨겨져 있다**(실측: 배너 크기 0×0, 흔들림 애니메이션도 숨은 요소에 적용). 실제로 보이는 푸터는
두 번째다. 그래서 사용자에게는 "눌러도 아무 일이 없다"로만 보였다.

### 곁다리로 발견된 같은 계열 2건 (저장이 성공할 때 발생)

- **유의사항(notes)이 매 저장마다 삭제**: 지금 편집기 라이브 DOM에는 `rf_notes` 가 없는데(레거시
  `<template>` 안에만 존재) `?.` 폴백으로 **빈 문자열**을 전송했고, 서버는 `notes = COALESCE($10, notes)`
  라 `''` 를 "지움"으로 받았다.
- **시트 탭 연결이 조용히 끊길 수 있었다**: 연결탭 select가 비면 무조건 `linked_tab_mode:'unlinked'`
  를 보내 서버가 연결(gid)을 비웠다. 탭 목록 로드 실패·리네임·아카이브로 **복원하지 못한 경우**까지
  "사람이 비웠다"로 읽었다.

## 변경

1. **차단 배너를 보이는 푸터에 붙인다** — `_blockHost()` 신설(푸터를 뒤에서부터 훑어 `offsetParent`
   가 살아 있는 것을 고르고, 전부 숨었으면 모달 상자에 붙인다). 붙이지 못하면 `false` 를 돌려주고
   화면이 토스트로 폴백한다(사유를 삼키지 않는다). 남은 배너는 `querySelectorAll` 로 전부 정리.
2. **옵션 URL은 값이 있는데 형식이 틀릴 때만 차단** — 빈 값은 미입력이지 오류가 아니다.
3. **유의사항은 입력칸이 있는 화면에서만 전송** — 미전송 = 서버가 기존 값 유지(옵션표·리뷰타입과
   같은 원칙).
4. **연결 해제는 사람이 비웠을 때만** — `_rfExplicitUnlink()` 단일 판정. 신규 공고는 그대로 해제,
   **탭 목록 미로드·저장된 탭 복원 실패는 판단 불가로 보고 미전송**(기존 연결 보존).

- 실 http 오리진 브라우저 4시나리오: ㉮ 옵션 URL 빈 기존 공고 → **저장 나감**(일건수 10 반영,
  notes 미전송, `linked_tab_mode:'keep'`) ㉯ 옵션 URL 형식 오류 → 차단되고 **배너가 1088×41로 보임**
  ㉰ 목록 정상 + 사람이 비움 → `unlinked` ㉱ 연결 유지 → `linked`.
- 회귀가드 신설 `server/tests/recruitSaveBlockVisible.test.js`(16케이스 — 배너 호스트 선택·옵션 URL
  완화·notes 조건부 전송 + `_rfExplicitUnlink` 를 vm 으로 **실제 실행**해 4갈래 판정 고정).
