# 2026-08-19 패치 노트 — 미확인 이체 공고 추천·검색 개선

## 변경 사항

- 미확인 이체의 작업 대조 모달을 넓고 높게 조정하고, 검색창과 후보 목록을 분리했습니다.
- 작업명·모집공고명·입금명으로 후보를 검색할 수 있습니다.
- 통장표시와 모집공고의 입금명이 정확히 일치하는 연결 공고는 목록 상단에 `추천 공고`로 표시합니다.

## 안전 규칙

- 추천은 작업 대조를 시작하기 위한 후보 제안이며, 작업을 자동 선택하지 않습니다.
- 추천 또는 후보 선택만으로 입금완료 기록은 생성되지 않습니다.
- 미확인 이체 검색·대조 API는 기존과 같이 관리자·마스터 권한에서만 사용할 수 있습니다.
