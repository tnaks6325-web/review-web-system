# 리뷰웹시스템 모바일 홈 UI

## 적용 대상

- 리뷰웹시스템[3버전] 내부 직원용 홈
- 화면 너비 720px 이하

## 변경

- 상단 메뉴를 줄바꿈 대신 한 줄 가로 탐색으로 표시
- 현황 영역을 2열 숫자판으로 재배치
- 작업 목록 표를 모바일 카드로 변환하고 각 값에 라벨 표시
- 작업표, 공유, 저장폴더, 공고, 오늘 완료, 마감 버튼을 터치하기 쉬운 크기로 확대
- 빠른 메뉴를 2열로 배치

## PC 화면

- 721px 이상에서는 기존 헤더, 현황 영역, 작업 목록 표를 그대로 사용

## 검증

- 390px 렌더링에서 가로 넘침 없음
- 작업 카드 너비 334px, 주요 버튼 높이 38px
- 홈, 작업 목록, 공고, 마감, 인라인 스크립트 자동 점검 통과

## 롤백

- 이 변경 커밋을 되돌리면 기존 PC·모바일 공용 화면으로 복귀
