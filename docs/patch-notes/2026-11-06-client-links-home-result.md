## 변경

- 홈과 현재 작업에서 해당 작업부터 열리는 업체용 링크를 복사한다. 같은 업체의 다른 작업 접근과 대표 링크는 유지한다. 휴대폰은 기존 전체 작업 목록으로 돌아갈 수 있다.
- 홈의 이체결과 대기 항목에서 파일을 선택/끌어놓기 한다. 선택 전에 대량이체 UUID를 고정하고 서버가 다른 회차 파일을 쓰기 전에 거절한다. 기존 금융 엔진만 사용하며 옛 주소로 자동 재전송하지 않는다.
- 홈 결과창은 읽기 전용이다. 이미 저장된 입금 결과와 홈 목록 갱신 실패를 구분하고, 재첨부 시 입금을 중복 기록하지 않은 채 필요한 질문 갱신을 다시 시도한다. 이전 로그인 응답은 새 로그인 상태를 덮지 않는다.
- 담당자 `기타`·양쪽 수정권한·알림 추가/활성화는 이번 반영에 포함하지 않는다. 스키마·마이그레이션 변경 없음.
