# 2026-08-18 패치노트 — 작업오더·모집공고 정원 동기화

## 변경

- 연결된 작업오더의 목표인원과 모집공고 총정원을 저장 시 자동으로 일치시킵니다.
- 작업오더에서 목표인원을 수정하면 연결된 모집공고의 총정원과 옵션별 정원이 함께 갱신됩니다.
- 모집공고에서 총정원 또는 옵션별 인원을 수정하면 연결된 작업오더 목표인원도 함께 갱신됩니다.

## 안전 규칙

- 이미 참여하거나 진행 중인 인원보다 작은 값으로는 줄일 수 없습니다.
- 후속 차수가 있는 공고는 후속 차수 인원을 보존하고 1차 인원만 조정합니다.
- 후속 차수 합계보다 낮은 목표인원 저장은 거부합니다.
- 연결된 작업오더 또는 모집공고가 둘 이상이면 자동으로 임의 선택하지 않고 저장을 중단합니다.
- 옵션별 정원의 합계는 항상 모집공고 총정원과 일치하도록 배분합니다.

## 검증

- 정원 동기화 회귀 테스트: 7개 통과
- 작업오더 관리자 수정 회귀 테스트: 15개 통과
- 모집공고 무시트 저장 회귀 테스트: 8개 통과
