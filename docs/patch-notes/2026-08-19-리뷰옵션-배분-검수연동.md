# 2026-08-19 — 작업표 리뷰옵션(리뷰 종류) 배분 + 옵션별 지정 수량 + 검수 행 단위 리뷰타입 (PR #876)

## 적용 대상
- 본섭(`main`) — Railway(백엔드) + Cloudflare Pages(프론트) 자동배포.
- 마이그레이션 0 · 신규 엔드포인트 0(plan 라우트 SELECT 컬럼만 확장).

## 배경 (사용자 확정)
옵션에는 상품옵션뿐 아니라 **리뷰 종류(포토리뷰/텍스트/구매확정/별점)** 가 있다 — 시트 시절
직원이 `리뷰옵션` 칸에 손으로 적던 행별 리뷰형태 선기입(㉯ 작업옵션)을 작업표 생성이 자동으로
해 주어야, 리뷰어가 행 배정과 함께 리뷰 종류를 배정받는다. 재료(`review_type_mix`, 106·107·109)는
이미 원장까지 실려 오는데 **소비처가 0곳**이었다.
확정 4건 = ① 배분 순서 **날짜별 비율 유지** ② 기입 칸 **리뷰옵션** ③ 갭 A(옵션별 지정 수량)
동시 수정 ④ 검수 행 단위 연동(구매확정 행은 구매확정 화면 인정).

## 변경
- **작업표 계획**(`worktablePlan`): 혼합 수량을 행별로 배분해 `리뷰옵션` 칸에 기입.
  날짜별 비율 유지(largest remainder) · 리뷰옵션 칸 자동 추가(번호·구매일자 뒤) ·
  옵션별 mix 는 옵션 묶음 안에서 배분 · 유형 2가지 미만 = 기입 없음(opt-in, 기존 동작 불변).
- **갭 A**: `product_options_json` 의 옵션별 `count` 를 배분에 적용(같은 라벨 합산).
  합계 불일치·일부만 지정 = 균등 폴백 + `option_count_mismatch` 경고(막다른 길 금지).
- **칸 분리**: 상품옵션/리뷰옵션 기입 칸 분리(`isReviewOptionHeader` 단일 판정) ·
  행배정 매칭(`buildCandidateRows`)은 리뷰옵션 칸을 대조에서 제외(상품옵션 매칭 전패 방지).
- **검수 행 단위**: `reviewTypeContext.reviewTypeForRow`(row_json × optionWriteColumns ×
  rowOptionReviewType) → 2차 검수 `_okKinds` · 업로드 `verifyCapture` · 1차 필터 안전핀이
  행 우선 유효 리뷰타입을 본다. 전부 fail-open. 폴더 라벨은 탭 값 유지.
- **미리보기 정합**: plan 라우트 SELECT 에 `review_type_mix`·`skip_weekends`·`holidays`·
  `courier_proxy`·`delivery_type` 합류(미리보기 ≠ 실제 표였던 자리) + 접수 확인의 휴무일
  기본값을 계획 값으로 + 미리보기에 "리뷰 종류 배분" 표시.

## 검증
- 회귀가드 `worktablePlan` 114→128 · `reviewOptionRowType` 신설 16 · 드리프트 3건 갱신
  (reviewType ③ / fileAutoRoute / worktableTemplate — worktableTemplate 는 착수 전부터 빨간
  상태(dedupe 라우트 목록 드리프트)를 함께 복구).
- **변이시험 8종 전부 검출**(날짜 묶음 무시 · count 무시 · 열 주입 제거 · 칸 분리 제거 ·
  매칭 제외 제거 · _okKinds 회귀 · 추출 우선순위 뒤집기 · fail-open 제거).
- 무시트 접수 왕복 스모크(리뷰옵션 열 주입 + 포토리뷰 10/텍스트 20) + 영향권 스위트 26종 통과.

## 롤백
- 코드 롤백 = PR #876 리버트(마이그레이션 없음 · 데이터 비파괴).
- 이미 만들어진 작업표의 리뷰옵션 값은 선기입 데이터라 리버트해도 남는다(blank-only 보호 —
  종전 ㉯ 손기입과 같은 상태라 무해). 잘못 배분된 표는 작업보드 그리드에서 셀 편집으로 교정.

## 잔여(문서화)
- 표 끝을 넘은 추가 배정(append) 행에서는 매퍼가 상품옵션을 리뷰옵션 칸에 쓸 수 있다
  (blank-only 가 선기입 행을 보호 — 넘침 행 한정 표기 문제).
- 리뷰어 화면 슬롯·안내문은 종전대로 탭 단위(행별 리뷰 형태는 참여상품 정보 팝업 D 표시 담당).
