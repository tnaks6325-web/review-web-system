# 2026-08-18 패치노트 — 작업보드 staff 전체 권한

## 변경

- `staff` 계정은 담당 작업 여부와 관계없이 모든 작업보드 탭을 열람하고 관리할 수 있습니다.
- 작업보드 그리드의 셀 드래그 선택과 선택 셀 수·결제금액 합계 표시는 모든 내부 운영 역할에서 사용할 수 있습니다.
- staff가 다른 담당자의 작업을 열어도 탭 협업 대화와 미확인 건수 집계가 정상적으로 표시됩니다.

## 권한 기준

| 역할 | 작업보드 열람 | 작업 처리 | 개인정보 |
| --- | --- | --- | --- |
| master / admin | 전체 | 가능 | 기존 정책 유지 |
| staff | 전체 | 가능 | 내부 운영 권한 기준 |
| advertiser | 소유 작업만 | 불가 | 기존 마스킹 유지 |
| reviewer | 불가 | 불가 | 해당 없음 |

## 안전 조치

- 광고주는 비소유 작업에 접근할 수 없으며, 작업보드 수정·마감·정산 처리는 계속 차단됩니다.
- reviewer의 작업보드 접근 차단은 유지됩니다.
- 업체 소유자 배정, 담당 AE 관리 등 작업보드 밖의 소유권 관리 권한은 이번 변경에 포함하지 않았습니다.
- 본 반영은 TEST_REVIEW 브랜치 병합이 아니라 검증된 권한 변경 두 건만 본섭 최신 코드에 선별 적용했습니다.
