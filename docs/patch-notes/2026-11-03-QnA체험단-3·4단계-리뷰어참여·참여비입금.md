## 변경

- 3단계: Q&A 공고 신청 시 그날 열린 자리(공개 우선)를 바로 묶는다. 구매양식 대신 「오늘 남길 문의」 카드(공개/비공개·문구 복사·캡처 1장). 캡처 기한 = min(신청 + 1시간, 그날 자정) + 30초 여유, 23:50부터 신규 신청 막음. 1인 1회(재구매 기간 대신). 일반 구매양식 제출은 Q&A 홀드에서 거절.
- 캡처 기한 넘김 정리: 매분 크론이 미제출 건을 「줄 삭제」와 같은 경로로 풀고 같은 자리에 빈 줄을 다시 깐다(`sweepQnaCaptureTimeouts`, 잠금 `qna_capture_sweep`). 캡처 완료 판정은 `campaign_participants.is_submitted` 기준(`review_index` 는 재구성 때 비므로 보조).
- 일정 끝: 「추가모집」(못 채운 자리를 다음 영업일부터 같은 일일 수로 다시 깐다) / 「끝내기」. 잠금 순서 탭 → 공고로 통일.
- 4단계: Q&A 건은 상품값 0·참여비만 입금 대상. 「리뷰비만 보낸 건」(결정 292) 판정에서 제외해 입금일 칸·PAID·페이백 완료가 일반 입금과 같이 남는다(`is_qna`).
- 모집 카드 Q&A 배지는 아이콘 없이 「Q&A」 글자만(사용자 확정).
