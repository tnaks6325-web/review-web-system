# 2026-08-18 패치 노트 — 입금 대상 없는 작업 숨김

## 변경 사항

- 입금 대상·회차 화면의 작업 선택 목록에서 현재 입금 처리 대상이 0건인 작업을 표시하지 않습니다.
- 입금 대상이 모두 제외된 작업도 목록에서 표시하지 않습니다.
- 이전에 선택한 작업이 입금 대상 0건 상태가 되면 선택 목록에서 자동으로 해제하여 선택 작업 수와 실제 처리 대상을 일치시킵니다.

## 영향 범위

- 변경 화면: 워크데스크 > 입금 대상·회차 > 작업 선택
- 결제 데이터, 입금 처리 API, 권한 정책은 변경하지 않았습니다.

## 검증

- 입금 대상 없음, 제외됨, 입금 대상 있음의 세 작업을 포함한 회귀 테스트를 통과했습니다.
- 테스트 서버 배포 및 본섭 배포 후 화면 스크립트와 헬스체크를 확인했습니다.

## 되돌리기

- 문제가 발생하면 이 변경을 되돌리는 커밋을 `main`에 적용하면 기존처럼 모든 작업을 목록에 표시할 수 있습니다.
