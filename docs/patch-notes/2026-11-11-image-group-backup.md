## 남은 일
- 기존 사진의 전수 채우기·범위 대조·독립 manifest 전수/바이트 표본 복원 진행 중. 새 방식 전체 전환 완료가 아니다.
- 첫 운영 채우기는 중간 미분류 오류(SCAN_FAILED)로 중단됐으나 durable cursor와 완료 사본을 유지했고 서버 백업은 계속 동작했다. 운영 CLI에만 공개 DB 접속/쿼리 시간 상한을 조정하고 제한된 재시도를 넣어 재개했다. 운영 앱의 시간 제한은 유지했다.
- 기존 `drive-backup.yml`은 active 유지. 승인된 저장/복원 조건 통과 직후 disable하고 정확한 state를 읽어 확인한다. 옛 R2 `drive/` 자료·DB 백업/복원·이체결과 보관은 삭제/중단하지 않는다.
- 비차단 접수 영속화 전 종료와 야간 전 원본 삭제가 겹치는 공백은 남는다. 독립 전체 바이트 전수 감사도 별도 미검증이다.

## 롤백
