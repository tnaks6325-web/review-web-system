## 변경

- 상품 본체명과 용량·수량·농도·모델·연식의 역할을 같은 순수 엔진으로 비교한다. 단위 환산과 순서만 다른 표기는 같게 보되 총량으로 다른 포장을 합치지 않는다.
- 선두 소수·큰 정수를 보존하고 모델 전체 토큰을 단위보다 먼저 읽는다. 정보 누락·애매한 포장은 미확인, 명시적 숫자 충돌은 정상 처리하지 않는다. 제출은 허용한다.
- canonical 기준과 별칭을 분리하고, 옵션이 빠진 작업오더 기준을 추측해 승인하지 않는다. 기존 공식 요약 생성기로 증명한 머리글·모집인원·소계는 옵션으로 오해하지 않는다.
- 과거 learned pass와 SQL 상품판단 보존이 새 conflict/insufficient를 덮지 못하게 한다. 과거 직원의 판정·메모·시각은 남긴다.
- 옛 키는 유지하되 새 증거 없는 옛 군집을 자동 승인하지 않는다. 전 행 증거·조회 상한·범위/구성원/snapshot·실행 잠금 후 재확인을 적용한다. 자동 판정을 사람 exact 규칙으로 덮어 학습하지 않는다.
- 명시적 사람 확인은 해당 상품 unknown만 해소하고, 원래 기계 근거와 다른 축 unknown은 보존한다.
- 모든 지원 숫자 역할은 기존 파서에서 부호를 함께 읽어 미확인으로 남긴다. 부분 단위 목록을 별도로 복제하지 않으며 모델의 정상 하이픈은 보호한다. 원본 상품 항목은 이름으로 거르기 전에 타입·옵션·이름 완전성을 전부 검사해 공식 요약 예외로 누락을 숨기지 않는다.
- 모델 숫자 구획 사이 하이픈은 보존해 `AB100-2`/`AB10-02`를 구별한다. `AB-100`/`AB100`처럼 숫자 구획을 바꾸지 않는 접두 표기는 호환한다.
